# HumanResources

서버의 인사 영역 Application 경계다.

인사 영역은 사람이 어떤 성격의 참여자이고, 어떤 역할로 어떤 업무를 처리할 수 있는지 정의한다.

## 참여자 성격

- `CounterpartyRepresentative`: 거래 상대/대표
- `InternalProjectOperator`: 내부 실무/프로젝트 담당자
- `ExternalProfessional`: 외부 전문 참여자

## 포함 대상

- HR 역할 할당
- 업무 범위별 권한 확인
- 창고 담당자, 관세사, 행정사, 기사/배달기사 역할
- API 접근과 화면 노출의 전제 조건
