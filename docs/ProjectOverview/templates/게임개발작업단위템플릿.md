## 완료 판정

- [ ] 플레이어가 상황, 선택 이유와 선택 사이 차이를 이해할 수 있다.
- [ ] 재료·비용·시간·위험이 단순 생성이 아니라 획득·배정·소비 흐름으로 연결된다.
- [ ] 상황·선택·준비·행동·결과·귀환이 닫힌다.
- [ ] H2·H3는 이름이 아니라 H1 집합과 플레이 폐루프로 성장 판정된다.
- [ ] 성공·실패·중단 결과가 회복·귀환 또는 다음 선택으로 이어진다.
- [ ] 서버 권위와 Unity 표현 경계가 유지된다.
- [ ] 목표 E에 필요한 증거를 실제로 확인했다.
- [ ] 실제 증거를 EvidencePackage에 범위·제외·무효화 조건과 함께 기록했다.
- [ ] 담당·검토·허용 경로·의존·인계 경계를 작업 명세에 기록했다.
