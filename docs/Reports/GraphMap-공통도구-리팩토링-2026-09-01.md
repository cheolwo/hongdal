# Graph Map 공통 도구 리팩토링

## 결과

Graph Map 계획·기획 인계·개발 인계 관리자 세 곳에 중복되어 있던 저장소 경로 보호, JSON 읽기, SHA-256, 기대 해시, 중복 고유 식별자, 결정적 JSON, 줄바꿈 정규화, Markdown 셀 처리를 `eng/world-seedbeds/GraphMapTooling.ps1`로 추출했다.

각 관리자는 자신의 오류 접두사를 공통 도구에 넘긴다. 따라서 `GraphMapInvalid`, `GraphMapHandoffInvalid`, `GraphMapDevelopmentHandoffInvalid` 진단 계약과 생성 JSON·Markdown 형식은 유지하면서 공통 안전 규칙을 한 곳에서 관리한다. 공통 도구는 저장소 밖 절대 경로와 `..` 이동을 거부한다.

## 함께 고친 정합성 결함

직전 Graph Map 보고서의 끝 공백을 정리한 뒤 `graph-map-planning-handoffs.json`의 `reportExpectedSha256`가 이전 바이트 해시를 계속 가리키고 있었다. 공통화 뒤 현행 Check가 이 불일치를 차단했다. 검사 기준을 완화하지 않고 현재 보고서 해시를 원장에 다시 결속하고 기획 인계 JSON을 재생성했다.

이 수정은 보고서 내용이나 Graph Map의 노드·엣지·제약을 바꾼 것이 아니다. 현재 파일 바이트와 인계 계보가 일치하도록 고친 것이다.

- Goal·WI·작업 명세·EvidencePackage 단계와 개발 인계 상태를 변경하지 않았다.
- Unity 코드·Prefab·Scene·Editor·Play Mode·Game View·실제 이동·입력·결과를 실행하거나 수정하지 않았다.
