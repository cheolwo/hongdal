## API와 개발 후속 결속

네임스페이스 `Ssalddel.Unity.Presentation.VisitorAnimation`, 컴포넌트 `방문자AnimationAdapter`.

- `Configure(Animator, RuntimeAnimatorController)`: 동일/자식 Actor, Humanoid Avatar, Human Clip/Event 없음, 필수 Idle/Walk 상태 검사. Actor 하위 활성 MonoBehaviour 및 알려진 공용/방문자 뼈 작성자 충돌 거부.
- `SetIntent(방문자동작Intent.Idle|Walk|Greet)`: 전환 0.12초. 동일 Intent 반복은 재시작하지 않음. Greet 없는 Controller는 Idle 대체.
- `InterruptToIdle()`: 결정/이동 중단 때 Idle 즉시 지정. `Reconstruct(bool moving)`: Load/새 상태에서 과거 인사 없이 Idle/Walk 재구성.
- `ReadState()`: Ready, Intent, ActiveState, GreetingAvailable, Diagnostic, PresentationOnly. Update는 완료된 인사의 상태만 읽음.
- `AnimationRole=VisitorArrival`, `WaitingCue=Visitor.Waiting.Greet`, `StateCue=Visitor.State.IdleOrDepart`.
- runtime에는 Transform 위치·회전 쓰기, 절차형 뼈 쓰기, Command/Event/Revision/저장 호출 없음. 조립 결과 Animator 1개+본 Adapter 1개, root motion=false. 별도 fallback 뼈 작성자를 만들지 않음.
- 실패 시 실제 Actor는 유지하고 Animator 정지. Diagnostic→실패 카드 표시는 개발 후속이다.
- 직렬화된 참조만으로 자동 초기화하지 않는다. 생성/Load 후 Configure, 다음 Reconstruct/SetIntent 순서로 호출한다. 실제 이동·속도·방향·도착 판정과 Transform 작성자 한 개 결속은 개발 소유다. 준비 뒤 다른 뼈 작성자를 임의 추가하는 조합은 지원하지 않는다.

Editor `방문자AnimationBuilder.BuildController()`는 없을 때만 소유 경로에 생성한다. `CreateWrapper(Scene)`는 주어진 Scene에 Wrapper와 원본 Starter 남성 자식을 조립한다. 개발 통합 승인 없이 canonical Scene에 호출하지 않는다. Prefab 자산/Scene 저장 없음.
