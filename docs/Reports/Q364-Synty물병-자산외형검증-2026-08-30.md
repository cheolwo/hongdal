# Q364 Synty 물병·마개 외형 검증

- 날짜: 2026-08-30
- 상태: 자산 파일·직접 미리보기 확인. 조사 시점 Q364는 `Asked`였고 후속 사용자 동의로 D-349에서 휴대 방향을 확정했다. 이 보고서 자체는 기능 구현/실행 승인이 아니다.
- 조사: 기획은 디스크 Prefab/meta/YAML과 공간 담당이 만든 PNG를 직접 확인했다. Editor 격리 렌더·Bounds 측정은 월드·공간·배치 담당이 수행하고 개발 담당이 인수한다. 기획이 Editor를 중복 조작하지 않았다.
- 결론: 보유 자산에 닫힌 마개/뚜껑 외형을 가진 병과 보온병이 있다. 추가 구매 없이 휴대 용기 표현 후보로 사용할 수 있다. 마개 개폐 기능이 갖춰졌다는 뜻은 아니다.

## 구조 확인

- 8개 후보 모두 Prefab/meta 존재와 SHA256을 기획이 조회했다. YAML상 각각 GameObject 1개, MeshRenderer 1개, MeshCollider 1개, `m_Children: []`이다.
- 별도 뚜껑 자식 오브젝트가 없으므로 마개를 집어 열고 닫는 연출은 별도 모델 가공/프로젝트 표현 설계가 필요하다. 병을 표시하는 것과 개폐·마시기 애니메이션을 구분한다.
- Thermos의 공간 담당 측정 JSON을 기획이 읽어 확인했다: native scale 1, Mesh 1/subMesh 1, Renderer 활성, convex MeshCollider 활성. Bounds XYZ `0.1419073 / 0.407346845 / 0.141907245` Unity units. 기획이 Editor에서 별도 재측정한 값은 아니다.
- Bounds는 게임 내 리터 용량이나 보온·가열 능력의 근거가 아니다. 그런 능력은 물품 정의에서 별도 승인해야 한다.
- 초기 표현에서는 닫힌 용기 외형과 내용물/현재량 조회를 결속하는 접근이 가능하지만 아직 구현/기획 승인하지 않았다. 원본 Synty 수정·Scene 반입·재가열 규칙 변경을 이번 조사로 허용하지 않는다.
