# Graph Map 기획 인계 순환 구현 결과

## 결과

기획 스레드가 승인된 기획 판본만 인계하고, Graph Map 작업이 레벨 1·2·3을 구조화·검증한 뒤 최종 결과를 기획에 반환하는 파일 기반 순환을 구현했다.

이 순환은 실행 대기열이나 새 상태 권위가 아니다. 기획의 의미 원본은 기존 기획 문서와 결정이 계속 소유하고, 인계 원장은 판본·대상·상태·결과를 연결한다. Unity Scene·Prefab·Runtime·Game View·E 승격은 자동으로 수행하지 않는다.

## 소유 경계

- 기획은 단일 질문 심화, 승인 판본·hash, 일곱 칸, 결정/WI, 영향·제외 범위를 소유한다.
- Graph Map 작업은 기존 안정 ID 대조, 레벨 1 플레이 관계, 레벨 2 배치 제약, 레벨 3 코드 결속, federation·overlay와 최종 반환을 소유한다.
- 기획은 중간 Graph Map 진행을 기다리지 않고 다음 기획을 이어간다.
- Graph Map 작업은 빠진 플레이 의미를 만들지 않고 `Integrated`, `Blocked`, `NoImpact` 중 하나로 반환한다.
- 개발·월드 담당은 반환 결과를 별도 작업 명세와 실제 E5 실행 범위에 연결한다.

## 자동 차단

관리 도구와 회귀시험은 다음을 거부한다.

- 기획 문서 또는 Graph Map 결과의 SHA-256 drift
- 존재하지 않는 결정·WI·요청 레벨
- 지금·여기·나·너·이렇게→결과→다음 선택 참조 누락
- 대상 Graph Map 고유 식별자·판본 불일치
- 결과 없이 `Integrated`로 올리는 상태
- 차단 항목 없는 `Blocked`, 요청 레벨이 남은 `NoImpact`
- Scene·Prefab·Runtime·Game View·실제 통행·E·운영 상태를 인계 결과로 승격하는 표식

## 첫 등록 사례

`graph-map-handoff:northern-life-hub-discovery:r3`는 다음을 결속한다.

- 기획 판본 `northern-life-hub-discovery-graph-map-proposal.r3`
- 결정 D-442~D-447과 대표 WI 4개
- federation, 레벨 1, 레벨 2, 레벨 3 요청
- Graph Map `graph-map:mirror:northern-life-hub-discovery.v1` r3
- 반영 11노드·10엣지·9제약·6코드 결속
- 요동성 actual AreaSet/Graph/WI는 미반영 관문으로 보존

이는 기존 Graph Map 구현 결과를 새 절차의 첫 이력으로 등록한 것이다. 새 Unity 실행이나 E5 성립으로 소급 해석하지 않는다.

## 남은 범위

- 다음 승인 기획부터 실제로 새 인계 항목과 결과 판본을 추가한다.
- `Blocked`에서 플레이어 선택이 필요한 항목만 기획의 다음 단일 질문으로 환류한다.
- 실제 Prefab·Scene·입력·Game View가 필요한 항목은 개발 통합과 월드·공간·배치 검증으로 별도 인계한다.
- commit과 push는 수행하지 않았다.
