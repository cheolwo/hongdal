## D-529 작은 주제 반영 기준

`춘분 Farm 경계의 망가진 울타리 발견 → 가까운 허용 나무 한 그루 벌목 → 생성 목재 획득·운반 → 무보수 울타리 수리 → 한스가 전 과정을 직접 목격 → 첫 신뢰 → 침입 흔적 공동 조사`

- L1 공백: 한스의 목격·첫 신뢰·다음 조사 인계에는 승인된 WI가 없다.
- L2 확정: 채취 권한, 동일 원인 계보, 실제 시간·체력·도구 내구도·목재 소비, 무보수, 한스의 직접 목격.
