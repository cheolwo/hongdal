## 조회 계약과 실제 예시

저장소 루트에서 다음을 사용한다. 정확 반환 내용은 현재 원문 hash와 신선도 검사를 통과한 생성 사본을 기준으로 한다.

```powershell
./eng/planning-inquiries/manage-inquiry-search.ps1 -Spatial -Id Q143
./eng/planning-inquiries/manage-inquiry-search.ps1 -HId h1-stock:farm-production
./eng/planning-inquiries/manage-inquiry-search.ps1 -Circulation -Id Q371
./eng/planning-inquiries/manage-inquiry-search.ps1 -Circulation -Id Q239
./eng/planning-inquiries/manage-inquiry-search.ps1 -Circulation -Unreviewed -Limit 1000
./eng/planning-inquiries/manage-inquiry-search.ps1 -Gap NoImage -Limit 1000
```

- Q143: 수동 급수점의 기존 구상을 미등록 요구에 연결한다. WaterAccessible/개울 외형을 실제 채수 지점 완료로 간주하지 않는다.
- farm-production: 기존 개간·파종·관리·수확 WI와 능력, 필수/선택 H2 포함 경로, 표현 카드/역사적 이미지 관계를 분리한다.
- Q371: 재가열의 대상·직접 가열 금지와 다음 선택을 원문으로 조회한다. 물/차/용기/열원 상태를 한 대상으로 합치지 않는다.
- Q239: 원문에 없는 장비 반납을 만들지 않고 `미기재`로 반환한다.
- 미검토 조회: 379개를 반환한다. 이는 미정 질문379개 또는 구현 결손379개라는 뜻이 아니다.
- NoImage: 현재 관계 입력에 근거 이미지가 없는 H를 찾는다. 실제 전역 부재 판정이 아니다.

직접 공간 요구, 지원 후보, 포함, 표현 지원, 특정 판본 이미지 근거는 다른 관계다. 상위 H로부터 유도한 연결은 직접 문답 근거와 구분한다. 같은 topic/이름만으로 확정 연결하지 않으며 같은 이미지는 근거 노드 하나로 공유한다.

## 보호·정합성 관문

질문 proof는 원문 경로/hash/행/앵커뿐 아니라 해당 위치의 정확 Q/의미ID를 검사한다. 이미지 proof는 manifest 전체 hash만이 아니라 정확 항목 포인터·파일 경로·SHA를 대조한다. 소실 원문 항목을 복구 근거 없이 Explicit/Confirmed로 바꾸는 입력은 거부한다. 입력 변경 시 신선도 실패를 숨기거나 검토 hash를 자동 갱신하지 않는다.

catalog counts3 차이, worker-waiting의 LF 해시2/판본 차이, 질문 색인 상태와 대조한 원문 상태 차이는 검토 항목으로 남겼다. hash 문제와 실제 구현/배치 결손을 분리하고 원문·대장 자동수리/E 승격0이다. 문답 체계의 잔존 소묶음 상한 문구도 현행 복수작업 정책과의 검토 사항이며 기획 원문을 수정하지 않았다.

## 검증과 잔여

공간/순환 회귀64, 기존 문답 회귀20 및 공식 JSON/세 생성 문서 Write/Validate를 통과했다. D396 WI 읽기 확장의 전용 회귀는 경로누락 검사를 추가해21통과(초기18)했다. 후속 코드/명세 입력 변경 뒤 최종 생성/신선도 검증을 다시 수행한다. 초기 시험의 배열 Count 표현 오류는 시험 코드에서 수정했고, 한 번의 로컬 pwsh 생성은 `Releasing the double mapped memory failed`로 종료됐다. 당시 공식 새 문서는 미생성/기존 색인은 보존됐고 잔여 실행 없음 확인 뒤 순차 검증으로 재실행하여 성공했다. 이 오류를 게임/Unity 실패로 분류하지 않았다.

현재 전체 의미 이관은 58 대조/379 미검토이며, 색인 밖39개 문서 내용 대조와 주제별 실제 코드/자산/Unity 연결은 남아 있다. H1 전체 대표 이미지 확보와 모바일 실기기 수신도 별도 미완료다. 새 규칙·H/WI 등록·운영 DB/서버·Unity/Scene/Save·가공·r129/야간 재개·commit/push는 수행하지 않았다.
