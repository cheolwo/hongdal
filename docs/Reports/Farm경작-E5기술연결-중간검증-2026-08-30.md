# Farm 경작 E5 기술 연결 중간 검증

- 기준: 2026-08-30, `farm-crop-cycle.design.r1` / D-286.
- 승인: [E5 개발 인계](E5세계발현-개발승인인계-2026-08-30.md), [작업 명세](../../eng/execution-ledgers/work-orders/farm-crop-cycle.e7-work-order.json).
- 판정: 기술 결함 교정·자동시험 범위다. 현재 Logic E3 / Presentation E1 / 통합 E1을 유지하며 실제 E5 완료 또는 E6/E7 승격을 뜻하지 않는다.

## 실제 연결한 내용

1. WI-FARM-01 밭갈이·02 파종·03 재배 관리를 기존 04 수확과 동일한 실행 Pipeline에 연결했다. 실행 책임 메타데이터와 Runtime 포트의 WI 목록도 맞췄다.
2. LocalSimulationRuntime은 LocalProcess 문맥을 전달하고 서버 기본은 RemoteHost를 유지한다. 권위 위치 표시는 규칙 분기나 별도 Simulation을 만들지 않는다.
3. 첫 재배의 기존 식별자는 유지한다. 이미 존재하는 재배 단위를 삭제하지 않고 다음 재배에 `:cycle:2` 이후 식별자를 부여한다. 이전 수확 Lot도 보존한다.
4. 작업 시작 기록과 완료 기록을 구분했다. 작업 시작에는 분야 성장을 지급하지 않고, WorldTick 완료 시 같은 WI·시작 행위 기록·Task 계보로 완료 기록과 기존 농업 분야 기여를 남긴다. 새 명상 판정이나 보상 수치는 추가하지 않았다.
5. Confirm 추적용 Preview가 재요청의 과거 ExpectedRevision을 먼저 거부하던 경로를 수정했다. 실제 ExpectedRevision·명령 payload 검증은 기존 권위 Confirm이 맡는다.

## 시험과 한계

- Farm 및 하향 모듈 집중시험 30/30 통과. 작업 중 Save를 복원한 세션에도 동일 Tick을 적용해 완료 Save hash가 같은지 확인했다. Preview 무변경, 작업 시작 Confirm 재요청, 완료 행위 기록과 성장 1회, 기존 Lot 보존을 포함한다.
- LocalProcess/RemoteHost 문자열별 시험은 같은 Service/Core 문맥 검증이다. 그 시험만으로 실제 두 Host의 네트워크 실행 또는 Unity 입력 검증을 주장하지 않는다.
- 최초 Task 검증은 E 책임 생성 지도의 소스 불일치로 중단됐다. 지도 갱신 후 전체 재검증 결과는 아래에 기록한다.
- 전체 Task 재검증: `artifacts/local/validation/20260830-094221` 통과. 빌드 경고0/오류0, 전체1227/1227(skip0). 공간 전문 담당의 Adapter45개를 포함한 공유 저장소 결과다.
- 저장소 Fixture로 전환한 뒤 Farm+공간 Adapter+E 책임 집중75/75 재통과: `artifacts/local/e5-world-manifestation/farm-e5-integrated.trx`. 이 마지막 검증은 개인 worktree 기본 경로를 사용하지 않는다.
- 후속 범위 Fast `artifacts/local/validation/20260830-094634` 통과(코드지도·E 책임지도·시험 프로젝트 빌드·공간 집중시험). Goal/작업 명세 검사와 새 보고서·Fixture 출처 문서의 로컬 링크6개도 통과했다.
- 기존 Save 형식 변경 없음. 지식·방문자의 공통 다음 Save 판본 예약과 실제 구현은 별도이며 이번 Farm 교정이 이를 완료하지 않는다.
- Scene·Prefab·실제 측정·Player 입력·Game View는 아직 이 묶음에서 검증하지 않았다.

## 체력 차단을 성공으로 숨기지 않음

| 초기 상태 | 실제 결과 | 해석 |
| --- | --- | --- |
| 새 밭, 체력 100 | 첫 주기 수확 후 다음 파종·관리까지 가능, 두 번째 수확은 체력 부족 거부 | 7작업 × 15 = 105. 새 밭 연속 두 주기 성공이 아님 |
| 미리 경작된 독립 밭, 체력 100 | 파종·관리·수확 두 주기, Lot 2개 보존 | 6작업 × 15 = 90. 재파종 ID·저장·Lot 기술 회귀 |

[행동 체력 회복과 성장](../Architecture/PlayableLoops/플레이어행동체력회복과성장.md)은 D-287의 Draft 방향이다. 자연 회복·휴식·포션·최대치 성장은 실행 수치·조건이 승인되기 전 구현하지 않는다. HP·질병·내면 회복과 혼합하지 않으며 기존 체력 비용·상한을 그대로 유지했다.
