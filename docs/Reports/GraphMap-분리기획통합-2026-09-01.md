# Graph Map 분리 기획 통합 결과

- 상태: `Integrated`
- 기획 인계: `PLAN-GRAPH-PLANNING-INTEGRATION-001` / `graph-map-planning-integration.r1`
- Graph Map: `graph-map:mirror:northern-life-hub-discovery.v1`
- 통합 판본: `mirror-graph-map-plan.northern-life-hub-discovery.r7`

## 통합 결과

기존 r6의 안정 ID와 실제 참조 노드·엣지·배치 규칙을 보존하고, [분리 기획 기반 인계](../AI/GraphMap-분리기획통합-인계-2026-09-01.md)가 지정한 현행 기획을 증분 통합했다.

| 묶음 | 재사용 | 추가한 레벨 1 관계 | 경계 |
| --- | --- | --- | --- |
| Farm 경계 첫 순찰 | `gm-node:hans-mission-life-base` | 준비, 동물형·야수형 마수 조우, 대응·귀환, 흔적 조사, 더 깊은 위협 관문, 한스 검 단서 | 첫 순찰에서 조직 전체·한스 검 사용을 열지 않음 |
| Hub 미도착 화물 | 기존 입고·차량·출고 | 단서·가설, 현장 확인, 문제 예방·안도·회복, 선택적 명상 | 기록이 정답을 계산하지 않고 회복·명상 결과를 중복하지 않음 |
| Town 견습 공방 | `gm-node:town-living-square` | 실패 작업대 관찰, 작은 시험 batch | 완제품·Recipe·편린·숙련·공방 소유 자동 지급 금지 |
| 장기 위협 | Farm 더 깊은 위협 관문, 요동성 관문 | 거대 마수·적대 조직 위협망, 실제 연결 분할 대응 | 실제 분리 뒤에만 종합 역량 재판정 후보 |

레벨 1은 30노드·31엣지, 레벨 2는 21제약이다. 기존 21개 배치 규칙은 바꾸지 않았고 새 사건 제약 6개는 수치를 만드는 규칙이 아닌 관리 제약으로 연결했다. 하위 맵은 기존 5개를 유지하면서 각 영역 내부 사건을 확장했고, Farm 위협 관문에서 장기 위협망으로 가는 미해결 port·connector 하나를 추가했다.

## 레벨 3

기존에 파일·assembly·심볼이 확인된 6개 코드 결속만 유지했다. 새 기획 관계는 승인된 Unity 계약이 없으므로 20개 미해결 노드와 22개 미해결 엣지를 모두 `NoApprovedUnityBinding`으로 남겼다. 이는 코드·Scene·Runtime 미구현을 명시하는 것이며 실제 배치 실패나 E5 증거가 아니다.

## 순환 복구

- `Superseded` 기획 인계는 당시 SHA-256 형식과 파일 존재만 검사하고 현재 파일 바이트와 다시 비교하지 않는다.
- 현행 `Integrated` 인계는 현재 기획 인계 문서와 Graph Map·생성물·이 보고서의 SHA-256을 검사한다.
- 기존 r6 기획 인계는 역사로 전환하고 r7 인계를 현행 통합 결과로 추가한다.
- Farm 개발 인계는 대체된 r5가 아니라 현행 r7 기획 인계와 Graph Map을 가리키도록 재판정한다.

## 증거 경계

Unity Editor·Scene·Prefab·Play Mode·Game View를 실행하거나 변경하지 않았다. 신규 WI·Goal을 등록하거나 활성화하지 않았고 E5/E6를 승격하지 않았다. 실제 이동·입력·Save·서버 연결·자산 구매·다운로드·Blender 가공도 수행하지 않았다.

## 검증

- Graph Map 본체: 30노드·31엣지·21제약, 21배치 규칙, 하위 맵5·port10·connector5·overlay4, 미결속20노드/22엣지 Check/Write 통과
- Graph Map 도구 회귀 13, 본체 회귀 144, 기획 인계 회귀 44, 개발 인계 회귀 68 통과
- 문서 링크·diff 범위 Fast는 최종 판본에서 별도 기록한다.
