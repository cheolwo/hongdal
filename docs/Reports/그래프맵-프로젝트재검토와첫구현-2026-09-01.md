# Graph Map 프로젝트 재검토와 확장 구조 구현 결과

## 결과

[상세 제안](../AI/북부생활권-첫그래프맵-상세제안-2026-09-01.md)의 단일 Graph Map r2를 확장 가능한 r3 구조로 리팩토링했다. 레벨 1 플레이 관계, 레벨 2 배치 제약, 레벨 3 Unity 코드 결속의 의미는 유지하면서 맵 규모 문제를 별도 federation 계층으로 분리했다.

이번 결과는 파일 기반 계획·조회·검증 도구다. Unity Scene, Prefab, Runtime, Play Mode, Game View 또는 E5/E6를 변경하지 않았다.

## 자동 차단

검증기는 다음을 거부한다.

- 한 노드·엣지·제약이 둘 이상의 하위 맵에 속하거나 어디에도 속하지 않는 상태
- 하위 맵 내부 엣지가 소속 밖 노드를 잇는 상태
- connector의 포트 방향·끝점·공통 능력·상태 불일치
- 하위 맵 hard limit 초과
- 엣지의 이동 능력 프로필 누락
- 제약의 집행 방식·필요 E·validator·실패 코드·무효화 조건 누락
- 절기·날씨 오버레이가 기본 토폴로지나 권위를 변경하는 상태
- 코드 대장 binding의 대상 누락·미해결 대상 허위 결속
- Runtime binding의 Editor 파일 사용
- Unity 파일·canonical Scene hash 또는 선언 심볼 drift
- 생성 조회의 신선도 불일치

## 검증

- Graph Map 회귀: 130개 통과
- 엄격 소스 확인: Unity 소스 13개와 canonical `SimulationWorldShell.unity`를 읽기 전용으로 대조
- 생성 조회 최대 행 길이: 621자, 분할 기준의 1,200자 이내
- 보호 확인: 기존 실제 E5 공간 사본·WI·결정·C# 배치 검토 파일과 Unity 소스·Scene hash 불변
- Unity Editor·Scene·Play Mode·Game View: 실행하지 않음
- 실제 Prefab·Collider·Bounds·통행·입력·결과: 미검증

## 다음 경계

Graph Map r3는 E5 배치의 맥락 누락을 줄이는 준비 도구다. 다음 실제 단계에서는 하위 맵 하나를 선택해 동결된 Synty 후보, 지지면·통로·InteractionAnchor, 실제 입력·결과, 적용·해제·재적용을 별도 증거로 검증해야 한다. 현재 추천 첫 범위는 Hub 전체나 World 전체가 아니라 `Hub 입고↔차량 마당↔출고` 세 노드의 격리 Preview다.
