# 맥락별 커밋 전 정합성 점검

## 범위와 보존

사용자 요청에 따라 개발·공간·애니메이션 담당의 쓰기·생성·시험 중지를 확인한 뒤 Hongdal의 현재 변경을 정리했다. 게임 기능을 새로 확대하거나 동결된 승인 문서·연구 hash를 다시 쓰지 않았다. 별도 Unity 저장소의 기존 Scene·자산·표현 변경 전체를 이번 기능으로 간주하지 않는다. push는 요청되지 않았으며 실행하지 않는다.

## 이번 정리

- 새 경관 소비 검증 소스에 맞춰 코드 지도와 E 책임 지도를 재생성했다. 최초 Fast191940은 코드 지도 불일치로 중단됐고, 갱신 후 Task192113의 지도·빌드·전체 시험이 통과했다.
- 문답 검색 시험의 `supplements[1]` 고정 위치를 Q347 식별자 선택으로 바꿨다. 새 질문 묶음이 앞에 추가돼 Q346 원문 누락 오류가 발생하던 사례다. 등록 순서를 역전한 상태에서도 같은 질문으로 음성 시험을 수행한다. 운영 원문/색인의 검색 규칙은 완화하지 않았다.
- Farm 코드 근거 시험은 E2 하나만 있다는 가정 대신 E2 포함을 검사한다. 실제 자연회복 Contracts/Domain/Tests가 E1/E2/E3로 추가된 것을 확인했으며, 미결속 행 전체의 실행 차단 검사는 유지한다. 코드 근거 단계는 WI의 통합 성숙도 승격이 아니다.
- 문답 도구 README에서 낡은 Q340~347 상한 설명을 제거하고 원문·등록 목록을 기준으로 조회하도록 정리했다.
- 별도 Unity의 로컬 NPC 대화 폴더는 수동 작성 시험 csproj가 전역 ignore에 가려지고 meta만 보이던 상태였다. 세 시험 프로젝트에 한정해 하위 ignore 예외를 추가하여 재현 가능한 소스 묶음으로 보존한다.
- 같은 폴더의 `bin/obj`와 대응 meta는 제외한다. 독립 시험이 만든 DLL/실행 산출물은 커밋하지 않았다. Unity 생성 meta의 빈 YAML 값 공백과 동결 인계 보고의 말미 빈 줄은 hash 보존을 위해 다시 쓰지 않았고, 그 외 소스의 staged 공백 검사를 통과했다.

코드 지도 생성은 탐색 범위 밖 후보 경고를 출력했다. E 책임 지도는 후보762/주석759/제외3/미분류0이다. 기존 Console·Graph 문제를 해결했거나 전체 Editor가 오류 없이 실행된다는 뜻이 아니다. 이번에는 Editor 조작·Scene 저장·실제 Play/Game View·새 모델 다운로드를 하지 않았다.

코드·기획·원장 10개 커밋 후 Task `20260830-192751`에서 두 코드 지도 검사, Simulation/Unity 솔루션 빌드, 전체 Simulation1479/1479·Unity 공통545/545를 다시 통과했다. Goal r60 Check도 통과했다. 마지막 통합 보고만 후속 문서 커밋이며 위 코드 시험 이후 게임 소스 변경은 없다.

## 커밋 분류

Hongdal은 수출항만 Adapter 경계, 방문자 Runtime/HTTP, 체력 계산, 용기 내용물, 수확 위임, Farm 부지 확대, 경관 소비 검증, 문답 검색, 기획/운영 지침, 실행 원장/생성 지도, 통합 보고를 각각 나눈다. 공통 생성 지도와 실행 원장은 관련 코드 묶음 이후 함께 반영한다. 중간 커밋은 최종 조합 전체의 원장 정합성 검증을 대체하지 않는다.

별도 Unity에서는 D337 로컬 NPC 대화 코드·시험·고정 패키지 추가만 분리한다. lock의 기존 Interior→Simulation.Contracts 변경은 그대로 미커밋 보존한다. D359 공용 AnimationAdapter는 기존 미커밋 선행 수정에 의존하므로 일부만 떼어 같은 실행 검증을 주장하지 않으며, 관련 애니메이션 묶음 전체는 이번 커밋에서 보류한다. 나머지 Unity Scene·원본 자산·복구 사본도 건드리지 않는다.

## 남은 작업

- 방문자·지식·자연회복의 실제 Session/Save 통합과 v30은 미완료/예약 상태를 유지한다.
- 경관 검사 결과는 BindingVerified이며 실제 B 변환·지지면·통행·Unity 조립·화면 성공은 후속이다.
- D364 통합 파이프라인은 확정된 방향이지만 실제 통합 코드 완성으로 보고하지 않는다.
- D359 벌목 Task/Presenter/Bootstrap 연결·접촉·발 고정·Game View와 기존 Graph/Console 문제는 남는다.
- 통합 E·후보 승인 상태·명세 상한은 변경하지 않는다. 담당 재개는 커밋 검증 뒤 별도로 전달한다.
