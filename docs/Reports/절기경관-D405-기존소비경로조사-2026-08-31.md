## 다음 가장 작은 준비 단위

1. 공간 담당이 LS01의 정확 수목/풀/바위 후보와 기존 재질·LOD/공유 관계를 읽기 반환한다. 산 후보의 존재와 적합성, 변색할 첫 대상을 아직 확정하지 않는다.
2. 기존 이름필터와 실제 재질/Renderer 슬롯의 대응을 확인하고, 원본 재질을 건드리지 않는 **정확 소유 객체/슬롯 목록**을 후속 연구에서 정의한다. 동일 원본을 쓰는 다른 물체로 색이 번지지 않는지 별도 조건으로 둔다.
3. 기본 배치/상태hash를 보존하면서 계절표현 판본만 변경하는 기존 계약을 우선 재사용한다. 실제 `현재 시간·지역 → 표현 규칙 → 대상 Renderer → 해제/재진입`의 호출 결속은 별도 구현/명세가 필요하다. LH 능력 표시나 Sky 색을 이 경로의 완료 근거로 쓰지 않는다.
4. 정확 첫 지역/대상·사용조건·팔레트/전환 의미가 기획·Required 연구와 결속된 뒤에만 코드/시험 또는 고정조건 격리검증을 배분한다. 지금은 새 클래스/엔진·24벌 Prefab·전역 계절 교체·실제 실행을 제안값으로 확정하지 않는다.

시간/날씨를 고정한 계절표현 대조와 실제 시간/기상 통합 대조는 다르다. 원본·권위·지형·통행/작업식별을 보존해야 하며, 미확인 경관 표현은 무관한 WI 준비의 전역 선행 조건이 아니다. 기존 r129/야간 중지 및 D396 독립 준비는 그대로다.
