## 재사용과 첫 구현 경계

`외부상품가격스냅샷Dto`의 nullable 가격/배송비/통화와 `CommunityInformationReviewStates`의 PendingReview/Approved/Excluded를 재사용한다. 공식뉴스 검토의 IdempotencyKey/ExpectedRevision/검토자·시각·이력 패턴을 따른다. 공식뉴스 서비스 자체는 원천 재조회와 Mongo 저장을 수행하므로 이번 골격에서 호출하지 않는다. Amazon 참고 DTO 전체를 Alibaba에 위장 적용하거나 SNS Adapter를 전용하지 않는다.

서버가 제공한 현재 상태와 인증 주체를 입력받아 기존 `서버관리자전용` 정책으로 권한을 검사한 뒤 다음 상태 후보만 반환한다. 반환을 영속 확정으로 표시하지 않는다. 실제 저장 시의 compare-and-swap·멱등 이력 원자 저장, HTTP/DI·인증 경계 연결은 후속이다. 수집/게시/통지/게임 상태 변경 경로는 제공하지 않는다.

초안·검토·품목 대응 승인·제공자료 검토 승인/제외를 분리한다. 초안 내용 개정은 이전 대응/승인을 무효화한다. 불완전 초안은 보관 후보로 허용하되 미관측/권리 미확인/비교 불가/가격·조건 누락은 승인 준비를 거부한다. Fixture 가격은 가상값으로 표시하고 실제 플랫폼 관측으로 보고하지 않는다.

## 구현 인수 결과

전용 코드 3파일을 작성했다. 새 공개 API·DI 등록·영속 저장소는 없다. `준비Async`는 서버가 제공한 현재 상태·인증 주체와 요청을 받아 `PreparedNotPersisted` 상태 후보 또는 거부 사유를 반환한다. HTTP에서 현재 상태/인증 주체를 요청 본문으로 받아 신뢰하는 방식은 허용하지 않는다.

- `CreateDraft`: 현실 후보 없이 게임 상품부터 작성 가능. `ReviseDraft`: 같은 게임 상품 안에서 내용을 개정하고 대응/제공자료 승인을 해제한다.
- `SubmitReview` → `ApproveMapping` → `Approve`: 대응 확인과 제공자료 검토를 분리한다. 유사/동일 구분을 유지하고 근거 없는 대응을 거부한다. `Exclude`는 불완전 초안과 승인 자료에서도 가능하다.
- 인증 여부·NameIdentifier·기존 `서버관리자전용` 정책을 모두 검사한다. 정책 원문은 Program.cs의 `RequireRole(역할명.서버관리자)`이며 실제 AuthorizationService 역할 판정도 시험했다.
- `ExpectedRevision`·대상 식별자를 검사하고, 인증 검토자·요청 내용에 결속한 hash로 같은 멱등 키의 다른 내용/검토자를 거부한다. 정확한 재시도는 최신 상태 사본만 반환하며 감사 이력/개정은 늘리지 않는다.
- 관측 여부·시각·원천/판매자/규격/가격/통화/배송비/수량/MOQ·이용조건 검토 근거·비교 가능성과 부족 조건·표시 초안을 검사한다. null 비용을 0으로 채우지 않는다. 실제 이용조건의 법적 허용을 자동 판정하는 코드가 아니라 운영 검토 근거 누락을 막는 골격이다.
- 가상 보온병/병 입력은 `Fixture`, `example.invalid`, 가상 출처/가격으로 명시한다. 그 검토 통과는 Amazon/Alibaba 실제 상품 수집·가격 또는 권리 검증이 아니다.
- 입력 목록은 인증 await 전에 복사하고 반환 목록도 읽기 전용 사본이다. 수집·게시·통지·게임 상태 변경·영속 확정 결과는 항상 false다. 외부 실행/저장 포트는 없으며 주입 의존성은 권한 서비스와 시계뿐이다.

## 남은 연결과 제외

실제 영속 원장/CAS·동시 요청 원자성·멱등 이력 저장·재조회 API/DI·운영 검수 UI는 미연결이다. 같은 원본 상태로 동시에 준비된 후보 둘의 충돌을 이 비영속 서비스가 저장소 대신 해결했다고 주장하지 않는다. 게임상품 catalog의 실제 존재/접근권한 검증과 승인자료 읽기 사본 연계도 후속이다.

실제 자료 접근·보관/재노출 권리, Actor·예산·갱신·게시 방식은 기존 [D371 인수 경계](../Research/GameData/D371/development-intake.r1.md)를 유지한다. 이번에는 추가 조사·토큰 조회·Actor 목록 조회·수집·게시·알림·실데이터 쓰기·게임 Save/Scene/E/commit/push가 없다. D363/D359 작업을 대기시키거나 새 게임 WI/Goal을 등록하지 않았다.
