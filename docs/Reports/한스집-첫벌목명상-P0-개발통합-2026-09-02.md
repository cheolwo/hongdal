# 한스 집 첫 벌목 명상 P0 개발 통합

## 범위

이 보고서는 `WI-NATURE-06`의 플레이어 본인 첫 벌목 완료 기록과 한스 집 첫날밤의 검증된 안전 휴식을 입력으로 받아, 첫 `성찰 씨앗`을 준비하는 P0 범위만 기록한다. 명상 UI, 염체 그래프, 요동성, 도끼·방패 표현, Unity Scene·Play Mode·Game View는 포함하지 않는다.

현행 기획 입력은 다음과 같다.

- `PLAN-STORY-DUAL-PROTAGONIST-001`: `dual-possession-alchemist-succession.r63`, SHA-256 `1B0BDA2D9859372CF6D4E4F42C358BE18F7CD5512B9F8C61515C7F49311FFA7D`
- `PLAN-GAMEPLAY-MEDITATION-ACTION-001`: 현행 `player-mind-meditation.r25`, SHA-256 `EB1FE8EAD096746B05D12BE84B32D0456DB3D931AE361267C4CDCEEB491DF49A`
- `docs/AI/PLANNING.md`: 현행 SHA-256 `83FC25A2CCA3DABAF3DC50D5A1503C72EC75D129D7CF04AA704758B1DFBF0916`

r25와 함께 전달된 요동성 r71 변경은 P1 긴급 예비 자원·NPC 비용/증빙 검증 흐름이며 이 P0 행위·휴식·성찰 규칙에는 영향이 없다. P0 실행 관문은 계속 변하는 P1 판본이 아니라 위 r63 승인 기준선의 첫 벌목 명상 문단에 고정한다.

## 구현

- `Simulation첫벌목성찰SeedEngine`은 호출자가 완전하다고 선언한 행위 기록에서 플레이어 본인이 실제로 완료한 최초 `WI-NATURE-06 / HarvestCompleted`만 고른다.
- NPC 수행, 실패, 다른 WI, 잘못된 행위 기록 해시는 첫 벌목 경험으로 인정하지 않는다.
- 한스 집 안전 휴식 근거는 `safe-rest:hans-house:first-night` 식별자, 플레이어, 성공 여부, 벌목 이후 판본을 검증한다.
- 씨앗 식별자는 행위 기록·행위 해시·휴식 근거·규칙 판본으로 결정적으로 계산한다.
- 진행 상태는 `Observation → Cause → Improvement`의 정확한 접두부만 허용하므로 중단 뒤 같은 씨앗을 재개할 수 있다.
- 완료 보상 준비는 기존에 승인된 `Simulation명상숙련기여Request`의 양수 집중 근거를 재사용한다. 새 성장량을 만들지 않으며 같은 행위 기록 기여가 프로필에 있으면 이미 적용된 결과로 반환한다.
- Save/Replay v29 복원 뒤에도 같은 씨앗을 다시 계산하며 기존 기여를 중복 적용하지 않는다.

## 검증

`SimulationFocusMeditationTests` 집중 실행 결과는 13/13 통과, 실패 0, 건너뜀 0이다.

추가된 회귀는 다음을 확인한다.

1. 플레이어 본인의 첫 벌목과 한스 집 안전 휴식이 함께 있어야 씨앗이 준비된다.
2. NPC 벌목은 플레이어 경험으로 계상되지 않는다.
3. 중단한 `Observation` 진행을 같은 씨앗에서 재개하고 잘못된 편린 순서는 거부한다.
4. 기존 집중 성장량만 사용하고 같은 씨앗 보상을 한 번만 적용한다.
5. v29 복원 뒤 같은 씨앗과 이미 적용된 보상 계보를 확인한다.

시험 결과: `artifacts/local/validation/first-logging-reflection-p0/first-logging-reflection.trx`

## 증거 상한과 남은 연결

- 코드·독립 단위시험·Graph Map 계획 결속까지 완료한 준비 증거다.
- 실제 제품의 한스 집 안전 휴식 공급자와 튜토리얼 소비 UI는 아직 연결되지 않았다.
- 중단 진행은 순수 입력으로 재개됨을 검증했지만 제품 Save v29에 성찰 진행 상태를 저장하는 소비 경로는 아직 없다.
- Unity Editor, Scene 저장, Play Mode, Game View, 실제 입력, 서버 연결은 실행하지 않았다.
- 현재 `GraphInventoryChanged` 등 다른 전문 작업의 실패를 소급 통과시키지 않는다.
- P1 염체 그래프와 요동성 r69는 별도 승인 관문 없이는 구현하지 않는다.

따라서 이 결과는 P0 논리 준비의 부분 통합이며 Presentation E5나 전체 명상 기능 완료가 아니다.
