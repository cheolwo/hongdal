# Ssalddel 1.0 Scope

| 기능 | 상태 | 경계 |
| --- | --- | --- |
| 음식·재료 공개 탐색 | 포함 | 출처·단위·기준 시각 표시 |
| 공동구매 제안과 공개 모집 | 포함 | 공개 정보와 보호된 작성 명령 분리 |
| 비구속 수요 등록·변경·철회 | 포함 | 결제·주문 확정 없음 |
| 품목·지역·수령 조건별 자동집단화 | 포함 | 설명 가능한 규칙과 미리보기 제공 |
| 참여 수·목표 수량·진행 상태 | 포함 | 개인 주소·연락처 비공개 |
| 생산자·공급자 후보 연결과 협의 기록 | 포함 | 사용자가 선택하고 플랫폼은 자동 선정하지 않음 |
| 공급 견적·HS·HTS·수입 준비 | `1.5`로 인계 | 확정 분류·신고 없음 |
| 운송 의뢰·배차·증빙·정산 | `2.0`으로 인계 | 자동 실행 없음 |
| 입고·재고·판매·최종 배분 | `2.5`로 인계 | 자동 실행 없음 |
