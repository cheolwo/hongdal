# Ssalddel 1.0

## 목표

`1.0`은 **공동구매와 주문자 집단화**의 첫 제품 버전입니다. 사용자가 한국 음식과 식재료를 탐색하다 구매 의향을 남기면, 서버가 품목·지역·수령 조건별로 수요를 모아 비구속 공동구매 모집으로 보여 줍니다.

## 핵심 흐름

```text
음식·재료 탐색
  → 비구속 수요 등록·철회
  → 서버 집단화 미리보기
  → 주문자 집단·모집 원장
  → 공급자 후보와 조건 협의
  → 1.5 공급·무역 준비로 인계
```

## 원칙

- 집단화는 상품, 수량, 지역, 수령 조건과 시간창처럼 구매 이행에 필요한 정보만 사용합니다.
- 국적·언어 등 비관련 속성으로 참여자를 배제하거나 가격을 차별하지 않습니다.
- 수요 등록은 주문, 결제, 계약 또는 수입 신고가 아닙니다.
- 서버는 멱등 키로 중복 수요와 중복 집단 생성을 막고 사용자의 철회를 반영합니다.
- 기본 모집 기간은 14일이며, 종료 시 목표 충족 여부와 다음 검토 단계를 명시합니다.
- 운송사·창고·관세사·판매자를 자동 선정하지 않습니다.

## 다음 단계

목표 수량, 참여 의사, 공급 조건과 운영 주체가 검토 가능한 상태가 되면 `1.5`로 넘깁니다. 국내 공동구매는 통관 준비를 생략할 수 있지만 공급·가격 근거는 남겨야 합니다.
