# Ssalddel 2.0 Scope

| 기능 | 상태 | 경계 |
| --- | --- | --- |
| 화주 운송 의뢰와 조회 | 포함 | 소유·역할 범위 검증 |
| 기사·운송사 후보와 명시적 수락·거절 | 포함 | 자동 계약 확정 없음 |
| 상차·하차·인수 상태 전이 | 포함 | 서버 권한·선행 상태 검증 |
| POD·문서·감사 이벤트 | 포함 | 민감정보 최소 노출 |
| 운임 구성과 정산 후보 | 포함 | 실제 수취·지급은 별도 운영 승인 |
| 공동구매 해외 선적 추적 | 포함 | 통관 판단은 `1.5` 준비 원장 참조 |
| 차량 추천과 적재 검토 | 포함 | 추천 이유 표시, 자동 배차 금지 |
| 창고 입고·재고·판매채널 | `2.5`로 인계 | 자동 상태 변경 없음 |
