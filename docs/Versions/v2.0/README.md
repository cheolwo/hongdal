# Hongdal 2.0

## 목표

국제 물류, 통관, HS 코드 데이터를 플랫폼 안에서 조회하고 업무에 연결합니다.

## 포함 범위

| 영역 | 내용 |
| --- | --- |
| HS 코드 | HS 코드 DB화, 식품/비식품/화물 분류 |
| 통관 | 통관/수입 대행 가능 여부 조회 |
| 관세사 | 관세사 전용 앱 또는 화면, 데이터 보정 권한 |
| FCL/LCL | 화주가 운송 단위를 판단하고 상담할 수 있는 정보 |
| 데이터 공개 | 화주가 공개를 허용한 통관 데이터를 결제 후 조회 |

## 보류 범위

- 공동주택 기반 공동 주문/FCL 단지 입고
- 홍달마트 즉시배송 실운영
- 도심 마트 피킹/포장 운영 고도화

## 우선 앱/모듈

- `CustomsBrokerApp`
- HS 코드 DB
- 해외/통관 서비스
- `CargoYongdalDispatchEngine`

## 안정화 기준

- HS 코드가 구조화된 데이터로 조회된다.
- 관세사 역할 사용자가 보정 가능한 범위가 분리된다.
- 공개 허용된 통관 데이터만 조회 가능하다.
- FCL/LCL 판단 정보가 화주 운송 계획에 연결된다.
