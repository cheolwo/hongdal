# 문화교통 0.5 Scope

| 기능 | 상태 | 경계 |
| --- | --- | --- |
| 공개 음식·재료·가격 근거 참조 | 포함 | `0.0` 원자료의 출처·기준 시각·단위 유지 |
| 개별주문 의향 등록 | 포함 | 사용자 본인 소유, 멱등 저장 |
| 개별 원장 목록·상세 재조회 | 포함 | 인증된 소유자만 조회 |
| 수량·수령 조건 변경 | 포함 | 변경 이력과 revision 유지 |
| 개별주문 철회 | 포함 | 철회 상태 보존, 공동 집계 제외 |
| 같이 주문 참여 동의·철회 | 포함 | 주문 의향과 별도 상태 |
| 자동집단화·같이 주문 모집 | `1.0`으로 인계 | 동의한 stable 개별 원장만 입력 |
| 결제·계약·재고 예약·배송 확정 | 제외 | 후속 운영 경계 전 실행하지 않음 |
| 공급·HS·HTS·수입 준비 | `1.5`로 인계 | 0.5에서 전문 판단하지 않음 |
