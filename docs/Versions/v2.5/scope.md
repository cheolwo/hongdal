# Ssalddel 2.5 Scope

| 기능 | 상태 | 경계 |
| --- | --- | --- |
| 입고 예정·현장 수령·검수 | 포함 | 창고 소유·배정 범위 검증 |
| 적재·재고 로트·위치 | 포함 | 같은 원장 ID 재조회와 멱등 전이 |
| 피킹·포장·출고 인계 | 포함 | 선행 상태와 수량 검증 |
| 판매상품·채널 연결 준비 | 포함 | 외부 발행·동기화 별도 승인 |
| 주문자 집단 최종 분류·배분 | 포함 | 개인 주소·연락처 최소 노출 |
| 공동주택 잔여재고 판정 | 설계 포함 | 예약분 보호 뒤 소유권·자금·동의·품질을 확인한 수량만 후보화 |
| B2C/B2B 잔여재고 판매·정산 | 설계 포함, 기본 Simulation | 판매자·품목 자격과 외부 발행 승인 전 실판매 없음 |
| 공동주택 수익귀속·관리비 절감 handoff | 설계 포함, 외부 확인 필요 | 순귀속 가능액과 의결·예산·입금·실제 부과 반영을 분리 |
| 운영 역할 지원·검토 | 포함 | 고용·보수·보험 자동 확정 없음 |
| 공동구매 수요·집단화 | `1.0` 참조 | 이 단계에서 새로 정의하지 않음 |
| HS·통관·수입 준비 | `1.5` 참조 | 전문 판단 대체 금지 |
| 운송 의뢰·배차·증빙 | `2.0` 참조 | 창고가 자동 배차하지 않음 |
