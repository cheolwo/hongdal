# Ssalddel 2.5 Migration Notes

## 2026-07-22 · 창고·판매 이행 재분류

- 기존 `1.5` 창고·판매 물류 범위를 `2.5`로 이동했습니다.
- 창고 작업과 관점 조회 API 메타데이터를 `2.5`로 이동했습니다.
- 판매채널과 커머스 이행 메타데이터는 `2.5`에 유지합니다.
- 공동구매 수요·집단화는 `1.0`, 공급·HS·수입 준비는 `1.5`, 운송은 `2.0`으로 분리했습니다.
- 기존 `WarehouseV15` 설정은 호환 별칭으로 유지하고 신규 설정은 `WarehouseFulfillmentWorkflow`를 사용합니다.
- HTTP route와 기존 창고·판매 원장 ID는 변경하지 않습니다.
