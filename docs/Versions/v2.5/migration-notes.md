# Hongdal 2.5 Migration Notes

2.5에서는 공동주택 식별, 공동 주문 모집, 주민 구매 의사, FCL/대량 입고, 단지 내 분류/배분 관련 데이터 변경을 기록합니다.

## 기록 대상

- 공동주택 후보/확정 식별자
- 사용자 단지 소속 확인 상태
- 공동 주문 모집과 참여 의사
- 목표 수량/금액/FCL 조건
- 단지 대표 입고지
- 동/수령 지점별 분류 작업
- 내부 배분 담당자/방식
- 공동 주문 정산 항목

## 주의

공동주택 단지 식별은 개인정보와 거주 정보에 가까운 데이터입니다. 외부 API의 단지 코드와 사용자의 상세주소를 직접 공개하지 않고, 내부 식별자와 마스킹된 표시값을 사용합니다.

2.5 데이터는 2.0의 통관/수입 계획과 연결될 수 있지만, 모든 공동 주문이 수입 통관을 전제로 하지는 않습니다. 국내 대량 구매나 화주 재고 공동 구매도 같은 모델로 처리할 수 있게 둡니다.
