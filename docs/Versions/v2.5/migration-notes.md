# Ssalddel 2.5 Migration Notes

2.5에서는 주문자 집단 식별, 공동주택 하위 식별, 공동 주문 모집, 주문자 구매 의사, FCL/대량 입고, 집단 내 분류/배분 관련 데이터 변경을 기록합니다.

## 기록 대상

- 주문자 집단 후보/확정 식별자
- 주문자 집단 범위 기준: 도로명주소/Kakao 지역 2단계, 선택적 3단계 세부 범위
- 공동주택 후보/확정 식별자
- 사용자 집단 소속 확인 상태
- 공동 주문 모집과 참여 의사
- HS 코드 기반 먹거리 공동주문 우선 후보 여부
- HS 상품 카드 식별자와 주문자 집단 개설 신청 상태
- 개설 신청자, 주문자 집단 범위, 비구속 신청 동의 여부
- 수입 식품 공동 주문 계약서 번호, 당사자, 필수 조항, 검토 상태
- 냉장/냉동, 수입식품 신고/검역, 해외제조업소 조회 필요 여부
- 공동구매 지급 마일스톤, 지급 비율, 지급 조건, 지급 완료 상태
- 분배 확인율과 최종 지급 가능 여부
- 목표 수량/금액/FCL 조건
- 집단 대표 입고지
- 동/수령 지점/그룹 수령 지점별 분류 작업
- 내부 배분 담당자/방식
- 공동 주문 정산 항목

## 주의

주문자 집단 식별은 개인정보와 거주 정보에 가까운 데이터입니다. 기본 범위는 도로명주소/Kakao 지역 2단계로 잡고, 공동주택은 이 집단 식별의 하위 근거로만 사용합니다. 외부 API의 단지 코드와 사용자의 상세주소를 직접 공개하지 않고 내부 식별자와 마스킹된 표시값을 사용합니다.

2.5 데이터는 2.0의 통관/수입 계획과 연결될 수 있지만, 모든 공동 주문이 수입 통관을 전제로 하지는 않습니다. 국내 대량 구매나 화주 재고 공동 구매도 같은 모델로 처리할 수 있게 둡니다.
