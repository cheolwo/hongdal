# Ssalddel 2.5 Checklist

- [ ] 입고·검수·적재·피킹·포장·출고가 각각 독립 상태 전이입니다.
- [ ] 모든 쓰기 명령이 역할, 소유 범위, 선행 상태와 멱등성을 검증합니다.
- [ ] 재고 수량·예약·가용·불량 수량의 불변식이 테스트됩니다.
- [ ] 판매상품과 내부 재고 원장을 공개 응답에서 분리합니다.
- [ ] 외부 판매채널 연결과 발행·동기화 실행을 분리합니다.
- [ ] 최종 배분에 필요한 개인정보만 필요한 시점에 노출합니다.
- [ ] 운송 인계는 `2.0` 원장을 참조하고 자동 배차하지 않습니다.
- [ ] 운영 역할과 실제 고용·계약·보험 판단을 분리합니다.
- [ ] 주문자 예약분·미수령분을 잔여재고로 자동 전환하지 않고 소유권·자금 출처·처분 동의를 검증합니다.
- [ ] 잔여재고 판매자는 B2C/B2B 거래 문맥, 품목별 자격, 표시·보관·반품 책임을 승인합니다.
- [ ] 총매출, 원자금 상환, 환불, 세금, 물류·노동비와 공동주택 귀속 가능액을 서로 다른 필드와 증빙으로 보존합니다.
- [ ] 공동주택 수익귀속은 관리규약·사업계획/예산·의결 근거와 지정 계좌 입금 확인 없이는 승인되지 않습니다.
- [ ] 예상 절감액, 차감 확정액과 실제 관리비 명세 반영액을 분리하고 적용 월별로 대사합니다.
- [ ] 실판매·외부 발행·결제·송금·관리비 반영은 기본 Simulation에서 실행되지 않습니다.
- [ ] 완료 결과가 공동 원장과 개인정보를 줄인 사례로 환류됩니다.
- [ ] 창고·판매 API와 화면 메타데이터가 제품 버전 `2.5`를 사용합니다.
