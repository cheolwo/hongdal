# Hongdal 2.5 Checklist

- [ ] 도로명주소/Kakao 지역 2단계 기본 범위를 통한 주문자 집단 후보 조회 흐름 확인
- [ ] 3단계 주소/반경 km는 즉시 배송권 또는 세부 필터로만 사용되는지 확인
- [ ] 공동주택 단지 코드가 주문자 집단 식별의 하위 단서로 저장되는지 확인
- [ ] 사용자 집단 소속 후보/확정 상태 확인
- [ ] 공동 주문 모집 생성 확인
- [ ] HS chapter 01~24 식품/식품 인접 화물이 먹거리 공동주문 우선 후보로 분류되는지 확인
- [ ] 주문자가 HS 먹거리 상품 카드에서 공동 주문 집단 개설 신청을 할 수 있는지 확인
- [ ] 운영 승인 전에는 다른 주문자의 참여 모집이 열리지 않는지 확인
- [ ] 운영 승인 후 같은 주문자 집단 범위의 다른 주문자가 구매 의향으로 참여할 수 있는지 확인
- [ ] 수입 식품 공동 주문 계약서에 개설 신청자, 공급자/화주, 플랫폼 운영자 당사자가 포함되는지 확인
- [ ] 계약서에 비구속 수요 확인, 수입식품 검토, 콜드체인, 마일스톤 지급, 분배 확인, 환불/취소 조항이 포함되는지 확인
- [ ] 계약이 서명 가능한 상태일 때 필수 당사자별 전자서명 요청과 증적 해시가 기록되는지 확인
- [ ] 서명 패드는 계약/업무 단계가 요구할 때만 `HongdalSignatureGate`를 통해 노출되는지 확인
- [ ] 수입 식품 공동 주문 계약서가 개인정보/계약 ISMS-P 준비도 필수 항목을 통과하는지 확인
- [ ] 냉장/냉동 먹거리 후보가 콜드체인/수입식품 검토 단계로 연결되는지 확인
- [ ] 공동구매 금액이 상차, 하차, 분배 확인 마일스톤으로 나뉘는지 확인
- [ ] 분배 확인율 기준에 도달하기 전 최종 지급이 보류되는지 확인
- [ ] 해외 판매자 공동주문이 BL/AWB와 문서관리번호를 등록할 수 있는지 확인
- [ ] UNI-PASS 화물통관 진행 조회 결과가 공동주문 해외 선적 이벤트로 반영되는지 확인
- [ ] 통관 완료 후 국내 물류대행 입고 상태와 재고 로트 확정 상태가 분리되는지 확인
- [ ] 물류대행 입고 플랜이 입고상품, 판매상품, 채널출품, 출고 배치 가능 상태를 함께 표시하는지 확인
- [ ] 스마트스토어/쿠팡 등 판매채널 주문이 1.5 출고 배치 엔진을 통해 `출고예정`으로 연결되는지 확인
- [ ] 공동주택 관리비 공공데이터와 공동판매 예상 수익을 함께 조회/시뮬레이션할 수 있는지 확인
- [ ] 주문자 집단 운영 주체가 비사업자/사업자/법인/협동조합/관리사무소 위임/플랫폼 위임 중 하나로 구분되는지 확인
- [ ] 사업자 검증 상태에 따라 수입자 역할과 고용주 역할 가능 여부가 분리 표시되는지 확인
- [ ] 공동주문 분류/배분/물품 집합/공동주택 관리 보조 역할이 입주민 우선 정책으로 노출되는지 확인
- [ ] 경비/순찰 보조 역할은 법적 경비 업무와 구분되고 교육/결격사유 등 확인 필요 항목으로 표시되는지 확인
- [ ] 주문자 구매 의사 등록 확인
- [ ] 목표 수량/금액/FCL 가능 조건 계산 확인
- [ ] 화주 수입/대량 구매 계획과 공동 주문 연결 확인
- [ ] 집단 대표 입고지 설정 확인
- [ ] 집단 내 동/수령 지점별 분류 작업 확인
- [ ] 내부 배분 방식 선택 확인
- [ ] 개인정보 마스킹과 공개 범위 확인
- [ ] 개인정보 보유/파기, 제3자 제공/위탁, 감사 로그 기준 확인
- [ ] 공동구매에서 다루는 연락처, 상세주소, 결제수단, 계약 문서, 통관 참조 정보가 개인정보 필드 보호 카탈로그에 등록되어 있는지 확인
- [ ] 수입 식품 공동 주문 계약서 DTO의 개인정보/계약 속성에 `IsmsPProtectedDataAttribute`가 붙어 있는지 확인
- [ ] 주문자 집단 소속 정보의 공개 범위 확인
- [ ] 공동 주문 정산 항목 분리 확인
- [ ] 3.0 음식점 일반 배달, 3.5 홍달마트 즉시배송과 기능 경계가 섞이지 않는지 확인
- [ ] 내부 테스트 또는 2.5 릴리즈에서 `OrdererGroupOrderV25=true` 확인
- [ ] `FoodDeliveryV30`, `HongdalMartV35` 기본 비활성 확인
- [ ] [공통 릴리즈 게이트](../release-gates.md) 통과 확인
