# Hongdal 2.5 Checklist

- [ ] 주소 검색과 공동주택 후보 조회 흐름 확인
- [ ] 공동주택 단지 코드 또는 내부 단지 식별자 저장 확인
- [ ] 사용자 단지 소속 후보/확정 상태 확인
- [ ] 공동 주문 모집 생성 확인
- [ ] 주민 구매 의사 등록 확인
- [ ] 목표 수량/금액/FCL 가능 조건 계산 확인
- [ ] 화주 수입/대량 구매 계획과 공동 주문 연결 확인
- [ ] 단지 대표 입고지 설정 확인
- [ ] 단지 내 동/수령 지점별 분류 작업 확인
- [ ] 내부 배분 방식 선택 확인
- [ ] 개인정보 마스킹과 공개 범위 확인
- [ ] 공동 주문 정산 항목 분리 확인
- [ ] 3.0 홍달마트 즉시배송과 기능 경계가 섞이지 않는지 확인
