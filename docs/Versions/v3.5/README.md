# Hongdal 3.5

## 목표

홍달마트와 도심 즉시배송을 운영 가능한 흐름으로 확장합니다.

3.5는 3.0 음식점 일반 음식 배달과 구분됩니다. 홍달마트는 음식점 조리 흐름이 아니라 도심 재고, 피킹, 포장, 음식 배달 기사형 픽업/배송이 결합된 창고형 즉시배송 흐름입니다.

## 포함 범위

| 영역 | 내용 |
| --- | --- |
| 홍달마트 주문 | 주문자 앱에서 홍달마트 상품 주문 |
| 도심 재고 | 마트형 재고 보충과 가용 재고 관리 |
| 피킹/포장 | 창고 작업 완료 후 음식 배달 기사 픽업 가능 상태 생성 |
| 즉시배송 | 음식 배달 기사 앱과 연결된 짧은 거리 배송 |
| 묶음 배달 | 도심 재고/거리/시간 기준으로 묶음 가능성 판단 |

## 보류 범위

- 1.0 핵심 운송 흐름을 흔드는 대규모 구조 변경
- 2.5 공동주택 공동 주문 모델을 홍달마트 실시간 주문으로 흡수
- 일반 음식점 조리 흐름과 홍달마트 피킹/포장 흐름의 무리한 통합

## 우선 앱/모듈

- `WarehouseManagerApp`
- `OrdererApp`
- `FoodDeliveryDispatchEngine`
- `Deliver`

## 안정화 기준

- 홍달마트 주문이 재고 확인, 피킹, 포장을 거쳐 배차 대기 상태로 전환된다.
- 포장 완료 전에는 음식 배달 배차가 진행되지 않는다.
- 음식 배달 기사 앱에서 픽업/배송에 필요한 정보만 확인한다.
- 홍달마트 흐름이 1.0 화물/용달 운송 흐름과 3.0 음식점 일반 배달 흐름을 침범하지 않는다.
