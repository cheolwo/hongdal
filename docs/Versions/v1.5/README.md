# Hongdal 1.5

## 목표

판매 물류와 창고 기반 출고/재위탁 흐름을 1.0 운송 흐름 위에 얹습니다.

## 포함 범위

| 영역 | 내용 |
| --- | --- |
| 입고 | 계약 기반 입고, 현장 임시 입고, 주문 자동 입고 예정 |
| 적재 | 검수, 보관 위치, 재고 이동 기록 |
| 출고 | 주문 출고 알림, 피킹, 포장, 출고 예정 |
| 재위탁 | 창고 출고 후 화물/용달 운송 연결 |
| 작업자 검증 | 휴대폰 뒤 8자리, 작업대 바코드, 역할 확인 |

## 보류 범위

- 홍달마트 도심 즉시배송 실운영
- 해외 통관 자동화
- HS 데이터 유료 공유

## 우선 앱/모듈

- `WarehouseManagerApp`
- `ShipperApp`
- `OrdererApp`
- `Hongdal.Domain`
- `Hongdal.Infrastructure`

## 안정화 기준

- 입고, 적재, 출고가 각각 독립적인 업무 흐름으로 설명되고 기록된다.
- 주문 발생 시 판매자 창고에 출고 알림이 생성된다.
- 플랫폼 참여 주문자에게만 자동 입고 예정 연결을 시도한다.
- 창고 출고 연계 운송이 1.0 화물/용달 운송 흐름을 재사용한다.
