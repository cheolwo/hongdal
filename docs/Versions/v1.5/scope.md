# 문화교통 1.5 Scope

## 동결 상태

- 기준일: `2026-07-23`
- 상태: **기능 범위 동결**
- 허용 변경: 아래 포함 기능의 결함 수정, 보안·권한·데이터 무결성 보완, 테스트·마이그레이션·운영 증적
- 후속 버전으로 넘길 변경: 새 업무 영역, 실제 계약·결제·신고·운송·창고 실행, 자동 업체 선정·외부 자동 전송
- 동결 예외는 이 문서의 경계와 `SsalddelExecution:Mode`를 함께 검토한 명시적 승인 없이는 운영 노출하지 않는다.

| 기능 | 상태 | 경계 |
| --- | --- | --- |
| 국내외 공급자·관련 기업 조사 | 포함 | 출처, 확인 시각, 식별 근거 저장 |
| 견적·MOQ·납기·포장 조건 | 포함 | 유효기간과 통화·단위 필수 |
| 예상 총원가 비교 | 포함 | 확정 가격·세액으로 표시하지 않음 |
| 재료·상품의 HS·HTS 후보 | 포함 | 후보와 근거·검토 상태를 분리 |
| 수입식품·표시·해외제조업소 참고 | 포함 | 관계 기관·전문가 확인 대체 금지 |
| 기존 같이 수입 원장의 준비 블록과 계약 초안 | 포함 | 별도 준비 원장, 서명·결제·신고 실행 없음 |
| 개별수입 원장 확장 계약 | 포함 | `individual-import`는 `order`의 선택적 하위 원장이며 상품·수량·가격·서명 원본을 복제하지 않고 수입 준비·상태만 기록 |
| 수출 교류장과 선택적 환류 | 포함 | 기존 커뮤니티 게시글·비구속 관심·가원장을 조립하고, 관심·연락처·주문·수출·완료 공유 동의를 분리하며 마음이나 관심을 점수화하지 않음 |
| 개별수출 원장 확장 계약 | 포함 | `individual-export`는 `order`의 선택적 하위 원장이며 거래 원본을 복제하지 않고 수출자·구매자, Incoterms, 요건·서류, 신고·수리·적재와 대금 증빙을 기록 |
| 공동수출 물류 집계 원장 | 포함 | `group-export`에는 `individual-export`만 연결하고 집하·합포장·포워더 인계·공통비를 조율하되 수출자별 신고·서류·적재 실적을 보존 |
| 수출 신고 방식·규정 근거 | 포함 | 금액 기준을 코드에 고정하지 않고 공식 출처·시행일·사람 확인 상태를 저장하며 신고 제출은 실행하지 않음 |
| 수출 전략물자·원산지·FTA 검토 | 포함 | 엔진은 후보·누락만 제안하고 판정·허가·원산지증명 적용 여부는 전문 검토를 대체하지 않음 |
| 다중 재료 수요 묶음 | 포함 | 재료별 수량·단위·온도를 유지하되 B2B/B2C와 부가세 기준이 같은 수요만 한 원장에 결합 |
| 같이 수입 원장 거래 문맥 | 포함 | 원천 공동주문 원장을 참조하고 구매 조직 식별정보 없이 유형별 집계를 보존 |
| 포워더·물류대행업체 인계와 회신 기록 | 포함 | 사람이 업체를 정해 전달하며 OS 자동 선정·외부 자동 전송 없음 |
| 사용자 정보 전달 동의 | 포함 | 기본은 집계 정보, 사용자 단위 정보는 명시적 동의와 근거 필수 |
| 1.5 OS 상태·정기 점검 | 포함 | 기존 같이 수입 원장의 근거 최신성·handoff만 조율 |
| KAMIS·USDA·기업 근거 공유 배치 | 포함 | 기존 Quartz 등록을 재사용하고 수동 점검은 외부 호출 없음 |
| 관리자 수동 점검·재시도·전문 검토 인계 | 포함 | 멱등 키·Revision·사람이 정한 수신자 기록 필수 |
| 해외 선적·국내 운송 실행 | `2.0`으로 인계 | 운송 수행자 자동 선정 없음 |
| 입고·재고·판매 이행 | `2.5`로 인계 | 창고 상태 변경 없음 |

## 동결된 전용 진입점

| 원장 | API | UseCase | 화면 |
| --- | --- | --- | --- |
| 개별수입 | `POST /api/v1/orderer/order-ledgers/{orderLedgerId}/individual-import-ledger` | `I무역확장원장UseCase.개별수입생성Async` | `/orderer/ledgers/individual-import` |
| 개별수출 | `POST /api/v1/orderer/order-ledgers/{orderLedgerId}/individual-export-ledger` | `I무역확장원장UseCase.개별수출생성Async` | `/orderer/ledgers/individual-export` |
| 공동수출 | `POST /api/v1/orderer/group-export-ledgers` | `I무역확장원장UseCase.공동수출생성Async` | `/orderer/ledgers/group-export` |

세 진입점은 모두 원천 거래 원본을 복제하지 않고, 서버에서 권한·멱등 키·Revision과 원장 조합 규칙을 검증한다. `1.5`에서는 계약·결제·신고 제출·포워더 자동 선정·외부 자동 전송 플래그를 `false`로 저장한다.
