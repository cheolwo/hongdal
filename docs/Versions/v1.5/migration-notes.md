# 문화교통 1.5 Migration Notes

## 2026-07-22 · 무역 준비 재분류

- 기존 `2.0` 통관·HS 범위를 `1.5` 공급·가격·무역 준비로 앞당겼습니다.
- HS 검토, 수입식품 표시·해외제조업소, 같이 수입 HS와 기존 같이 수입 원장의 준비 블록 API 메타데이터를 `1.5`로 이동했습니다.
- 과거 `같이 수입 준비 원장` 표현은 별도 원장 유형을 뜻하지 않습니다. 정식 `group-import` 하나에 1.5 준비 블록을 병합합니다.
- 기존 `CustomsHsV20` 설정은 호환 별칭으로 유지하고 신규 설정은 `CustomsAndTradeDataWorkflow`를 사용합니다.
- 기존 `1.5` 창고 범위는 `2.5`로 이동했습니다.
- HTTP route와 기존 원장 ID는 변경하지 않습니다.
