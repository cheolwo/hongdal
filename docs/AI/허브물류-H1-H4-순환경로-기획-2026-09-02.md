## H1~H4 계층

### H1 — 개별 시설과 이동 운송대

- 차량·운송 수단 등록소
- 화물 검수·접수장
- 하역 대기장
- 창고 입출고장
- 출차·운송 완료 확인소
- 중계소·검문소·안전 거점
- 운송대 편성: 교체 가능한 운송 수단, 운전, 선택적 호위·정비/응급·화물 관리 역할, 적재 화물, 선택 경로

등록과 검수는 서로 다른 H1이다. 차량·운송 수단은 통과했지만 화물이 검수에서 보류되는 상태를 허용한다.

### H2 — 완결 순환과 운송 실행 패턴

- 시설 H1들과 일방통행 도로를 묶은 허브 물류 순환 구역
- 보행·손수레, 짐승·마차, 트럭, 마력 운송 등 운송 수단별 순환
- 출발 H1, 도로 엣지, 선택적 중계 H1, 목적지 H1, 도착·회수 결과를 묶은 운송 실행 패턴

H2 완료는 하역으로 끝나지 않는다. `입차 → 등록 → 검수 → 하역 대기 → 창고 입출고 → 출차 확인 → 허브 이탈`까지 닫혀야 한다.

### H3 — 복합 운송 허브

- 공통 입구와 행정 기록
- 운송 수단별 H2와 전용 차로·하역 설비
- 공용 창고와 목적지 배정
- 손수레·마차·트럭·마력 운송 수단 사이의 환적

외곽·농촌은 인력 운반·손수레·짐승·마차, Town은 대형 마차와 혼합 운송, City는 트럭·화물차, 마법 기술권은 마력 운송체까지 사용할 수 있다. 이는 외형만의 차이가 아니라 속도·적재량·노면 요구·유지비·정비·기상 저항·필요 NPC 역량에 영향을 준다.

### H4 — 허브 중심 지역 물류권과 Graph Map 단위

Graph Map 한 장의 우선 범위는 H4 하나다. 첫 H4는 `허브 중심 지역 물류권`이며, 실제 목적 영역이 미정인 외부 연결 노드는 Farm·Town·City로 추정하지 않는다. H3 허브와 외부 연결점, 주도로·비포장도로, 중계 거점, 기상·위협·물류·플레이어 선택 레이어를 함께 관리한다.

## 입고·출고 순환

모든 화물은 등록·검수 관문을 통과한다. 창고 처리 뒤에는 두 경로를 허용한다.

- 적재 없음: `창고 처리 → 출차 확인 → 빈 운송 수단 출차`
- 확정 출고 있음: `출고 지시 확인 → 화물 적재 → 출차 확인 → 적재 운송 수단 출차`

출고 적재 전에는 다음이 필요하다.

- 목적지 H1
- 수령 주체
- 운송 담당
- 사용할 도로 경로
- 출발 가능 시간
- 화물 수량과 상태 판본

하나라도 없으면 화물은 `출고 대기`로 남는다. 출차 확인은 반입 처리 결과, 잔여 화물, 회수 용기·반품, 이상 사항, 다음 목적지 또는 운송 종료를 기록하는 마지막 관문이다.

## 경로 선택과 화물 분할

시스템은 거리·시간·금전·기상·노면·위협·검문·보급·휴식·예상 손실을 가진 후보 경로를 계산하지만 자동 확정하지 않는다. 플레이어 또는 권한을 받은 NPC가 근거를 본 뒤 경로를 선택하고 선택 당시 판본을 남긴다.

화물은 상황에 따라 하위 운송 묶음으로 분할할 수 있다. 차량 적재 한도, 도착 시한, 여러 목적지, 긴급 물량, 경로 위험 분산이 대표 사유다. 출발 뒤 재분할·합류·차량 교체·경로 변경은 일반 도로 위가 아니라 중계소·검문소·안전 거점 H1에서만 허용한다. 전체 완료는 모든 하위 묶음이 도착·회수·손실 가운데 하나로 정리됐을 때 성립한다.

## 중계와 운송대 역량

장거리 중계·휴식 H1은 권장이지 절대 통행 조건이 아니다. 운송 수단과 NPC 역량이 충분하면 무정차 통과를 선택할 수 있다. 준비가 부족하면 다음 위험이 커진다.

- 운전자·동행대 피로
- 운송 수단 고장
- 화물 품질 저하·파손
- 야간·악천후 노출
- 몬스터·산적 대응력 저하
- 구조·회항 부담

운송대 H1의 역할은 운전, 호위, 정비·응급, 화물 관리로 구분하되 모두를 강제하지 않는다. 한 NPC가 여러 역할을 겸할 수 있고 누락된 역할에 대응하는 위험만 상승한다. 운송 수단은 손수레·짐승·마차·트럭·마력 운송체를 교체 가능한 슬롯으로 둔다.

## 도로와 승격

운송은 등록된 도로 엣지를 따른다. 플레이어 보행의 도로 밖 탐색과 화물 운송 판정은 분리한다.

- 주도로: 빠른 운송, 높은 처리량과 적재 안정성, 유지비 필요
- 비포장도로: 느리고 기상 영향이 크지만 초기 경로·우회로로 사용
- 위협 레이어: 몬스터·산적·붕괴·검문으로 어느 도로든 비용 증가·일시 봉쇄 가능

도로는 새 안정 ID로 교체하지 않고 같은 엣지의 판본화된 상태로 승격한다.

`자연 통행로 → 정비된 비포장도로 → 주도로 → 특수 운송 대응도로`

승격은 교통량 조건으로 잠그지 않는다. 현재 정체·손실·미운송 재고, 비용·유지비와 예상 처리량·시간 절감, 도로만으로 해결되지 않는 위협을 보여 주고 사용자가 선택한다.

## 도로 공사 시간과 위험

- 주간 공사: 안전하지만 기존 운송량과 통행에 부담
- 야간 공사: 주간 운송을 유지하지만 몬스터·마물·인건비 위험 증가
- 분할 공사: 일부 통행을 유지하지만 기간 증가
- 긴급 전면 공사: 빠르지만 운송 중단과 비용 증가

야간 공사에는 경비대·조명·마법 보호 자원을 배치해 위험을 낮출 수 있다. 배치한 자원과 NPC는 해당 시간 동안 다른 임무에 동시에 사용할 수 없다. 따라서 야간 공사의 안전을 높이면 다른 도로·거점의 경비나 대응 여력이 낮아질 수 있으며, 사용자는 공사 속도·주간 운송 유지와 지역 전체 안전 사이의 대가를 확인하고 선택한다.

## 공사 진행·파손·복구

도로 공사는 작업 교대마다 구간별 진행도를 누적한다. 몬스터 습격·홍수·산사태·폭설처럼 실제 사건이 발생하면 미완성 구간뿐 아니라 이미 완료한 구간도 파손될 수 있다. 전체 진행도를 일괄 초기화하지 않고 피해 구간만 다음 상태로 관리한다.

- 정상
- 경미 손상
- 중대 손상
- 통행 불가

완료한 주도로가 중대 손상을 입어도 곧바로 비포장도로로 강등하지 않는다. `파손된 주도로` 상태로 남겨 기존 안정 ID·건설 이력·기반 시설을 보존하고, 처리량·허용 중량·속도·적재 안정성을 낮춘 제한 통행과 긴급 보수를 허용한다. 완전 유실이 확인된 구간만 별도 재건 판정을 연다.

긴급 보수는 통행량을 임시로 회복하지만 정식 보수를 대체하지 않는다. 직후에는 안전 유예가 있으며, 유예가 끝난 뒤 누적 하중이 커질수록 노면 재파손·차량 손상·화물 쏠림·전복·연쇄 정체·도로 차단·구조 비용·납기 실패·인명 피해의 위험이 상승한다. 사고는 유예 종료 즉시 확정하지 않는다.

안전 유예는 단순 경과 시간보다 다음 누적 통행 하중을 중심으로 소모한다.

- 차량 자체 중량과 화물 중량·적재 방식
- 통행 횟수, 속도와 급제동
- 비·눈·결빙·침수
- 몬스터 습격과 충돌
- 긴급 보수 품질과 사용 자재

권한을 가진 운영 주체는 차량 중량 제한·속도 제한·일방 교대 통행을 설정해 처리량을 낮추는 대신 긴급 보수 수명과 안전을 늘릴 수 있다. 정확 하중 공식·유예 시간·사고 확률은 실제 표본 전까지 미정이다.

## 역할별 권한과 업무 위임

도로 운영 정책은 플레이어라는 이유만으로 모두 사용할 수 있는 기능이 아니다.

- 모험가 플레이어: 도로 상태 관찰, 위험 신고, 현장 구조, 표지 설치 보조, 통행 제한 준수
- 운송 책임자: 배차 조정, 운송대 우회, 화물 우선순위 변경
- 성주·소가주·지역 행정 책임자: 중량·속도·교대 통행, 도로 공사·긴급 보수·정식 복구 승인
- 경비 책임자: 위험 구간 봉쇄, 호위·순찰·야간 공사 경비 배치
- 기술 책임자: 안전 평가와 보수 완료 확인

모험가는 단순 레벨이나 호감도만으로 행정 권한을 얻지 않는다. 위험 도로의 정확한 보고, 화물·생존자 구조, 운송 약속 이행, 공동 행동 성공, 책임 있는 기록, 관련 퀘스트의 현장 판단처럼 실제 인과가 쌓이면 권한자가 임시 권한을 위임할 수 있다.

임시 권한은 사건·경로·권역·업무·복합 단위 가운데 인과와 위임자의 판단에 맞는 범위를 가진다. 위임 기록은 대상 범위, 허용 행동, 유효 기간, 예산 한도, 보고 대상, 회수 조건을 명시한다. 반드시 한 도로로 제한하지 않으며, 관계와 역량이 충분하면 여러 도로나 일정 기간의 물류 운영까지 넓어질 수 있다.

플레이어는 자기 권한 범위 안에서 친분 NPC·용병대·운송 책임자·상단 관리자·기술자·경비대에 업무를 위임할 수 있다. Graph Map은 `플레이어 권한 → 위임 약속·계약 → 담당 NPC·조직 → 실행 경로 → 결과 보고`를 연결하고, 담당자의 역량·성향·가용 자원과 실제 수행 결과를 분리한다.

위임 결과의 최종 운영 책임은 위임한 플레이어에게 남는다. 플레이어는 담당 NPC의 실제 수행·보고·규칙 준수와 자기 지시·자원·기한·담당자 선정 근거를 함께 보고 재기회·교육·휴식·동행 배치·보직 변경·권한 축소·해임을 선택한다. NPC 처분으로 플레이어의 잘못된 지시나 부족한 지원 책임을 지우지 않는다. 불가항력·역량 부족·부주의·명령 위반·고의 은폐의 정확 판정과 처분 기준은 후속 질문으로 남긴다.

## NPC 사건 성장·성향 단서와 로컬 LLM 대사

NPC는 실패·사고·구조·복구를 겪으며 회복·위협·숙련·관계·신뢰와 행동 경향이 변할 수 있다. 실패가 항상 하락만 뜻하지 않는다. 책임을 다하고 경험을 학습한 긍정적 NPC는 회복과 관련 숙련이 오를 수 있고, 공포·죄책감·부상·압박을 크게 받은 NPC는 위협이 오를 수 있다. 재도전·회피·과잉 자신감·신중함·책임 전가 같은 경향은 한 사건으로 확정하지 않고 여러 사건과 실제 행동 기록에서 점차 드러낸다.

플레이어는 처음부터 숨은 성향 이름과 정확 수치를 모두 보지 않는다. 사건 보고, 대화, 표정·행동 변화, 약속 이행과 동료 평가를 단서로 읽는다. 충분한 관찰·관계·적법한 역할 접근이 쌓이면 `압박 속에서도 회복이 빠름`, `위험을 과소평가하는 경향`처럼 더 명확한 분석을 열 수 있다. 이 단서는 NPC를 자동 처분하거나 유죄로 확정하지 않고 플레이어 판단을 돕는다.

기존 [로컬 NPC 대화·검색 지원 기반](../Architecture/PlayableLoops/로컬Npc대화지원기반.md)을 재사용할 수 있다. 로컬 LLM은 같은 Session·Revision에서 해당 NPC가 알 수 있는 다음 제한 사본을 입력으로 받아 짧은 대사 후보를 만들 수 있다.

- 현재 회복·위협의 공개 가능한 범주와 최근 변화 원인
- 실제 참여 사건·역할·부상·실패·복구·약속 이행 기록의 허용된 요약
- NPC가 스스로 경험했거나 적법하게 보고받은 사실
- 현재 플레이어와의 관계·위임 범위·대화 상황
- 성향을 확정값으로 노출하지 않는 관찰 가능한 행동 경향

LLM 대사는 비권위 표현이다. 회복·위협·성향·숙련·신뢰 수치를 만들거나 바꾸지 않고, 실패 원인·책임·처분·보상·퀘스트 완료·권한 위임을 확정하지 않는다. 다른 NPC의 비공개 정보, 숨은 세계 상태, 전체 원장, 운영 개인정보를 입력하지 않는다. 기능 비활성·모델 없음·근거 없음·취소·오류·오래된 응답에는 같은 플레이를 막지 않는 기본 대사를 사용한다. 실제 모델 추론·NPC 화면·Game View와 대사 품질은 별도 증거다.

## 레이어와 Graph Map 반영

- 기준 공간: H1~H4, 공통 입구, 일방통행 순환, 도로·중계·외부 연결
- 기상·시간: 노면, 공사 시간, 야간 위험, 관측 신선도
- 운송: 운송 수단별 통과·속도·적재·정비·휴식
- 위협·경비: 몬스터·산적·호위·조명·마법 보호·통행 봉쇄
- 물류·보급: 입고·재고·출고·분할 묶음·기한·병목·환적
- 플레이어 선택: 경로, 운송대, 분할, 중계 생략, 도로 승격, 공사 시간, 제한 통행, 권한 위임과 업무 배정

같은 안정 노드·엣지를 레이어별로 복제하지 않는다. 미정인 거리·비용·용량·확률·좌표는 `Unknown` 또는 `Blocked`로 유지한다.

## Synty Presentation E4 조사 요구

개발 통합 담당은 기존 13팩 기능 대장과 `needs-review` 활용 프로필, 실제 Prefab·meta·GUID와 기존 이미지·manifest를 먼저 재사용해 다음 후보를 조사한다.

- 등록·검문 부스, 화물 검수·하역 설비, 창고·야적장
- 도로·비포장길·울타리·표지
- 손수레·마차·짐승·트럭과 대체 운송 수단
- 공사 도구·조명·경비 시설·마법 보호의 대체 표현

후보·대체·fallback·미확인·구매 필요를 분리한다. 이 조사는 Presentation E4 준비이며 실제 자산 채택, Scene 배치, Play Mode, Game View, E5 증거가 아니다.

## 확정하지 않은 것

- 외부 연결 노드의 실제 Farm·Town·City 결속
- 정확 거리·비용·용량·시간·위험 확률
- 실제 도로 좌표·노면·교차로·회전 반경
- 운송 수단·시설의 최종 Prefab
- 도로 하중·안전 유예·사고 위험의 정확 공식과 수치
- 불가항력·역량 부족·부주의·명령 위반·고의 은폐의 판정·처분 기준
- NPC 회복·위협·성향 단서의 정확 수치·공개 문턱·대사 품질 기준
- Goal·WI·PlayableLoop·E7 작업 명세와 구현 순서
- 서버·Simulation·Unity 권위 결속, Scene·Save·Replay

## 인계 경계

Graph Map 담당은 기존 안정 ID를 우선 대조해 레벨 1 관계와 레벨 2 제약만 필요한 범위에서 증분 반영한다. 기획에 없는 공간·수치·게임 규칙을 보완 창작하지 않는다. 레벨 3은 기존 코드 후보 조사와 미결속 표시까지만 허용하며, 실제 개발 활성화에는 별도의 Goal·WI·승인 작업 명세가 필요하다.
