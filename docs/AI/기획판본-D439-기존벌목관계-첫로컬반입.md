# D439 첫 로컬 반입 — 기존 벌목 WI와 나무 대상

이 문서는 [D439 파이프라인](../Architecture/기획판본-서버반입파이프라인.md)의 최소 실제 반입 단위다. [D435](../Reports/WI문서-게임객체-D435-개발통합-2026-08-31.md)에서 이미 등록한 나무 정의를 재사용하며 새로운 벌목 규칙·객체·Prefab을 선택하지 않는다. 같은 객체/WI에 이번 기획 문서의 별도 문맥과 판본을 연결한다. 기존 D435의 문맥/관계 행은 그대로 보존한다.

지금은 기존 벌목 시작 조건이 갖춰진 시점이다. 여기에서는 Nature의 서 있는 나무를, 나는 기존 생존 플레이어로서 장착된 도구와 함께 선택하여 벌목 작업을 시작한다. 시작과 완료는 다르며 후속 진행/완료 조건은 기존 WI가 소유한다. 다음 선택은 기존 작업의 진행·중단 조건을 확인하는 것이다. 이 문서는 실제 작업을 실행하지 않는다.
