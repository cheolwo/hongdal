# Ssalddel Current Work

> GPT Chat과 Codex가 다음 작업을 이어받기 위한 최신 상태판이다. 완료 이력을 누적하지 않으며 장기 결정은 [DECISIONS.md](DECISIONS.md), 세부 설계와 과거 근거는 연결된 Architecture 문서를 따른다.

## 현재 목표

- `Nature 생존 생활거점`을 첫 실제 플레이 폐루프로 완성한다. 안전 빈터 등장 → 도끼 획득 → 벌목 → 통나무 → 오두막 → 황혼 위협 → 전투/후퇴 → 회복·재출발을 먼저 닫고, Nature↔Farm 및 다른 영역 연결은 별도 통합 slice로 다룬다.
- 공식 Unity 진입점은 `SimulationWorldShell` 하나로 유지한다. 검토·실험 Scene과 Fixture는 실제 서버 플레이 및 완료 증거와 분리한다.
- 운영 서버, Simulation 상태, Unity 표현의 책임을 분리한다. 운영 자료는 승인·동기화·세션 동결을 거쳐 정보와 제안으로만 사용하며 자동 생산량·수익·사건 규칙을 만들지 않는다.
- 공간은 `H1 작업공간 → H2 블록 → H3 경관 → H4 AreaSet → H5 세계 배치`, 증거는 `E0~E9`, 관리 체계는 `G1~G4`로 분리해 판정한다. E의 판정 주체는 WI 또는 WI 폐루프이며 E4는 실행 문맥 결속, E5는 결정적 세계 발현이다. H·AreaSet·Graph는 필요한 WI의 조건부 공간 증거이고 G 작업 완료나 공간 조립 출력은 E 승격을 대신하지 않는다.
- H 공간 깊이와 공간 형성 방식을 분리한다. LH가 기본 결과를 조립한 `LhComposed`, 플레이어 Confirm으로 성립한 `PlayerComposed`, LH 기본 공간에 플레이어 변경분이 누적된 `HybridEvolving`을 사용한다. 플레이어는 H1을 직접 조립하지만 H2는 H1 집합, H3는 H2 폐루프에서 성장 판정하며 현재 단계에서 H4를 직접 생성하지 않는다.
- 모든 게임 작업은 플레이어가 상황과 욕구를 보고 선택의 대가·재료·위험을 비교하고, 획득·배정·조립한 결과를 체감해 귀환 또는 다음 선택으로 이어지는 폐루프에서 시작한다. E1~E9는 이 폐루프가 각 증거 단계에서 실제로 성립하는지 검토하고, H1 직접 조립과 H2/H3 성장 판정을 분리한다. 플레이어 중심 관점은 Unity 상태 권위나 E7 증거를 앞당기지 않는다.
- 의미 있는 새 게임 작업과 권위·저장·Replay·Local/Remote Adapter 리팩토링은 E9 안정 세계 목표부터 E1 계약까지 먼저 영향을 검토한다. 가장 낮은 미완료 의존성부터 구현하고 E1→E9 상향 조립·증거를 확인한 뒤, 새 영향이나 계약 변경이 발견되면 같은 명세를 다시 E9→E1로 검토한다. 안정 또는 명시적 차단까지 왕복하며 기준 E8·Migration·회귀가 없으면 E9 승격 가능 상태로 표시하지 않는다.
- 새 기능 수를 늘리기보다 현재 세로 조각의 Solo 로컬/Hosted 서버 권위, Save/Replay, Unity 실제 실행 증거를 먼저 닫는다.
- Nature 위협 제거가 발생 업무 영역의 독립 발전으로 돌아오는 첫 통합 조각은 Farm으로 제한한다. 현재는 즉시 경로 안전, 사건당 한 번의 발전 기회, 플레이어가 재료·노동·시간을 들여 세 H1을 조립하고 H2 독립 준비를 여는 Simulation 기준선까지 구현하며 WI-FARM-07~09와 Unity 귀환 팔레트는 다음 관문으로 남긴다.
