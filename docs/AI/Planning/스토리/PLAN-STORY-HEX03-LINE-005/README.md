## 원문과 출처

> 九五：屯其膏；小貞吉，大貞凶。

- 출처: [《周易》 제3괘 屯](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E5%B1%AF)
- 평이한 의미: 감당 가능한 작은 질서를 지키는 것은 길하지만 성급히 크게 벌이면 어려워진다.
- Mirror 서사 해석: 세계를 한 번에 바꾸기보다 한 생명 무리와의 반복 돌봄에서 책임의 크기를 배운다.

## 이야기

- 발단: 임시 보호 중인 숲닭이 농장에 머물지 떠날지 망설인다.
- 등장 주체: 플레이어, 균형을 살피는 한스, 자발적으로 선택하는 숲닭 무리.
- 장소: 작은 은신처·먹이·물·안전한 출구가 이어진 농장 가장자리.
- 사건: 플레이어가 첫 돌봄을 직접 하고 한스와 작은 질서의 한계를 확인한다.
- 선택: 현재 무리만 안정시키거나 더 크게 확장하려 한다.
- 대가: 작은 범위를 지키면 확장이 늦고, 무리하게 넓히면 돌봄이 흩어진다.
- 결과: 반복 돌봄이 안정되면 숲닭이 자발적으로 머물며 농장 식량 회복의 작은 가능성이 열린다.
- 실패: 자원이 부족하거나 위협이 커지면 무리는 죽지 않고 야생으로 떠난다.
- 회복: 보호 환경을 다시 갖추고 떠난 무리가 돌아올 여지를 남긴다.
- 귀환: 한스에게 일상 돌봄을 부탁해도 플레이어의 책임과 결과 기록은 사라지지 않는다.
- 다음 가능성: 더 큰 위협 앞에서 무엇을 지키고 무엇을 잃을지 선택한다.

## 확정 / 미정 / 다음 질문 하나

- 확정: 한 종·한 무리의 작은 질서부터 안정시키며 성급한 대규모 확장은 하지 않는다.
- 미정: 자발 정착과 불안·이탈을 이야기에서 보여 줄 구체 징후.
- 다음 질문 하나: 한정된 준비로 모든 것을 지킬 수 없을 때 무엇을 선택할까?
