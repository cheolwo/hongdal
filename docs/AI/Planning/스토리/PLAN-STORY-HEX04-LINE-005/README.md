## 이야기 씨앗

- 발단: 플레이어가 막힘을 인정하고 구체적으로 묻는다.
- 등장 주체: 플레이어, 답을 바로 주지 않는 스승, 행동의 영향을 받는 상대.
- 장소: 질문을 곧바로 작은 행동으로 확인할 수 있는 현장.
- 사건: 스승이 답 대신 관찰할 한 가지를 알려 준다.
- 선택: 조언을 실제로 시험하거나 듣는 데서 멈춘다.
- 대가: 재시도에는 시간과 겸손이 필요하다.
- 결과: 행동과 결과의 관계를 스스로 설명할 수 있게 된다.
- 실패: 말만 외우면 다른 상황에서 다시 막힌다.
- 회복: 무엇이 달랐는지 질문하고 한 번 더 시도한다.
- 귀환: 이해한 내용은 스승의 권위가 아니라 플레이어의 경험으로 남는다.
- 다음 가능성: 배운 힘을 공격이 아니라 보호에 사용한다.

- 미정: 플레이어가 스스로 설명해야 할 관계.
- 다음 질문 하나: 재시도 뒤 플레이어는 무엇을 말로 설명할 수 있어야 할까?
