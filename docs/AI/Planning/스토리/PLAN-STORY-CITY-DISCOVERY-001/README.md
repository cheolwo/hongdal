## 첫 공간 골격

City의 첫 중심은 행정 시설과 시장만 있는 장식 광장이 아니다. 중앙 생활권 옆에 상차장과 하차장을 붙여, 시장의 물품이 어디서 들어오고 나가는지 공간적으로 이해할 수 있게 한다.

```text
성문·주 진입로
  → 중앙 생활권
      ├─ 행정 시설
      ├─ 시장·상점가
      └─ 물류 연결 통로
           ├─ 하차장
           └─ 상차장
                → 도시 외부 주도로
```

- 상차장과 하차장은 서로 인접하지만 같은 작업점을 공유하지 않는다.
- 시장과도 가까워야 하지만 시민의 주 보행로를 대형 화물차가 가로막지 않는다.
- 행정 시설에서는 공개 가능한 물류 요약과 허가·일정 후보를 볼 수 있으나 현장 작업을 직접 대신하지 않는다.
- 시장에서는 상품의 도착·부족·출고 흔적을 읽을 수 있지만 실제 재고 권위는 별도 상태가 소유한다.
- 상하차장은 City의 생활감을 보여 주는 활동 공간이지만 차량 도착만으로 입고·출고 완료를 만들지 않는다.

## City의 H2·H3·H4 규모 규칙

City는 이름만으로 H 단계를 고정하지 않는다. H 단계는 행정상 명칭이 아니라 실제 공간 조립 범위로 판정한다.

| 단계 | City에서의 역할 | 첫 후보 |
| --- | --- | --- |
| H1 | 플레이어가 관찰하거나 사용하는 개별 행동·공간 역할 | 행정 창구·건물 입구, 시장 상점·진열점, 상차 작업점, 하차 작업점, 차량 대기점, 보행 횡단점 |
| H2 | 여러 H1을 한 번에 배치·운영할 수 있는 기능 블록 | 행정 구역, 시장·상점가, 상차·하차 물류 구역, 선택 주거·생활 구역 |
| H3 | 여러 H2를 도로·경계·연결구로 묶은 하나의 City 구역 | 행정 H2·시장 H2·물류 H2가 연결된 `City 중앙 업무권`, 주거·생활 H2를 묶은 별도 `City 주거권` |
| H4 | 여러 H3와 외부 연결을 묶은 광역 지역 청사진 | 중앙 업무권 H3, 주거권 H3, 선택 외곽 생산·산업권 H3와 성문·주도로를 포함하는 `광역 City` 후보 |

첫 플레이 가능한 City 범위는 H3 `City 중앙 업무권`으로 둔다. 이 범위만으로 행정 조회, 시장 활동, 상·하차 흐름과 다음 거리 선택이 충분히 성립하면 H3에서 멈춘다. 주거·생활 시설은 중앙 업무권에 흩어 넣지 않고 별도 H3 `City 주거권`으로 묶는다. 두 H3와 선택 외곽 산업권·복수 성문·권역 간 도로까지 함께 다뤄야 할 때만 H4 `광역 City` 후보로 올린다.

### 중앙 업무권 H3와 주거권 H3의 연결

- 시민은 보행로·대중 이동·생활 서비스 연결을 통해 두 H3를 자연스럽게 오갈 수 있다.
- 시장의 소규모 생활 배송은 주거권 가장자리까지 들어갈 수 있지만 대형 상하차 차량의 주 통과로는 주거 중심을 우회한다.
- 중앙 업무권의 소음·먼지·야간 작업 조명은 완충 거리·건물 전면 방향·녹지 또는 벽체 후보로 주거권과 분리한다.
- 주거권에서 중앙 업무권의 활동을 전혀 알 수 없게 막지는 않는다. 원경 표지, 도로 흐름, 출퇴근 NPC로 두 권역의 관계를 읽게 한다.
- 이 연결 원칙은 Graph Map 관계와 배치 맵 제약 후보다. 정확 도로 수·거리·운송 수단·Prefab을 확정하지 않는다.

### 주거권의 첫인상은 생활 동선으로 읽는다

- 주거권 H3는 주택 외형만 나열하지 않고 출근·귀가, 생활 배송, 장보기, 휴식, 공공시설 이용처럼 시간대에 맞는 주민 이동으로 생활권임을 보여 준다.
- 주민 이동은 중앙 업무권 H3의 행정·시장·물류 기능과 이어지되 모든 NPC가 같은 시각에 같은 경로를 반복하지 않는다.
- 대형 화물 주 통과는 주거 중심을 우회하고, 소형 생활 배송·서비스 차량과 보행은 주거 가장자리의 허용 접점만 사용한다.
- 이동 표현은 근무 완료·구매·배송 완료를 대신하지 않는다. 실제 일정·목적지·업무 결과가 있을 때만 해당 상태를 표시한다.

## City의 메인 퀘스트 중심 안내

City에는 여러 일반 퀘스트가 존재하지만, 플레이어가 무엇을 해야 할지 잃지 않도록 현재 장의 메인 퀘스트를 안내 골격으로 유지한다.

- 파란 `?`는 일반 퀘스트 후보, 금색 `?`는 메인 퀘스트 후보, 초록 `!`는 실제 목표 충족 뒤 완료 보고 가능 상태라는 기존 기준을 재사용한다. 색만이 아니라 문양·텍스트·화면 읽기 이름을 함께 사용한다.
- City 첫 진입에서는 현재 메인 이야기의 목적과 다음으로 확인할 대표 장소를 퀘스트 기록과 지도에서 쉽게 다시 찾을 수 있게 한다. 자동 수락·자동 이동·강제 카메라는 사용하지 않는다.
- 일반 퀘스트는 행정 H2·시장 H2·물류 H2·주거 H3의 사람과 시설을 이해하거나 문제 해결 준비를 돕는다. 무관한 반복 완료 횟수로 메인 퀘스트를 열지 않는다.
- 메인 퀘스트는 필요한 사람·시설·문제 원인·준비 결과가 실제로 갖춰졌을 때 열리며, 같은 준비 목적에는 대화·조사·운반·제작·전투 등 여러 일반 경로를 허용할 수 있다.
- 플레이어는 메인을 잠시 추적 해제하고 일반 퀘스트·공방·시장·자유 탐색을 할 수 있다. 다시 메인을 선택하면 현재까지 확인한 근거와 다음 가능한 지점을 보여 준다.
- 한꺼번에 보이는 표식을 제한하고 가까운 문맥·현재 추적·새로 공개된 후보를 우선한다. 지도 전체를 퀘스트 아이콘으로 채우지 않는다.

### 메인 퀘스트 길 안내 강도

- 메인 퀘스트를 추적하면 기본 화면에는 화면 가장자리의 간결한 목적지 방향과 짧은 현재 목표만 표시한다.
- 거리 전체를 덮는 선·연속 화살표·자동 카메라 회전은 기본으로 켜지 않는다.
- 플레이어가 지도에서 `경로 보기`를 선택했을 때만 현재까지 발견한 도로·통로·출입구를 이용한 상세 후보 경로를 표시한다.
- 후보 경로는 이동 명령이나 안전 보장이 아니다. 도로 차단·시간 제한·위협·권한·일방통행 상태가 바뀌면 현재 정보로 다시 계산하거나 `경로 불확실`을 보여 준다.
- 미발견 지름길·숨은 출입구·적의 위치와 아직 알지 못하는 퀘스트 단서를 경로선이 먼저 공개하지 않는다.
- 방향 표시·목표 문구·지도 경로는 각각 끌 수 있고, 색 외 형태·텍스트·진동·읽어주기 후보를 제공한다.

- City H3는 H2 이름만 나열해서 성립하지 않는다. 각 H2 사이에 시민 접근, 화물 접근, 행정·거래 정보 연결과 외부 출구가 있어야 한다.
- H4는 큰 배경 장식이나 많은 Prefab의 동의어가 아니다. 독립적으로 읽히는 H3 둘 이상과 그 사이의 이동·물류·경계 관계가 필요하다.
- H2·H3·H4 후보 등록은 실제 Unity 배치나 E5 성립을 뜻하지 않는다. Graph Map 계보, 배치 맵 제약, WI와 표현 후보가 같은 판본으로 결속된 뒤 별도로 검증한다.

## Graph Map과 배치 맵 분리

Graph Map은 `성문 진입`, `행정 접근`, `시장 관찰·거래`, `하차 인수`, `상차 출고`, `도시 외부 연결`의 노드·엣지를 분리한다. 상차와 하차는 반대 방향의 물류 의미를 가지므로 하나의 포괄 `화물장` 엣지로 축약하지 않는다.

배치 맵은 다음 공간 제약을 준비한다.

- 하차 차량 진입·대기·하역·빈 차량 이탈 동선
- 상차 차량 진입·대기·적재·출발 동선
- 시장 보행자와 상하차 작업자의 안전 완충
- 중앙 생활권에서 작업 흐름은 인식되지만 차량·적재물이 행정 시설 정면을 가리지 않는 시야
- 소음·먼지·야간 조명과 시장·행정 공간 사이의 완충
- 비상차량·수레·마차·트럭의 서로 다른 회전 반경과 하역 높이 후보

인접은 같은 좌표나 무제한 혼합을 뜻하지 않는다. 실제 거리·높이·차선 수·차량 수·출입 통제는 미정이다.
