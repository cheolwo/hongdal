## 원문과 출처

> 六四：乘馬班如，求婚媾，往，吉无不利。

- 출처: [《周易》 제3괘 屯](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E5%B1%AF)
- 평이한 의미: 믿을 관계를 구하고 함께 나아가면 막힘 속에서도 길을 찾을 수 있다.
- Mirror 서사 해석: 권한은 소유가 아니라 책임질 수 있는 범위를 함께 정하는 약속이다.

## 이야기

- 발단: 깊은 숲으로 돌아가지 못한 작은 숲닭 무리가 농장 경계에 나타난다.
- 등장 주체: 플레이어, 보호 범위를 정하는 한스, 겁먹은 숲닭 무리.
- 장소: 한스가 지정한 농장 가장자리의 작은 보호 구역.
- 사건: 한스는 농장 전체가 아닌 제한된 구역에서만 임시 보호를 허락한다.
- 선택: 보호 책임을 받아들이거나, 준비가 부족함을 인정하고 보류한다.
- 대가: 보호를 맡으면 먹이·물·안전한 출구를 돌봐야 하고 다른 일의 시간이 줄어든다.
- 결과: 책임을 지키면 숲닭이 해를 입지 않고 잠시 머문다.
- 실패: 준비 없이 붙잡거나 소유하려 하면 무리가 불안해져 떠난다.
- 회복: 출구를 열고 부족한 돌봄을 보완한 뒤 다시 접근한다.
- 귀환: 임시 보호가 끝나도 한스의 농장 소유권과 플레이어의 손님 지위는 변하지 않는다.
- 다음 가능성: 작은 무리가 자발적으로 머물 수 있는 돌봄 질서를 시험한다.

## 확정 / 미정 / 다음 질문 하나

- 확정: 보호권은 한스가 정한 범위와 책임 안에서만 유효하다.
- 미정: 숲닭이 스스로 머물기로 판단하는 이야기 징후.
- 다음 질문 하나: 한 무리를 돌보는 작은 질서를 언제 안정되었다고 볼까?
