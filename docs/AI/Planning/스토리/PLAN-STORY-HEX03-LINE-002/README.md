## 원문과 출처

> 六二：屯如邅如，乘馬班如，匪寇婚媾，女子貞不字，十年乃字。

- 출처: [《周易》 제3괘 屯](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E5%B1%AF)
- 평이한 의미: 다가오는 상대를 성급히 적이나 동료로 단정하지 않고 시간을 들여 뜻을 확인한다.
- Mirror 서사 해석: 말보다 함께 겪은 행동과 결과가 관계의 첫 근거가 된다.

## 이야기

- 발단: 손님이 된 플레이어와 한스는 아직 서로를 충분히 알지 못한다.
- 등장 주체: 플레이어, 한스, 피해를 입을 수 있는 농장 경계.
- 장소: 생활주택에서 울타리와 숲 가장자리로 이어지는 농장 둘레.
- 사건: 둘이 경계를 함께 돌며 피해 흔적과 취약 구간을 확인한다.
- 선택: 함께 순찰하거나, 다른 공동 작업을 제안하거나, 지금은 관계를 깊게 하지 않는다.
- 대가: 한 작업에 시간과 체력을 쓰는 동안 다른 생활과 이동이 늦어진다.
- 결과: 약속한 구간을 끝까지 확인하면 다음 공동 행동을 제안할 첫 신뢰 근거가 생긴다.
- 실패: 작업 실패를 배신이나 영구 관계 악화로 확대하지 않는다.
- 회복: 실패 원인을 함께 확인하고 역할을 바꾸거나 다시 시도한다.
- 귀환: 체류 선택과 이미 고친 공간은 별도로 보존된다.
- 다음 가능성: 낯선 흔적을 발견했을 때 사실과 추정을 구분한다.

## 확정 / 미정 / 다음 질문 하나

- 미정: 공동 순찰에서 서로가 확인해야 할 최소 약속.
