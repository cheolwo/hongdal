## 원문과 출처

> 初九：磐桓，利居貞，利建侯。

- 출처: [《周易》 제3괘 屯](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E5%B1%AF)
- 평이한 의미: 처음에는 성급히 멀리 나아가지 않고 머물 자리를 바로 정해 작은 기반을 세운다.
- Mirror 서사 해석: 낯선 세계에서 첫 관계를 소유가 아니라 허가받은 머묾으로 시작한다.

## 이야기

- 발단: 플레이어가 손상된 울타리를 수리한 뒤 한스가 결과를 확인한다.
- 등장 주체: 나무꾼의 몸에 빙의한 모험가, 농장 주인 한스, 손님을 받아들일 생활 공간.
- 장소: 숲 경계의 한스 농장과 생활주택.
- 사건: 한스가 안전하게 머물 손님 자리를 제안한다.
- 선택: `머문다 / 지금은 떠난다` 가운데 하나를 명시한다.
- 대가: 머무르면 다른 지역으로 떠나는 시점이 늦고, 떠나면 안전한 휴식과 소량 보관 이용이 늦어진다.
- 결과: 수락하면 손님으로서 제한된 체류가 열리고, 보류하면 제안이 남는다.
- 실패: 오래된 제안이나 대상 불일치, 명시 선택 없음은 관계를 바꾸지 않는다.
- 회복: 최신 제안과 한스의 상태를 다시 확인해 선택한다.
- 귀환: 떠났다가 돌아와도 완료한 수리와 관계의 첫 근거는 보존된다.
- 다음 가능성: 한스와 실제 공동 작업으로 서로의 태도를 확인한다.

## 확정 / 미정 / 다음 질문 하나

- 확정: 체류는 한스의 제안과 플레이어의 명시 선택으로만 성립하며 농장 소유·운영권을 주지 않는다.
- 미정: 실제 체류가 어느 생활 경험까지 이어지는지.
- 다음 질문 하나: 한스와 신뢰를 확인할 첫 공동 작업을 무엇으로 삼을까?
