## 원문과 출처

> 九二：包蒙吉，納婦吉，子克家。

- 출처: [《周易》 제4괘 蒙](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E8%92%99)
- 평이한 의미: 배우는 이의 미숙함을 품되 책임을 감당하도록 길러 주는 것이 길하다.
- Mirror 서사 해석: 좋은 스승은 대신 싸우지 않고 초보자가 기본 행동을 성공시켜 자기 힘으로 책임을 맡게 한다.

## 이야기

- 발단: 로웬이 경비대원 알렉스를 플레이어의 첫 훈련 파트너로 배정한다.
- 등장인물: 플레이어, 경비대원 알렉스, 경비대장 로웬.
- 장소: 경비대 훈련장과 의약품·보존식량을 싣는 북쪽 경비 거점.
- 사건: 플레이어는 알렉스와의 모의전에서 도끼 전투술의 기본 공격과 기본 방어를 차례로 익힌다.
- 선택: 상대의 틈만 노리기보다 공격 뒤 방어 자세로 돌아오는 기본을 지킨다.
- 대가: 빠른 승리보다 반복 훈련과 알렉스의 교정을 받아들여야 한다.
- 결과: 성공한 공격·방어 행동이 플레이어의 경험으로 남고, 이데아 맵에 두 기술이 처음 드러난다.
- 실패: 공격만 서두르면 알렉스의 반격에 자세가 무너진다.
- 회복: 알렉스가 거리를 다시 잡아 주고 플레이어가 기본 공격과 방어를 한 번씩 재현한다.
- 귀환: 로웬은 훈련 결과를 확인한 뒤 플레이어와 알렉스에게 의약품·보존식량 호송을 맡긴다.
- 다음 질문: 실제 호송 중 예상하지 못한 위협 앞에서 플레이어는 배운 기본과 책임을 함께 지킬 수 있을까?

## 확정 / 미정 / 다음 질문 하나

- 확정: 알렉스가 모의전을 통해 도끼 기본 공격·방어를 가르치고, 성공한 행동 기록을 통해 이데아 맵에 두 기술이 발현된 뒤 호송이 시작된다.
- 미정: 모의전의 세부 대사와 호송 마차의 정확한 편성.
- 다음 질문 하나: 깊은 숲의 위협이 나타났을 때 플레이어는 무엇을 먼저 지켜야 할까?
