## 목적

수뢰둔에서는 낯선 세계에서 직접 행하고 성찰하며 **혼자 읽을 수 있는 기초 이데아 맵**을 익힌다. 상육의 부분 손실에서 운영과 방어의 학습 필요를 발견한 뒤, 산수몽에서는 멘토에게 관계를 교정받고 후속 실제 행동으로 이해를 검증한다.

이데아 맵은 새 권위 원장이 아니다. 기존 `ActionRecord`, 플레이어 분야 Profile, 명상 기여, NPC 학습중점의 활성·효과 기록을 같은 revision에서 읽어 만든 파생 조회 결과다.

## 수뢰둔의 여섯 학습 국면

| 효 | 이데아 맵 학습 역할 |
| --- | --- |
| 초구 | 장소와 무관하게 첫 유효한 플레이어 행위가 기록되면 `RecentExperience`가 생기고 기초 보기가 열린다. 한스 울타리 수리는 대표 표본일 뿐 필수 해금 장소가 아니다. |
| 육이 | 한스와 농장 경계를 함께 순찰하며 `행동 → 직접 결과 → 관계 변화`를 처음 읽는다. |
| 육삼 | 흔적에서 확인한 사실과 아직 검증하지 않은 원인 추정을 분리하고, 안내 없는 추격을 멈춘다. |
| 육사 | 한스가 준 제한 권한을 `권한 → 책임 → 돌봄 대상` 관계로 읽는다. |
| 구오 | 실제 돌봄의 반복과 명상으로 후보 관계 일부를 검증하되 대규모 질서로 성급히 일반화하지 않는다. |
| 상육 | 부분 손실을 복기해 `운영 학습 필요`와 `방어 학습 필요` 두 개만 연다. 스킬·능력치·카드를 즉시 지급하지 않는다. |

## 산수몽 괘상 맥락 카드

산수몽은 여섯 효를 차례대로 통과해야 닫히는 선형 퀘스트가 아니다. 시스템이 현재의 학습 필요와 실제 행위 이력을 근거로 `괘상 맥락 카드`를 제안하고, 플레이어가 수락하거나 보류한다. 아르카나 카드와 NPC 학습 카드는 그대로 별도 슬롯과 권위를 유지한다.

- 한 번에 주 괘상 맥락 하나만 활성화하며 다른 제안은 대기한다.
- 수락 자체는 지식·숙련·능력치를 지급하지 않는다.
- 농사·탐험·전투·물류 등 자유 행동을 막지 않는다.
- 발단이 된 학습 필요 하나를 관련 실제 행동과 결과 기록으로 확인하면 해소할 수 있다. 육효 전부를 한 활성화에서 볼 필요는 없다.
- 활성 맥락은 해소되거나, 완료된 `ActionRecord`가 있는 안전한 활동 경계에서 플레이어가 해제할 때까지 유지한다.

## 산수몽의 여섯 독립 공명 원형

고전 원문은 [《周易》 蒙](https://zh.wikisource.org/wiki/%E5%91%A8%E6%98%93/%E8%92%99)을 기준으로 대조한다. 원문과 프로젝트의 게임 번역은 분리한다.

| 효 | 원문 | 게임 기획 번역 |
| --- | --- | --- |
| 초육 | `發蒙，利用刑人，用說桎梏，以往吝。` | 먼저 배울 길을 하나 고른다. 한스의 운영·위임 또는 훈련 교관의 방어 기초를 택하되, 규칙을 익히지 않고 계속 나아가면 막힌다. |
| 구이 | `包蒙吉，納婦吉，子克家。` | 멘토가 흐릿한 핵심 관계 하나를 바로잡고 플레이어에게 재현 과제를 준다. |
| 육삼 | `勿用取女，見金夫，不有躬，无攸利。` | 원리 없이 화려한 고급 결과를 모방하는 유혹을 보여 주며, 모방만으로 숙련을 지급하지 않는다. |
| 육사 | `困蒙，吝。` | 같은 방법을 되풀이하며 막히면 관계를 `NeedsCorrection`으로 표시한다. |
| 육오 | `童蒙，吉。` | 질문하고, 행동하고, 피드백을 받고, 다시 시도하여 이해를 검증한다. |
| 상구 | `擊蒙，不利為寇，利禦寇。` | 배운 것을 공격적 과시에 쓰지 않고 농장·사람·보급로를 지키는 데 적용한다. |

육효는 runtime 해금 순서가 아니라 실제 행위의 의미를 읽는 독립 공명 원형이다. 한 활성화에서 일부만 나타날 수 있고, 보지 못한 원형은 이후 산수몽 맥락에서 다시 나타날 수 있다. 현재 Logic E3는 성공·멘토 참조·의미 있는 실패·후퇴/회복처럼 `ActionRecord`로 검증 가능한 공명만 기록한다.

## 자유 플레이와 지리 학습

지리 학습은 특정 효에 고정하지 않는 횡단 배경이다. 산수몽 맥락을 처음 받아들일 때 한스의 설명으로 현재 위치·농장·가까운 생활권을 보여 주는 기초 지도를 열 수 있다. 이후 소문, 설명, 탐험, 호송의 실제 기록으로 도로·경계·위험 지역의 의미가 누적된다. 요동성 호송은 선택 가능한 학습 사건이지 산수몽 완료 조건이 아니다.

## 멘토 역할

- 한스: 운영, 위임, 자원 배분, 생활 질서
- 경비대장: 방어 기록을 검토하고 훈련 교관을 소개하는 연결자
- 훈련 교관: 자세, 거리, 병목, 위협 대응의 실제 교정

멘토 효과는 `관계 교정 + 이후 관련 실제 행동의 제한된 성장`이다. 현행 NPC 학습중점과 산수몽 맥락 보정은 서로 다른 효과 출처로 같은 실제 행동에 가산된다. 각 출처는 한 `ActionRecord`·세부 숙련마다 한 번만 적용되며 총합 상한을 두지 않는다. 대기, 카드 장착 자체, 취소된 행위에는 성장을 주지 않고 같은 기록은 멱등 처리한다.

## 이데아 맵 계약

초기 노드 종류는 `RecentExperience`, `ReflectionSeed`, `ObservedUnskilled`, `FragmentCandidate`, `LearningNeed`, `VerifiedKnowledgeSkill`이다. 초기 엣지 종류는 `ObservedFrom`, `ReflectionOf`, `CauseHypothesis`, `NeedsCorrection`, `MentoredBy`, `VerifiedBy`다.

- 실제 기록 없이 추론한 노드와 엣지는 만들지 않는다.
- 상육의 두 `LearningNeed`는 후속 권위 계약이 생기기 전까지 기획 요구로만 남긴다.
- 전역 명상 숙련과 이데아별 이해도·현장 숙련도·운영 숙련도를 서로 다른 값으로 보여 준다.
- 현재 Logic E1~E3는 계약, 결정적 파생, LocalProcess·HTTP 조회와 시험까지만 포함한다.
- 산수몽 제안·수락·보류·안전 경계 해제, 활성 맥락, 효 공명과 보정 영수증은 NPC 학습중점 Save/Replay 사본에 함께 보존한다.
- Unity UI, Graph Map 표현, 애니메이션, Scene, Play Mode, Game View와 Presentation E4 이상은 포함하지 않는다.

## 확정·미정

- 확정: 수뢰둔은 독학의 기초, 산수몽은 멘토 교정과 재현 학습이다.
- 확정: 첫 이데아 맵 보기는 특정 장소가 아니라 첫 유효 행동 기록으로 열린다.
- 확정: 멘토가 직접 성장을 지급하지 않고 후속 실제 행동이 이해도 `+1`을 만든다.
- 확정: 이데아 맵은 파생 조회이고 Simulation 권위 상태를 변경하지 않는다.
- 확정: 산수몽은 독립 맥락 카드이고 육효는 선형 진행 관문이 아니다.
- 확정: 한 학습 필요를 실제 행동으로 확인하면 맥락을 해소할 수 있다.
- 미정: 산수몽 카드 UI, 기초 지도 Presentation, 효별 추가 판정 근거와 정확 H·표현.
