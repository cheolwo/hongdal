## 이야기 씨앗

- 발단: 플레이어가 같은 방법을 거듭하지만 상황이 나아지지 않는다.
- 등장 주체: 플레이어, 막힘을 지켜보는 스승, 영향을 받는 상대.
- 장소: 같은 실패가 되풀이되는 현장.
- 사건: 노력은 이어지지만 결과는 달라지지 않는다.
- 선택: 고집을 이어가거나 멈추고 다른 관점을 청한다.
- 대가: 멈추면 당장의 성과는 늦지만 더 큰 손실을 막는다.
- 결과: 막힘을 인정하면 교정을 받을 수 있다.
- 실패: 반복을 숨기거나 남의 탓으로만 돌리면 관계가 멀어진다.
- 회복: 실패의 공통점을 함께 찾아 다시 시작한다.
- 귀환: 중단은 포기가 아니라 배움으로 돌아가는 길이다.
- 다음 가능성: 질문하고 행동하며 이해를 검증한다.
