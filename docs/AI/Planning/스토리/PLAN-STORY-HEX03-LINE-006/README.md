## 이야기

- 발단: 육삼에서 확인한 위협이 가까워지고 준비할 시간이 짧다.
- 등장 주체: 플레이어, 한스, 숲닭 무리, 작물 구역, 울타리와 정체 미상의 위협.
- 장소: 세 보호 대상과 위협 진입로가 한눈에 이어지는 한스 농장.
- 사건: 현재 인력과 자원으로는 숲닭·작물·울타리 가운데 둘만 온전히 지킬 수 있다.
- 선택: 플레이어가 맡을 대상, 한스에게 부탁할 대상, 부분 손실을 감수할 대상을 정한다.
- 대가: 선택하지 못한 한 대상에는 회복 가능한 손실이 남는다.
- 결과: 위협이 물러난 뒤 보호와 손실, 직접 행동과 부탁한 역할을 함께 복기한다.
- 실패: 준비가 부족하면 손실이 커질 수 있지만 사람·동물의 죽음이나 농장 전멸로 확대하지 않는다.
- 회복: 떠난 숲닭의 재정착, 작물의 재파종, 울타리의 수리 가운데 해당 회복을 시작한다.
- 귀환: 손실과 회복 가능성을 숨기지 않고 다음 방문에서도 읽을 수 있게 남긴다.
- 다음 가능성: 운영과 방어 가운데 지금 먼저 배워야 할 길을 정한다.

## 확정 / 미정 / 다음 질문 하나

- 확정: 세 대상 중 둘을 보호하고 하나의 회복 가능한 부분 손실을 받아들인다.
- 확정: 복기는 즉시 보상을 주지 않고 운영과 방어의 학습 필요를 드러낸다.
- 미정: 플레이어가 먼저 청할 배움과 그 선택의 관계적 대가.
- 다음 질문 하나: 한계를 인정한 플레이어는 누구에게 어떤 배움을 먼저 청할까?
