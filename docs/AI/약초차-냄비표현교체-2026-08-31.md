# 약초차 냄비 표현 후보 교체

- 판본: `herbal-pot-visual-replacement.r1` / D385 / 2026-08-31.
- 상태: `ApprovedDirection`. 사용자가 좁은 목의 병 형태인 기존 냄비 후보 대신 다른 Prefab을 찾아 적용하도록 요청했다.
- 대상: 기존 `playable-loop:nature-basic-herbal-recovery.v1`의 냄비 표현. [HB01 추가 승인](../Architecture/PlayableLoops/Nature약초차-HB01개발승인보완.md)과 현재 Required 연구·E 상한은 유지한다.

## 교체 기준

1. 실측 이미지에서 병 형태로 판독된 `SM_Prop_Camp_Pot_01`은 이번 약초차 **냄비 역할 후보에서 제외**한다. 원본 자산·기존 검증 자료는 삭제하지 않으며 다른 용도의 적합성은 이번에 결정하지 않는다.
2. 보유 Synty 자산에서 입구가 넓고 내부에 물·약초를 담아 달이는 조리 용기로 읽히는 대체 Prefab을 찾는다. 이름에 Pot이 있다는 이유로 통과시키지 않는다. 화분·병·막힌 소품과 구별하고 위/옆 실제 외형을 확인한다.
3. 개발이 공간 담당에게 기존 재고 조사와 단독 Editor 격리 미리보기/실측을 배분한다. 정확한 GUID/hash, 열린 입구·내부 면, 크기·pivot·Collider, 열원 위 배치·접근점 적합성과 수정 필요를 확인한다. 후보 수를 채우기 위한 광범위 조사는 하지 않는다.
4. 기준에 맞는 기존 Prefab이 확인되면 개발이 선정 이유와 후보 비교 근거를 기존 연구의 후속 판본 및 명세에 추가 결속하고 승인된 표현 범위에서 교체 적용한다. 단순 후보 선택을 사용자에게 다시 묻는 대기를 만들지 않되, 새 형상 가공·미확인 권리·공간 기준/게임 의미 변경이 필요하면 그 부분만 반환한다. 적합 후보가 없으면 병을 냄비로 재사용해 성공 처리하지 않는다.

## 유지할 경계와 결과

- 냄비의 게임상 보관/가열 능력과 용량은 기존 계약으로 판정한다. 메시 크기에서 리터를 역산하거나 외형만으로 가열·달이기 성공을 주장하지 않는다. 이번 요청으로 용량·수율·연료·시간·음용 규칙은 바꾸지 않는다.
- Mug01은 이번 교체 대상이 아니다. 기존 Collider0과 음용/손 접촉 미검증을 그대로 남긴다.
- 원기획·원후보 hash는 과거 기준으로 보존하고 대체 관계를 명시한다. 기존 자산 원본 변경/삭제, 무관한 Scene 저장, 새 구매·패키지 설치·commit/push는 하지 않는다. canonical 적용은 기존 본인 변경 저장·복구 기준 안에서만 수행한다.
- 반환은 **선정 Prefab과 이유 → 실제 격리 이미지 → 교체한 참조/배치 → 실제 게임 연결 여부** 순서다. 격리 미리보기와 Game View를 구분한다. 실제 화면은 공간 담당, 검토·통합 및 CURRENT_WORK/기존 시각 목차 갱신은 개발 담당이다. 기존 승인 개발과 D383 동작 비교를 중단하지 않는다.
