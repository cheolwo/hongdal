## 목적

최근 확정한 이야기·전투·Hub 기획 가운데 실제 Prefab·Actor·동작 후보가 필요한 역할을 기획 단계에서 선별한다. 개발은 이미 MySQL에 축적한 보유 Synty 14,461개와 Prefab 4,221개 목록, 기존 기능 분류와 이미지 근거를 먼저 조회하고, 공간·애니메이션 담당에게 필요한 소수 후보의 Presentation E4 조사를 나눠 맡긴다.

이 인계는 Prefab 선택·가공·구매·다운로드·Unity Scene 배치·Play Mode·Game View·E5를 승인하지 않는다. 이름이 비슷하다는 이유로 적합성을 확정하거나 조사 이미지를 실제 게임 화면으로 보고하지 않는다.

| --- | --- | --- |

## 신규 또는 보완 조사 우선순위

### P0 — 첫 플레이 인과에 직접 필요한 표현

| 조사 묶음 | 기획 역할과 판독 순간 | 조사할 후보 | 반드시 구분할 결과 |
| --- | --- | --- | --- |
| 한스 집의 손상→수리 중→수리됨 | 플레이어가 목재를 두고 떠난 뒤 돌아와 집의 변화를 알아차림 | 기존 한스 집 후보, Construction 비계·사다리·목재 보강재·공사 소품, 호환 수리 완료 변형 | 원본 그대로 재사용 / 상태 덧입힘 / 격리 복사본 가공 필요 / 적합 후보 없음. 구멍 표현의 Blender 필요 여부 별도 |
| 한스의 검과 첫 순찰 현장 도구 | 집 안의 관리된 검 단서, 첫 순찰에서는 검 대신 평범한 도구 사용 | 검·검집·비전투 받침/벽걸이, Farm 농기구·현장 도구, 손 장착 후보 | 집 안 소유물·손 장착·검집·스케일·Rig/Animation 호환 분리. 검 첫 전투 사용은 보류 |
| 첫 경계 마수 무리 | 더 깊은 숲에서 밀려 내려온 굶주린 무리와 비정상 이동 단서 | 보유 동물형/마수형 Actor, 사람형 undead fallback, 상처·영역 흔적·발자국/부서진 표식 소품 | `동물형 적합 / 사람형 범주 대체 / 부적합 / 미확보`. Dungeon Realms 후보가 있다는 이유로 굶주린 야수로 확정 금지 |

D-554 P0 파일 조사 뒤 D-555에서 첫 경계 마수는 동물형·야수형 의미를 유지하고 현재 Demon/Undead 사람형 후보는 `적합 자산 미확보 / 보류`로 확정했다. P1·P2 조사는 계속하되 이 보류를 해제하거나 사람형 fallback을 주 후보로 승격하지 않는다.

## 개발과 전문 담당의 반환 형식

각 조사 묶음은 다음을 반환한다.

1. 기획 결정·WI 후보·플레이어 판독 순간·H/Graph Map 역할.
2. 기존 MySQL/기능 대장에서 조회한 후보와 제외 이유.
3. 실제 경로·GUID·원천 팩·Prefab/meta fingerprint.
4. 공간/소품은 외형 이미지, 크기·Pivot·Renderer/Collider/Bounds, 지지·통행·상호작용 Anchor 후보.
5. Actor는 Prefab·Avatar·Rig, Idle/이동/행동 Clip, root motion·Controller·중단/귀환·접촉 후보.
6. `그대로 재사용 / 연결·설정 보완 / 격리 가공 필요 / 신규 제작·구매 필요 / 미검사·미확보` 판정과 근거.
7. 파일 확인·격리 Preview·실제 Unity 대상/Scene 검증을 서로 다른 증거로 표시.
8. 주·대체·fallback 후보와 열린 결함. 적합 후보가 없으면 억지 대체하지 않는다.

## 소유와 실행 경계

- 개발: 기존 DB·자산 기능 대장 조회, 중복 조사 제거, 작업 명세 `presentationE4Preparation` 결속, 결과 통합·검증.
- 월드·공간·배치: 집·공방·Hub·몬스터/소품 후보의 외형·크기·Pivot·Collider·Bounds·지지/통행 조사와 필요한 격리 Preview.
- 애니메이션: 한스·견습·기사·몬스터의 Rig/Avatar·Clip·Controller·접촉·중단/귀환 조사.
- 기획: 후보가 플레이어 약속을 바꾸는 경우만 재결정한다. 개발·전문 결과가 완전히 반환되기 전까지 기다리지 않고 다른 기획 문답을 계속한다.

조사 중 새 팩 구매, 원본 Prefab 수정, Blender 가공, Scene 저장, 실제 배치·입력·Game View가 필요해지면 해당 단계에서 별도 승인으로 돌린다. 이번 승인 범위는 보유 자산과 기존 근거를 사용한 조사·격리 미리보기·E4 준비 기록까지다.
