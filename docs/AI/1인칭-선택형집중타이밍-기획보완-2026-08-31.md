- 날짜: 2026-08-31
- 기획 판본: `first-person-optional-focus-timing.r4`
- 결정 식별: D419 / D420 / D421. r1~r3은 D417/D418 동결 검증과 분리해 작성했고, 검증 종료 뒤 r4에서 공통/DECISIONS 연결과 명시 의미ID 표를 추가했다. r3의 답변 의미는 변경하지 않는다.

- 1인칭의 가까운 관찰과 직접 조작을 살려, 적절한 타이밍에 버튼을 누르거나 마우스를 클릭하고 성공 시 추가 효과를 얻는 체계를 특화해 발전시킨다.
- 시점 자체에 일률적인 능력치 배율을 주는 것이 아니라, 해당 WI에서 플레이어가 직접 참여한 집중 수행을 구별한다. 어떤 작업·시점에서 가능한지와 효과는 각각의 원문/명세를 따른다.
- 1인칭 특화는 다른 시점의 기존 집중 기능을 금지하거나 모든 WI를 1인칭 전용으로 바꾸는 결정이 아니다. D418의 사용 가능 여부·특화 편의·전용 제한 구분을 유지한다.

## 4. 기존 구현 재사용과 확인할 경계

아래는 기획의 파일 읽기 결과이며 새 시험·Unity 화면 결과가 아니다.

- [집중 판정 Policy](../../Ssalddel.Simulation.Domain/UnityPackage/Runtime/SimulationFocusTimingPolicy.cs): 정수 시간·왕복 위치에 따른 Perfect/Good/Miss/NoInput, Assisted/NeutralSkip 지원이 있다. 결과에 명상 경험과 회복 후보가 함께 들어 있으므로 새 WI 적용 때 효과를 함께 자동 승인하지 않는다.
- [집중 Profile](../../Ssalddel.Simulation.Domain/UnityPackage/Runtime/SimulationFocusProfileCatalog.cs): Nature `BeginHarvestWorldInteractionId`만 첫 적용으로 분류하고 다른 항목은 Pending/NpcOnly/Excluded 등으로 나눈다. 전 WI 또는 농사/양조까지 실제 연결됐다는 증거가 아니다.
- [Nature 집중 연결](../../Ssalddel.Simulation.Domain/UnityPackage/Runtime/SimulationNatureFocusMeditation.cs): 시작 명령·Challenge 판본·세계 개정·완료 행위 기록을 연결한다. UI 재조회/연타/시점 왕복/Save 복원으로 같은 회차의 성장을 중복 지급하지 않아야 한다.

개발은 기존 위 세 경로와 입력·표현 소비자를 읽어 현재 연결/미연결을 확인한다. 새 독립 집중 보상 엔진이나 1인칭 전용 복제 WI를 만들지 않는다. 기본 작업과 추가 도전의 상태, 입력을 받을 시점/주체, 한 회차 판정·적용 근거, 취소/시점 전환/재진입을 기존 명세에서 구분한다.

D421의 새 반복 기회는 기존 `SubmitNatureFocusTiming`의 제출 후 중복 거부 및 작업에 결속된 단일 Challenge와 차이가 있다. 실제 후속 동작에서 새로 시도하는 것과 동일 입력/판정의 재전송을 분리할 필요를 개발에 인계한다. 기존 멱등 검사를 없애거나 한 성공 결과를 여러 번 적용해서 반복 도전을 구현하지 않는다. 작업 동작·도전 회차·부모 작업/완료 근거의 정확 대응과 판본/저장 영향은 구현 전 검토하며 이 문서에서 신규 schema를 정하지 않는다.

기본 상호작용 클릭·공격·메뉴와 집중 입력이 겹치지 않게 하는 것은 기술 검토 항목이다. 기존 Space 전투 입력·짧은 마우스 클릭/중복 소비 문제를 다시 만들지 않고 명시적 입력 소유를 확인한다. UI 프레임이나 효과 재생만으로 성패·성장·작업 완료를 판정하지 않는다.

## 5. 제시 조건 확정 — 선택한 작업에서만 (D420)

- 의미 식별자: `first-person-focus-presentation-trigger`.
- 상태: `Confirmed` — r1의 Asked를 사용자 답변으로 대체한다.
- 질문: 타이밍 도전을 매 작업마다 자동으로 보여주기보다, 플레이어가 원할 때 ‘집중해서 하기’를 선택한 작업에서만 나타나도록 할까?
- 사용자 답변: “그래 그렇게 하는 게 좋을 것 같아. 원하는 작업에서 집중해서 하기를 선택했을 때만.”
- 확정: 타이밍 도전은 해당 작업의 집중 수행을 명시적으로 선택한 경우에만 제시한다. 1인칭 진입·대상 바라보기·일반 작업 시작만으로 도전을 자동 표시하지 않는다. 선택하지 않은 작업의 기본 진행은 유지한다.
- 선택의 대가: 풍경 감상과 평상시 작업을 반복 도전으로 끊지 않는 대신 집중 수행을 시작하는 선택이 필요하다. 안내 방식과 실제 UI는 후속 준비다.
- 이 선택만으로 타이밍 성공·추가 보상·기본 작업 완료가 되지 않는다. 해당 WI의 허용 조건·기본 비용·위험과 Q398/D366의 성공 추가 성장·미스/불참 기본 손실 없음은 그대로다.
- ‘집중해서 하기’의 의미는 확정하되 버튼 배치·정확 표시명·선택할 수 있는 순간·전체 작업 설정/선택 기억은 미정이다. 반복 기회와 작업 효율 방향은 D421로 보완하며 정확 횟수/수치, Town 양조 및 기존 다른 미답변을 승인한 것으로 보지 않는다.

### 반복 동작에서 계속 도전한다 (D421)

- 의미 식별자: `first-person-focus-attempt-count`.
- 상태: `ConfirmedDirection` — r2의 질문을 사용자의 다른 방향 답변으로 정리한다. 추천한 ‘작업당 한 번·미스 후 반복 재시도 없음’은 **미채택**이며 과거 확정 규칙이 아니다.
- 당시 질문: 집중 수행을 선택한 한 작업 회차에서는 타이밍 도전을 한 번만 하고, 놓쳐도 그 회차의 도전을 반복 재시도하지 않는 방식으로 할까?
- 사용자 답변 요지: 집중은 작업 한 번에 한 번만 하는 것이 아니다. 여러 번 도끼질하듯 작업 중 계속 시도할 수 있어야 하며, 세 번 중 한 번을 예로 들었지만 가능하면 찍을 때마다 기회를 제공하여 원하는 사람이 집중으로 더 빨리 작업을 끝내기를 원한다.
- 확정 방향: 집중을 선택한 작업의 유효한 반복 동작에서 계속 도전 기회를 제공한다. 한 번 실패했다고 전체 작업의 추가 기회를 소진시키지 않는다. 다음 동작의 실제 새 시도와 같은 판정 재전송은 구별한다.
- 선호와 미정: 가능하면 매 도끼질처럼 작업 리듬에 맞추는 쪽을 우선 검토한다. ‘세 번 중 한 번’을 고정 간격으로 만들지 않는다. 모든 WI의 동작 수·간격·한 동작 안에서의 재입력·정확 시간은 미정이다.
- 기존 Nature의 단일 Challenge/제출 중복 거부는 현재 구현 경계이지 이번 기획을 한 번 제한으로 되돌리는 근거가 아니다. 반대로 새 방향만으로 기존 저장/규칙 판본을 바꾸거나 중복 검사를 완화하지 않는다.

### 성공이 작업을 더 빨리 끝내는 데 기여한다 (D421)

- 의미 식별자: `first-person-focus-efficiency-bonus`.
- 상태: `ConfirmedDirection`.
- 기본 작업은 원래 조건과 속도로 진행하고, 유효한 집중 성공은 해당 작업의 진행/완료에 추가로 기여해 더 빨리 끝낼 수 있게 한다. 미스/불참은 그 기회의 추가 효율을 얻지 못할 뿐 기본 작업에 추가 손실을 만들지 않는다.
- 한 나무 작업의 예: 집중 수행 선택 → 도끼질과 타이밍 기회 → 실패하면 기본 진행 뒤 다음 도끼질에서 다시 도전 → 성공하면 추가 작업 기여 → 반복 → 권위 완료 조건에 도달하면 종료. 이는 설명 예시이며 도끼 타격 횟수·나무 내구도·추가 진척 수치를 정한 것이 아니다.
- 정확 효율 계산·상한·도구/체력/재료 소모·작업 완료 시점, 기존 고정 작업 시간과의 이행은 후속 명세에서 정한다. 완료된 작업/없는 대상에 도전을 반복해 진척이나 성장을 생성하지 않는다.
- 추가 명상 성장은 기존 방향을 유지하지만 반복 성공마다 작업 전체 성장량을 지급하거나 무제한 누적하는 것으로 해석하지 않는다. 반복 수행의 정당한 보상과 동일 성공의 중복 지급은 다르며 분배 단위·총량·적용 시점은 별도다.

## 6. 인계

D417/D418 동결 검증이 종료되어 r4에서 공통/DECISIONS에 연결·대체 관계를 추가했다. 개발은 이 최종 원문과 기존 시점 문서의 D162 이력 보완을 기존 조회에 한 번에 결속한다. r1 제시 조건 Asked→r2 Confirmed와 r2 1회 제한 질문 Asked→r3 반복 방향 ConfirmedDirection을 구별하며, 미채택 추천을 과거 확정으로 소급하지 않는다. r4는 그 의미를 유지하는 문서 연결 판본이다. 기존474항목/175회귀는 D417/D418 당시 검증이고 이번 네 의미ID의 통합 성공을 뜻하지 않는다.

개발은 기존 `docs/Reports/탐험운영시점-D417-기존구현대조-2026-08-31.md`의 D419 절에 기존 Q398/Policy/Profile·실제 입력 연결과 필요한 다음 범위를 반환한다. 별도 중복 대장/보고 체계는 만들지 않는다. 기획은 이 원문을, 개발은 문서/조회 검증·CURRENT/통합판을 소유하며 첫 적용 WI·정확 효과/빈도/입력·명세가 결속되기 전 새 게임 코드/Save·Scene·Editor/캡처·E승격·운영 연결·r129/야간·commit/push는 실행하지 않는다.
