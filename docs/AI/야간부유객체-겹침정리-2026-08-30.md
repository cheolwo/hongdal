# 야간 부유 객체·겹침 정리

- 판본: `overnight-floating-overlap-cleanup.r1`, D378, 2026-08-30.
- 승인 범위: 사용자가 현재 Unity 화면에서 지적한 공중의 흰색 객체 제거와 겹쳐 보이는 네모난 면의 조정. 정확한 객체/원인/수정 결과는 아직 미확인이다.
- [D376 배경 연속성 보완](야간월드경계보완-2026-08-30.md), [D377 전체 문답 통합](전체문답-E5세계통합계획-2026-08-30.md)의 추가 범위이며 기존 원문/hash·E상한·09시 안전마감을 보존한다.

## 식별과 수정

개발이 기존 공간 담당의 단독 Editor 슬롯에 이 항목을 합쳐 배분한다. 먼저 사용자가 지적한 현상을 Scene/Game View에서 구분해 캡처하고 객체 경로·Instance/Stable ID·원본/생성 주체·Renderer/Collider·상호작용·표현 계층·재생성 경로를 확인한다. 흰색이라는 이유만으로 일괄 삭제하지 않으며 기존 진단용 표시/Gizmo인지 실제 Renderer인지도 구별한다.

1. 화면상 부유 객체가 불필요한 임시/중복 표현임이 확인되면 프로젝트 소유 생성 경로에서 제거 또는 비활성화하고 재조립 때 되살아나지 않는지 검증한다. 의도된 상호작용 객체의 위치 오류라면 기능을 삭제하지 말고 승인된 배치/지지면으로 수정한다. 자산 원본 파일 삭제는 요청 범위가 아니다.
2. 네모난 겹침은 중복 바닥, 면 깊이 충돌(z-fighting), 회랑/선택/진단 표시, 셀 접합·재질 경계 등을 구분한다. 한 지지면의 권위와 유효 Collider를 보존하며 지면을 가리는 임의 높이 이동이나 넓은 지형 삭제로 해결하지 않는다. 승인 고정계획/연구를 바꿔야 하면 해당 부분만 반환한다.
3. 실제 대상 식별이 불가능하거나 여러 의미 있는 후보가 남으면 표시한 캡처와 후보를 반환하고 추측 삭제하지 않는다. 이 항목 때문에 독립 승인 작업은 멈추지 않는다.

## 검증과 보존

- 같은 카메라/시간의 UI 포함 실제 Game View 전후, 이동·통행/충돌·선택 영향, 해제/재조립/재진입 시 중복·부유 재발 여부와 Console을 확인한다.
- 생성 코드 수정은 집중시험/소비자 검증을 연결한다. Scene 수정은 변경 전 사본/차이를 보존하고 본인 변경만 분리 가능한 기존 저장 승인 범위에서 수행한다. 미소유 dirty 일괄 저장·폐기, 공급사 Prefab/자산 삭제, 강제 복구, 새로운 Scene·권위 상태/Save 변경은 하지 않는다.
- 개발이 작업 명세·담당/경로 소유에 추가 결속하고 실제 삭제/비활성/위치 수정한 정확한 대상과 복구 방법을 보고한다. 공간 결과→개발 직접 검토→기획 반환을 유지한다. 이번 문서는 화면 진단/수정 범위 승인이지 삭제 실행 또는 E5 완료 보고가 아니다.
