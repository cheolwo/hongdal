## 목적

거점 사이의 이동이 충분히 길면 플레이어가 장시간 아무 일도 없이 걷는 대신 정찰·준비·위험 대응·우회·귀환을 선택할 수 있어야 한다. 그러나 `거리가 길다`는 이유만으로 몬스터를 자동 생성하지 않는다. 장거리 경로는 위험에 노출될 기회를 늘리는 조건이고, 실제 조우는 생태·세계 상태·시간·경비·최근 사건과 함께 성립한다.

## 핵심 규칙

> 거점 간 경로의 연속 이동 부담이 커질수록 중간 구간과 안전점·위험 원천을 명시하고, 실제 위험 원천과 현재 조건이 함께 성립할 때만 몬스터 조우 후보를 연다.

경로 위험은 단일 거리 값이 아니라 다음을 함께 읽는다.

- 이동 거리와 예상 이동 시간
- 시야·엄폐·지형 병목·우회 가능성
- 절기·시간대·날씨
- 주변 서식지와 현재 몬스터 압력
- 경비·순찰·조명·통행량·최근 토벌 기록
- 가장 가까운 안전 거점 또는 후퇴 지점까지의 복귀 부담
- 플레이어·동행대의 정찰, 운송 화물, 소음과 이동 방식

정확한 미터·분·확률·개체 수는 이동 속도, 월드 규모, 실제 AreaSet과 Play Mode 검증 없이 만들지 않는다.

## 엣지는 연결선이 아니라 판본화된 운송 선택지다

같은 두 거점 사이에도 산길, 평지 도로, 강변길, 우회로처럼 여러 엣지가 있을 수 있다. 각 엣지는 최소한 다음 의미를 독립적으로 가진다.

- 출발·도착 거점과 방향성
- 경로 구간 목록과 현재 판본
- 예상 거리·시간·금전·연료·식량·도구 내구도 비용
- 화물 중량·부피·차량·동행대에 따른 통과 가능 여부
- 수송 용량과 시간창별 처리 가능량
- 몬스터·산사태·홍수·파손·검문·혼잡 등 확인된 위험과 불확실성
- `Open`, `Degraded`, `Blocked`, `Unknown` 상태와 그 근거·관측 시각
- 가장 가까운 우회·중간 안전점·귀환 경로

비용은 하나의 숨은 점수로만 합치지 않는다. 플레이어는 `가장 빠름`, `가장 안전함`, `가장 저렴함`, `대량 수송`, `균형`처럼 서로 다른 기준의 후보와 각 대가를 비교하고, 실제 사용할 경로를 명시적으로 선택할 수 있다. 추천은 선택을 돕는 후보일 뿐 자동 출발·자동 비용 지출·자동 계약 확정 권한이 아니다.

## Graph Map 레벨과 레이어를 구분한다

`레벨 1·2·3`은 같은 대상을 얼마나 깊게 설명하는지 나타낸다.

- 레벨 1: 플레이어가 무엇을 보고 선택하며 어디로 이어지는가
- 레벨 2: 자연스럽고 실행 가능하려면 어떤 배치·비용·통행 제약을 만족해야 하는가
- 레벨 3: 어떤 코드·계약·컴포넌트가 그 의미를 소비·검사하는가

`레이어`는 같은 안정 노드·엣지를 서로 다른 업무 관점으로 조회하는 방식이다. 레이어마다 노드와 엣지를 복제하거나 별도 세계를 만들지 않는다. 모든 레이어는 기준 topology의 안정 식별자를 참조하고 자기 판본·출처·관측 시각·적용 범위·미확정 값을 가진다.

| 레이어 | 주요 내용 | 허용되는 영향 | 금지되는 확대 |
| --- | --- | --- | --- |
| 기준 공간 레이어 | 거점, 교차로, 다리, 길, 방향, 물리 연결 | 다른 레이어가 참조할 topology 제공 | 날씨·운송 사유로 원본 노드·엣지를 조용히 생성·삭제 |
| 기상·시간 레이어 | 절기, 시간대, 비·눈·안개·바람, 관측 신뢰도 | 이동 시간·가시성·노면·위험·통행 후보 보정 | 날씨 표현만으로 실제 길 차단·몬스터 생성·화물 손실 확정 |
| 운송 레이어 | 도보·말·마차·차량별 통과, 거리·시간·비용·용량 | 가능한 운송 모드와 경로 후보 계산 | 후보 계산만으로 출발·계약·비용 차감·도착 확정 |
| 위협·경비 레이어 | 몬스터 압력, 습격, 순찰, 초소, 최근 토벌, 적대 점거 | 위험 비용·호위 필요·조우 후보·통행 상태 보정 | 근처 몬스터 하나로 보급망 전체 차단 |
| 물류·보급 레이어 | 출발 재고, 수요, 화물, 기한, 처리 용량, 인수·인계 | 대체 경로·총 수송량·병목·부족 상태 계산 | 엣지 차단만으로 재고 0·전투 패배·납품 완료 확정 |
| 플레이어 선택 레이어 | 빠름·안전·저렴·대량·균형 후보, 알려진 근거와 불확실성 | 후보 비교·경로 선택·재승인·우회 선택 | 숨은 정답 강제, 다른 후보 은폐, 자동 Confirm |

### 레이어 합성 순서

경로 후보는 다음 순서로 같은 topology를 읽는다.

```text
기준 공간 topology
  → 기상·시간에 따른 현재 통행 보정
  → 운송 수단별 통과 가능성·기본 비용·용량
  → 위협·경비에 따른 위험·호위·차단 후보
  → 화물·수요·기한에 따른 물류·보급 적합성
  → 플레이어에게 설명 가능한 대체 경로 후보 제시
  → 플레이어 또는 승인된 NPC 정책의 명시적 선택
```

앞 레이어의 원자료를 뒤 레이어가 덮어쓰지 않는다. 예를 들어 폭우는 기준 도로를 삭제하지 않고 `기상 레이어의 노면 악화`를 남긴다. 실제 통행 금지 기준을 넘으면 운송 레이어가 해당 수단을 제외하고, 그 결과 필요한 수송량을 보낼 다른 길이 없을 때 물류·보급 레이어가 보급망 차단을 판정한다.

### 레이어 충돌과 신선도

- 각 보정은 대상 노드·엣지, 기준 revision, 관측 시각과 근거를 가진다.
- 오래된 기상·정찰·경비 정보는 `Unknown` 또는 낮은 신뢰도로 표시하고 현재 사실처럼 합산하지 않는다.
- 같은 비용을 여러 레이어에서 중복 더하지 않는다. 예를 들어 눈길 지연을 기상과 운송 양쪽에서 각각 더하지 않고 기상 원인을 운송 시간 보정의 계보로 연결한다.
- 두 레이어가 충돌하면 더 위험한 값을 무조건 택하는 대신 권위·시각·범위를 비교하고, 해결되지 않으면 후보를 `Unknown` 또는 `Conditional`로 반환한다.
- 화면에서 레이어를 켜고 끄는 것은 조회 방식만 바꾸며 권위 상태·경로 비용·실제 운송 결과를 변경하지 않는다.

## 물류 운송·보급로 차단 규칙

몬스터 습격, 다리 파손, 기상 재해, 적대 세력 점거처럼 실제 사건이 경로 구간의 통행이나 처리 용량을 훼손하면 해당 엣지는 `Degraded` 또는 `Blocked` 후보가 된다. 몬스터가 근처에 있다는 사실만으로 곧바로 보급로 전체를 막지 않으며, 실제 통행 불가·호송 실패·위험 상한 초과·용량 부족과 같은 판정 근거가 필요하다.

`보급로 차단`은 엣지 하나의 상태와 구분한다.

- 특정 엣지가 막혀도 요구 물자·수량·기한을 만족하는 대체 경로가 있으면 보급로는 우회 가능하다.
- 출발지에서 목적지까지 현재 조건을 만족하는 경로가 하나도 없으면 `Blocked`다.
- 경로는 존재하지만 기한 안에 필요한 최소 수송량을 보내지 못하면 `InsufficientCapacity`다.
- 정찰되지 않아 비용·위험·통행을 판단할 수 없으면 `Unknown`이며 안전한 열린 길로 간주하지 않는다.
- 복구·토벌·호위·교량 수리·기상 회복의 실제 결과가 기록되면 같은 판본 계보에서 재평가한다.

따라서 보급품이 실제로 이동하지 못하면 전방 재고·의약품·식량·난방·탄약 같은 소비 상태에 지연 효과가 나타날 수 있지만, 엣지 차단만으로 재고를 즉시 0으로 만들거나 전투 결과를 확정하지 않는다.

## 경로 탐색 알고리즘 적용 원칙

알고리즘은 경로 후보를 계산하고 비교 근거를 만드는 도구이며 세계 상태나 플레이어 선택을 대신하지 않는다.

| 목적 | 우선 검토 알고리즘 | 적용 경계 |
| --- | --- | --- |
| 선택한 비음수 비용 기준의 한 최적 경로 | Dijkstra | 거리·시간·비용처럼 음수가 없는 동결 비용에 사용 |
| 좌표와 통과 가능한 공간 휴리스틱이 있는 이동 | A* | 실제 비용을 과대평가하지 않는 휴리스틱이 있을 때만 사용 |
| 서로 다른 여러 대체 경로 제시 | Yen의 K-최단 단순 경로 | 거의 같은 경로의 중복을 줄이고 소수 후보만 UI에 제시 |
| 시간·위험·금전·용량의 상충 비교 | 다목적 Pareto 전선 | 한 가중치로 숨기지 않고 지배되지 않는 후보와 대가를 표시 |
| 전체 보급량과 병목·차단 구간 분석 | 최대 유량·최소 컷 | 엣지 용량과 기간이 정의된 물류망에서만 사용 |
| 이동 중 엣지 차단·복구에 따른 재계산 | 증분 재탐색 후보(D* Lite 등) | 실제 동적 변경 빈도와 지도 규모를 검증한 뒤 채택 여부 결정 |

최단 경로 하나만 보여 주지 않는다. 기본 UI는 빠름·안전·저렴·대량 수송 후보를 함께 보여 주고, 경로별 시간·비용·위험·용량·불확실성과 차단 이유를 설명한다. 플레이어가 선택한 우선순위는 후보 정렬에 사용하지만 다른 경로를 숨기거나 선택을 강제하지 않는다.

## Graph Map 레벨 1 — 플레이 관계

```text
출발 거점
  → 화물·기한·호위·경로·준비 상태 확인
  → 빠름 / 안전 / 저렴 / 대량 수송 / 균형 후보 비교
  → 플레이어 경로 선택
  → 장거리 경로 구간 진입
  → 이동 / 정찰 / 우회 / 되돌아가기
  → 위험 징후 발견
  → 회피 / 준비 / 교전 / 대체 경로 전환 / 중간 안전점 이동 / 출발 거점 귀환
  → 이동 재개
  → 도착 거점
```

장거리 경로 하나를 거대한 단일 엣지와 한 번의 무작위 판정으로 처리하지 않는다. 플레이어가 읽고 선택할 수 있도록 `경로 구간`, `중간 안전점`, `위험 징후`, `조우 후보`, `귀환 지점`을 필요한 범위에서 분리한다. 모든 장거리 이동에 전투를 강제하지 않으며, 정찰·우회·순찰 강화·최근 토벌로 조우 없이 통과할 수도 있다.

## Graph Map 레벨 2 — 배치·조우 제약

### 장거리 경로 분절

- 연속 이동 부담이 관찰·선택·후퇴 없이 지나치게 커지는 경로는 둘 이상의 구간으로 나눈다.
- 구간 경계는 임의 거리 표지가 아니라 교차로, 계곡 입구, 숲 경계, 다리, 야영 가능 지점, 경비 초소처럼 플레이어가 판독할 수 있는 공간 변화 후보를 사용한다.
- 중간 안전점은 반드시 완전 무위험 장소가 아니며, 휴식·관찰·귀환 판단을 할 수 있는 상대적 안전 지점이다.
- 길이 끊기거나 통행 불가능한 지형을 몬스터 조우로 가리지 않는다. 통행·경사·Collider·복귀 가능성은 별도 공간 관문에서 먼저 검증한다.

### 조우 후보 성립

다음 세 조건이 모두 있어야 조우 후보를 열 수 있다.

1. 플레이어가 위험에 노출되는 실제 경로 구간을 이동한다.
2. 주변 서식지·침입 경로·최근 사건·권위 상태 가운데 현재 몬스터가 존재할 근거가 있다.
3. 시간·날씨·경비·통행·정찰 결과를 반영한 현재 조건이 조우를 허용한다.

길다는 이유만으로 몬스터를 무에서 생성하지 않는다. 승인된 동물형·야수형 의미와 실제 세계 상태를 사용하며, 적합 자산이 없다는 이유로 사람형 적을 대신 놓지 않는다.

### 자연스러운 배치와 안전

- 몬스터는 거점 안전 반경·출입구 바로 앞·플레이어 시야 한가운데에 갑자기 나타나지 않는다.
- 실제 접근 가능한 서식지·엄폐·진입 엣지에서 경로로 들어오며, 표현 생성 위치와 권위상 존재 위치를 구분한다.
- 연속된 모든 구간을 피할 수 없는 전투로 채우지 않는다. 한 경로 안에서 위험·완충·안전의 리듬을 둔다.
- 조우 뒤에는 진행, 우회, 중간 안전점, 출발 거점 귀환 가운데 현재 가능한 선택을 보존한다. 이야기상 퇴로가 막히는 사건은 별도 승인된 원인과 회복 경로가 있어야 한다.
- 최근 토벌, 순찰 증강, 경비 초소 복구, 계절 변화는 다음 이동의 위험 조건을 바꿀 수 있지만 해당 결과 기록 없이 즉시 안전·위험 상태를 바꾸지 않는다.

### 병렬 엣지·비용·용량 제약

- 같은 거점 쌍의 여러 경로를 허용하되 각 경로의 안정 식별자와 방향·구간·판본을 구분한다.
- 통행 불가 조건은 큰 비용으로 위장하지 않고 명시적 제약 또는 `Blocked`로 제외한다.
- 비용 단위가 다른 값은 원자료로 보존한다. 가중 합산 점수를 쓰더라도 구성 요소와 가중치 판본을 함께 보여 준다.
- 위험의 기대 손실과 실제 손실을 구분한다. 예상치는 후보 비교 자료이고 실제 피해·지연은 사건 결과다.
- 물류 용량은 차량 한 대의 적재량뿐 아니라 경로 폭·교량 제한·시간창·호위·하역 가능량을 함께 읽는다.
- 최적 경로가 자주 바뀌어도 이미 출발한 운송을 자동 순간이동시키지 않는다. 경로 변경 가능 지점과 추가 시간·비용·위험을 다시 Confirm한다.

## Graph Map 레벨 3 — 조사할 결속

Graph Map 담당은 코드를 새로 만들기 전에 다음 기존 책임의 재사용 여부를 조사한다.

- 거점·경로·경로 구간과 통행 가능성 조회
- 이동 시간·거리·복귀 지점 계산
- 절기·날씨·시간대 상태 사본
- 몬스터 집단·서식지·최근 사건의 권위 상태
- 순찰·토벌·경비 초소·통행량 결과 기록
- 조우 Preview·Confirm·중단·귀환과 행위 기록
- Unity의 표현 생성, 가시성, Collider, Bounds와 실제 입력 검증
- 동일 안정 엣지에 대한 기상·운송·위협·물류 레이어 합성과 중복 비용 방지

현재 저장소에서 확인한 재사용 후보는 다음과 같다.

- `SimulationFreightDispatch`의 상차 거리·일정·차량 용량·복귀 우회 후보 입력
- `화물배차추천점수Policy`와 `배차추천평가Service`의 거리·지연·수익·화물 민감도·복귀 부담 점수 구성
- `OutboundBatchEngine`의 재고·서비스 구역·후보 점수 기반 출고 할당

이들은 현재 후보·배차·출고 점수 책임이며 Graph Map의 다중 엣지 최단 경로·최대 유량·동적 차단을 직접 증명하지 않는다. Graph Map 담당과 개발은 기존 입력을 재사용할 수 있는지 확인하되 운영 물류 규칙과 게임 Simulation 권위를 조용히 합치지 않는다.

파일이나 클래스가 있다는 사실만으로 실제 결속을 선언하지 않는다. 기존 계약이 없거나 의미가 다르면 `NoApprovedBinding`과 가장 이른 재개 E를 남긴다.

## E 단계 경계

- 이 문서는 레벨 1 플레이 관계와 레벨 2 제약의 기획 기준이다.
- 후보 경로·몬스터·Synty 자산 조사는 Presentation E4 준비일 수 있지만 실제 배치가 아니다.
- E5에는 이전 E1~E4의 경로 의미·위험 원천·상태·자산 후보를 모두 참조해 실제 경로, 활성 표현, 통행, 조우 입력과 결과·귀환을 같은 판본으로 검증해야 한다.
- 자동 시험만으로 실제 이동·몬스터 조우·Game View를 증명하지 않는다.

## 남은 수치 결정

다음은 Graph Map 구조와 실제 이동 표본을 확보한 뒤 별도로 정한다.

- 한 구간의 최대 권장 이동 시간과 거리
- 중간 안전점의 최소 간격과 기능
- 위험 조건별 조우 빈도·집단 크기·재발 대기
- 거점 안전 반경과 화면 밖 표현 생성 거리
- 짐·동행대·날씨가 노출 부담에 주는 가중치
- 경로 비용 구성 요소와 플레이 성향별 가중치
- 대체 경로 UI에 제시할 후보 수와 유사 경로 병합 기준
- 보급로 `Degraded`·`Blocked`·`InsufficientCapacity` 판정 상한
- 최대 유량·최소 컷과 증분 재탐색의 실제 채택 여부
- 레이어별 권위 소스·갱신 주기·신선도와 충돌 해결 순서

수치가 미정이어도 `긴 경로를 분절한다`, `거리만으로 생성하지 않는다`, `실제 위험 원천과 현재 조건을 요구한다`, `여러 비용과 용량을 가진 대체 경로를 비교한다`, `한 엣지 차단과 보급망 전체 차단을 구분한다`, `플레이어가 경로를 확정한다`, `회피·우회·귀환을 보존한다`는 원칙은 유지한다.
