## 목적

게임의 상위 목적은 플레이어인 나와 내가 대하는 상대의 필요한 오행 관계가 실제 행동·결과·회복·귀환으로 이어지게 하고, 그 순환 개선이 권위 결과로 확인될 때 관련 회복을 높여 개인과 공동체가 광복기 가능성을 넓히는 것이다.

기능을 많이 갖추는 것 자체는 목적이 아니다. 플레이어는 먼저 자신의 오행이 막힌 원인을 알아차리고 생활·탐험·작업·관계·명상을 통해 순환을 회복한다. 이렇게 확보한 안정·지식·기술·물자·관계와 회복역량으로 자신이 대하는 사람·사물·환경의 막힌 순환을 도울 수 있다. 상대의 실제 회복은 다시 안전한 관계, 이용 가능한 길과 시설, 풍부한 생태, 신뢰와 협력, 새로운 배움과 선택으로 돌아와 나의 다음 회복을 돕는다.

```text
나의 막힌 오행을 관찰
→ 작은 행동으로 나의 순환과 회복을 안정
→ 확보한 역량·지식·물자·관계를 상대에게 적용
→ 상대의 실제 상태가 개선되거나 피해가 예방됨
→ 변화된 사람·사물·환경이 새로운 선택과 도움을 돌려줌
→ 나와 공동체의 다음 회복 순환
```

나의 회복이 높다고 상대의 회복을 버튼 하나로 직접 올리지는 않는다. 높은 회복은 더 어려운 상황에서도 침착하게 관찰하고, 더 복잡한 행동을 지속하며, 실패 뒤 다시 시도하고, 더 넓은 대상과 협력할 수 있는 **기여 조건**이 된다. 상대의 회복은 상대에게 실제로 필요한 행동과 자원, 동의, 권위 결과가 성립했을 때만 오른다.

상대 또는 `너`는 NPC·동행자·주민·조직·적대자 같은 사람과 집단뿐 아니라 손도끼·나무·약초·밭·집·창고·도로 같은 사물·자원·시설, 숲·물길·기상·서식지 같은 환경·공간·생태도 포함한다. 사람의 주체성·동의·거절은 보존하고 사물·환경에 의도나 감정을 부여하지 않는다.

## 회복과 회복역량

- `회복`은 실제 상태 개선 또는 확인된 피해 예방과 그 기여다.
- `회복역량`은 손상·실패·위기 뒤에 회복할 수 있는 능력과 여지다.
- 플레이어의 명상 역량 성장은 개인 회복역량을 높이는 대표 경로지만 현재 회복을 즉시 채우지는 않는다.
- 회복 결과 하나만으로 회복역량을 자동 성장시키지 않는다. 숙련·시설·관계·지식·비축 등 별도 근거와 Profile이 필요하다.
- 정확 변환식·상한·해금·감쇠·반복 방지는 각 하위 기획에서 정한다.

사람의 회복은 개인·공동체 상태, 사물·시설의 회복은 내구·기능·운영 상태, 환경의 회복은 생태·경로·안전·생산 상태처럼 기존 권위 상태로 구체화한다. 모든 대상을 하나의 공통 회복 수치로 합치지 않는다.

## 회복 기여 판독 경계

회복 기여 후보는 같은 WI·ActionRecord·Actor·대상·Session·Revision에 연결된 권위 결과, 전후 상태 차이 또는 확인된 피해 예방, 판본화된 기여 Profile이 있을 때만 남긴다.

한 결과에서는 다음을 분리한다.

- 관점 플레이어
- 실제 실행 Actor
- 직접 대상
- 간접 영향 범위
- 회복 판정 대상
- 대상별 `개선 / 유지 / 손실 / 미확인`

위임한 플레이어와 수행 NPC를 합치지 않으며, 개별 나무의 소모를 숲의 회복으로, 적대 개체의 제압을 그 개체의 회복으로, 재료 소모를 수혜자의 회복으로 자동 치환하지 않는다. 화면 열람·Preview·취소·중복 Confirm·Save 재조회도 기여 원인이 아니다.

## 하위 기획의 목적 관문

새 기능이나 장면은 다음 질문을 통과해야 한다. 모든 칸에서 수치를 만들 필요는 없지만, 상위 목적과 어떤 관계인지 설명할 수 없는 기능을 핵심 진행으로 승격하지 않는다.

1. **나의 현재 막힘:** 플레이어의 어떤 오행 관계·생활 상태·선택 여지가 막혀 있는가?
2. **나의 회복 행동:** 플레이어가 무엇을 관찰하고 어떤 WI를 선택하며 어떤 대가를 치르는가?
3. **기여 자원:** 회복으로 얻은 안정·기술·지식·물자·관계 가운데 무엇을 상대에게 쓸 수 있는가?
4. **상대의 실제 필요:** 사람·사물·환경의 어떤 상태를 개선하거나 어떤 피해를 예방하는가?
5. **권위 결과:** 누구의 어떤 상태가 실제로 개선·유지·손실·미확인됐는가?
6. **환류:** 상대의 변화가 나와 주변 공동체에 어떤 새 선택·안전·관계·자원을 돌려주는가?
7. **비기여 경계:** 단순 관찰·장식·설명·Preview처럼 회복을 직접 만들지 않는 부분은 무엇인가?

이 관문은 [기획 문서 독립 관리 체계](../Architecture/기획문서독립관리체계.md)의 문답 영향 묶음, [Graph Map 기획 인계 순환 체계](../Architecture/GraphMap기획인계순환체계.md)의 레벨 1 목적 연결, [Graph Map 개발 인계 체계](../Architecture/GraphMap개발인계체계.md)의 작은 slice 수용·반환 관문에 반영한다. 기획은 확정과 미정을 구분하고, Graph Map은 확인된 관계만 연결하며, 개발은 그 slice에서 실제로 닫힌 권위 결과와 환류 범위만 반환한다. 이 공통 적용은 Graph Map 원장·게임 코드·Unity Scene을 자동 변경하거나 E를 승격하는 권한이 아니다.

최근 수평 기획은 다음처럼 이 관문 안에서 역할을 가진다.

| 기획 요소 | 상위 목적에서의 역할 | 직접 회복으로 세지 않는 것 |
| --- | --- | --- |
| 절기별 복장·식생 | 현재 세계 상태와 상대의 필요를 관찰하게 하는 신호 | 옷이나 색이 바뀐 사실 자체 |
| 절기별 농사·운송·수리 | 식량·물류·시설의 막힌 순환에 참여할 행동 후보 | NPC 애니메이션만 재생된 상태 |
| Town의 계절 가격 | 공급·재고·수요의 막힘을 읽고 조달·대체·기다림을 선택하게 하는 정보 | 가격표 열람이나 현실 자료 조회 |
| 일반 주민 말풍선 | 상대의 관측 가능한 필요와 생활 맥락을 선택적으로 이해하는 접점 | 클릭·대화 열람 자체 |
| 퀘스트 대화창 | 실제 필요·대가·선택을 명시하고 WI로 진입하는 관문 | 대화창을 연 상태나 자동 수락 |

이 표는 각 하위 기획의 독립 목적을 없애거나 모든 콘텐츠를 회복 수치 보상으로 바꾸지 않는다. 경관·음악·유머·탐색처럼 직접 회복을 만들지 않는 콘텐츠도 세계를 이해하고 머물 이유를 제공하는 보조 층으로 유지할 수 있다. 다만 핵심 진행·성장·광복기 기여로 연결할 때는 위 사슬의 실제 결과를 요구한다.

## 광복기 경계

개인 광복기와 공동체 광복기는 독립적으로 판정한다. 사물·시설·환경 자체를 심리적 광복기에 넣지 않는다. 이들의 회복 결과가 실제 공동체 문제 완화로 이어졌을 때만 참여자·대상·영향 범위가 명시된 공동체 회복 기여 후보가 된다.

현재 구현된 플레이어별 `NatureMind`·개인 기간 전이와 일부 전체 플레이어 사건 배분은 보존한다. 이는 사람·사물·환경 전반의 공통 회복 기여, 공동체 집계 또는 별도 회복역량 구현을 뜻하지 않는다.

## 문답·기록 원칙

이 기획의 후속 답변은 새 `D-###`를 만들지 않는다. 답변마다 이 문서의 `기획 판본`과 상태·확정 내용·미정·다음 질문을 갱신하고 [기획 목차](PLANNING.md)에 현재 판본만 반영한다. 둘 이상의 독립 기획에 적용되는 권위·안전·호환 규칙이 별도로 확정될 때만 그 규칙을 결정 원장에 요약할 수 있다.

## 아직 정하지 않은 것

- 대상별 회복 기여 수치·상한·감쇠
- 명상 역량에서 회복역량으로 이어지는 정확한 변환식과 해금
- 공동체 회복 집계 Profile
- UI·Audio·Graph Map의 정확 표현
- WI·Save/Replay·Unity 결속

이 문서는 기획 기준선이며 코드 구현, Scene 배치, 실제 입력, Unity 실행 또는 E 승격의 증거가 아니다.
