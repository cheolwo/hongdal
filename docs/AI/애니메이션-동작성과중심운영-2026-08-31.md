# 애니메이션 담당의 동작 성과 중심 운영

- 판본: `animation-visible-outcome-operation.r1` / D383 / 2026-08-31.
- 상태: `AcceptedDirection`. 사용자가 일반 Unity 검증 지원에 치우친 역할과 체감 성과 부족의 개선을 요청했다.
- 기존 [D361 운영](../Architecture/PlayableLoops/WI애니메이션보완제작운영.md)에 대한 추가 운영 기준이다. 기존 원문/hash·Accepted 연구는 수정하지 않는다. [D380 정밀화 계획](../Architecture/PlayableLoops/WI애니메이션-리깅정밀화계획.md)의 모든 신규 제작을 승인한 것은 아니다.

## 1. 개선할 문제와 역할

애니메이션 담당이 동작 재고 조사·재생 모듈·뼈 작성 충돌 보호 외에 입력/UI/카메라의 일반 회귀까지 반복 지원하면서 실제 동작 품질 결과가 뒤로 밀렸다. 기반 코드와 시험은 유효하지만 이를 새로운 Clip이나 실제 게임 동작 완성으로 설명하지 않는다.

| 책임 | 기본 소유자 | 인계 경계 |
| --- | --- | --- |
| 대상 Actor/Clip/Rig, 자세·그립·발 접지·전환·중단 복귀, 물체 애니메이션과 전용 시험 | 애니메이션 | 보유 자산 재사용부터 실제 부족을 판정하고 승인된 복사본만 보완 |
| 일반 입력/UI/커서/카메라/농장 표시, 공통 상태와 명령 연결, 공통 회귀 | 개발 | 애니메이션에 상시 시험 실행 대행으로 재배분하지 않음 |
| 실제 입력·Game View 및 보조 장면 캡처 | 월드·공간·배치 | 개발이 대상·조건·입력·판본을 인계, Editor 단독 점유 유지 |
| 최종 통합·원장·명세·현재 작업·기획 반환 | 개발 | 전문 시험과 실제 동작 품질을 나누어 보고 |

진행 중인 r97 Farm 검토/시험은 안전한 종료 경계까지 마무리한다. 그 뒤 애니메이션 Queue의 일반 지원 업무는 개발로 반환한다. 임시 지원이 꼭 필요하면 개발이 이유·정확 범위·종료 조건을 기록하고 본래 동작 작업으로 돌아갈 시점을 정한다. 별도 스레드 생성이나 전역 WIP 상한은 추가하지 않는다.

## 2. 다음 배분과 정체 시 처리

1. 개발은 기존 작업 목록에서 애니메이션 전문 작업과 일반 검증 지원을 구분한다. 기존 D361 보고를 재사용하고 새 중복 대장이나 전수 재조사를 만들지 않는다.
2. 다음 전문 묶음은 대표 Actor 하나의 보유 이동 Clip에 대해 대기→걷기→정지 전환을 실제 대상에서 비교하는 좁은 연구로 우선 준비한다. 기존 승인 범위·Avatar·상태 공급·소유 경로를 먼저 대조하고 필요한 연구를 명세에 결속한다. 기존 D359/D379 중 독립적으로 즉시 비교 가능한 후보가 더 준비되어 있으면 선정 근거를 남기고 그것을 먼저 진행할 수 있다.
3. 실제 입력 연결이 막혀도 승인된 격리 비교는 별도 진행할 수 있다. 격리 재생은 게임 상태 연결 성공이 아니며, 권위 상태를 주입하거나 완료를 꾸며내지 않는다. 기존 Escape/F8 실패를 같은 방식으로 다시 반복하지 않는다.
4. 신규 Clip·리깅·모델링이 필요하다는 결론은 실제 보유 후보 평가 후 내린다. 미확인 가공 방식·새 행위 의미·비용·피해·시간 변경은 해당 범위만 보류한다. 기술 연결은 이미 승인된 의미 안에서 개발 책임으로 해결한다.

## 3. 동작 한 묶음의 반환물

기존 전문 보고/개발 통합 상태판에 아래 항목을 남기고 D382 시각 목차로 연결한다. 시험 수·문서 수·파일 수를 주 성과로 삼지 않는다.

- **보이는 목표:** 어떤 어색함을 줄이는지 한 문장. 예: 멈출 때 발이 미끄러지거나 팔이 튀는 현상.
- **대상/재사용:** Actor·도구·대상 및 Clip/Rig의 정확한 경로·판본, 신규 제작인지 기존 Clip 연결인지.
- **동일 조건 비교:** 같은 시점·카메라·속도·동작 구간의 수정 전후. 변경하지 못했다면 개선 전/후라고 부르지 않고 후보 비교 또는 차단으로 표시한다.
- **동작 근거:** 준비·행동·접촉·중단·복귀를 확인할 연속 화면 또는 순서가 있는 프레임. 정지 PNG 하나만으로 부드러움이 검증됐다고 하지 않는다. 촬영은 공간 담당이 맡는다.
- **품질 판정:** 그립/대상 접촉, 발 접지, 관통, 이동·뼈 단일 작성자, 중단 복귀를 항목별 통과/실패/해당 없음으로 표시한다. 오차 수치는 기존 Accepted 연구를 따르고 새 임의 숫자로 통과시키지 않는다.
- **통합 수준:** 자산 조사 / 격리 재생 / 실제 상태 연결 / 실제 입력·화면 확인을 구분한다. 오디오는 파일·재생 연결·청취를 별도 표시한다.
- **다음 한 가지:** 남은 문제와 소유자·재개 조건. 공통 입력 문제는 개발로 반환하고 전문 담당 전체를 그 문제에 묶어두지 않는다.

## 4. 적용과 안전

기획→개발→전문→개발 통합→기획 반환 체계를 유지한다. 개발이 기존 명세에 본 추가 기준/hash·담당·비중첩 경로를 결속하고 CURRENT_WORK 및 통합 상태판의 다음 작업을 갱신한다. 배분 변경과 실제 동작 개선 완료는 구별한다.

[D382 분야별 시각 목표](야간개발-분야별시각진척-2026-08-31.md)와 [야간 안전 기준](야간개발순환-2026-08-30.md)은 유지한다. 벌목만 다시 유일한 선행으로 만들지 않는다. 09:00 이후 새 야간 묶음 없음, 미소유 dirty/원본 보존·Scene 저장 권한·기존 사용조건·E 상한·commit/push 금지는 불변이다. 이번 운영 개선은 새 애니메이션 완성·권리 확인·E 승격의 증거가 아니다.
