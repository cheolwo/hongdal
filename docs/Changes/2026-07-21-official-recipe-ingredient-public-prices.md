# 공식 레시피 재료의 한국·미국 공공가격 연결

## 변경 요약

| 변경 | 시각 영향 | 확인 |
| --- | --- | --- |
| 명확히 식별되는 공식 레시피 재료를 한국 KAMIS와 미국 USDA NASS 보관 관측값에 연결 | 화면 없음 — 관리자 재료·레시피 API 응답의 `PublicPrices`에 국가별 참고가격 표시 | 단위 테스트, 서버 빌드, EF 마이그레이션, 로컬 DB 백필로 간접 확인 |

## 구현 경계

- 재료 분류가 검토 대기이거나 가공식품·장류·조미료이고 공공 품목을 정확히 확인할 수 없으면 가격 매핑을 만들지 않는다.
- 한국은 KAMIS 전국 도매·소매 가격을 평균·최소·최대·표본 수와 함께 표시하며, 검토 교차표에 지정된 국산 품종 코드가 있으면 그 품종만 포함한다.
- 미국은 USDA NASS 전국 생산자 수취가격을 원문 USD 단위로 표시한다. 쇠고기·돼지고기·닭고기는 완제품 가격이 아니라 원료 가축·가금 생산자 가격이라는 주의문을 붙인다.
- 두 나라 가격은 통화, 단위와 시장 단계가 달라 자동 환산하거나 우열을 계산하지 않는다.
- 매핑과 실제 가격 관측값이 분리되어 공공 원천 갱신 뒤 같은 재료에 최신 관측값이 표시된다.

## 로컬 자료 검증

- 공식 재료 1,903개 처리
- 재료 37개에 국가별 매핑 50개 생성: 한국 33개, 미국 17개
- 최신 보관 관측값이 있는 재료 31개
- 응답 가능한 가격 행: 한국 47개, 미국 14개
- 미매핑 1,866개는 유사 품목을 추정하지 않고 무가격 상태 유지
- USDA 수집 범위를 농작물 전용에서 축산물과 NASS 조사 대상 양식 수산물까지 확장한 뒤 미국 가격 행이 9개에서 14개로 증가
- KAMIS 2026-07-20 전국 일별 자료 366건 수집
- USDA NASS 2025년 이후 전국 월별 자료 2,010건 확인: 신규 399건, 기존 1,611건, 원천 최근 적재 시각 2026-07-02 15:00 UTC

위 건수는 2026-07-21 로컬 개발 DB의 수집 snapshot이며 이후 공식 원천 갱신과 재료 검토에 따라 달라진다.
