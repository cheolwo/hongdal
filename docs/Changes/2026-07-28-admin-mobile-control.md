# 모바일 관리자 운영 개요와 운송 관제

## 결과

- 기존 `SsalddelAdminApp`을 커뮤니티 자료 검토 중심 앱에서 플랫폼 모바일 관제 앱으로 확장했다.
- `/`와 `/overview`에서 실제 `api/v1/admin/dashboard` 응답의 관리자 확인, 운송 예외, 배차 대기, 운송 중과 오늘의 주문·이행 지표를 확인한다.
- `/operations`에서 실제 관리자 운송 목록과 현재 운행 기사 목록을 함께 조회하고, 관리자 확인 또는 예외가 있는 운송을 먼저 모아 보여 준다.
- 두 운영 화면은 앱이 열려 있을 때 30초마다 보조 조회하며 수동 새로고침과 실패 재시도를 제공한다.
- 저장된 refresh token의 만료 시각을 보존하고 앱 시작·API 요청 전 자동 갱신, `401` 뒤 강제 갱신과 한 번의 재요청을 적용했다.
- 현재 운송·기사 관제는 읽기 전용이며, 상태 조정은 업무 의미가 있는 Command와 감사 경계가 준비된 뒤 연다.

## 화면 확인

간접 확인이다. Windows MAUI 대상 Razor와 서비스 조립이 컴파일되는 것은 확인했지만, 인증된 서버관리자 계정과 운영 원장을 사용한 실제 기기·브라우저 PNG는 만들지 않았다. sample data로 성공 화면을 대신하지 않았다.
