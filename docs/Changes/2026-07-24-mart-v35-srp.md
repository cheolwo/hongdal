# 3.5 알뜰살뜰 마트 페이지 단일책임 정리

## 결과

3.5 마트 화면을 새 기능 확장보다 배포 가능한 책임 경계에 맞춰 정리했다.

- 주문자 Web·App의 공개 상품 목록, stable-ID 상세, 후기, 비구속 주문 요청 Route는 기존 분리를 유지했다.
- Web·창고 앱의 피킹 주문 목록과 주문 상세를 독립 Route와 공용 Screen으로 분리했다.
- 마트 홈과 업무 흐름 화면은 고정 샘플 주문 수·작업 카드 대신 실제 서버 원장 화면으로 이동하는 공용 읽기 전용 허브를 사용한다.
- 로컬 작업자 번호 확인 화면은 `Simulation`임을 명시하고 샘플 번호 노출을 제거했다.
- 배달 기사 인계 전용 영속 화면이 없는 상태를 `준비 중`으로 표시해 실제 운영 기능처럼 보이지 않게 했다.

## 배포 경계

`deploy/azure-vm/compose.mart-v35.override.yaml`은 다음 조건을 고정한다.

- `SsalddelExecution__Mode=Simulation`
- `VersionFeatureFlags__FoodDeliveryWorkflow=true`
- `VersionFeatureFlags__SsalddelMartWorkflow=true`
- `SalesChannelOrderSync__Enabled=false`

따라서 3.5 화면과 내부 흐름은 확인할 수 있지만 판매채널 주문 동기화와 외부 실행 효과는 켜지 않는다.

## 시각 확인

간접 확인. 공용 Razor Screen과 Web·Windows 배포 빌드로 컴포넌트 조립을 확인했으며 이번 작업에서 브라우저 캡처나 실제 배포는 수행하지 않았다.
