# 싱글 플레이 로컬 LH 지도 생성

## 변경 결과

`SimulationWorldShell`은 이제 서버 연결이 없어도 로컬 LH 엔진이 플레이어 위치를 기준으로 주변 지도를 계산한다. 기본 상태 문구는 생성 출처를 `로컬 싱글 플레이 생성`으로 표시한다.

- 기본 월드 시드와 로컬 시작일은 Scene 구성 요소에 저장한다.
- 상세 3×3, 이동 준비 5×5, 선행 자료 9×9 셀 창을 유지한다.
- H4·H3 승인 참조, H2 설계 후보, 승인 H1 상호작용 참조를 분리한다.
- 수확 기준작 네 거점, 셀당 3~5개 결정적 주변 배치와 이웃 셀 공유 경계를 계산한다.
- 계절은 기본 배치를 바꾸지 않고 별도 표현 해시와 공유 Material 색에만 반영한다.
- 서버 경로는 선택 동기화용으로 남기며 실운영 업무 권위는 로컬 지도 생성으로 이동하지 않는다.
