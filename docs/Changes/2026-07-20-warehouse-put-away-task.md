## 변경 기록

| 변경 축 | 화면 변경 여부 | 결과 |
| --- | --- | --- |
| 적재 대상 | 화면·서버 변경 | 창고 소유·배정 범위의 검수 완료 재고만 검색·상태·서버 페이징으로 조회 |
| 정확한 상세 | 화면·서버 변경 | 선택한 `inboundItemId`의 검수 수량·불량·주문 참조·보관 조건만 재조회 |
| 위치 확정 | 화면·서버 변경 | 검수 결과와 위치 표찰 확인 뒤 `검수완료 → 적재완료` 한 상태 전이만 실행 |
| 멱등·분리 | 서버 변경 | 동일 위치 재시도는 이력·이동·감사·Event 중복 없이 반환하고 다른 위치 변경은 별도 업무로 거부 |
| 단일 책임 | 구조 변경 | 목록, 상세, 작성 Command, 페이지 조정, host 인증/capability를 각각 분리 |
