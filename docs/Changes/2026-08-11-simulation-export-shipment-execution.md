# Simulation 수출 출항·운송·성공/손실 정산

## 결과

선택한 수출 계획 후보를 별도 Confirm 뒤 세계 시간으로 실행한다. 결과는 완료 전까지 숨기고, 세션 seed와 실행 stable ID의 결정적 roll로 성공 또는 손실을 확정한다.

## 흐름

```text
PlannedCandidate
  → 실행 Preview
  → 성공 확률·성공/손실 재정 후보 확인
  → 실행 Confirm
  → 최악 손실 여력 예약
  → InTransit
  → 계획 기간 완료
  ├─ DeliveredInSimulation
  │    → 300kg 도착
  │    → 성공 재정 차액
  └─ DisruptedWithLossInSimulation
       → 300kg 손실
       → 손실 재정 차액
```

## 정산

- 판로 선택에서 이미 반영한 예상 매출 45만 원을 결과에서 조정한다.
- 예시 성공 차액: 계획 순수익 110만 원 - 기존 예상 매출 45만 원 = +65만 원.
- 예시 손실 차액: 계획 비용 70만 원 + 기존 예상 매출 45만 원 = -115만 원.
- 성공과 손실 모두 출고 예약 300kg을 종료한다.

## 경계

- 결과는 실제 예측이 아니라 결정적 Simulation 결과다.
- 완료 전 outcome roll을 공개하지 않는다.
- 실제 운송 예약·수출신고·공식 검사·검역 승인·통관·선적·운영 정산을 생성하지 않는다.

## 검증

- 수출 준비부터 성공·손실 결과까지 집중 테스트: 56/56 통과
- Simulation 전체 테스트: 252/252 통과
- scoped Fast 통과
- scoped Task 빌드 통과, 전체 테스트는 기존 비관련 7건 실패로 4,501/4,508 통과
- 화면 변경 없음
