# 물류대행 계약 비용 검토안

## 결과

- 로그인한 개인·판매자·공동행동 운영자도 물건을 맡기는 계약에서는 계약별 `화주` 당사자가 될 수 있도록 했다.
- 요청 본문에서 화주 사용자 ID를 받지 않고 서버의 인증 사용자 ID를 계약 초안에 기록한다.
- 입고·검수·적재·보관·피킹·포장·출고와 반품·폐기·긴급 처리 비용을 공통 항목 코드, 단위, 산식 설명과 작업 증빙 코드로 표현한다.
- 요율과 최소 청구액, 예상 작업량을 기준으로 공급가액·세액·합계를 계산하고 해당 요율표의 해시 버전을 초안에 고정한다.
- 결과는 양측 전자서명 전에는 활성화할 수 없는 비구속 검토안이며 입고·보관·정산을 실행하지 않는다.
- `SsalddelApp`의 화주 창고 작업공간과 메뉴에서 `/shipper/warehouse/logistics-contract` 화면으로 이동한다.

## 화면 확인

간접 확인이다. 공용 Razor 구성, 서버 API, 계약 계산 테스트와 `SsalddelApp` Windows 대상 빌드는 통과했지만 실제 기기 PNG는 만들지 않았다.

## 검증

- 물류대행 요율·계약 계획·라우트 테스트 11개 통과
- `SsalddelApp` Windows 대상 빌드: 경고 0개, 오류 0개
- 변경 경로 `Fast` 및 `Task` 검증 통과
