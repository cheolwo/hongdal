# 공식뉴스 RSS 검토 후보 파이프라인

## 변경 목적

지도와 커뮤니티 글쓰기에서 참고할 최신 공식 맥락을 확보하되, 기사 수집이 자동 게시나 가격·재고·공급 주장으로 이어지지 않도록 관리자 검토 후보 경계를 먼저 만든다.

## 구현 범위

- 농림축산식품부 보도자료 RSS
- 농림축산식품부 설명·반박자료 RSS
- 식품의약품안전처 보도자료 RSS
- 기관별 안정 source key와 공식 도메인 allowlist
- 제목, 300자 이하 요약, 발행 시각, 원문 URL, 기관, 피드 URL, 수집 시각
- GUID 또는 원문을 SHA-256으로 정규화한 안정 후보 key
- `ETag`·`Last-Modified` 조건부 요청과 프로세스 메모리 캐시
- `PendingReview` 고정, 외부 호출 및 자동 게시 기본 비활성

관리자는 기존 `GET /api/v1/admin/content/information/candidates?sourceKey={sourceKey}`에서 한 원천을 명시해 후보를 조회한다. 전체 후보 조회는 공식뉴스 RSS를 호출하지 않는다.

## 안전 경계

- 기사 원문 전체와 이미지를 복제하지 않는다.
- 기관 공식 도메인이 아닌 기사 링크는 후보에서 제외한다.
- 제목의 지역 표현으로 좌표나 상세 위치를 추론하지 않는다.
- 기사에 가격 표현이 있어도 공공 가격 관측값으로 변환하지 않는다.
- 검토 후보 생성만으로 게시글, 지도 관측, 알림, 원장 또는 공동행동을 만들지 않는다.

## 설정

`OfficialNewsRss:Enabled` 기본값은 `false`다. 운영자가 설정을 명시적으로 활성화한 환경에서만 외부 RSS를 조회한다.

## 화면과 검증

화면 없음. 기존 관리자 후보 조회 API에 source가 추가되는 서버·계약 변경이며, 실제 외부 피드는 호출하지 않고 fixture 기반으로 파싱·도메인 제한·조건부 요청·비활성 경계를 검증한다.

국가별 언론사 자체를 가리키는 `news-publisher` 지도 마커는 별도 편집 맥락으로 추가되었다. 아직 포함하지 않은 범위는 후보 승인·제외의 영속 저장, 주기 실행 Worker, 개별 RSS 기사의 지도 카드와 사용자 선택형 글 초안 연결이다.
