- 개발 계정 `shipper1` 로그인과 창고관리자 역할 판정 성공

- 선택한 `V1-DEV-PICK-001`이 URL query와 상세에 동일하게 표시
- 시작 뒤 같은 Key의 `진행중` 상세 재조회 성공
- 적재대 `A-01-03`, 상품과 전체 수량 확인 전 완료 버튼 비활성·확인 뒤 활성
- 완료 뒤 같은 Key의 `완료` 상세와 후속 출고 단계 안내 재조회 성공
