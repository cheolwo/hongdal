# 저장 없는 공동구매 체험 모드

## 변경 요약

- 공동구매를 처음 접하는 사용자가 로그인 없이 가상 이웃과 3라운드 집단화 과정을 연습하는 공용 화면을 Web과 Orderer App에 추가했습니다.
- 냉동 삼겹살, 간편식 소스와 가공육 세트 시나리오에 상품·HS 코드 후보·보관 온도·목표 인원·목표 수량을 연결했습니다.
- 연습 결과는 기존 주문자 집단화 엔진으로 계산하지만 세션, 대화, 수요와 결과를 서버 원장에 저장하지 않습니다.
- 체험 완료 뒤에는 실제 비구속 수요 화면으로 가는 선택지만 제공하며 수량이나 동의를 자동 제출하지 않습니다.
- 실제 수요 기능과 독립된 `GroupPurchasePracticeWorkflow` 플래그를 추가해 실제 구매 기능을 닫은 상태에서도 연습할 수 있게 했습니다.

## 사용자 경험

- 모든 가상 참여자는 `연습 이웃 · ...`와 `가상 참여자`로 표시합니다.
- 사용자는 처음 참여, 요리 이야기, 보관 방법과 수령 방법 중 대화 주제를 고를 수 있습니다.
- 라운드마다 참여자 수와 수량 진행이 바뀌고, 목표 충족 뒤에도 주문이나 결제가 발생하지 않는다는 안내를 유지합니다.
- HS 코드와 예상 단가는 학습용 예시이며 실제 품목분류나 견적이 아님을 표시합니다.

## 실행 경계

- 로그인, 계정 식별, 주소, 연락처와 결제 정보를 요구하지 않습니다.
- 연습 세션과 대화를 저장하지 않습니다.
- 실제 사용자 참여를 가장하지 않습니다.
- 주문·결제·계약·통관 신고·연락처 전달·운송 의뢰·자동 배차를 실행하지 않습니다.
- 실제 비구속 수요는 별도 화면에서 사용자가 상품, 수량, 배송권과 동의를 다시 확인해야 합니다.
