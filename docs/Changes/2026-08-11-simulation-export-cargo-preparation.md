# Simulation 수출 Cargo 준비 후보

## 결과

검사 통과한 최신 수출 준비 시도를 HarvestLot·포장 Lot·Cargo·경로 입력이 연결된 Cargo 준비 후보로 전환했다. 기존 수출 준비의 예약량을 승계하므로 수량을 중복 예약하지 않는다.

## 흐름

```text
검사 통과한 최신 수출 준비
  → Cargo 준비 Preview
  → Cargo 준비 Confirm
  → 준비 Task
  → ReadyForHandoff
  → 별도 배송대행지 인계 결정 대기
```

## 경계

- Cargo 준비 완료는 실제 배송대행지 인계가 아니다.
- 운송사 계약, 배차, 차량 출발과 물류 이동을 만들지 않는다.
- 수출신고와 통관을 만들지 않는다.
- 기존 수출 준비 예약량 300kg을 유지하며 다시 예약하지 않는다.

## 검증

- 수출 준비·재작업·Cargo 준비 집중 테스트: 16/16 통과
- Simulation 전체 테스트: 212/212 통과
- scoped Fast 통과
- scoped Task 빌드 통과, 전체 테스트는 기존 비관련 7건 실패로 4,501/4,508 통과
- 화면 변경 없음
