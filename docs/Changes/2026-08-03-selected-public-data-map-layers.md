# 관광·온라인가격·KOSIS 공공데이터 지도 레이어

- 날짜: 2026-08-03
- 화면: `/community/home`
- 범위: 공공데이터 배경 snapshot, 세 개의 독립 지도 레이어, 출처·단위·위치 경계

## 변경 내용

- 한국관광공사 TourAPI의 지역기반 관광정보에서 공식 공개 좌표가 있는 항목만 제한된 snapshot으로 표시한다.
- 관광 주소·전화번호·이미지는 지도 계약과 snapshot에 저장하지 않는다. 표시된 지점은 지역문화 대표성이나 상업 가용성을 확정하지 않는다.
- 온라인가격은 실제 가격 응답까지 호출되지만 판매단위가 구조화되어 제공되지 않아, 가격과 절감액 대신 품목코드 연결 범위만 표시한다.
- KOSIS는 `소비자물가지수` 전국 월별 값을 `2020=100` 단위와 기준월을 함께 표시한다. 온라인 개별 상품가격과 직접 비교·순위화하지 않는다.
- 세 원천을 독립적으로 갱신하며, 한 원천의 실패가 다른 원천이나 이전 성공 snapshot을 지우지 않는다. 지도 조회 경로에서는 외부 API를 직접 호출하지 않는다.

## 공식 원천

- [한국관광공사 국문 관광정보 서비스_GW](https://www.data.go.kr/data/15101578/openapi.do)
- [국가데이터처 온라인가격정보](https://www.data.go.kr/data/15080757/openapi.do)
- [국가데이터처 KOSIS 지표정보 조회 서비스](https://www.data.go.kr/data/15127763/openapi.do)

## 시각 검증

간접 확인이다. 레이어 버튼·마커 스타일·메타데이터 표시 코드와 WebApp 빌드를 검증했다. 실제 서버는 기존 개발 DB 암호문에 필요한 Data Protection 키가 현재 키링에 없어 초기 데이터 seed 단계에서 중단되었다. 새 화면 PNG와 브라우저 route 확인은 남기지 못했다.

## 검증

- 단위 투영·실패 보존·비식별 표시 테스트 3개 통과
- 세계지도 UseCase·구성 포함 관련 테스트 34개 통과
- 실제 API를 쓰는 임시 live probe 통과: 관광 좌표 5개, 온라인가격 품목코드 402건, KOSIS 소비자물가지수 119.92 (`2020=100`)
- live probe 소스는 검증 후 제거했으며 인증키 값은 로그·문서·코드에 남기지 않았다.
