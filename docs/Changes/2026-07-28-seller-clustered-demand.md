# 판매자 집단 수요 탐색

## 변경 요약

판매자 앱의 `주문자 수요` 화면에, 판매자가 이미 참여한 대량 주문 원장과 구분되는 `집단 수요` 단계를 추가했습니다.

- 기존 주문자 집단화 엔진과 `api/v1/orderer/group-purchase-auto-groups` 집계 API를 그대로 재사용합니다.
- 같은 상품·배송권·보관 온도·물류 방식·거래 유형으로 모인 수요를 상품별 카드로 표시합니다.
- 참여자 수, 수요 건수, 총 희망 수량, 원천 수량 단위, 목표까지 남은 수량, 모집 마감과 상태를 표시합니다.
- 참여자 이름, 상세 주소, 개인별 주문량은 판매자 화면에 노출하지 않습니다.
- 집단 수요의 조건 충족 여부에 따라 판매 조건 초안을 준비할 다음 행동을 안내합니다.
- 판매자 홈에서도 개별 주문, 모이고 있는 집단 수요, 참여 중인 대량 주문을 서로 다른 단계로 안내합니다.
- `1.0 같이 주문·주문자 집단화` 기능이 비활성인 환경에서는 빈 성공으로 숨기지 않고 사용 가능 조건을 안내합니다.

## 화면 변경

| 화면 | 변경 | 시각 확인 |
| --- | --- | --- |
| SellerApp `/seller/orderer-demand` | `개별 판매 → 집단 수요 → 대량 판매 → 수출 판매`의 4단계 수요 탐색, 집단 진행률과 개인정보 보호 안내 추가 | 간접 확인 — Razor 구성·반응형 CSS·컴파일 및 구성 테스트로 확인, 실제 기기 PNG 미수집 |

## 경계

- 집단 수요 조회만으로 판매자 참여, 공급 확정, 주문, 결제 또는 물류 실행은 발생하지 않습니다.
- 수량은 `kg`로 강제 변환하지 않고 집단 원장에 기록된 원천 거래 단위를 그대로 표시합니다.
- 판매 조건 버튼은 기존 판매 페이지 초안 작성 화면으로 이동하며, 외부 판매채널 게시를 자동 수행하지 않습니다.
