# 지역문화 3D 애니메이션 이미지 순차 생성

## 변경

- 한국 17개, 미국 50개, 중국 31개로 구성된 기존 98개 지역문화 조사 초안을 시네마틱 3D 애니메이션 스타일 v2로 갱신했다.
- 지역마다 하루 시작, 시장·음식, 공예·생업, 지형·이동 등 서로 다른 10개 장면 슬롯을 고정했다.
- 공식 원천과 고정관념 위험을 모두 검토한 지역만 생성 승인할 수 있는 서버 관리자 API를 추가했다.
- 완료·진행 중인 장면은 건너뛰고 실패 장면은 명시적으로 요청할 때만 다시 시도하도록 했다.
- 한 번에 1장, 하루 최대 10장, 단일 활성 작업을 기본으로 하는 순차 생성 Worker를 추가했다.
- 외부 비용이 발생하는 작업은 기본 비활성, `Operational` 모드와 로컬 API key 구성 시에만 허용했다.

## 화면

화면 없음. 클라이언트는 변경하지 않았다.

서울 장면 01의 스타일 기준 이미지를 로컬에서 직접 생성했지만, 제품 화면이나 공식 문화 근거에는 연결하지 않았다. 생성물은 `artifacts/local/regional-culture-image-generation/`에만 보관한다.

## 검증

- 지역문화 대상 테스트: 11개 통과
- 확인 범위: 3D 애니메이션 프롬프트 안전 경계, 승인된 지역만 선택, 10개 장면 순서, 완료·진행·실패 중복 방지, 승인 조건, 진행률 계약, 관리자 route·권한

## 남은 위험

- 98개 지역의 조사 초안은 자동 승인되지 않는다. 지역별 공식 원천과 고정관념 위험을 검토한 뒤 하나씩 승인해야 한다.
- 생성 이미지에는 문화적 오류가 남을 수 있으므로 공개 전 사람의 최종 검수를 추가해야 한다.
- 실제 외부 Provider 대량 생성과 저장소 업로드는 이번 변경에서 활성화하지 않았다.
