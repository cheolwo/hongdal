# 구매 근거를 잇는 상품 상세·판매 초안 서버 흐름

## 변경 요약

| 변경 | 시각 영향 | 확인 |
| --- | --- | --- |
| 공개 상품에 완료 원장과 공개 후기의 비식별 투영 추가 | 화면 없음 — API 계약과 조회 UseCase 변경 | 서버 빌드와 관련 단위 테스트로 간접 확인 |
| 로그인 참여자가 완료된 원장에 구매후기를 작성하는 API 추가 | 화면 없음 — 기존 `완료 사례·후기` 게시글 발행 흐름 재사용 | 권한·미완료 차단·정상 작성 테스트 |
| 판매 페이지 초안에 서버 검증 구매 근거 스냅샷 저장 | 화면 없음 — 공개 상품 ID만 입력받아 서버가 재조회 | 위조·미완료 근거 차단과 저장 응답 테스트 |
| 후기 작성 client/ViewModel과 판매 초안용 비식별 query seed 추가 | 간접 확인 — 실제 Razor/CSS는 후속 시각 검증 커밋으로 분리 | client·입력 검증·자동 저장 금지 단위 테스트 |

## 공개·저장 경계

- 완료 여부·기준 시각, 공개 후기 수와 최근 공개 후기 최대 3개만 상품 상세에 포함한다.
- 원장 ID, 참여자·주소, 결제·계약, 개인별 수량과 내부 재고는 공개 응답과 판매 초안에 포함하지 않는다.
- 삭제·신고·예약 발행 글과 시스템 완료 글은 후기 목록에서 제외한다.
- 판매가·원산지·재고·배송 조건은 원장 자료로 자동 확정하지 않는다.

## 후속 UI

상품 상세의 후기 작성과 판매 초안 이동을 위한 client/ViewModel은 단위 테스트로 확인했다. 실제 Razor/CSS와 route 연결은 작업 트리에 분리해 두었으며, desktop/mobile PNG는 Chrome 연동 복구 후 남긴다.
