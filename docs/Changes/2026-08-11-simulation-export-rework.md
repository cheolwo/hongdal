# Simulation 수출 재작업·재검사 계보

## 결과

수출 준비 검사 실패분을 사용자가 별도 Preview·Confirm으로 재작업하고 다시 검사할 수 있게 했다. 최초 실패 원장과 각 재검사 시도는 삭제하거나 덮어쓰지 않는다.

## 계보

```text
수출 준비 시도 1
  → 검사 실패: PackagingDamage
  → 재작업 Preview
  → 재작업 Confirm
  → 수출 준비 시도 2
      ├─ 재검사 통과: 배송대행지 인계 후보
      └─ 재검사 실패: 새 사유 + 다음 재작업 가능
```

각 시도는 루트 준비 stable ID, 직전 준비 stable ID와 시도 번호를 보존한다. 같은 실패 시도에서 재작업 두 건을 동시에 예약할 수 없다.

## 운영 경계

- 재검사는 공식 검사나 통관 검사가 아닌 Simulation 입력이다.
- 통과 결과도 실제 수출신고·통관·계약·운송사 인계가 아니다.
- 실패 수량은 소진하지 않고 원배분에 반환한다.
- 화면이나 차량 연출은 재작업·검사 결과를 확정하지 않는다.

## 검증

- 수출 준비·재작업 집중 테스트: 10/10 통과
- Simulation 전체 테스트: 206/206 통과
- scoped Fast 통과
- scoped Task 빌드 통과, 전체 테스트는 기존 비관련 7건 실패로 4,501/4,508 통과
- 화면 변경 없음
