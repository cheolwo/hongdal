# 공식 레시피 재료 전산화

## 변경 기록

| 변경 축 | 화면 변경 여부 | 확인 내용 |
| --- | --- | --- |
| 재료 분류 사전 | 화면 없음 | 곡류·채소·육류·수산물·장류 등 18개 분류를 DB seed와 공용 계약으로 추가 |
| 표준 재료 마스터 | 화면 없음 | 언어+정규화 이름의 안정 Key, 자동 분류 방식·신뢰도·검토 상태와 레시피 사용 횟수 저장 |
| 레시피별 사용 재료 | 화면 없음 | 원문 묶음·항목·수량·단위·가정 계량·표시 순서와 parser 버전을 별도 행으로 저장하고 원문 JSON 유지 |
| 백필·재수집 | 화면 없음 | 기존 레시피 배치 색인 CLI·관리자 API와 이후 공식 원천 수집 시 자동 동기화 연결 |
| 운영 경계 | 화면 없음 | 미분류·무수량 항목을 삭제하거나 임의 확정하지 않고 명시적인 검토 대상으로 보존 |

## 검증

- 식약처 묶음·괄호 계량·줄바꿈·약간·무수량 parser 단위 테스트
- 여러 레시피의 재료 마스터 공유와 parser 버전 기반 멱등 백필 테스트
- `Ssalddel` 서버 build 및 전체 clean worktree 테스트
- AgriculturalFisheries 전용 Context 추가형 migration과 model snapshot 정합성 확인
- 로컬 식약처 레시피 1,146건을 12,781개 사용 행·1,903개 표준 재료로 백필하고 18개 분류 집계 확인
- 오탈자·상품명·비식재료 문구처럼 자동 확정이 위험한 표준 재료 161개는 `PendingReview`로 유지
- 같은 parser 버전으로 다시 실행했을 때 처리 대상 0건 확인
- 화면 변경이 없어 PNG는 추가하지 않음
