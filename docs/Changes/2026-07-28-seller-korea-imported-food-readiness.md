# 해외 판매자의 한국 수입식품 준비

## 결과

- 해외 판매자·수출자와 실제 제조·가공·포장 시설을 별도 주체로 입력한다.
- 한국의 수입·판매 영업등록을 보유한 국내 수입자를 따로 지정하고 확인한다.
- 식약처 해외제조업소 등록 서식의 시설명·주소·대표자·연락처·국가, 생산 품목, 업종, 안전관리 체계와 수출국 증빙을 준비 원장에 저장한다.
- 기존 식약처 해외제조업소 공식자료 조회 모듈을 판매자 앱에서 재사용해 등록 코드·시설명·주소를 불러오되, 같은 시설인지 판매자가 직접 확인한다.
- 동물성 식품, 축산물 해외작업장, 별도 정부 경로 검토가 필요한 수산물을 일반 해외제조업소 등록과 구분한다.
- 한국어·영어가 아닌 증빙의 공식 영문 확인·공증 번역, 등록 만료와 갱신 시점, 국내 수입자 누락을 준비도 차단 사유 또는 주의사항으로 표시한다.
- 식약처 등록·수입 신고·검사·통관은 자동 실행하지 않고 `Simulation` 준비와 사람 검토까지만 제공한다.

## 화면 확인

간접 확인이다. `SellerApp`의 Android·Windows 빌드와 화면 조립 테스트로 Route, 세 주체별 입력, 특수 품목 절차, 증빙, 준비도 결과가 컴파일되는지 확인했다. 이번 변경에서는 실제 기기 렌더 PNG를 만들지 않았다.
