# 기사 정산계좌 서버 API

## 결과

- 기사 본인의 정산 입금 계좌를 `GET`, `PUT`, `DELETE /api/v1/driver/settlement-account`로 조회·등록·철회할 수 있게 했다.
- 인증된 기사 ID만 사용하며 다른 기사의 계좌 ID를 요청으로 받지 않는다.
- 등록·변경 요청에는 정산계좌 개인정보 저장 동의를 요구한다.
- 예금주명과 계좌번호는 persistence 경계의 value converter로 암호화한다.
- 응답에는 전체 계좌번호 대신 끝 네 자리만 남긴 마스킹 값을 반환한다.
- 계좌가 등록되거나 변경되면 외부 실명 확인 전까지 `Unverified` 상태로 둔다.
- 한국과 미국 등 운영 시장을 같은 계약으로 지원할 수 있도록 ISO 2자리 국가코드를 저장한다.
- 등록·변경·삭제 감사 로그에는 국가코드만 남기고 예금주명과 계좌번호는 포함하지 않는다.
- 계좌 삭제는 반복 호출해도 성공하는 멱등 동작으로 구성했다.

## 화면

- 화면 없음 — 이번 변경은 서버 계약, UseCase, 영속 모델과 테스트만 포함한다.
- 기존 Figma 기사 계좌 화면과 연결할 수 있는 서버 경계를 마련했으며 `DriverApp`과 `FDriverApp`은 수정하지 않았다.

## 검증

- 기사별 계좌 한 건의 unique index와 민감 필드 암호화 converter를 모델 테스트로 확인한다.
- 미등록 조회, 저장 동의, 응답 마스킹, 다른 기사 계좌 비노출, 변경 시 확인 상태 초기화, 멱등 삭제를 UseCase 테스트로 확인한다.
- MySQL 마이그레이션 `AddDriverSettlementAccount`는 `기사정산계좌` 테이블과 기사 ID unique index만 생성한다.
