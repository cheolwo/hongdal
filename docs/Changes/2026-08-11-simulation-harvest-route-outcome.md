# Simulation HarvestLot 네 판로 결과 통합 projection

## 결과

하나의 HarvestLot을 기준으로 조합 출하·직판·보관·외부 교역 네 경로를 같은 읽기 모델로 반환한다. 선택된 경로만 실제 원장에서 현재 단계와 결과를 읽고 나머지는 `NotSelected`로 표시한다.

## 경로별 읽기

| 경로 | 읽는 결과 |
| --- | --- |
| 조합 출하 | 인수 후보, Cargo 예약·운송·도착 단계와 해결 수량 |
| 직접 판매 | 시장 공급 반영 수량과 판로 재정 효과 |
| 보관 | 감모 후 비축 Lot·잔여 수량과 비축 현황 |
| 외부 교역 | 준비·Cargo·인계·항만·준비성·계획·실행, 성공·손실 수량과 누적 재정 |

## 검증 예시

- 조합 인수 전: 해결 0kg, 잔여 300kg.
- 직판 적용: 시장 공급 300kg, 누적 재정 +30만 원.
- 보관 적용: 2% 감모 후 비축 294kg, 잔여 6kg, 누적 재정 -1.5만 원.
- 수출 성공: 도착 300kg, 누적 재정 +101만 원.
- 수출 손실: 손실 300kg, 누적 재정 -79만 원.

## 경계

- projection 조회는 session revision과 재정을 변경하지 않는다.
- 선택되지 않은 경로에 실제 결과를 생성하지 않는다.
- save/replay authority나 운영 효과를 만들지 않는다.

## 검증

- 수출 및 네 판로 집중 테스트: 63/63 통과
- Simulation 전체 테스트: 259/259 통과
- scoped Fast: build 및 변경 검사 통과
- scoped Task: build 통과, 전체 4,508건 중 4,501건 통과. 이번 범위와 무관한 기존 route·metadata·CSS 기대 7건 실패
- 화면 변경 없음
