# 재료 관련 국내외 기업 공식 근거 조사

## 목표

공식 음식의 구조화 재료를 선택한 뒤 국내 제조업소, 국내 수입업체와 해외 제조업소의 공개 근거를 같은 화면에서 조사할 수 있도록 연결했다. 기업 목록을 추천 순위나 거래 가능 업체 명부로 만들지 않고, 공식 제품·표시 이력에서 확인된 관계 후보와 출처 상태를 제공한다.

## 공식 원천

| 역할 | 공식 원천 | 연결 근거 | 한계 |
|---|---|---|---|
| 국내 제조업소 | 식품안전나라 `C002` 식품(첨가물) 품목제조보고(원재료) | 원재료명, 업소명, 인허가번호, 제품명, 품목유형 | 품목제조보고 이력이 현재 공급능력이나 판매 의사를 보증하지 않음 |
| 국내 수입업체 | MFDS 수입식품 제품별 한글표시사항 | 원재료명, 수입업체명, 제품명, 품목 | 표시 이력에 수입업체 인허가번호가 없으므로 별도 공식 대조 필요 |
| 해외 제조업소 | MFDS 수입식품 제품별 한글표시사항 + 해외제조업소 정보 | 원재료가 표시된 제품의 제조업소명·제조국, 정확히 일치한 시설 코드와 주의 상태 | 이름·국가 일치도 후보 연결이며 최신 수입 가능성이나 계약 권한을 확정하지 않음 |

## 구현

- 공개 API: `GET /api/v1/agricultural-fisheries/food-ingredients/companies`
- 저장 조회 API: `GET /api/v1/agricultural-fisheries/food-ingredients/companies/archive`
- 전산화 범위 API: `GET /api/v1/agricultural-fisheries/food-ingredients/companies/coverage`
- 조회 조건: `ingredientKey`, `ingredientName`, `take`이며 `take`는 최대 20건이다.
- 외부 원천별 성공·미설정·실패 상태를 분리하고 일부 원천이 실패해도 다른 원천의 결과를 유지한다.
- 공개 후보에는 사업체명, 국가, 역할, 관련 제품, 공식 식별자, 원재료 원문, 보고·처리일, 변경일, 근거 출처와 조회시각을 포함한다.
- 대표자명, 전화번호와 상세 주소를 공개 계약에 포함하지 않는다.
- 모든 후보의 `CanAutoSelect`와 `CanAutoContact`는 `false`이고 최신 공식 상태 재확인이 필요하다.

## 재료별 전산화

전체 공식 음식 재료 색인을 순차 처리하는 배치 아카이브를 추가했다.

- 조사 실행: 실행 키, 수동·배치·예약 구분, 처리·실패·근거 건수, 시작·종료시각을 저장한다.
- 재료 프로필: 마지막 조사어, 상태, 업체·제품근거·역할별 건수와 원천 실패 횟수를 저장한다.
- 제품 근거: 재료-업체-제품 관계, 공식 식별자, 원재료 원문, 공식 날짜, 최초·최근 관찰시각과 관찰 횟수를 저장한다.
- 중국 해외제조업소 근거에는 식약처 지역명·주소에서 확인한 제조업소 소재 권역, 분류 방식, 근거 요약과 확신도를 함께 저장한다. 세부 정의는 [중국 수입식품 제조업소 권역 조사](../Architecture/ChinaImportedFoodRegionResearch.md)를 따른다.
- 원천 관찰: 실행·재료·원천별 성공, 미설정, 실패 상태와 공식 URL을 이력으로 저장한다.
- 성공한 직접 근거 원천에서 사라진 제품만 비활성화한다. 원천이 실패하거나 설정되지 않은 경우에는 기존 근거를 삭제하지 않는다.
- 동일 업체의 여러 제품 근거는 정규화한 업체명·국가·역할로 묶어 조회하되 법인 동일성을 자동 확정하지 않는다.

수동 화면 조회도 같은 아카이브에 저장되며 화면에 전산화 실행 키와 업체·제품 근거 수를 표시한다. 전체 배치는 다음 명령으로 실행한다.

```powershell
dotnet run --project Ssalddel -- --research-official-food-ingredient-companies --max-items=500 --candidates-per-ingredient=100
```

`--force`, `--refresh-after-days=30`, `--request-delay-ms=250`을 지원한다. 예약 배치는 `AgriculturalFisheriesBatch:IngredientCompanyResearchEnabled`를 명시적으로 켠 경우에만 실행한다.

## 화면 흐름

`나라·음식 → 레시피 재료 → 관련 기업 공식 근거 → 국내 공동구매/공동수입 검토 → 제안 초안`

기업 조사는 사용자가 버튼을 누를 때만 실행된다. 음식의 문화적 국가를 기업 국가, 제품 원산지 또는 실제 선적 출발국으로 자동 변환하지 않는다.

## 설정

- 국내 원재료 보고: `PublicData:MfdsIngredientCompanies:ApiKey`
- 식품안전나라 키 재사용: 위 값이 비어 있으면 `PublicData:MfdsCookRecipe:ApiKey`
- 수입표시·해외 제조업소: `PublicData:DataGoKrServiceKey` 또는 각 MFDS 서비스별 `ServiceKey`
- 식품안전나라 키가 존재해도 `C002` 데이터활용 권한이 활성화되어야 한다. HTML 오류 응답은 기업 근거로 저장하지 않고 출처 실패 상태와 점검 안내만 보관한다.

키가 없으면 화면은 허위 샘플 업체를 표시하지 않고 해당 원천을 `연동 준비 필요`로 표시한다.

외국어 재료는 현재 재료의 공식 색인 명칭을 조사어로 보존한다. MFDS 원천의 검색 언어와 맞지 않는 재료는 결과 없음 또는 검토 대상으로 남기며 번역어를 자동으로 기업 관계 근거로 확정하지 않는다.
