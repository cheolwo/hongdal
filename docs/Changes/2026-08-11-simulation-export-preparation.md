# Simulation 수출 준비 포장·검사·인계 후보 원장

## 결과

`ExportAgent` 판로로 적용 완료된 수확 배분을 원천으로 포장 준비, 모의 검사와 배송대행지 인계 후보까지 연결했다. 검사 실패는 재작업 가능한 결과로 남고 예약 수량은 원배분에 반환된다.

## 업무 흐름

```text
수출 대행 판로 배분
  → 수출 준비 Preview
  → Confirm과 수량 예약
  → 포장 중
  → 검사 중
  ├─ 통과: 배송대행지 인계 후보 준비
  └─ 실패: 재작업 필요 + 예약 수량 반환
```

## 운영 경계

- 모든 결과는 Simulation 후보이며 실제 수출신고가 아니다.
- 통관, 무역계약, 실제 운송사 인계와 정산을 생성하지 않는다.
- 검사 결과는 공식 검사 결과가 아니라 시나리오 입력이다.
- 차량·NPC·포장 상자 표현은 원장 상태를 확정하지 않는다.
