# 해양수산 어획구역 바다 타일

## 화면 변화

- Web·MAUI 공통 농수산 지도에 `수산·바다 구역` 콘텐츠 레이어를 추가했다.
- 세계 해양 개략도에 `북국해`, `베링해`, `지중해`, `대서양`, `태평양`, `인도양`, `남극수역` 타일을 표시하고 선택한 바다의 공식 분류 구역 수와 예시를 보여 준다.
- 타일에는 부유·물결 애니메이션을 적용하고 `prefers-reduced-motion`에서는 움직임을 끈다.
- 애니메이션과 개략 위치가 실시간 어획량·수온·조업 이동이나 공식 해역 경계를 뜻하지 않는다는 안내를 지도와 상세에 함께 표시한다.

## 데이터 수집과 경계

- 원천: [해양수산부 공동활용체계 어획구역](https://www.data.go.kr/data/15147444/fileData.do)
- 원천 버전: `20211230`
- 갱신 주기: 공공데이터포털 표기상 `수시 (1회성 데이터)`
- 제공 필드: 영어 약자, 구역 영문명, 구역 한글명, 바다
- 제공하지 않는 값: 좌표, 경계 도형, 어획량, 수온, 관측 시각

서버는 CP949 CSV를 읽어 수집 시각과 SHA-256을 남기고 24시간 캐시한다. 실제 원문 169행 중 공식 바다 배치에 연결한 167행을 7개 타일로 집계했으며, 빈 바다 값과 시험 행 2개는 제외 수로 공개한다. 원천 수집 실패를 표본 데이터로 대체하지 않는다.

## 시각 검증

간접 확인이다. WebApp과 공유 Razor 컴포넌트 빌드는 성공했고 브라우저 DOM에서 새 제목·레이어 선택·한계 안내가 렌더링되는 것까지 확인했다. 다만 이미 실행 중이던 WebApp 개발 서버가 재빌드된 Blazor 동적 모듈과 어긋나 전체 화면 로딩이 중단되어 실제 PNG를 남기지 못했다. 해당 기존 프로세스는 다른 작업일 수 있어 종료하지 않았다.

## 검증

- 수집 인코딩·CSV 따옴표·캐시·원문 해시·바다별 집계 테스트 통과
- 지도 API client·ViewModel·Web·MAUI 공통 presentation 테스트 통과
- 관련 테스트 17개 통과
- `Ssalddel.Contracts`, `Ssalddel.Ui.Common`, `Ssalddel`, `Ssalddel.WebApp` 빌드 성공
- 실제 서버에서 공식 원문 수집 API 응답 확인: 169행, 연결 167행, 제외 2행, 타일 7개
