# Simulation 수출 목적 시장·선적 계획 비교

## 결과

수출 준비 후보 Cargo에 목적 국가·시장과 해상/항공 운송 방식을 붙여 예상 매출·비용·순수익·기간·위험을 비교한다. 여러 Preview 중 선택한 하나만 Confirm하여 계획 후보로 남긴다.

## 흐름

```text
ReadyCandidate
  → 목적 시장 A·해상 Preview
  → 목적 시장 B·항공 Preview
  → 수익·비용·기간·위험 비교
  → 하나의 계획 Confirm
  → 계획 Task
  → WorldTick
  → PlannedCandidate
```

## 경계

- 모든 상업 조건은 출처를 가진 Simulation 추정치다.
- 위험 점수는 0~100, 수준은 낮음·중간·높음으로 결정적으로 계산한다.
- 계획 전후 정착지 재정과 출고 예약 300kg은 동일하다.
- 같은 준비성 검토에서 계획을 중복 확정하지 않는다.
- 실제 견적·운송 예약·수출신고·공식 검사·검역 승인·통관·선적을 생성하지 않는다.

## 검증

- 수출 준비부터 선적 계획까지 집중 테스트: 48/48 통과
- Simulation 전체 테스트: 244/244 통과
- scoped Fast 통과
- scoped Task 빌드 통과, 전체 테스트는 기존 비관련 7건 실패로 4,501/4,508 통과
- 화면 변경 없음
