# 주문자 해외 구매 목적과 통관 안내

## 변경 목적

주문자가 해외 상품의 개인 소비와 사업·판매 목적을 구분하더라도 기존 화면에서는 그 선택이 통관·세금 의미로 이어지지 않았다. 개인통관고유부호를 입력하면 자동으로 면세되는 것으로 오해하거나, 판매용 물품을 개인 자가사용 경로로 처리하려는 판단을 막기 위해 기존 주문자 여정에 통관 목적 안내를 연결했다.

## 변경 내용

| 구간 | 변경 |
| --- | --- |
| 공동구매 원함 등록 | 기존 `B2C 개인 소비`와 `B2B 사업 목적` 선택 바로 아래에 목적별 통관 경계를 표시한다. |
| 같이 수입 준비 개요 | 원장 거래유형을 개인 자가사용 또는 사업·판매 수입 목적으로 투영하고 면세 후보·사업 수입 비용 검토 상태를 표시한다. |
| 견적·예상 비용 | 개인 구매도 요건 확인 전 관세·세금을 0원으로 확정하지 않고, 판매 목적은 관세·수입 부가세·품목별 비용을 견적에 포함하도록 안내한다. |
| 정보 제공 | 개인통관고유부호 원문을 공동 원장이나 포워더 집계에 기록하지 않고 실제 개인 통관 절차의 전용 입력 단계에서만 받도록 안내한다. 판매 목적에는 해당 입력을 열지 않는다. |
| 서버 통관 동의 | 통관 동의 요청에 수입 목적을 요구하고 사업·판매 목적 요청은 개인통관고유부호 등록 전에 차단한다. |
| 통관·3PL 경로 | 물품가격, 식품 여부, 냉장·냉동 조건을 입력해 목록통관·일반 수입신고, 과세 검토, 식품요건과 3PL 권유를 분리해서 확인한다. 판매 목적은 3PL 이용을 권유하고, 150달러 초과 또는 냉장·냉동 물량은 비교 검토로 안내한다. |
| 조건별 3PL 비교 | 상온·냉장·냉동과 식품 여부를 구분하고, 공동재고 보관·정확한 상품 취급 근거·취급 불가 제한·온도제어 역량을 함께 확인해 조건을 모두 충족한 공개 후보만 표시한다. |

## 판단 기준

- 개인통관고유부호는 개인 물품 수입자의 식별수단이며 면세 증명이 아니다.
- 일반 자가사용 소액물품은 미화 150달러 이하를 기준으로 검토한다.
- 미국발 미화 200달러 기준은 목록통관 대상 등 조건을 충족한 물품에 한해 검토한다.
- 판매·영업 목적 물품에는 자가사용 소액면세를 적용하지 않으며 HS 코드, 원산지, 과세가격과 품목별 요건에 따라 사업 수입 절차와 예상 세액을 검토한다.
- 같이 주문·같이 수입이라는 사실만으로 참여자별 면세를 가정하거나 판매용 물량을 개인 명의로 분할하지 않는다.
- 식품류·건강기능식품은 목록통관 배제 대상이지만, 개인 자가사용이고 물품가격이 미화 150달러 이하라면 일반 수입신고를 거쳐 관세·부가세 면세가 가능할 수 있다.
- 3PL은 세금을 면제하는 수단이 아니며 수입자·관세사를 자동으로 대신하지 않는다. 판매용 물량의 통관 후 입고·검수·보관·피킹·출고와 식품·냉장 역량을 비교하는 후속 물류 선택지다.
- 표시되는 3PL은 공개된 업체 자료를 검토한 중립 비교 후보이며 플랫폼 제휴사나 운영 배정 대상이 아니다. 실제 시설별 온도 범위, 식품 취급, 견적과 허가·등록 상태는 계약 전에 다시 확인한다.
- 현재 배포 운영시장에 카탈로그가 없거나 정확한 조건의 후보가 없으면 조건을 임의로 완화하거나 가상 업체를 표시하지 않는다.
