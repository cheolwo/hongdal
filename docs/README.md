## 문서 유형

### 기준 문서

현재 판단의 단일 기준이다. 동일한 정책이나 로드맵을 설명하는 새 문서를 만들기 전에 기존 기준 문서에 절을 추가한다.

### 제안서와 구현 계획

아직 확정되지 않은 선택지, 단계별 구현안과 검증 계획을 기록한다. 문서 첫부분에 어떤 기준 문서를 따르는지와 무엇을 결정하지 않는지를 적는다.

### 변경 기록과 페이지 증빙

특정 시점에 무엇이 바뀌었고 무엇을 검증했는지 남기는 기록이다. 현재 코드와 달라질 수 있으므로 삭제하거나 기준 문서에 합치지 않는다. 현재 상태를 판단할 때는 실제 route, contract, test와 기준 문서를 함께 확인한다.

## 새 문서 작성 기준

1. 먼저 이 문서와 대상 폴더의 `README.md`에서 같은 책임의 기준 문서를 찾는다.
2. 기존 기준을 보완할 수 있으면 새 문서를 만들지 않고 해당 절을 갱신한다.
3. 별도 제안서가 필요하면 기준 문서와의 책임 차이, 확정되지 않은 범위와 종료 조건을 명시한다.
4. 파일을 대체할 때는 기존 경로를 바로 삭제하지 않고 짧은 호환 안내를 남긴다.
5. 변경 기록과 페이지별 캡처 증빙은 중복처럼 보여도 이력 추적을 위해 보존한다.
6. 문서 링크와 `git diff --check`를 검증하고, 코드 상태를 문서만으로 완료했다고 표현하지 않는다.
