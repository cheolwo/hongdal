# 미국 수입식품 제조업소 주별 조사

## 목적과 표시 원칙

식품의약품안전처의 수입식품 제품·해외제조업소 공식 근거에서 제조국이 미국인 기록을 미국 50개 주 단위로 분류해 재료별 조사 원장에 누적한다. 주는 USPS 2자리 약어를 붙인 `US-CA`, `US-WA` 같은 안정 코드로 저장하고, Census ANSI/FIPS 코드를 분류 카탈로그에 함께 둔다.

워싱턴 D.C.와 미국령 사모아·괌·북마리아나제도·푸에르토리코·미국령 버진아일랜드는 50개 주 통계와 분리한다. 미국 국가만 확인되고 주 근거가 없거나 제조업소 주소가 미국 외 국가를 가리키면 `US-OTHER-UNCLASSIFIED`로 보존한다. 도시명만 보고 주를 추정하지 않는다.

이 값은 **식약처 근거에 나타난 해외제조업소 소재 주**다. 원재료의 생산·재배·어획 주, 제품의 법정 원산지 또는 수출항을 뜻하지 않는다. 소비자 표시에서는 법정 국가 원산지 `미국산`을 유지하고 주 정보는 `제조업소 소재: 캘리포니아주`처럼 별도 근거로 표시한다.

## 분류 근거

| 분류 | 안정 코드 예 | 자동 분류 근거 | 표시 제한 |
| --- | --- | --- | --- |
| 미국 50개 주 | `US-CA`, `US-WA` | 식약처 공식 지역명의 주 전체 이름·USPS 코드 또는 제조업소 주소의 주 전체 이름·USPS 코드와 우편번호 문맥 | 제조업소 소재를 원재료 산지로 확정하지 않음 |
| 워싱턴 D.C. | `US-DC` | `District of Columbia`, `Washington DC`, `DC`와 우편번호 문맥 | 50개 주 수치와 분리 |
| 미국령 지역 | `US-PR`, `US-GU` 등 | 공식 지역명 또는 주소의 지역 전체 이름·USPS 코드 | 미국 본토 주 수치와 분리 |
| 미국 기타·미분류 | `US-OTHER-UNCLASSIFIED` | 제품 국가는 미국이나 안전한 주·지역 근거가 없음 | 통계에서 숨기거나 인접 주로 추정하지 않음 |

주 이름과 우편 약어는 [USPS Publication 28 Appendix B](https://pe.usps.com/text/pub28/28apb.htm), 주·연방구·미국령의 숫자 코드는 [미국 Census Bureau ANSI/FIPS 코드 목록](https://www.census.gov/library/reference/code-lists/ansi/ansi-codes-for-states.html)을 기준으로 한다. 주소의 `CA`처럼 일반 단어와 충돌할 수 있는 두 글자는 단독 포함만으로 판정하지 않고 우편번호, 주소 구분자 또는 미국 국가 표기가 이어지는 주소 문맥에서만 사용한다.

## 첫 공개자료 스냅샷

기준 자료는 식품의약품안전처가 공공데이터포털에 공개한 [수입식품 제품 목록 데이터(2025년)](https://www.data.go.kr/data/15098434/fileData.do?recommendDataYn=Y)다. 2026-07-24에 조사한 연간 파일은 전체 3,901개 제품 행이며, `NTNCD=US` 또는 국가명 `미국`인 행은 378개다.

| 구분 | 제품 행 수 | 미국 제품 행 대비 |
| --- | ---: | ---: |
| 캘리포니아주 | 189 | 50.0% |
| 워싱턴주 | 61 | 16.1% |
| 알래스카주 | 12 | 3.2% |
| 메인주 | 8 | 2.1% |
| 오리건주 | 7 | 1.9% |
| 위스콘신주 | 5 | 1.3% |
| 미네소타주 | 5 | 1.3% |
| 루이지애나주 | 4 | 1.1% |
| 네브래스카주 | 3 | 0.8% |
| 애리조나주 | 3 | 0.8% |
| 그 밖의 안전 분류 주 | 21 | 5.6% |
| 미국 기타·미분류 | 60 | 15.9% |
| 합계 | 378 | 100.0% |

주 이름 또는 USPS 코드·우편번호 문맥으로 안전하게 분류된 행은 318개로 84.1%다. 60개 미분류 행에는 제품 국가는 미국이지만 첫 유효 제조·수출 관련 주소가 중국·베트남 등 미국 외 국가를 명시한 경우와, Stockton·Kalama처럼 도시만 있고 주·우편번호가 없어 단정할 수 없는 경우가 포함된다.

주소는 `OVSMNFST_ADDR`(해외제조업소), `EST_ADDR`(수출업소), `PCKLOC_ADDR`(포장장소), `EXPTER_ADDR`(수출자) 순서로 첫 유효값을 사용했다. 파일 SHA-256은 `E234E8245290DC166187BB212D8EEB11F149931A2586B9F594BF7E99E132D73A`다.

이 수치는 **수입량, 수입액, 업체 수 또는 생산량이 아니라 공개 목록의 제품 행 수**다. 같은 업체·품목의 여러 제품이 각각 포함될 수 있다. 특히 제품 국가가 미국이라고 해서 선택된 제조·수출 관련 주소까지 반드시 미국에 있는 것은 아니므로 주소 근거가 불충분한 행을 주별 수치에 강제 배분하지 않는다.

## 원장에 누적하는 필드

중국 권역 근거와 같은 `food_ingredient_company_evidence` 필드를 재사용한다.

| 필드 | 의미 |
| --- | --- |
| `ManufacturerRegionCode` | `US-` + USPS 코드 또는 `US-OTHER-UNCLASSIFIED` |
| `ManufacturerRegionName` | 한국어 주·연방구·미국령 표시명 |
| `ManufacturerRegionScope` | 지역 유형, USPS 코드, Census FIPS와 해석 제한 |
| `ManufacturerRegionClassificationMethod` | 공식 지역명·공식 약어·주소 주 이름·주소 약어·외국 주소·국가만 확인 중 실제 근거 |
| `ManufacturerRegionEvidence` | 상세 주소를 복제하지 않은 일치 지역명·코드 요약 |
| `ManufacturerRegionConfidence` | 공식 지역명·코드 `1.0`, 주소 주 이름 `0.95`, 주소 약어 문맥 `0.90`, 미분류 `0.40~0.50` |

상세 제조업소 주소는 공개 조사 계약이나 근거 원장에 복제하지 않는다. 식약처 해외제조업소명과 국가가 일치한 경우에만 조회 중 주소·지역명을 분류 입력으로 쓰고, 원장에는 일치한 주·지역명과 분류 방식만 남긴다.

배치와 OpenAPI 연결은 기본 비활성이다. 키가 없거나 원천이 실패한 경우 기존 관측값을 삭제하거나 샘플 데이터로 대체하지 않으며, 성공한 직접 근거 원천에서 사라진 제품만 현재 근거에서 비활성화한다.

## 관련 게시판 월간 누적

재료별 기업 근거 배치가 성공한 뒤 `AgriculturalFisheriesBatch:PublishUnitedStatesImportedFoodStateBriefs=true`이면 현재 미국 주별 근거를 `MFDS 수입식품 데이터` 게시판의 시스템 글로 누적한다.

- 식별자는 `us-imported-food-state-brief + yyyyMM`이므로 같은 달에는 한 글만 생성한다.
- 제품 근거가 많은 주 최대 10개, 나머지 분류 주 합계, 워싱턴 D.C.·미국령, 미국 기타·미분류를 분리한다.
- 현재 제품 근거 행, 정규화한 업체 후보 묶음 수, 재료 수, 이번 달 신규·재확인 행과 상위 재료를 표시한다.
- 상세 제조업소 주소, 연락처, 제품 원문, 수입업체 연락 정보는 게시하지 않는다.
- 현재 근거가 없으면 빈 안내 글을 만들지 않는다.
- 게시글은 수입량·수입액·거래 가능 업체 수가 아니며 업체 추천·선정·연락이나 같이 수입 원장을 자동 실행하지 않는다.

게시 저장은 공통 자동 정보 Publisher가 맡으며 같은 월의 재실행과 Quartz 즉시 재시도에도 중복 게시하지 않는다. 조사 배치와 미국 게시 설정은 모두 기본 비활성이다.

## 다음 축적 순서

1. 새 연도 식약처 제품 목록이 공개되면 원본 파일 해시, 공개일, 기준연도와 분류 규칙 버전을 함께 저장한다.
2. 미분류 행은 도시명 사전을 넓혀 추정하지 않고 식약처 공식 지역명 또는 주·우편번호가 보강될 때만 재분류한다.
3. 제품 행 수, 업체 수, 수입 중량, 수입 금액을 서로 다른 지표 코드와 단위로 저장한다.
4. 주별 제조업소 근거를 USDA 생산자 가격과 연결할 때도 품목·기준월·단위가 일치하는 별도 교차표를 사용하고 같은 수치 계열로 합치지 않는다.
5. 주 분류율, 외국 주소 보류율, 공식 지역명·주소 기반 분류 비율을 연도별 품질 지표로 남긴다.
