# 상향식 배치 성립 통제 계층

## 결정

배치 통제의 주 조립 관점은 `H1 → H2 → H3 → H4 준비도`로 둔다. 세계 외곽에서 객체까지 내려오는 기존 계층은 제거하지 않고 상위 제약 검사 축으로 재분류한다.

```text
주 성립 축: H1 운영 증거 → H2 성립 → H3 성립 → H4 AreaSet 준비도
제약 검사 축: WorldEnvelope → AreaEnvelope → H3/H2/H1 외곽 → 실내·통로·설비
```

물리적 포함 관계와 의미 공간 성립은 같은 방향일 필요가 없다. 포함 외곽은 상위에서 하위로 위치·크기·충돌을 제한하지만, 상위 H 인스턴스는 승인된 하위 인스턴스의 능력·용량·연결·운영 상태·배치 검증 증거를 모아 Simulation이 성립시킨다.

## 성립 상태

- `Blocked`: 필수 자식, 능력, 용량, 연결, 폐루프 또는 배치 증거가 부족하다.
- `Qualified`: 규칙은 충족했지만 아직 WorldTick이 성립을 확정하지 않았다.
- `Formed`: WorldTick이 상위 공간 인스턴스를 성립시켰다.
- `Degraded`: 이미 성립한 공간의 필수 하위 증거가 사라졌다.
- H4는 첫 판본에서 `NotReady | PartiallyReady | Ready` 준비도만 계산하며 AreaSet 인스턴스를 자동 생성하지 않는다.

성립 판정은 Stable ID 정렬, 규칙 catalog revision/hash, 하위 배치 계획 hash와 World revision을 입력으로 사용한다. 입력 순서와 Unity Scene 계층 순서는 결과 hash를 바꾸지 않는다. 순환 H 규칙과 중복 증거는 계약 오류로 거부한다.

## Hub 첫 조립

`h2-candidate:hub-internal-warehouse`는 다음 H1이 모두 운영 가능할 때 성립한다.

- `h1-stock:hub-receiving-storage`
- `h1-stock:hub-outbound-staging`

두 H1은 canonical 25×20m `interior-placement-plan.v2`의 같은 계획 hash, 필요한 공간 능력, 300 KGM 저장 용량, 1개 출고 작업면, 입고 `Output → Input` 출고 연결을 제공한다. 초기 평가는 `Qualified`, 다음 WorldTick에서 `Formed`가 된다. 이후 하위 H1이 중단되거나 배치 검증이 무효가 되면 H2는 `Degraded`가 된다.

H3 진부 Hub는 내부 창고 H2와 `h2-candidate:hub-outbound-vehicle` 및 두 Hub 독립 폐루프를 요구한다. 차량·`WI-HUB-06`은 현재 범위 밖이므로 H3는 `Blocked`, H4 Hub AreaSet은 `PartiallyReady`다. 이는 Hub 내부 폐루프 완성을 외부 운송과 독립시키기 위한 의도된 결과다.

## 권위와 호환

- H 정의와 Simulation 공간 상태가 능력·성립 권위를 소유한다.
- Unity `placement-control-hierarchy.v3`는 상향식 주 성립 축과 하향식 제약 축을 표현할 뿐 WorldTick을 변경하지 않는다.
- `placement-control-hierarchy.v1/v2`, Town `interior-placement-plan.v1`, `simulation-save.v21` 이하는 그대로 읽고 기존 hash 의미를 유지한다.
- 상향식 공간 상태를 명시적으로 켠 세션만 `simulation-save.v22`에 구성 상태와 graph handle을 저장한다.
- Solo `LocalProcess`와 Hosted `RemoteHost`는 같은 Simulation Core의 graph hash를 조회한다.

## 현재 증거 경계

계약·결정성·성립/저하·v22 저장 재생·Local/Hosted Adapter 동등성은 자동 시험 E3 증거다. canonical `SimulationWorldShell`의 저장된 v3 배선, 실제 Player·손수레 이동, NPC 동선, Play Mode·Game View·Console은 별도 E7 증거가 필요하다. 동적 NavMesh, 지게차, 차량 이동, 외부 운송과 운영 효과는 포함하지 않는다.
