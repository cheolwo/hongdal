# 공공 레시피 재료에서 상품 판매로 이어지는 여정

## 목적

공식 레시피의 재료를 공공가격과 실제 레시피 관계로 살펴본 사용자가 공동구매에 자발적으로 참여하고, 완료된 공동 원장의 공개 후기와 비식별 집계를 근거로 다음 상품 판매를 준비할 수 있게 한다.

```text
공식 레시피 수집
  -> 표준 재료·분류
  -> 출처가 확인된 공공가격 + 실제 관련 레시피(최대 3개)
  -> 사용자가 여는 공동구매 초안
  -> 입고·구매 원장 완료
  -> 참여자의 공개 후기
  -> 마트 상품 상세의 비식별 구매 근거
  -> 판매자가 검토·수정하는 판매 페이지 초안
```

각 화살표는 자동 계약이나 자동 판매 확정이 아니다. 사용자의 명시적 선택과 서버의 권한·현재 상태 검증을 거쳐 다음 단계로 이동한다.

## 연결 규칙

1. 재료에는 실제 사용 행으로 확인된 레시피만 최대 3개 연결한다. 부족한 관계를 유사 재료로 채우지 않는다.
2. 한국 KAMIS와 미국 USDA NASS의 정확한 품목 매핑이 있는 농수축산물만 가격을 표시한다. 통화·단위·시장 단계가 다른 수치는 직접 비교하지 않는다.
3. 공동구매 화면에는 재료·레시피 문맥을 초안 값으로만 전달한다. 참여·가격·수량·배송권은 사용자가 확인한다.
4. 공개 상품의 구매 근거는 `공개 상품 -> 판매상품 -> 입고상품 -> 커뮤니티 원장`의 기존 연결을 따라 서버가 계산한다.
5. 원장 상태가 완료이거나 시스템 완료 글이 발행된 경우에만 구매 완료로 표시하고 후기를 받을 수 있다.
6. 구매후기는 새 평점 원장을 만들지 않고 기존 `완료 사례·후기` 커뮤니티 글로 저장한다. 로그인과 해당 원장 접근 권한은 기존 게시글 발행 UseCase가 다시 검증한다.
7. 판매 페이지 초안은 공개 상품 ID만 입력으로 받고, 완료 여부와 공개 후기 수는 서버가 다시 조회해 비식별 스냅샷으로 저장한다.

## 상품 상세 공개 범위

상품 상세에는 완료 여부·확인 시각, 공개 후기 수, 최근 공개 후기 최대 3개, 추천·댓글 수만 표시한다. 다음 정보는 노출하거나 판매 초안으로 복사하지 않는다.

- 원장 ID와 내부 상태 원문
- 참여자 명단, 사용자 ID, 연락처와 주소
- 결제·계약·정산 정보
- 개인별 주문 수량과 내부 재고 원문

후기 본문은 공개 게시글이므로 작성 화면에서 개인정보를 적지 않도록 안내한다. 삭제·신고 게시글, 예약 발행 전 글과 시스템 완료 글은 구매후기 목록에서 제외한다.

## 판매 준비 경계

완료 근거가 있는 상품에서만 기존 판매 페이지 작성기로 이동한다. 상품명·설명·근거는 편집 가능한 초안의 출발값이고 판매가, 원산지, 재고, 배송 조건과 최소 주문 수량은 자동 확정하지 않는다. 판매자가 내용을 검토해 저장하더라도 실제 판매상품 연결과 공개 검수 전에는 주문을 받지 않는다.

현재 실행 경계는 기존 `SsalddelExecution:Mode`와 기능 플래그를 따른다. 외부 API 호출, 결제, 계약, 입고, 배차 또는 판매 공개를 이 여정이 자동 실행하지 않는다.
