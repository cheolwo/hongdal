# AreaSet 구성 패턴

## 목적

AreaSet 구성 패턴은 승인된 H2·H3 공간 재고를 역할 슬롯에 배치하고 연결해 Nature·Farm·Town·City/Hub다운 하나의 지역을 만드는 위치 독립 조립 설명서다.

```text
게임 기획과 WI
        ↓
H1 행동 공간
        ↓
H2 블록 패턴
        ↓
H3 경관 조립 패턴
        ↓
AreaSet 구성 패턴
        ↓
Actual E5 공간망
        ↓
Unity 공용 검토실
```

AreaSet 구성 패턴은 H4와 H5 사이에 새 계층을 만들지 않는다. H4의 지역 세계 의도를 실제 H3·H2 선택, 상대 배치, 연결 지점과 플레이 폐루프로 번역하는 제작 계약이다.

## 권위와 산출물

| 산출물 | 책임 |
| --- | --- |
| 팩별 Markdown | 사람이 장소 의도, WI, 기준안과 변형 이유를 읽는다. |
| `area-set-composition-patterns.v1.json` | 역할 슬롯, H3 선택, H2 교체, 상대 배치와 연결을 선언한다. |
| `area-set-composition-plans.v1.json` | 검증·정규화·해시를 마친 결정적 조립 계획이다. |
| Actual E5 | 기준 구성 패턴을 실제 AreaSet의 Graph 포함 관계와 내부 관계 계보로 사용한다. |
| Unity 검토실 | 같은 계획의 구조와 Synty 표현을 보여주는 비권위 투영이다. |

Unity Scene, GameObject, Prefab, 카메라와 표시 토글은 Simulation 상태나 구성 패턴 선택의 권위가 아니다. 실제 Runtime 변형 선택이 필요해지면 서버가 Session 상태와 규칙으로 선택하고 Unity는 그 결과를 표시한다.

## 역할 슬롯

구성 패턴은 H3 고유 식별자를 나열하는 데서 끝나지 않고, 각 장소가 맡는 역할 슬롯에 H3를 배치한다.

- Nature: 생활핵, 탐색·조우, 방어·대피, 회복·복귀
- Farm: 농가·작업지원, 생산, 수확 후처리, 계절 출하, 사고 격리·회복
- Town: 저층 생활핵, 시장·서비스, 반품·회수, 오염통제·구호, 공동수령
- City/Hub: 입고·출고, 회복력 보관, 정비·비상, 보관·피킹·상차

역할 슬롯 덕분에 재고가 추가되거나 교체되어도 패턴의 플레이 의미를 유지할 수 있다. H2 교체는 소속 H3의 역할 슬롯과 연결 계약을 모두 만족할 때만 허용한다.

## 기준안과 변형안

각 AreaSet은 하나의 기준안과 하나 이상의 불변 변형안을 가질 수 있다.

- 기준안은 Actual E5의 기본 조립 계보다.
- 변형안은 위협, 계절, 오염, 격리 같은 게임 상황에서 사용할 수 있는 별도 설계 후보다.
- 변형안 JSON 자체는 Runtime 상태가 아니다.
- 기준안이나 변형안을 선택하는 실제 Session 규칙은 서버 권위다.

현재 첫 재고는 네 기준안과 네 변형안, 총 8종이다.

## 플레이 폐루프 검증

구성 패턴은 다음 조건을 모두 만족해야 한다.

1. 필수 역할 슬롯마다 TheoryQualified H3가 존재한다.
2. 상대 배치, 회전과 크기 변형이 허용된 값이다.
3. 연결 지점의 방향과 이동 종류가 호환된다.
4. 모든 H3가 하나의 구조 연결 성분에 속한다.
5. 시작 역할 → 결과 역할 → 복귀 역할의 방향성 경로가 닫힌다.
6. 참조한 WI가 공식 WI 대장에 존재한다.
7. 같은 입력에서 같은 정규 JSON과 SHA-256을 생성한다.

## Unity 공용 검토실

`AreaSetCompositionPatternReview.unity`는 네 AreaSet의 기준안과 변형안을 한 Scene에서 비교한다.

- `1~4`: Nature, Farm, Town, City/Hub 전환
- `B` / `V`: 기준안 / 변형안
- `T`: Synty 표현 표시 전환
- `H` / `J`: H3 / H2 경계
- `K`: 연결 지점
- `L`: WI 동선

검토실은 구조 결함과 표현 후보를 함께 보는 도구이며 canonical `SimulationWorldShell`을 대체하지 않는다. 검토가 끝난 구성만 별도 통합 작업으로 canonical Scene에 반영한다.

## 현실 자료 경계

구성 패턴은 위치 독립 설계 재고다. 실제 도로, 건물, 블록 경계, DEM과 공공데이터는 패턴 생성의 필수 입력이 아니며 E6 현실 결속에서 필요할 때 연결한다. 현실 근거가 없다는 이유로 Scenario 공간으로 묵시적으로 대체하지 않는다.
