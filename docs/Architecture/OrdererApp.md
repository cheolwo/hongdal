# 살뜰 주문자 앱

살뜰 주문자 앱은 주문자 관점의 별도 앱이다. 음식 배달, 홈달마트, 화물·공산품 주문은 모두 "주문"처럼 보이지만 처리 흐름이 다르므로 첫 화면에서 분리한다.

## 주문 축

### 음식 주문

음식 주문 영역은 다시 두 갈래로 나뉜다.

- 일반 음식점 주문: 가게가 조리하고, 조리 완료 후 음식 배달 기사가 픽업한다.
- 홈달마트 주문: 조리하지 않고, 도심 창고 재고를 피킹하고 포장 완료 후 음식 배달 기사가 픽업한다.

두 흐름 모두 마지막 배송은 음식 배달 기사와 연결되지만, 앞단의 처리 주체가 다르다.

### 음식점 조회 반경

음식점 주문은 주문자의 현재 위치 기준 반경 km 안에서 조회한다. 너무 먼 거리의 음식점까지 주문 가능하게 두면 기사 동선이 길어지고 플랫폼 배달료 부담이 커질 수 있기 때문이다.

초기 UI 기준:

- 기본 반경: 7km
- 빠른 선택: 3km, 5km, 7km, 10km
- 7km 이하: 기본 운영 반경
- 10km 이하: 배달료 주의
- 10km 초과: 장거리 주문

향후 서버 정책에서는 지역, 시간대, 날씨, 기사 밀도, 음식점 준비 시간에 따라 최대 주문 가능 반경을 조정할 수 있다.

### 화물·공산품 주문

화물·공산품 주문은 음식 배달과 분리한다.

- 화물 운송 의뢰
- 공산품 주문
- 대량 주문/견적
- 창고 출고 배송 연결

이 영역은 상차지, 하차지, 독차/혼적, 포장 단위, 물류 증빙 같은 항목이 중요하다.

## 현재 앱 구조

현재 `OrdererApp`은 Windows 타깃의 MAUI Blazor 앱으로 시작한다.

- `/`: 주문자 홈
- `/food`: 음식 주문 홈
- `/food/mart`: 홈달마트 주문
- `/food/restaurants`: 음식점 주문
- `/cargo`: 화물·공산품 주문
- `/orders`: 주문 내역
