## 추가 승인 범위

기존 r5의 지식 습득 실행 범위를 유지하면서, 아래 첫 차 내용물·데우기·섭취·시간 규칙을 추가 개발할 수 있도록 승인한다. r5의 후속 구현 금지 문구는 이번에 명시적으로 추가한 범위에 대해서만 이 보완으로 대체한다. 채집·의료·포션·경제 전체를 포괄 승인하지 않는다. 이미 승인된 원문 규칙과 현재 구현을 먼저 재사용한다.

첫 시험은 결정적인 차/용기/열원/Actor 상태 Fixture로 시작할 수 있다. Fixture 초기 공급을 실제 채집·완성 플레이의 증거로 보고하지 않는다. 지식·채집의 실제 상태 연결이 필요한 통합 단계에서는 기존 승인과 미완료 의존성을 별도로 확인한다.

## WI와 실행 책임

- [보편 WI 정리](문답기반보편WI계층정리.md)의 비실행군/대상별 프로필/절차 조합을 구분한다.
- `WI-HEAT-SOURCE-STATE-CHANGE`는 점화·보충·소화, 데우기는 내용물 온도 변화, `WI-CRAFT-BREW`는 배합물 완성이다. 기존 ID를 보존하고 새 데우기/전송 책임이 필요하면 개발 통합 담당이 중복 검토 후 현행 등록 절차와 작업 명세에 결속한다.
- 섭취는 `WI-ACTOR-CONSUME` 재사용을 우선한다. 부모/자식 이중 Confirm·재료 차감·ActionRecord·성장 지급 금지.
- Preview 무변경, ExpectedRevision 검증, Confirm 멱등, 같은 권위 결과의 행위 기록, 승인된 성장 적용 또는 사유 있는 제외를 유지한다.
- 전송·음용 경합으로 양이 복제되거나 온도/효과 판본이 바뀌지 않게 한다. 입력/애니메이션은 권위 완료를 대신하지 않는다.
- 최초 약초 제작의 실패/위험·처방 조건은 기존 원문을 따른다. 이번 보완을 근거로 모든 처방의 실패 손실/중단 정책을 하나로 합치지 않는다.

## 개발 분배와 단계

1. 개발 통합 담당: 기존 Goal 아래 추가 승인으로 결속하고 경로가 겹치지 않는 workItem/작업 명세를 등록한다. 첫 묶음은 용기·동종 전송·데우기·섭취 프로필의 Contracts/Domain/Application 및 집중 시험이다. 기존 지식/방문자 승인 개발을 중지하지 않는다.
2. 다음 묶음: 같은 Session의 권위 시간·Actor 활동·열원·효과와 LocalProcess/RemoteHost를 연결한다. Save 판본은 실행 시점의 실제 버전과 공용 예약을 확인해 개발 담당이 조율하며 이 문서가 새 버전 번호를 강제하지 않는다. 기존 읽기/hash 호환을 보존한다.
3. 공간 담당: 기존 폐야영지 H1의 냄비·컵·불·병 후보를 실제 측정/상호작용에 연결한다. canonical SimulationWorldShell만 사용하며 실제 View 검증·캡처를 담당한다. 사전 자산 미리보기는 Game View 증거가 아니다.
4. 애니 담당: 음용 시작/완료/중단 복귀와 기존 warmth-exhale 요구를 권위 결과에 연결한다. 전용 음원/클립 미확보는 명시하고 새 구매를 자동 수행하지 않는다.

이번 수직 진행 상한은 기존 방향과 같은 E5이며 E6/E7 이상 자동 승격은 허용하지 않는다. 첫 C# 묶음은 Logic E3 증거부터 반환한다. 표현 E4 준비·Required 전문 연구의 Accepted 결속·해당 Logic 상태 사본을 갖춘 뒤 E5 표현 작업으로 진행한다. 아직 부족한 자산/연구/공간 수용 근거는 전문 담당이 보완하되 새 게임 규칙을 임의로 바꾸지 않는다. 기획 승인 자체로 현재 E를 변경하지 않는다.

## 검증·실패·귀환 기준

- 가득 찬 용기·잘못된 판본·물 보관/가열 불가 대상은 이유와 함께 거부하고 상태를 보존한다.
- 전송 전후 총량 보존, 0/초과/부분량·동일 용기·멱등·서로 경합하는 명령을 시험한다.
- 전량/잔량 섭취, 효과 비중첩·정상 체온 상한, 완료 전 중단과 완료 직후 중단의 경계, 같은 프레임 중복 완료를 시험한다.
- 물 가열과 차 재가열이 차 제작·정수·약효 강화로 둔갑하지 않는지 검사한다.
- 불 소진/연료 조건·분할 시간 계산·LH 해제 후 지속·복원 및 Local/Remote 같은 Core 결과를 검증한다.
- 잘못된 접근/상태는 최신 조회 후 다시 선택할 수 있게 하고, 중단된 음용은 수동 재시도한다. 차를 소비한 뒤에는 남은 차를 보존해 탐험/휴식/재보충으로 돌아간다.
- 실제 화면에서는 종류/잔량/따뜻함/차단 이유·작은 완료 표시·음용 중단·다른 활동 복귀를 확인한다. 저장/재진입 이후 알림·음용·날숨·효과를 중복 발생시키지 않는다.
- 제외: 후반 술식 포션·자유 Recipe 작성·경제/상환·부패/오염·신규 난이도 보상·자동 기부/납품·새 공식 Scene·운영 DB·실제 의학적 효능.
