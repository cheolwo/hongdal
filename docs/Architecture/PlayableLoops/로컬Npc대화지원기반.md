# 로컬 NPC 대화·검색 지원 기반

## 승인 범위

- 기획 식별자: `local-npc-dialogue-foundation.design.r1`
- 상태: `Approved` (2026-08-30, D-337)
- 사용자 근거: 로컬 LLM/RAG를 설치하여 호출당 비용 없이 프로젝트에 반영할 수 있는 구조를 먼저 만들도록 요청했다.
- 성격: 기존 `playable-loop:nature-camp-visitor-stay.v1`의 선택형 비권위 대화 지원. 새로운 PlayableUnit·권위 WI·Goal이나 방문자 선정 규칙을 추가하지 않는다.
- 완료 범위: 고정된 LLMUnity 의존성 설치, 격리된 연결부·로컬 검색 입력 경계·기본 대사 대체 경로, 관련 코드 시험/소비자 컴파일. 실제 모델 추론·NPC 화면·Game View·콘솔 플랫폼 출하는 별도 증거다.
- 승인 담당: 기획. 설치/코드/공통 작업 등록·통합 담당: 개발. Editor 점유는 개발이 월드·공간·배치 담당과 조율한다.

## 플레이어 약속과 제외

플레이어가 NPC와 이야기할 때 NPC에게 허용된 세계관·플레이 기록을 참고한 짧은 대사를 제공할 수 있다. 모델이 없거나 기능이 꺼졌거나 오류가 나도 기존 기본 대사와 플레이 선택은 사용할 수 있다. 대화 생성이 게임 시간을 멈추거나 Confirm·보상·학습·거래·방문 후보 선정을 대신하지 않는다.

- `Enabled=false` 기본값. 모델 미설치 상태를 숨기지 않고 `ModelMissing` 등 명시적 가용 상태와 기본 대사를 반환한다.
- 클라우드 추론·임베딩 API·유료 서비스·API key·원격 대체 호출은 사용하지 않는다. 설치 파일 다운로드와 런타임 추론 네트워크를 구분한다.
- 첫 묶음은 PC/Windows 개발 기반이다. 콘솔 플랫폼 네이티브 플러그인 호환·인증은 확인하지 않았다.
- 원본 Scene 저장·dirty 폐기·새 공식 Scene·기존 UI 교체·물약 효과 변경·Save 판본 변경은 제외한다.
- 모델은 아직 미선정이다. 대용량 모델 자동 다운로드는 하지 않으며 파일 경로/가용성 구조를 먼저 둔다. 실제 추론 검증 전 모델의 한국어 품질·성능·상업 이용/재배포 조건을 확인한다.

## 책임과 모듈

| 모듈 역할 | 입력/출력 | 금지 |
| --- | --- | --- |
| NPC대화근거 Projection | 같은 Session/Revision에서 NPC가 알 수 있는 요약된 사실 | 모든 원장·숨겨진 지식·운영 개인정보 무차별 노출 |
| 로컬대화근거 Retriever | 허용된 자료 안에서 상한 있는 관련 근거 목록 | 검색 결과를 새 권위 사실로 저장 |
| 로컬Npc대화 Service | 근거·NPC 성격·요청을 묶어 짧은 표현 생성 | WI/Console/파일/URL 실행 도구 제공 |
| LLMUnity Adapter | 로컬 모델만 사용, 비동기 요청·취소·길이/동시성 제한 | Cloud/remote fallback, 게임 메인 스레드 동기 대기 |
| 기본대사 Provider | 비활성·모델 없음·근거 없음·취소·오류 시 명시적 대체 | 생성 성공처럼 상태를 위장 |

명칭은 책임 설명이며 기존 유사 계약을 먼저 재사용한다. 새 업무 의미는 한국어+영어 기술 역할로 명명하고 공개 vendor API는 그대로 둔다.

## 기록과 RAG 경계

1. 관심 카드·확정 WI 행위·인연·지식 등 현재 허용된 게임 상태에서 읽기 사본을 만든다. 클라이언트 입력만으로 사실을 만들어 넣지 않는다.
2. NPC/플레이어/Session/Revision·자료 공개범위로 먼저 제한한 뒤 검색한다. 다른 NPC가 모르는 사실이나 잠긴 Recipe는 검색 후보에서 제외한다.
3. 원본 사실 식별자·자료 개정·출처를 검색 결과와 함께 유지한다. 자료 안의 명령형 문장은 실행 지시가 아닌 인용 자료로 취급한다.
4. LLM 결과는 비권위 대사다. 정확한 자원량·가격·보상·선택 가능 여부는 Core 상태를 표시하며 LLM이 바꾸지 못한다. 근거 검색으로도 환각을 완전히 없애지는 못한다.
5. 첫 시험은 승인된 동결 Fixture를 사용한다. 실제 전체 원장 색인 수집은 제외한다. 로컬 키워드 검색을 쓴 초기 시험을 임베딩/의미 검색 검증이라고 부르지 않는다.
6. 저장할 때 권위 Save/hash와 검색 색인/생성 대사 cache를 분리한다. Session/자료 revision 변경·취소 후 돌아온 응답은 폐기할 수 있는 경계를 둔다. 이번에 권위 Save 형식은 수정하지 않는다.

## 패키지 선정과 설치

- 대상 `ai.undream.llm` / LLMUnity `v3.0.3`, 확인한 tag commit `9931a9ea46906b1f43adaf9498c05ccf227b5d0b`에 고정한다. 설치 직전 package.json·소스·의존성·라이선스를 대조하고 태그가 다르면 중단 원인을 보고한다.
- 공식 README는 로컬 실행·RAG·CPU/GPU 지원을 안내한다. 라이선스는 패키지와 모델을 구분하며 현재 프로젝트(Unity 6000.5.6f1)의 실제 컴파일 증거는 별도다.
- 기존 Newtonsoft 및 기타 의존성은 이유 없이 낮추지 않는다. vendor 코드를 직접 고치지 않고 별도 Adapter로 격리한다.
- 네이티브 backend의 설치 시 다운로드 여부·출처·버전·용량을 기록한다. 설치 의존성과 모델 파일, 로컬 추론 성공을 각각 별도 판정한다.
- `Packages/manifest.json`과 `packages-lock.json`의 기존 병렬 변경을 보존하고 Unity Package Manager가 작성한 결과를 검증한다. 패키지 해석이 실패하면 실제 오류와 남은 상태를 남기며 수동으로 설치 성공을 꾸미지 않는다.
