# WI 애니메이션 보유 자산 대조와 보완 제작

- 판본: `wi-animation-gap-production.r1`.
- 승인: D-361, 2026-08-30. 사용자는 기존 WI와 보유 애니메이션 자산을 확인하고 없는 동작을 제작하도록 요청했다.
- 목적: 게임의 행위와 전환을 부드럽게 연결하되 이미 보유한 Clip을 다시 만드는 낭비를 줄인다. 첫 제작은 D359 도끼 벌목 동작을 유지한다.

## 조사 단위

질문 수나 WI 수를 새 Clip 수로 환산하지 않는다. 기존 WI/활성 폐루프의 플레이 순간을 준비·수행·접촉·완료·중단·복귀로 나누고, 동일 동작을 여러 WI가 재사용할 수 있게 AnimationRole/ActionCue를 연결한다. UI 조회·추상 정책은 전용 몸동작이 불필요할 수 있다.

대장은 WI/실제 구현 상태, 플레이 순간, 기존 자산 경로·GUID·hash·Clip·Rig, Unity 연결 상태, 부족한 점, 우선순위, 담당·산출물, 실제 재생 검증을 가진다. 팩 소개나 Clip 이름만으로 재생 성공을 주장하지 않는다.

| 분류 | 다음 처리 |
| --- | --- |
| 직접 재사용 가능 | 실제 Rig/재생을 확인하고 기존 상태에 연결 |
| 보정·재타깃 필요 | 원본 보존 후 필요한 범위만 조정 |
| 자산 있음·게임 미결속 | Controller/Adapter/전환을 연결; 새 Clip 제작으로 우회하지 않음 |
| 자산 없음 | 기존 행위 의미에 맞는 최소 동작 제작 후보 |
| 미검증 / 전용 동작 불필요 | 조사 공백 또는 불필요 사유 명시; 자산 없음과 구분 |

## 제작 우선순위와 권한

활성 폐루프에서 실제 사용 빈도, 동작 끊김이 조작에 미치는 영향, 현재 논리 상태 공급 여부, 재사용 범위로 정렬한다. 이동/대기 전환·도구 작업·줍기/장착·수확/운반·컵 사용·중단/복귀는 조사 출발 후보이며 실제 대조 결과로 순서를 결정한다. 미래 미구현 업무를 위한 모든 Clip을 먼저 만들지 않는다.

애니 담당이 대조와 기술 후보를 만들고 개발이 기존 승인 WI/수용 기준/연구/경로를 묶어 좁은 작업으로 배분한다. 기존 승인 행위의 의미를 바꾸지 않는 빠진 표현 제작은 이 사용자 요청 안에서 단계적으로 진행할 수 있다. 동작마다 같은 제작 의향을 다시 묻지 않되 새 게임 선택·소모·성공 조건·미승인 자산 가공은 기획으로 반환한다. Required 연구와 현재 E 상한은 유지한다.

## 책임과 결과

- 기획: 어떤 행동을 어떻게 읽게 할지와 중요한 수용 기준.
- 애니: 보유 자산 조사, Rig/Clip 확인, 최소 보정 또는 제작, 전용 .blend/FBX 및 검증 근거.
- 개발: 공통 상태·취소·행위 계보·Controller/Adapter와 단일 뼈 작성자 통합. 원장/명세 및 현재 작업 상태 동기화.
- 공간: Editor 점유 조율, canonical 실제 입력/동작·Game View 캡처.

산출물은 전문→개발 통합→기획으로 반환한다. 신규 구매 없이 구매한 자산을 우선 활용하고 원본/기존 Clip·dirty 변경을 보존한다. 공급사 라이선스와 AI 가공 제한은 계속 적용한다. 새 모델 생성이나 외부 AI 서비스 업로드를 포괄 승인하지 않는다.

현재는 운영 방향과 조사 착수만 확정됐다. 보유 Clip 전체 대조·신규 제작·Unity 연결·Game View 결과는 아직 미검증이다. 설치·파일 생성·자동시험만으로 동작 품질이나 E7을 선언하지 않는다.
