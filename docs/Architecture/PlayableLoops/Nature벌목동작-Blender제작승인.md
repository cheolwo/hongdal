# Nature 벌목 동작 — Blender 첫 제작 승인

- 식별: `nature-woodcutting-animation.design.r1`
- 상태: `Approved` (2026-08-30, D-359).
- 승인 근거: 사용자가 구매한 Synty 자산을 활용해 앞서 제안한 기존 캐릭터의 도끼 벌목 동작 하나를 진행하도록 요청했다.
- 대상: 기존 `WI-NATURE-06` 나무 벌목 작업 시작 및 연결 Task의 행위 표현. 새 전투 기술·수확 보상·도구 소모 규칙을 추가하지 않는다.
- 제작 환경: [D358 Blender 환경 준비](../../Reports/Blender환경준비-D358-2026-08-30.md). 환경 시험 성공과 캐릭터/애니메이션 성공은 별개다.

## 첫 제작 범위와 수용 기준

1. 현재 Nature 플레이어에 쓰는 구매 Synty 캐릭터와 장착 도끼를 우선 사용한다. 전문 담당이 실제 원본 경로·GUID·hash·Rig/Avatar·기존 Clip을 확인해 제작 기준선에 고정한다. 적합한 원본 선택은 이 범위 내 기술 조사이며 새 캐릭터 디자인을 요구하지 않는다.
2. 도끼를 준비해 들어 올리고, 나무에 내려친 뒤 기본 자세로 돌아오는 스윙 한 동작을 만든다. 기존 애니메이션을 재사용·보정할 수 있으면 우선 활용한다. 외형 전체 재모델링·도끼 교체·새 유료 자산 구매는 이번 범위가 아니다.
3. 손과 도끼 손잡이의 결합을 유지하고 날의 접촉이 나무 표면과 맞아야 한다. 발이 눈에 띄게 미끄러지거나 몸이 비정상적으로 늘어나지 않도록 한다. 손/도구 접촉·발 고정은 정면과 측면, 기존 플레이 시점에서 확인한다.
4. 기존 권위 Task 시간과 진행/완료 상태를 표현이 따른다. 한 스윙은 나무 한 그루의 완료와 같지 않다. 필요하면 같은 동작을 반복하되 기존 4초 작업 의미나 보상 횟수를 바꾸지 않는다. 프레임 수·FPS·재생속도·접촉 구간·전환 시간은 기존 Task와 맞추는 전문 조정값으로 기록하며 숫자마다 재승인을 요구하지 않는다.
5. 타격 순간에는 기존 의미 기반 접촉 Cue와 가능한 효과음/FX를 연결한다. 음원이 없으면 요구사항으로 기록하고 청취 완료를 주장하지 않는다. Animation Event만으로 나무·재고·피해·권위 시간을 바꾸지 않으며 반복/재조회/저장 복원으로 보상을 중복 생성하지 않는다.
6. 이동·피격 등 기존 작업 취소 조건에서 스윙을 중단하고 실제 이동 또는 기본 자세로 자연스럽게 복귀한다. 미완료 작업을 성공 처리하지 않는다. 취소의 진행률/소모 규칙은 기존 계약을 보존하며 표현 개선을 이유로 바꾸지 않는다.
7. 이동 권위와 root motion, 상체/팔/척추의 작성자를 하나씩 명확히 한다. 기존 procedural fallback·LateUpdate·Animator가 같은 뼈를 경쟁 작성하지 않도록 개발이 연결한다. 새 이동 방식이나 강제 시점 전환은 도입하지 않는다.

## 제작·통합·화면 확인

- 애니메이션 담당: 실제 대상 조사와 Required 적용 연구, 수정용 `.blend` 및 전달 `.fbx` 제작, 저장/재열기·뼈/단위/클립·왕복 검증. `ArtSource/Blender`의 전용 하위 경로를 개발과 정하고 공급사 원본을 덮어쓰지 않는다.
- 개발 담당: 기존 Nature 기획/명세와 추가 승인을 결속하고 전문 기준선의 수용 기준 일치를 검토한다. 기술적 자산/Rig/시간 조정은 이 승인 안에서 처리하고, 플레이 의미 변경이 필요한 경우만 기획에 반환한다. 공용 Adapter와 원장·상태·취소 연결은 개발이 단독 통합한다.
- 공간 담당: Editor 점유를 조율해 canonical `SimulationWorldShell`에서 실제 입력→스윙 반복→타격→완료 및 중단→복귀를 확인한다. Game View 대표 PNG와 동작을 판단할 수 있는 연속 캡처 또는 짧은 영상, Console 결과를 개발에 반환한다. 정지 이미지 한 장만으로 동작 품질 전체를 통과시키지 않는다.
- 기존 실험물·dirty Scene은 보존한다. 새 공식 Scene을 만들지 않으며 저장/재진입은 소유가 확인된 변경 범위에서 수행한다. 제작물 확인과 실제 WI 연결의 검증 결과를 분리한다.
- 현재 E는 유지하고 기존 승인 상한을 높이지 않는다. 설치/FBX 생성/빌드만으로 E5 또는 E7 성공을 기록하지 않는다. Farm·방문자·HB01 개발은 별도로 계속한다.

## 라이선스와 미검증

사용자가 보유 자산 구매 사실을 확인했다. 추가 구매를 요구하지 않는다. 담당은 선택한 팩의 로컬 라이선스/구매 채널 자료와 편집 방식의 적용 범위를 확인하고, 자료가 부족하면 확인한 사실과 부족한 항목만 반환한다. 사용자 구매 확인을 생성형 AI 가공 제한의 면제로 해석하지 않는다. Synty 원본의 외부 AI 모델 생성 서비스 업로드는 하지 않으며, AI 자동 가공 허용이 불명확하면 해당 작업만 중단하고 허용되는 기존 Clip 활용·분석·일반 편집 경로를 구분한다.

이번 승인은 첫 동작 제작과 연결을 시작하는 근거다. 실제 제작 파일·리깅·Unity 재생·Game View 결과는 아직 없다. 결과는 애니메이션/공간→개발 통합→기획으로 반환한다.
