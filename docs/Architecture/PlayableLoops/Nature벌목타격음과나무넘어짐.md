# Nature 벌목 타격음과 나무 넘어짐

- 판본: `nature-woodcutting-impact-tree-fall.design.r1`, D379, 2026-08-30.
- 상태: `ApprovedDirectionAndResearchScope`. 기존 WI-NATURE-06의 타격감과 벌목 완료 표현 보완. 전문 연구·개별 실행 명세 결속 후 해당 범위를 제작/연결한다.
- 사용자 의도: 도끼로 나무를 실제로 치는 듯한 소리가 접촉 순간에 나고, 벌목 완료 뒤 나무가 쓰러지는 애니메이션을 표현한다. 나무 넘어짐 제작은 애니메이션 담당의 Blender 작업 경로를 우선 검토한다.
- 관계: 기존 [D359 제작 승인](Nature벌목동작-Blender제작승인.md)과 적용 연구 원문/hash를 보존한 추가 범위다. 진행 중 실제 입력 결함 수정은 계속한다. 새 보상·피해·벌목 시간·Save 의미를 추가하지 않는다.

## 1. 기존 재고와 중복 방지

[오디오 요구사항 대장](오디오요구사항대장.md)의 `audio:nature:axe:impact.r1` 및 `audio:nature:tree:fall.r1`을 재사용한다. 대장상 절차형 연결은 존재하나 실제 청취는 미검증이다. 현재 소리가 없다고 단정하거나 중복 Cue를 만들지 않는다. 전문은 기존 나무 낙하 표현/Prefab 계층·pivot·Renderer/LOD/Collider·완료 소비를 조사한 뒤 부족한 부분만 보완한다.

## 2. 타격음 수용 기준

- 들려야 할 의미는 단단한 목재에 도끼날이 박히는 짧고 분명한 타격이다. 단순 알림음과 실제 목재 타격 질감의 차이를 실제 청취로 검토한다.
- 스윙 시작이 아니라 시각상 도끼날 접촉 순간에 3D 타격음을 연결한다. 진행 타격과 마지막 완료 타격을 구분하고 기존 Task/접촉 토큰·단일 소비 경계를 사용한다.
- 허공 스윙·중단 이후·오래된 상태 재조회·복원만으로 타격음을 재생하지 않는다. 실제 접촉 표현 검증 없이 Animation Event나 음원 호출만으로 통과시키지 않는다.
- 기존 효과음 음량/끄기와 시각 피드백을 보존한다. 음원 후보·이용조건·원본/가공 hash·결속·실제 장치 청취를 각각 기록한다. 새 구매·외부 유료 생성·모델 다운로드 승인이 아니다.

## 3. 나무 넘어짐 수용 기준

- 완전히 베어진 나무가 밑동을 기준으로 기울고 지면 쪽으로 넘어지는 연속 동작을 표현한다. 매 타격에 나무 전체가 넘어지거나 작업 취소 때 성공 낙하를 재생하지 않는다.
- 같은 Session/Actor/대상/OriginCommand/완료 행위에 결속해 한 번 재생한다. 이미 Stump인 상태를 불러온 사실만으로 낙하를 새로 시작하지 않는다. 재조회/재진입/복원 중복 소비도 검사한다.
- 기존 밑동·통나무/자원 결과를 보존한다. 나무 낙하가 별도 피해·NPC 압사·길 봉쇄·추가 자원 생성의 근거가 되지 않는다. 그런 게임 규칙은 이번 요청에 포함되지 않는다.
- 넘어지는 방향·pivot·시간/곡선·수관/줄기 동기화·지지면·인접 물체/플레이어 시야 관통을 전문 연구에서 정한다. 기존 배치 기준과 일치하지 않으면 임의 지형 변경이나 나무 축소로 숨기지 않는다.
- 나무는 캐릭터 Humanoid 리그와 별개다. 기존 나무 모델/낙하 표현 재사용 가능성과 Blender 객체 애니메이션 또는 전용 복사본 제작을 비교한다. `.blend` 저장/재열기→필요 `.fbx` 왕복→Unity 실제 대상에서 축·단위·pivot·클립·Collider 처리 확인을 거친다. Blender 파일 존재만으로 실제 연결 완료라 하지 않는다.

## 4. 소유·제작 경계

개발이 현행 벌목 명세에 추가 승인·Required 연구·소유 경로·현재 E/상한을 결속한다. 애니메이션 담당은 실제 대상 나무 하나와 기존 타격음/낙하 재고를 조사하고 후속 연구 기준선을 제출한다. Accepted 결속 후 사용조건이 확인된 방식으로 전용 복사본·Blender 산출물만 제작한다. 공급사 원본은 덮어쓰지 않는다. 기존 신규 키프레임/bake/AI 자동 가공의 미확인 사용조건은 이 요청으로 해제되지 않으며 해당 방식만 보류하고 허용되는 기존 표현 연결은 계속한다.

공간은 개발이 동결한 입력·대상·판본으로 정상 벌목과 중단/재개를 실행하고 시각/오디오 근거를 반환한다. Game View 연속 캡처나 짧은 영상으로 접촉→기울기→넘어짐→완료 상태를 확인한다. PNG는 소리의 증거가 아니므로 실제 청취 또는 확보 가능한 오디오 근거를 별도로 남긴다. 장치/도구 제약으로 청취하지 못하면 미청취로 보고한다.

## 5. 완료·미정

이번에 확정한 것은 타격음의 접촉 동기와 완료 후 나무 넘어짐 표현, Blender 전문 검토 경로다. 정확한 음원·나무/Clip·방향/길이/지면 접촉 방식은 연구 조정값으로 남는다. 새 권위 규칙이 필요할 때만 별도 기획으로 반환한다. 기존 야간 종료시간·상한·원본/미소유 dirty 보호·외부 효과/commit/push 금지를 유지한다. 기존 Actor 스윙·입력 연결 성공과 새 나무 넘어짐/청취 성공은 따로 보고한다.
