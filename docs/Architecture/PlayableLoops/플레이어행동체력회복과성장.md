# 플레이어 행동 체력 회복과 성장

## 식별과 결정 상태

- 기획 판본: `player-stamina-recovery-growth.design.r12`
- 범위: Farm에서 발견한 행동 체력 고갈을 출발점으로 하는 공통 Actor 상태·회복·성장 연결 설계. 새로운 PlayableLoop나 WI를 등록한 문서가 아니다.
- 상태: `Draft` — 아래 네 가지 방향, 자연 회복의 활동 조건, 시설 없는 제자리 휴식과 안전한 오두막의 회복 효율 우대, 버튼1회 휴식 시작·입력 유지 불필요, 전투 중 휴식 시작 금지·전투 종료 후 재사용, 이동·작업·피격 시 휴식 중단과 기회복 체력 보존, 세 회복 속도의 순서와 Farm 반복 시험을 통한 수치 조정 방식은 사용자 확정이다. 구체 회복 수치는 개발 시험 조정 대상이며 안전 판정·성장 기준과 실행 인계는 미확정이다.
- 근거: 2026-08-30 Farm 두 번째 수확에 체력105가 필요하지만 상한100/회복경로 없음이라는 개발 반환 후, 사용자가 지속 회복·포션 회복·휴식 회복·레벨 상승에 따른 상한 증가를 요청했다.
- 기존 범위: [Farm E5 기획 r1](Farm경작세계발현E5.md), [E5 승인 인계](../../Reports/E5세계발현-개발승인인계-2026-08-30.md). 이 문서만으로 동결된 기획·명세 hash나 E 상한을 변경하지 않는다.

## 확인된 현재 구조

- `SimulationFarmSurvival.cs`의 PlayerDirect 작업 비용은 Stamina15, Actor 초기값 검증의 상한은100이다. 새 밭 작업01→02→03→04→02→03→04에는105가 필요하다.
- `MedicalRest`는 부상자를 대상으로 자원을 사용해 Health를 회복하고 Injured를 해제한다. 현재 Farm Stamina 회복은 아니다.
- 전투는 `StaminaPermille`을 사용하고 Farm은 절대 Stamina를 사용한다. 표기가 비슷해도 같은 상태 저장소나 최대치라고 가정하지 않는다.
- `SimulationPlayerDomainProficiencyContracts.cs`에는 분야별 진척·숙련 단계가 있다. 플레이어 공통 숫자 레벨→최대 Stamina를 연결한 계약은 이번 검색에서 확인하지 못했다. 별도 RPG 레벨을 이미 구현한 것으로 보고하지 않는다.

## 사용자 확정 방향

| 회복·성장 경로 | 역할 | 구분 |
| --- | --- | --- |
| 지속적인 자연 회복 | 플레이 중 시간이 흐르며 다시 행동할 여력을 얻음 | 자동 시간 기반 회복 |
| 휴식 | 플레이어가 쉬는 행동을 선택해 회복 | 의도적인 회복 행동 |
| 포션 | 회복 물품을 소비해 체력을 얻음 | 물품 소비·효과 |
| 레벨/성장 | 성장에 따라 행동 체력 최대치가 증가 | 장기 능력 성장, 일시 회복과 별개 |

이 문서의 체력은 Farm 차단 원인인 **행동 체력(Stamina)**으로 해석한다. 생명력(Health), 질병·체온, 내면의 회복·위협 수치는 서로 다른 상태다. HP 포션·질병 치료·명상 보너스를 이번 답변만으로 함께 추가하지 않는다.

## 자연 회복 활동 조건 — 확정

- 걷기·대기 중에는 자연 회복이 진행된다.
- 노동·질주·전투 중에는 자연 회복이 중단된다. 전투 중 가만히 서 있거나 걷는다는 이유로 대기·걷기 회복을 적용하지 않는다.
- 이는 자연 회복의 조건이며 명시적 휴식·포션의 사용 조건을 함께 확정한 것은 아니다. 회복 속도는 D-291에 따라 개발 시험으로 조정하는 항목이며 숫자별 사용자 재승인 대기가 아니다.
- 노동·질주·전투가 끝나 실제 걷기·대기 상태가 되면 별도 대기시간 없이 자연 회복을 재개한다(r10 확정). 다른 회복 금지 활동이 남아 있으면 재개하지 않는다.
- 재개는 해당 시점 이후 권위 경과 시간에 대한 회복 누적을 뜻한다. 상태 전환 순간의 고정 회복 보상이나 이전 금지 구간의 소급 회복을 부여하지 않는다. 일반 휴식의 자동 재시작과도 구분한다.

## 휴식 장소 조건 — 확정

- 플레이어는 별도 시설 없이 제자리에서 휴식을 취할 수 있다. 오두막 건설이나 침대 획득을 기본 휴식의 선행 조건으로 요구하지 않는다.
- 안전한 오두막에서는 시설 없는 일반 휴식보다 행동 체력을 더 효율적으로 회복한다. 구체적인 배율·회복량은 아직 정하지 않았다.
- 오두막이 존재한다는 사실만으로 안전이 보장되는 것은 아니다. 기존 주변 위협·방호 조건과의 안전 판정 연결은 구현 전에 검토한다. 위협 접근 시 빠른 회복 우대만 해제하고 일반 속도로 휴식을 유지하는 반응은 r9에서 확정했다.
- 이번 확정은 휴식 장소와 상대적인 효율에 한정한다. 수면·체온·질병·생명력 치료 효과를 자동으로 추가하지 않으며, 휴식 중 공격 면역이나 전투 중 휴식 허용도 뜻하지 않는다.

## 휴식 중단과 누적 회복 — 확정

### 불과 휴식 회복 — 추가 확정

- 사용자는 불이 있으면 휴식 중 행동 체력이 더 빠르게 회복되기를 요청했다. 기존 시설 없는 휴식은 유지하며 불을 기본 휴식의 필수 조건으로 추가하지 않는다.
- 같은 휴식·안전 조건에서 유효하게 타는 불이 있으면 없는 경우보다 회복을 빠르게 한다. 불 자체가 주변 위협 부재나 안전을 증명하지 않으며 전투 중 휴식 금지·피격 중단을 우회하지 않는다.
- 꺼진 불의 장식 Prefab·불꽃 애니메이션만으로 회복 효과를 부여하지 않는다. 꺼짐 이후에는 불의 추가 효과가 남지 않도록 실제 열원 상태와 연결해야 한다. 이미 정상 적용된 회복량은 보존한다.
- 이 응답은 불의 추가 회복 효과를 확정한 것이다. 직전 질문의 '완성된 내부+접근 위협 없음이면 충분'이라는 안전 정책 전체까지 승인한 것으로 확대하지 않는다.
- 오두막 밖에서도 모닥불 곁에서 쉬면 불에 의한 추가 회복을 받는다(r12 확정). 오두막이나 다른 건물을 야외 모닥불 휴식의 필수 조건으로 요구하지 않는다.
- 불의 회복 효과와 안전한 오두막의 회복 우대는 구분한다. 야외 모닥불이 오두막의 보호·수면·안전 효과까지 주는 것은 아니며 전투/피격 중단 규칙도 유지한다.
- 유효 열원 거리·가림·잔불 인정, 여러 불의 중첩, 위협 접근 중 불 효과 유지 여부는 아직 미정이다. 구체 회복량은 D-291의 시험 조정 대상으로 두되 새 정책의 적용 범위를 숫자로 대신 결정하지 않는다. 야외 모닥불과 불 없는 안전한 오두막 중 어느 쪽이 더 빠른지는 이번 답변으로 고정하지 않는다.

### 기본 중단 규칙

- 이동·작업을 시작하거나 공격받으면 휴식을 즉시 끝낸다. r9에서는 실제 전투 진입 시에도 휴식을 종료하도록 확정했다. 휴식 완료를 기다리게 하거나 휴식 애니메이션 때문에 이동·행동을 잠그지 않는다.

- 체력 보존은 회복 취소를 하지 않는다는 뜻이다. 이후 작업 비용이나 피격 피해를 무효화하거나 면역을 주는 규칙이 아니다. 중단 후에는 실제 활동에 맞는 자연 회복 조건을 적용한다.
- 추가 회복량을 중단 자체의 보상으로 부여하지 않는다. 같은 시점의 회복·피격·행동 비용 처리 순서는 공통 Simulation 시간 계약에 맞춰 검증한다.

## 제안 — 아직 확정되지 않은 조건

- 자연 회복을 포함한 구체 속도는 위의 시험 조정 기준으로 선정한다. 자연 회복의 재개 지연0은 r10 확정 조건으로 시험하며 휴식 속도의 중첩 여부 같은 별도 비교 가정을 함께 승인된 것으로 취급하지 않는다.
- 휴식 속도의 상대 순서는 확정했다. 부상 치료 전용 MedicalRest를 피로 회복으로 바꾸지 않고 기존 일반 휴식·수면 계약의 재사용 가능성을 먼저 검토한다.
- 포션은 보편적인 `WI-ACTOR-CONSUME` 아래 물품 정의·승인 효과로 연결하는 후보로 둔다. 포션 획득처·회복량·사용 시간·전투 중 사용·소비 실패/최대치 상태 정책은 아직 정하지 않는다. 약초차 처방을 Stamina 포션으로 전용하지 않는다.
- 최대치는 현재값과 별도 상태/정책으로 표현한다. 레벨 상승 시 최대치가 오르는 것은 확정이지만 그 순간 현재값도 채워지는지는 미확정이다. 성장 근거가 공통 레벨인지 분야 숙련인지, 증가량·최종 상한도 후속 결정이다.

## 권위·시간·저장 연결 원칙

### 개발 준비 반환 — 구현 증거 아님

[권위 시간·회복 속도 후보 보고](../../Reports/행동체력-권위시간과회복속도후보-2026-08-30.md)는 기획 r5를 읽은 코드 조사·산술 비교 결과다. 추천 후보는 자연0.25/제자리1/안전오두막2 Stamina/권위 진행초이고 작업1회분 +15의 산술 예상은60/15/8초다. 정수초 올림·지연0·휴식 총속도 비중첩을 가정한 계산이며 실제 회복 시험이나 플레이 시간 측정으로 취급하지 않는다. 후보 숫자는 승인된 조정 방법 아래 검토할 출발점이지 확정된 실행 규칙이 아니다.

보고된 시간 경계상 Farm WorldTick은 GameDate의 일 단위 진행과 연결되고 Nature는 정수초·1,200초 주기·별도 수면 배율을 사용한다. 기존 WorldTick을1초로 재정의하거나 회복1초마다 세계 전체 Tick을 진행하는 방식으로 연결하지 않는다. 일반 휴식에 수면6배를 자동 적용하지 않는다. 단일 권위 경과 시간과 Actor 활동 검증, 구간별 회복·중단 정산이 필요한 기술 연결이다.

버튼1회 휴식 시작과 입력 유지 불필요는 r7에서, 전투 중 시작 금지와 전투 종료 후 재사용은 r8에서, 자연 회복 재개 지연0은 r10에서 확정했다. 위 산술 보고의 당시 지연0 가정은 이제 자연 회복에 한해 확정 조건이다. 실제 안전한 오두막 판정은 아직 남은 조건이다. 기존 후보 안전 판정을 실제 안전으로 승격하거나 기존 MedicalRest/야간 수면을 일반 휴식으로 전용하지 않는다.

실행은 Unity Update가 아니라 공통 Simulation Core가 소유한다. 자연 회복은 기존 권위 게임 시간/WorldTick 진행에 연결하고, 프레임 속도·실제 PC 대기 시간·재접속으로 중복 회복되지 않아야 한다. 게임을 종료한 동안의 오프라인 회복은 이번 답변에 포함하지 않는다.

휴식과 포션은 Preview/Confirm·Task/Effect·행위 기록·멱등성을 기존 WI 규칙으로 연결한다. 자연 회복을 매 프레임 새로운 플레이어 명령이나 성장 보상으로 적재하지 않는다. 구체 자동 WI/Effect 매핑은 기존 시간 진행 계약을 조사해 결정한다.

현재 Stamina, 최대치와 그 근거, 마지막 적용한 회복 시간/나머지 누적값, 사용 물품·명령 중복 방지는 같은 Session Save/Replay 경계에서 보존한다. 기존 저장 판본의 상한100·hash를 소급 변경하지 않는다. 현재 v30 예약과 충돌하지 않도록 개발 담당이 후속 판본·호환 정책을 조율한다.

## 구현 인계 전 남은 결정

1. 자연 회복 재개 지연0 및 금지/허용 활동 전환의 권위 상태 연결. 지연 유무의 기획 선택은 확정됐고 시간·활동 연결은 기술 검증 대상이다.
2. 게임 시간 단위·안전한 오두막 판정. 버튼1회 시작/입력 유지 불필요 및 전투 중 시작 금지는 확정했고 명령 결속은 기술 연결 대상이다. 구체 속도·우대량은 확정된 순서를 지키며 Farm 시험으로 조정할 항목이지 숫자마다 사용자 재승인이 필요한 미정은 아니다. 같은 시점의 회복/중단 처리는 기술 검증 대상이다.
3. 포션 기본 효과·소비·획득 경계.
4. 성장 입력·최대치 증가 규칙과 레벨 상승 순간 현재값 처리.

우선 자연 회복·휴식의 작은 실행 범위를 정해 Farm의 반복을 닫고, 포션·성장 연결은 같은 설계 안에서 후속 범위로 분리할 수 있다. 이 순서는 제안이며 아직 새 WI 활성화 또는 코드 구현 승인이 아니다.

## 당장 유지할 검증과 후속 완료 조건

- 기존 새 밭 첫 주기와 이미 Tilled인 독립 Fixture의 두 재배 주기는 각각 검증한다. 이는 고정ID·이전Lot보존 기술회귀이며 새 밭 연속 두 주기 체력 문제의 해결 증거가 아니다.
- 새 회복 규칙 승인 후에는 새 밭 첫 수확→체력 부족/회복→재파종→둘째 수확을 Session 초기화·Lot 삭제·체력200 Fixture 없이 실행한다.
- 초과 회복 방지, 회복/소비 명령 중복, 중단/재시작, 저장·복원·Replay, 권위 시간 진행 분할의 결과 동등성, 성장 전후 현재/최대치, 기존 v1~현행 Save 호환을 시험한다.
- 휴식 중 이동·작업·피격 각각의 즉시 중단, 중단 전 회복량 보존, 중단 후 휴식 회복 미적용과 실제 활동에 따른 자연 회복, 이후 작업 비용·피해의 정상 적용을 검증한다. 중단/재시작 반복으로 같은 시간의 회복을 중복 획득하면 안 된다.
- 휴식 버튼1회 시작 후 입력 해제 상태에서도 유지되는지, 연타·동일 명령 재전송으로 시작 보상/회복량이 중복되지 않는지 검증한다.
- 자연 회복 금지 활동 종료 후 걷기·대기 전환에 추가 지연이 없는지 검증한다. 경과 시간0인 전환 반복은 회복량0이며, 노동 종료 후에도 전투 등 금지 활동이 남으면 회복하지 않는다. 명시적 휴식은 자동으로 재시작하지 않는다.
- 전투 중 휴식 시작 거부, 전투 종료 후 명시적 재시작 허용, 오두막/카메라 시점에 의한 우회 거부를 검증한다. Preview 후 전투 상태가 바뀌면 Confirm에서 현재 상태와 revision을 재검사한다.
- 다른 지식·방문자·공간 작업은 이 미정 때문에 중지하지 않는다. 실제 회복에 의존하는 Farm 반복 완료 판정만 다음 승인 기획/명세에 결속한다.
