- `SimulationFarmSurvival.cs`의 PlayerDirect 작업 비용은 Stamina15, Actor 초기값 검증의 상한은100이다. 새 밭 작업01→02→03→04→02→03→04에는105가 필요하다.

## 사용자 확정 방향

| 회복·성장 경로 | 역할 | 구분 |
| --- | --- | --- |
| 지속적인 자연 회복 | 플레이 중 시간이 흐르며 다시 행동할 여력을 얻음 | 자동 시간 기반 회복 |
| 휴식 | 플레이어가 쉬는 행동을 선택해 회복 | 의도적인 회복 행동 |
| 포션 | 한 개 소비가 확정되면 행동 체력을 즉시 일정량 회복 | 물품 소비·즉시 효과, 양은 시험 조정 |
| 레벨/성장 | 성장에 따라 행동 체력 최대치가 증가 | 장기 능력 성장, 일시 회복과 별개 |

이 문서의 체력은 Farm 차단 원인인 **행동 체력(Stamina)**으로 해석한다. 생명력(Health), 질병·체온, 내면의 회복·위협 수치는 서로 다른 상태다. HP 포션·질병 치료·명상 보너스를 이번 답변만으로 함께 추가하지 않는다.

## 자연 회복 활동 조건 — 확정

- 걷기·대기 중에는 자연 회복이 진행된다.
- 노동·질주·전투 중에는 자연 회복이 중단된다. 전투 중 가만히 서 있거나 걷는다는 이유로 대기·걷기 회복을 적용하지 않는다.
- 이는 자연 회복의 조건이며 명시적 휴식·포션의 사용 조건을 함께 확정한 것은 아니다. 회복 속도는 D-291에 따라 개발 시험으로 조정하는 항목이며 숫자별 사용자 재승인 대기가 아니다.
- 노동·질주·전투가 끝나 실제 걷기·대기 상태가 되면 별도 대기시간 없이 자연 회복을 재개한다(r10 확정). 다른 회복 금지 활동이 남아 있으면 재개하지 않는다.
- 재개는 해당 시점 이후 권위 경과 시간에 대한 회복 누적을 뜻한다. 상태 전환 순간의 고정 회복 보상이나 이전 금지 구간의 소급 회복을 부여하지 않는다. 일반 휴식의 자동 재시작과도 구분한다.

- 이번 확정은 휴식 장소와 상대적인 효율에 한정한다. 수면·체온·질병·생명력 치료 효과를 자동으로 추가하지 않으며, 휴식 중 공격 면역이나 전투 중 휴식 허용도 뜻하지 않는다.

## 휴식 중단과 누적 회복 — 확정

### 불과 휴식 회복 — 추가 확정

- 사용자는 불이 있으면 휴식 중 행동 체력이 더 빠르게 회복되기를 요청했다. 기존 시설 없는 휴식은 유지하며 불을 기본 휴식의 필수 조건으로 추가하지 않는다.
- 같은 휴식·안전 조건에서 유효하게 타는 불이 있으면 없는 경우보다 회복을 빠르게 한다. 불 자체가 주변 위협 부재나 안전을 증명하지 않으며 전투 중 휴식 금지·피격 중단을 우회하지 않는다.
- 꺼진 불의 장식 Prefab·불꽃 애니메이션만으로 회복 효과를 부여하지 않는다. 꺼짐 이후에는 불의 추가 효과가 남지 않도록 실제 열원 상태와 연결해야 한다. 이미 정상 적용된 회복량은 보존한다.
- 이 응답은 불의 추가 회복 효과를 확정한 것이다. 직전 질문의 '완성된 내부+접근 위협 없음이면 충분'이라는 안전 정책 전체까지 승인한 것으로 확대하지 않는다.
- 오두막 밖에서도 모닥불 곁에서 쉬면 불에 의한 추가 회복을 받는다(r12 확정). 오두막이나 다른 건물을 야외 모닥불 휴식의 필수 조건으로 요구하지 않는다.
- 불의 회복 효과와 안전한 오두막의 회복 우대는 구분한다. 야외 모닥불이 오두막의 보호·수면·안전 효과까지 주는 것은 아니며 전투/피격 중단 규칙도 유지한다.
- 여러 불의 추가 회복은 합산하지 않고 현재 가장 효과적인 유효 열원 하나만 적용한다(r13 확정). 선택 열원이 꺼지거나 유효하지 않게 되면 남은 유효 열원 중 가장 효과적인 하나를 적용하며, 없으면 불의 추가 효과만 제거한다. 전환 자체로 즉시 회복을 지급하거나 같은 시간 구간을 중복 정산하지 않는다.
- 플레이어와 불 사이가 막힌 벽으로 차단되면 가까워도 해당 불의 추가 회복을 적용하지 않는다(r14 확정). 벽에 차단된 열원을 제외한 뒤 r13의 가장 효과적인 유효 열원 하나를 선택한다. 다른 유효 열원이 없으면 불의 추가 효과만 해제하며 일반 휴식·이미 회복한 체력은 유지한다.
- 유효 열원 거리·열린 문/창문/틈의 처리·잔불 인정, 위협 접근 중 불 효과 유지 여부는 아직 미정이다. 구체 회복량은 D-291의 시험 조정 대상으로 두되 새 정책의 적용 범위를 숫자로 대신 결정하지 않는다. 야외 모닥불과 불 없는 안전한 오두막 중 어느 쪽이 더 빠른지는 이번 답변으로 고정하지 않는다. 열원 간 비중첩 확정은 자연 회복·일반 휴식·오두막 우대 사이의 계산 방식을 함께 승인한 것이 아니다.

### 회복 속도 순서와 조정 방법

- 구체 회복량·배율은 영구 고정값으로 먼저 결정하지 않고 Farm의 실제 작업 비용·시간 진행·반복 시험을 근거로 개발 담당이 초기 조정값을 선정하고 비교한다. 수치 하나하나를 기획 질문으로 다시 확정받는 방식은 요구하지 않는다.

- 시험 결과에는 시간 단위, 각 회복 속도, 작업1회분 회복 소요 시간, 같은 조건에서 최대치까지의 시간, 새 밭 첫 주기→회복→두 번째 주기 결과를 함께 남긴다. 자동 시간 진행 시험과 실제 입력·Game View 체감 검증은 구별한다.

## 제안 — 아직 확정되지 않은 조건

## 선택한 활동을 통한 행동 체력 성장 — 확정

- 전투뿐 아니라 농사·채집·건설 등 플레이어가 실제 수행한 활동도 행동 체력 최대치의 성장에 기여한다(r21 확정). 농사 중심·탐험 중심 등 선택한 생활을 이어가며 성장할 수 있고 여러 활동을 의무적으로 골고루 수행할 필요는 없다.
- 성장의 근거는 실제 행위 결과다. Preview·버튼 반복·거부된 명령·동일 행위 기록 재처리를 새로운 성장으로 계산하지 않는다. 기존 행위 기록·분야 성장 연결을 재사용 검토한다.
- 활동별 성장량이 모두 같다는 뜻이나 모든 활동이 매번 최대치를 올린다는 뜻은 아니다. 해당 활동의 기여 기준·증가량·성장 간격·최종 상한은 후속 설계와 검증 대상으로 남긴다. 단순 반복을 강제하는 별도 과제나 활동 다양성 필수 조건을 추가하지 않는다.
- 최대치는 현재값과 별도 상태/정책으로 표현한다. 성장으로 최대치가 증가하면 현재값도 실제 최대치 증가분만큼 보충한다(r22 확정). 예시: 최대치100→105, 현재값30→35. 전체 회복이나 현재 비율 유지가 아니며 새 최대치를 넘지 않는다. 예시의 증가량5는 확정 성장 수치가 아니다.
- 같은 성장 결과를 재처리해 최대치나 현재값을 반복 증가시키지 않는다. 실제 최대치 증가분이 0이면 보충도 0이다. 일시 버프 재적용·장비 교체·최대치 감소 정책으로 이 규칙을 확대하지 않는다.
- 공통 레벨·분야 숙련을 어떤 방식으로 최대치에 연결할지는 아직 결정하지 않았다. 새 RPG 레벨 체계를 구현한 것으로 기록하지 않는다.

- 충만 안내는 같은 충만 상태에서 매 프레임 반복하지 않는다. 짧은 상태 안내이며 별도 효과음·새 팝업·애니메이션을 추가 확정하지 않는다. 충만 안내의 정확한 문구·재알림 조건·단축키는 별도 표현 설계이며 종료 버튼은 아래 r30을 따른다.

## 권위·시간·저장 연결 원칙

### 개발 준비 반환 — 구현 증거 아님

[권위 시간·회복 속도 후보 보고](../../Reports/행동체력-권위시간과회복속도후보-2026-08-30.md)는 기획 r5를 읽은 코드 조사·산술 비교 결과다. 추천 후보는 자연0.25/제자리1/안전오두막2 Stamina/권위 진행초이고 작업1회분 +15의 산술 예상은60/15/8초다. 정수초 올림·지연0·휴식 총속도 비중첩을 가정한 계산이며 실제 회복 시험이나 플레이 시간 측정으로 취급하지 않는다. 후보 숫자는 승인된 조정 방법 아래 검토할 출발점이지 확정된 실행 규칙이 아니다.

보고된 시간 경계상 Farm WorldTick은 GameDate의 일 단위 진행과 연결되고 Nature는 정수초·1,200초 주기·별도 수면 배율을 사용한다. 기존 WorldTick을1초로 재정의하거나 회복1초마다 세계 전체 Tick을 진행하는 방식으로 연결하지 않는다. 일반 휴식에 수면6배를 자동 적용하지 않는다. 단일 권위 경과 시간과 Actor 활동 검증, 구간별 회복·중단 정산이 필요한 기술 연결이다.

버튼1회 휴식 시작과 입력 유지 불필요는 r7에서, 전투 중 시작 금지와 전투 종료 후 재사용은 r8에서, 자연 회복 재개 지연0은 r10에서 확정했다. 위 산술 보고의 당시 지연0 가정은 이제 자연 회복에 한해 확정 조건이다. 실제 안전한 오두막 판정은 아직 남은 조건이다. 기존 후보 안전 판정을 실제 안전으로 승격하거나 기존 MedicalRest/야간 수면을 일반 휴식으로 전용하지 않는다.

실행은 Unity Update가 아니라 공통 Simulation Core가 소유한다. 자연 회복은 기존 권위 게임 시간/WorldTick 진행에 연결하고, 프레임 속도·실제 PC 대기 시간·재접속으로 중복 회복되지 않아야 한다. 게임을 종료한 동안의 오프라인 회복은 이번 답변에 포함하지 않는다.

휴식과 포션은 Preview/Confirm·Task/Effect·행위 기록·멱등성을 기존 WI 규칙으로 연결한다. 자연 회복을 매 프레임 새로운 플레이어 명령이나 성장 보상으로 적재하지 않는다. 구체 자동 WI/Effect 매핑은 기존 시간 진행 계약을 조사해 결정한다.

현재 Stamina, 최대치와 그 근거, 마지막 적용한 회복 시간/나머지 누적값, 사용 물품·명령 중복 방지는 같은 Session Save/Replay 경계에서 보존한다. 기존 저장 판본의 상한100·hash를 소급 변경하지 않는다. 현재 v30 예약과 충돌하지 않도록 개발 담당이 후속 판본·호환 정책을 조율한다.

## 구현 인계 전 남은 결정

1. 자연 회복 재개 지연0 및 금지/허용 활동 전환의 권위 상태 연결. 지연 유무의 기획 선택은 확정됐고 시간·활동 연결은 기술 검증 대상이다.
2. 게임 시간 단위·안전한 오두막 판정. 버튼1회 시작/입력 유지 불필요 및 전투 중 시작 금지는 확정했고 명령 결속은 기술 연결 대상이다. 구체 속도·우대량은 확정된 순서를 지키며 Farm 시험으로 조정할 항목이지 숫자마다 사용자 재승인이 필요한 미정은 아니다. 같은 시점의 회복/중단 처리는 기술 검증 대상이다.
3. 포션 기본 효과·소비·획득 경계.
4. 성장 입력·최대치 증가 규칙과 r22 증가분 보충의 실제 실행 연결.

우선 자연 회복·휴식의 작은 실행 범위를 정해 Farm의 반복을 닫고, 포션·성장 연결은 같은 설계 안에서 후속 범위로 분리할 수 있다. 이 순서는 제안이며 아직 새 WI 활성화 또는 코드 구현 승인이 아니다.
