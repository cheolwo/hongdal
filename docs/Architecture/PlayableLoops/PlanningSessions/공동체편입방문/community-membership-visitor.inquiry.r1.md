### Q-354 관심·행동 기록에 따른 방문 NPC 후보

- 확인된 결정: 플레이어의 터를 오가는 NPC를 항상 같은 명단으로 고정하지 않는다. 플레이어가 관심을 기울인 주제와 실제로 수행한 행동을 게임 원장에 기록하고, 그 기록을 근거로 어떤 NPC가 방문할 후보인지 결정한다.
- 연결: [Q-353 관심 카드·이데아의 편린](../약초Recipe제작/herbal-recipe-crafting.inquiry.r1.md#q-353-첫-물약-술식을-만나는-경로)은 관심/인연 단서를 제공한다. 기존 Q-114의 납품·관계 형성과 연결 길 안전화는 행동 기반 인연의 기존 사례로 유지한다. 모든 방문자에게 납품 또는 편린 하나를 필수 조건으로 강제하지 않는다.
- 책임 구분: 관심·관련 행동·인연 기록은 ‘누가 관련 있는 방문 후보인가’를 판단하는 근거다. 연결 길·위협·거점 접근 조건은 ‘그 후보가 지금 실제로 방문할 수 있는가’를 별도로 판단한다. 관심 변경만으로 위험한 길을 건너뛰어 NPC를 순간 이동시키지 않는다.
- 후보와 결과: 후보 선정·방문 예정·실제 도착·대화·체류·고용/공동체 합류를 구분한다. 후보 선정이나 관심 카드 선택만으로 실제 도착·호감·합류를 확정하지 않는다. NPC 종류/직업에 관한 반복 가능성까지 금지하거나 매번 반드시 다른 사람을 보내는 규칙은 아니다.
- 기록 경계: 관심은 명시적으로 선택한 게임 상태, 행동은 기존 WI의 확정된 행위 기록과 결과를 우선 재사용한다. UI 클릭 횟수·단순 Preview를 성공 행동으로 누적하지 않는다. 기존 지식·편린·관계 기록과 연결하되 별도 중복 원장부터 만들지 않는다.
- 저장·권위 방향: Solo는 LocalProcess의 공통 Simulation Core와 로컬 저장으로 성립해야 하며 외부 DB/상시 서버를 선행 요구하지 않는다. Hosted도 같은 규칙을 소비한다. 구체 저장 계약·조회 사본·선정 규칙은 별도 구현 명세에서 결정한다. 실제 사용자의 외부 활동이나 개인정보를 수집하는 요청이 아니다.
- 미정: 행동 분류/조회 기간/최근성·반복 상한, 관심과 행동의 비중, 편린의 필수 여부, NPC 후보 공급·기존 인물 재사용·확률/빈도·동시 방문 수·불발 처리·안전 조건 재평가. 실제 인물 생성과 기존 인물의 방문 일정 선택도 아직 구분 설계가 필요하다.
- 표현 준비: Q-113/209의 길을 따라 접근하는 NPC·짧은 인사·방문 알림을 재사용 검토한다. 새 자산·음원·Scene 배치를 확보했다고 간주하지 않는다.

### Q-355 NPC의 분야 화두와 거래 제안

- 식별: `Q-방문인연-D3-02 · 전체 Q-355`

- 확정 방향: 전투를 해온 플레이어에게는 무기·방어구를, 물약 제조를 해온 플레이어에게는 제조 재료·레시피를 공급할 수 있는 NPC 활동을 설계한다. 이는 예시이며 방문자를 두 직업으로 한정하지 않는다. Q-354 관심/행동 기반 후보 선정과 연결한다.

- 선택권: 화두와 거래 제안은 선택 가능한 기회이며 대화 시작만으로 구매·납품·학습·고용을 확정하지 않는다. Q-354의 실제 도착·접근 조건도 그대로 유지한다.
- 입력: 주제 카드는 보조 입력으로 허용한다. 직전 제안에 포함된 자유 입력 전체가 승인된 것으로 해석하지 않으며, 자유 입력 채택·구체 UI·대화 빈도·알림은 미정이다.
- 권위: 실제 제공 가능한 품목·재고·가격·조건은 기존 Simulation 거래/지식 계약에서 확인한다. LLM은 허용된 사실의 화두·대사 표현만 맡고 상품·거래 조건·학습 효과를 생성하지 않는다. 무료 제공, 무제한 공급, 관심 변경 즉시 재고 갱신은 승인하지 않았다.
- 미정: 첫 공급 품목과 수량, 가격/교환 방식, 재방문·재입고 주기, 물품 미보유 시 주문 가능 여부, 대화 시작 시점과 중단 방식. 기존 경제 문답과 대조한 뒤 필요한 공백만 후속 질문한다.
- 표현 준비: 기존 방문 NPC와 선택형 대화/거래 UI 재사용부터 검토한다. 무기·방어구·책·재료는 표현 역할 후보이며 이번 경로 검색에서 실제 Prefab 후보를 확인하지 못했다. 전용 모델·애니메이션·음원·Scene 확보를 주장하지 않는다. H1 응대 지점/H2 접근 관계는 기존 방문 연구를 재사용 검토하며 새 상점 건물을 필수화하지 않는다.
