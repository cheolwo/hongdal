## 공간·자산 준비와 의존성

- Q383은 기존 Farm 집하 WI/H1에 상자 후보를 조합하는 방향이다. 실제 파일 `Assets/Synty/PolygonGeneric/Prefabs/Props/SM_Gen_Prop_Crate_03.prefab`와 `SM_Gen_Prop_Sack_01.prefab` 존재를 읽기 전용 확인했다. 외형·크기·Collider·유효 보관 용량은 이번에 측정하지 않았다. 새 이미지나 실제 배치 증거를 만들었다고 주장하지 않는다.
- H1 밭/집하/작업 위치, H2 Farm 동선과 접근/안전 후보, H3는 현재 Farm 경관 문맥을 유지한다. 새 성·병영·대규모 장비는 요구하지 않는다.
- Q380 수확 수용량과 Q381 위임 결과는 기존 인벤토리·집하 상태를 공유해야 한다. Q268을 수정하면 Q382의 자율 사용 범위도 재검토한다.
- 순수 조회/알림(Q386)을 새 실행 WI로 만들지 않는다. 개발이 기술 구현·시험·기존 승인과의 충돌을 판정하고 게임 선택만 기획에 반환한다.

## 승인 뒤 인계

농장/위임 원문 판본과 범위를 합성해 기존 개발 통합 담당에게 인계한다. 공간 담당은 승인된 기존 자산·통행·상태 표시, 애니 담당은 작업/중단/귀환 표현을 맡는다. 범위·경로·상한을 작업 명세에 결속하기 전 새 게임 규칙을 구현하지 않는다. 기획 승인 자체로 현재 E·Save·Scene을 변경하지 않는다.
