## 확인된 방향

플레이어는 부품을 일일이 정밀 배치하는 사람이 아니라 건설 의도, 후보 구역, 자원·시간, 안전·편의·확장성 우선순위를 정한다. 배치 엔진은 지형·Bounds·출입구·도로·필수 H 능력·대피로·작업 동선·충돌·확장 공간을 검사해 온전한 청사진 후보를 만든다.

```text
건설 의도 선택
→ 대략적인 후보 구역 지정
→ 엔진이 온전한 배치안 생성
→ 플레이어가 전체안·근거 확인
→ 위치·방향·우선순위 조정
→ Preview
→ Confirm
→ NPC·작업 Task 시공
```
