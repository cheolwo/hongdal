- 설명용 상황: **지금**은 더 추운 절기로 넘어가는 때, **여기**는 비닐하우스로 덮은 밭, **나**는 늦게 심은 작물을 살리고 싶은 플레이어, **너**는 작물과 재배 시설이다. 특정 절기·작물의 실제 한계 기온을 단정하지 않는다.
- **질문 하나:** 첫 비닐하우스는 추위를 어느 정도 완화하지만, 더 심한 추위에는 별도 난방 같은 추가 준비가 필요하도록 하면 어떨까?
- 확인된 답변: 비닐하우스가 추위를 어느 정도 막고 별도 난방을 활용할 수 있으며, 더 추워지면 마법진도 활용하는 방향이다. **이렇게** 시설 보강 여부를 선택하고 **결과**에 따라 관리·수확 가능성이 달라지며 **다음 선택**으로 추가 준비나 다른 재배 계획을 생각할 수 있게 한다.
- 대가: 시설을 세운 뒤에도 모든 계절 위험이 사라지지는 않는다. 정확 기온·효과량·난방 방식·연료·보충 빈도·자동 관리·비용·새 자산은 이번 질문의 승인 범위가 아니다.

## 마법진을 재배의 추위 대응에도 활용한다 — D401

- 질문 식별: `seasonal-cultivation-magic-protection`
- 상태: `ConfirmedDirection`.
- 사용자 원문 요지: 기존 울타리 바깥의 마법진 구상과 연결해, 비닐하우스·별도 난방으로 추위에 대응하고 더 추워지면 마법진도 활용할 수 있게 한다.
- 보호 역할: 비닐하우스의 외부 환경 완화, 난방의 열 공급, 마법진의 재배 추위 대응을 구분한다. 같은 역할이나 상태를 세 번 중복 계산하지 않는다. 효과량·적용 범위·병행 방식은 미정이다.
- 성장과 선택: 추위가 강해질수록 추가 수단의 가치가 생기되 비닐하우스→난방→마법진을 모든 플레이어가 반드시 차례대로 구매하는 고정 경로로 만들지 않는다. 기존 성장/학습·해금 조건을 삭제하거나 모든 플레이어의 즉시 시전 자격을 부여하지 않는다.
- 기존 근거: [Farm Q080/Q084](../건물공간배치/building-spatial-placement.inquiry.r1.md)는 작물 보호와 토양 회복 마법진, [Nature Q025/Q030](../nature-night-day2.inquiry.r1.md)은 울타리/마법진의 서로 다른 보호 층과 물리 방어의 가치를 다룬다. 이 역할을 재사용 조사하되 기존 방어·토양 회복 효과를 보온 효과로 조용히 바꾸거나 모든 마법진에 보온 능력을 부여하지 않는다.
- 배치: 사용자가 언급한 울타리 바깥 마법진은 기존 배치 구상의 참조다. 정확 배치/H1·밭과의 거리·벽/시설 통과·보호 대상/범위는 별도 공간·규칙 검토가 필요하다. 원본 Prefab 적합성이나 실제 Scene 적용은 미검증이다.
- 미정: 마법진 종류·학습/제작 조건·마력/재료/유지 비용·추위 대응 한계·작물별 적용·중첩·고장/중단·기존 손실 회복. 영구 무비용 보호·자동 마나 차감·수확 성공·작물 부활을 확정하지 않는다.
