# PlayableLoop 문답 기록 경로

이 폴더는 하나의 긴 대화 기록에 서로 다른 게임 구성요소를 계속 추가하지 않고, 질문의 주 상태 소유자에 따라 문답을 나누어 저장한다.

## 기록 원칙

1. 질문 ID는 기존 `Q-001` 형식을 유지하며 이동 때문에 다시 번호를 부여하지 않는다.
2. 한 질문의 권위 답변은 한 주제 문서에만 둔다. 다른 주제는 링크만 건다.
3. 질문이 둘 이상의 분야에 영향을 주면 플레이어가 실제로 선택하거나 상태가 바뀌는 주제에 기록한다.
4. 전문 연구 결과는 문답 문서에 복제하지 않고 연구 문서 revision을 참조한다.
5. 개발 인계는 주제 문서의 확정 범위만 별도 승인 기획서와 작업 명세로 동결한다.
