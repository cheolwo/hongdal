## 현재 Q-076 제안

저장 상태를 먼저 복원한 뒤 플레이어 주변 H1의 지형·Collider·이동 가능 경로·핵심 배치 객체가 준비될 때까지 조작을 잠근다. 준비 완료 후 조작을 돌려주고 먼 공간은 점진적으로 불러온다. 대기 화면에는 Area·시간대·날씨·추적 계획을 간단히 표시한다.

## 권위 경계

- 자동 저장 방향은 확정됐지만 현재 `WI-ACTOR-03` 개발 인계에는 Save 판본 변경이나 자동 저장 구현이 포함되지 않았다.
- 실제 Save 구현 전에는 저장 판본·Migration·Replay hash·손상 복구 검증을 별도 작업 명세로 승인해야 한다.
- LH 준비는 저장 내용을 바꾸지 않고 복원된 권위 상태를 안전하게 표현할 준비만 담당한다.
