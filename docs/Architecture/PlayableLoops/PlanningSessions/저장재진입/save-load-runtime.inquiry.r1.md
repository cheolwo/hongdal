## Q-139 개간 재진입 기준

- 저장 대상: 자유형 밭 경계, 확정된 완료 구획, 제거된 장애물, 토양 상태, 마지막 권위 작업 checkpoint.
- 취소 대상: checkpoint에 도달하지 않은 한 번의 도구 동작, Animation 진행률, 임시 FX·Decal 후보.
- 재진입 위치: 마지막 완료 구획과 연결된 `SafeReentryAnchor` 중 Actor·Collider·NavMesh 검사를 통과한 가장 가까운 작업 위치.
- 표현 복원: 완료 구획의 Terrain·Decal·이랑 표현을 상태 사본에서 다시 조립한 뒤 플레이어 조작을 돌려준다.
- 실패 보정: 기존 작업 위치가 침수·건설·충돌 등으로 무효이면 같은 Farm H1의 다음 안전 Anchor로 이동시키고 보정 이유를 알린다.
- 권위 경계: Unity의 위치 보정과 애니메이션 초기화는 완료 구획이나 `WorldRevision`을 새로 변경하지 않는다.

## 현재 Q-076 제안

`Q-140`에서 다음과 같이 확정했다. 저장 상태를 먼저 복원한 뒤 플레이어 주변 H1의 지형·Collider·NavMesh 이동 경로·활성 폐루프의 핵심 WI 배치 객체가 준비될 때까지 조작을 잠근다. 준비 완료 후 조작을 돌려주고 작은 소품·먼 공간·고밀도 장식은 점진적으로 불러온다. 대기 화면에는 Area·시간대·날씨·추적 계획을 간단히 표시한다.

### 최소 안전 준비 관문

- 필수: 플레이어 지면, 충돌 경계, 이동 가능한 NavMesh 또는 동등 경로, `SafeReentryAnchor`, 현재 목표의 핵심 `InteractionAnchor`.
- 후행 가능: 작은 생활 소품, 먼 건물 내부, 장식 식생, 고밀도 FX, 관찰 대상이 아닌 영역의 상세 Renderer.
- 실패 처리: 필수 항목 준비가 실패하면 조작을 허용하지 않고 실패한 준비 항목과 재시도·안전 위치 이동 선택을 표시한다.
- LH 경계: LH는 준비·활성 상태를 보고할 뿐 Save 상태, WorldTick 또는 WI 완료를 대신 변경하지 않는다.

## 권위 경계

- 자동 저장 방향은 확정됐지만 현재 `WI-ACTOR-03` 개발 인계에는 Save 판본 변경이나 자동 저장 구현이 포함되지 않았다.
- 실제 Save 구현 전에는 저장 판본·Migration·Replay hash·손상 복구 검증을 별도 작업 명세로 승인해야 한다.
- LH 준비는 저장 내용을 바꾸지 않고 복원된 권위 상태를 안전하게 표현할 준비만 담당한다.
