# PlayableLoop 문답 정리 상태판

## 목적과 기준 시각

- 기준 시각: `2026-08-30`
- 확인 기획 문답 범위: 전체 호환 번호 `Q-001~Q-346`; 다음 질문 `Q-347`은 답변 대기
- 구현 범위 원장 반영 범위: `Q-001~Q-339`; `Q-340~Q-346`는 다음 원장 revision의 이관 대기
- 목적: 긴 문답을 주 상태 소유자별로 다시 찾고, 확정 후보·미정·중복·개발 인계 상태를 한 번에 확인한다.
- 원칙: 문답 깊이 `D1~D5`는 구현 준비 전망이며 실제 Evidence가 아니다. 실제 E는 `playable-loops.json`, 작업 명세와 EvidencePackage만 판정한다.

이 문서는 각 답변의 전문을 복제하지 않는다. 권위 답변은 연결된 주제 문답 문서가 소유하고, 이 문서는 현재 위치와 다음 공백만 요약한다.

과거 `Q-001~Q-198`의 질문별 주제와 주 깊이는 [Q-001~Q-198 주제·깊이 색인](Q001-Q198주제깊이색인.md)에서 확인한다.

## 최근 문답 합성

### Hub 수요·분배 Q-240~250

1. Hub는 여러 영역의 욕구를 읽지만 다른 영역의 욕구 상태를 소유하지 않는다.
2. 시스템은 입지·할당·조달 후보와 근거를 제시하고 플레이어가 조정 후 Confirm한다.
3. 부족분은 요청자에게 알리고 열린 수요로 유지한다. 탐사·토벌·가공·구매 같은 해결 경로를 과제 후보로 제안한다.
4. 수요 중요도와 플레이어 책임은 분리한다. 중요한 식량 수요도 미수락이면 즉시 개인 실패가 아니며, 명시적 약속 뒤에는 의무가 생긴다.
5. `Q-250`의 필수 과제 미완료 대응은 생존경제 기준을 먼저 정하기 위해 보류했다.

### 생존경제 Q-251~266

1. 초기 경제의 첫 기준은 영양 완성도가 아니라 굶지 않을 수 있는 `생존 가능 일수`다.
2. 생산·소비는 합계 100% 비율로 방향을 읽고, 비축 일수는 별도 안전 지표로 유지한다.
3. 최근 7일 실제 흐름을 기본으로 오늘 수치와 전망 범위를 함께 보여 준다.
4. 불균형이 생기면 생산 확대·사냥·외부 조달·대체품·소비 조정을 선택한다. 생존 배급 축소는 최후 수단이다.
5. 직접 행동, NPC·분대 배정, 외부 공급 요청은 시간·비용·위험·확보량·품질·공동체 회복의 서로 다른 대가를 가진다.
6. 가격은 수요·공급·계절·거리·위험에 따라 제한 범위에서 변하고 근거를 표시한다. 미래 정보는 예상 범위와 신뢰도로 제공한다.
7. 생존 비축 판매는 금지하지 않지만 판매 뒤 생존 일수와 위험을 Preview하고 재확인한다.
8. HUD는 위험 신호만, 경제·달력 패널은 전체 흐름, Farm·Hub·Town 현장 패널은 장소별 상세 상태를 보여 준다.
9. Synty 상자·자루·팔레트는 실제 재고의 일대일 복제가 아니라 구간별 표현이다. 정확한 수량은 Simulation 상태 사본이 소유한다.
10. 하루 시작에 사용한 기상·수요 관측과 계산 revision을 저장하며 다음 World Day에만 새 자료를 반영한다.
11. Hosted 권한 질문 `Q-266`은 Solo 우선 원칙에 따라 보류한다.

### Solo 업무 위임 Q-267~268

- `Q-267`은 새 답변이 필요한 질문이 아니었다. Q-129, Q-152, Q-154와 `WI-WORLD-01`의 기존 결정으로 대체한다.
- 기존 기준은 직접 경험 뒤 단계별 위임, 적합 NPC·역량·권한·도구·시설·안전 경로 확인, 되돌리기 어려운 행동의 명시 승인 또는 사전 위임이다.
- `Q-268`은 허용 범위 밖 예외만 플레이어에게 돌려주는 정책 후보를 제시한 상태에서 문답 정리를 위해 일시 정지했다.

### 공식 약초·처방 Q-269~296

- 공식 약초 이름·학명·처방 원문과 Simulation 게임 효과를 분리한다.
- 약초 식별·채집·재생, 실제 처방의 불완전한 기록, 재료 상태와 배합 단위, 단계형 획득 단서를 확인했다.
- Q-271의 감국+향유 고정 Fixture는 Q-284의 공식 자료 검토 방식으로 대체했다.
- Q-272~274는 중단된 응답에 질문 본문이 남지 않아 `NeedsSourceRecovery`로 유지한다.
- 이 구간은 아직 `nature-basic-herbal-recovery.design.r5`와 작업 명세에 승인·결속되지 않았고 구현·Runtime 증거가 없다.

### 첫 약초 회복 폐루프 Q-340~346

- 폐야영지의 물리 처방 기록·냄비·컵을 출발점으로 주변 약초를 찾아 회복까지 이어 간다.
- Q-346은 선택 1로 확인했다. 첫 약초차용 물 한 번 분량은 폐야영지에 있고 이후 주변 수원에서 직접 구한다. 양·수질·정화·용기는 아직 정하지 않았으며 Q-347에서 운반 용기를 묻는다.
- 약초 탐색·식별·채집·불 피우기·달이기는 기본 1인칭 월드 행동이며 Recipe 카드는 정보 확인과 재료 정리를 맡는다. 3×3 패널은 카메라를 강제로 3인칭으로 전환하지 않는다.
- 가까운 식물을 조준할 때만 약한 관찰 표시를 제공하고, 지식이 있는 약초만 이름과 효능 단서를 판독한다.
- 첫 채집은 2초 누르기 Task와 손/도구·식물 반응·오디오 피드백을 결합한다. 잘못 달인 혼합물은 재료와 개인 상태에 작은 대가를 주되 재도전을 막지 않는다.
- 실제 보유 자산 조사에서 Nature 식물·꽃, Alpine 꽃 군집, Nature 모닥불, Dungeon Realms Camp Pot, Generic 머그와 Base Locomotion의 웅크리기 clip을 확인했다. 전용 채집·젓기·마시기 clip과 오디오 파일은 없어 별도 제작 또는 라이선스 자산이 필요하다.
- 이 구간은 아직 Q-001~339 구현 범위 원장에 이관되지 않았고, 자산 후보 조사만으로 E5가 되지 않는다.

### Farm 경관·패턴 Q-297~339

- 하나의 정답 Farm을 고정하지 않고 지형·수원·세계 상태에 맞는 H2/H3 패턴 재고를 사용한다.
- 첫 H2는 `외부 진입→붉은 Barn 작업마당→내부 작업로→외부 출구`를 고정 골격으로 하는 강변 실용 Farm 블록이다.
- 변형은 회전·간격·필지·승인 Prefab 교체 순이며 부적합 지형은 조용히 평탄화하지 않는다.
- 후보는 별도 시험 월드에서 3~5개 변형으로 검사하고 자동 통행·충돌 검사와 낮·밤 Game View 사람 검토를 모두 통과해야 한다.
- H3는 승인 패턴 사이에 자연 완충지대를 남기고 호환 Connector만 결속하며, 판본·Seed·Hash를 Save 계보에 고정한다.
- 실제 패턴·Prefab·Scene·Runtime 증거는 없으므로 현재 문답은 E5 승격 근거가 아니다.

## 다음 문답 우선순위 후보

새 질문은 아래 순서를 그대로 강제하지 않고, 사용자가 다시 문답을 시작할 때 하나를 고른다.

1. **Farm 경관 패턴 합성**: Q-297~339를 `farm-player-placement`의 승인 기획 revision과 전문 공간 연구로 동결한다.
2. **생존경제의 첫 독립 적용 Area**: Farm·Hub·Town 중 하나의 Fixture만으로 첫 계산 폐루프를 닫을 곳을 선택한다.
3. **Q-250 재개**: 필수 조달 과제 실패 예측 뒤 부분 납품·대체품·추가 인력·기한 협상의 우선순위를 정한다.
4. **Q-268 재개**: NPC 위임 중 자동 처리 가능한 예외 상한과 반드시 플레이어에게 돌려줄 사건을 정한다.
5. **공동체 편입 첫 적용**: Nature 야영지·Farm 거점·Town 중 임시 손님 폐루프를 처음 검증할 장소를 선택한다.

현재 활성 개발 Goal은 이 정리로 바꾸지 않는다. 문답 묶음이 승인 기획서와 작업 명세로 동결되기 전에는 새 구현 인계를 만들지 않는다.
