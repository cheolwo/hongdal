```text
H3 Farm 외곽 방위 폐루프

```

초소는 Farm의 내부 경계 시설이 아니라 Farm으로 들어오는 외곽 접근로에 놓는다. `위협 감지 → 준비 시간 산출 → 방어 분대 자동 출동 → 플레이어 영웅 선택 참전 → 방어 결과 → 초소·Farm 귀환`이 같은 폐루프로 이어져야 한다. 초소 관리 화면의 분대 카드는 배치 후보를 보여 주는 표현이며, 실제 분대 배정과 상태 변경은 Preview·Confirm을 거친 Simulation 권위 Command가 확정한다.
