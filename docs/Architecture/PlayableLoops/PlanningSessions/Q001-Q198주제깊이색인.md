- 현행 기획 계보: [기획 목차](../../../AI/PLANNING.md), [생성 문답 순환 조회](../../../AI/generated/planning-inquiry-circulation.md)
- 현행화 판정: `ReferenceOnly / HistoricalQuestionIndex`; 질문 번호·당시 깊이는 보존하고 현행 기획 판본·상태를 대신하지 않음

## 목적

이 문서는 전체 호환 번호 `Q-001~Q-198`을 주 상태 소유 주제와 `D1~D5`의 주 깊이로 전수 분류한다. 답변 전문과 결정 근거는 연결된 주제 문답 문서가 소유하며, 이 색인은 과거 질문을 다시 찾고 다음 질문의 편중을 확인하기 위한 탐색 지도다.

- `D1`: 목적과 플레이어 약속
- `D2`: 폐루프와 기본 계약
- `D3`: 손익·실패·회복·성장 규칙
- `D4`: 공간·H·배치·Synty·UI·Animation 표현
- `D5`: Save/Replay·NPC 연속성·멀티플레이·Runtime 통합

깊이는 질문의 주된 책임 하나만 표시한다. 다른 깊이에 미치는 영향은 해당 주제 문답의 `영향`, `미정`, `전문 심화 연구`에서 계속 추적한다. D 분류는 구현 준비 전망이지 실제 Logic·Presentation·통합 Evidence가 아니다.

## 읽는 방법

`D3-04 / Q-023`은 해당 주제 안의 네 번째 D3 질문이며, 전체 문답 호환 번호는 Q-023이라는 뜻이다. 앞으로 질문을 다시 열 때는 `Q-{주제}-D{깊이}-{주제·깊이 내 연번} · 전체 Q-{전체 번호}`로 함께 표시한다.
