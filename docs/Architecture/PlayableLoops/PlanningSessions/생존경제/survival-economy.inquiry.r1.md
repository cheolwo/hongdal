- 계층: 기존 원천 관측/수집 이력 → 품목 대응·비교 가능성 검토 → 판본화한 게임 해석/시장 맥락 → Simulation 가격·거래 후보 → 간단한 기회 안내/상세 근거. 원자료는 변경하지 않고 각 변환의 출처·판본·기준 시각을 추적한다.
- 원천 의미: KAMIS와 AMS에는 시장 단계·지역·품종·등급·포장·통화·조사일 차이가 있다. 국가명만으로 전국 대표가격이나 동급 상품의 차익으로 단정하지 않는다. 대응 미확정, 중량 불명, 결측·오래된 자료는 비교 제한을 표시한다. 환율만 바꿔 곧바로 수익이라고 표현하지 않는다.
- 화면 방향: 기본은 이해하기 쉬운 게임 내 거래 기회 요약, 상세는 적용한 해석·게임값과 원천 관측값/기관/공식 링크/날짜/단위/한계를 분리한다. 국가를 게임 지역에 대응시키는 방식·카드 배치·수익 계산은 아직 미정이다.

- 인과 구분: 보험은 계약에 따른 손실 보전이며 경로의 몬스터·위협 자체를 없애는 행위가 아니다. 직접 개입은 실제 경로 안전 상태를 바꾸는 행동이며 보험 보상과 같은 효과로 합치지 않는다. 위험 표시만으로 사고·손실·보상금을 생성하지 않는다. 두 수단의 병행 조건은 아직 미정이다.
- 기존 연결: Q257 경로별 시간·비용·위험, 기존 회랑 안전·초소·순찰·몬스터 제거 기획과 구체 WI를 재사용 검토한다. 원천 가격 관측은 운송 사고 확률이나 보험료의 직접 근거가 아니며 게임 규칙의 별도 판본을 요구한다.
- 계약/UI 준비: 무엇을 보장하는지와 보장하지 않는지, 대상 적재물·운송, 비용, 보상 한도/조건, 유효 기간, 사고 확인·지급 상태를 플레이어가 구분할 수 있어야 한다. 이 목록은 계약 누락 방지용이며 보험료·보상 비율·면책·지연/부패 포함 여부·지급 방식/시점·가입 가능 시점·상단 지급능력은 미정이다. 무조건 전액/즉시 보상을 약속하지 않는다.
- 권위 준비: 기존 계약·운송·손실 기록의 재사용 여부를 개발이 조사한다. 거래 전 계약 확정과 이후 사고/실제 손실/보상 자격을 구분하며 동일 손실의 반복 지급·복원 재지급을 방지해야 한다. 명령/행위·재고·지급의 원자성/Save는 향후 명세 검토 대상이다. NPC 대사나 애니메이션 완료가 계약·지급을 확정하지 않는다.
- 자료 조사 범위: 필요한 현실 용어·사례는 참고 조사로만 관리하며 실제 보험 상품 가입·법률 판단·운영 계약으로 확장하지 않는다. 기존 KAMIS·AMS 조사와 승인된 개발은 계속한다.
- D369 후속 확정: 첫 보험은 몬스터 습격으로 확인된 적재물 손실부터 보장하고, 가격 하락·판매 실패는 별도 경영 위험으로 남긴다. 보험료·지급 비율/한도·시점은 미정이며 보장 범위 동의를 전액 보상 동의로 확대하지 않는다. 지연·부패 등 다른 원인의 보장은 이번 첫 범위에 추가하지 않는다.
- 구현 상태: 방향 확정/후속 경제 확장이다. 새 보험 WI·거래·보상·화면 구현 또는 E 승격을 뜻하지 않는다.

## Q-401 현실에 닿는 운영 경험과 게임의 재미

- 식별: `Q-생존경제-D2-01 · 전체 Q-401`. 상태: `ConfirmedDirection`.
- 사용자 의도: 게임을 마친 뒤 단지 시간을 버렸다는 느낌보다 무엇인가 운영해 본 경험이 남기를 원한다. 상단 운영(음성의 '상담'은 구매·물류 대행 맥락에서 이렇게 해석), 구매 대행·물류 대행·사냥을 통한 공급·제조가 현실과 완전히 동떨어진 의미로 제시되지 않기를 원한다.
- 공통 원칙: [플레이어 중심 업무 구조의 현실에 닿는 운영 경험](../../../플레이어중심게임개발업무구조.md#현실에-닿는-운영-경험-d369)을 참조한다. 앞선 자리이타와 연결해 자신의 운영 성과가 실제 게임 내 상대 수요를 충족하는 의미를 드러낸다. 효과적인 플레이가 현실 능력 향상을 보장한다는 주장은 아니다.
- 기획 적용 방향: 누가 무엇을 필요로 하는지, 직접 조달/구매/제조/위임 중 무엇을 선택했는지, 자원·시간·비용·위험을 어떻게 사용했는지, 결과가 다음 선택을 어떻게 바꾸는지 이해할 수 있게 한다. 기존 Q257~260의 비용·비축·위험·전망 결정을 재사용한다.
- 게임성 경계: 실제 업무의 모든 절차·서류·대기 시간을 재현하거나 정답 암기/시험을 강제하지 않는다. 반복 실무는 기존 NPC 위임 원칙을 유지하고 플레이어는 직접 수행과 운영 판단을 오갈 수 있다. 실패도 원인과 재선택을 이해하는 경험으로 설계하되 실패 페널티를 새로 승인하지 않는다.
- 자료 경계: 실제 자료/사용한 해석/가상의 규칙을 구분한다. 원문 상세는 선택적으로 열어 보며 현실의 규제·보험·거래 자격을 게임 성공으로 대체하지 않는다. 현실 사업/수익/자격 취득 또는 능력 전이를 보장하지 않는다.
- D370 후속 확정: 작업을 마친 뒤 긴 평가표 대신 '이번 선택 → 결과와 확인된 원인 → 다음에 바꿔볼 점'을 짧게 보여준다. 상세 원가·계산·자료는 원할 때 펼쳐 본다. 새 별도 점수나 학습 시험을 요구하지 않는다.
- 구현 검토 경계: 완료 기록과 같은 상태 사본에서 확인된 사실만 결과·원인으로 표시한다. 확인할 수 없는 원인을 지어내거나 다음 제안을 보장된 정답으로 표현하지 않는다. 기존 Q386 요약/알림과 중복되는 UI·행위 기록은 재사용 검토한다. 요약 열람으로 추가 보상이나 세계 상태 변경을 발생시키지 않는다.
- 미정: 첫 적용 활동, 작업 완료 시 정확한 알림/노출 방식·빈도, 실제 자료와 가상 규칙의 구체 대응. 결과 요약 방향은 확정이며 구체 화면·명세 연결은 개발 검토가 남는다. 새 경제 WI/강제 과제/수익 계산을 자동 추가하지 않는다. D2 준비와 실제 E·실행 증거는 분리한다.

## Q-402 게임 경험에서 현실 시장 통찰로 이어지는 참고 서비스

- 식별: `Q-생존경제-D2-02 · 전체 Q-402`. 상태: `ConfirmedDirection`, 구현은 `FutureExtension`.
- 사용자 의도: 게임 데이터가 현실 자료에서 해석·생성된 계보를 갖고, 게임에서 만난 상품/거래 경험이 현실 상품·시장 차이에 관한 유익한 통찰로 이어지기를 원한다. Amazon·Alibaba에서 비슷한 용도의 상품 가격이 다른 사례를 들었다. 음성의 '통실'은 문맥상 '통찰'로 해석했다.
- Q399~401과의 관계: 원자료→해석→게임 표현과 상세 출처를 유지하면서 현실 참고 정보로 확장하는 방향이다. 농산물 판매 한 건을 첫 요약 대상으로 삼자는 직전 추천까지 승인한 답변은 아니다.
- 계층 경계: 현실 관측과 상품 대응 근거, 게임용 변환/균형값, 현실 참고용 비교 결과를 분리한다. 현실 기회는 최신 원천과 조건에서 다시 검토하며 게임의 이익·확률·보험을 현실 수익 근거로 역산하지 않는다. 가상 상품 모두에 임의 현실 상품을 대응시키지 않고 대응 없음/미확인을 허용한다.
- 동일성: 외형/용도가 비슷하다는 사실은 동일 SKU·동일 품질·동일 보증의 증거가 아니다. 제조사·모델·규격·수량·품질·판매 조건에 따라 동일/유사/미확정으로 구분할 후보 구조를 검토한다. 판매 플랫폼, 판매자 소재지, 제조국, 출하국, 판매 대상 시장도 혼동하지 않는다.
- 비교 준비: 소매 표시가와 최소주문수량 조건의 도매 견적을 같은 거래처럼 빼지 않는다. 매입 수량·배송/물류·수수료·환율·세금/통관·보관·반품/불량·수요와 판매 가능성 등 필요한 비용/조건의 확인 여부를 보여준다. 미확인 비용을 0으로 넣어 이익을 확정하지 않는다. 이 목록은 검증 입력 후보이며 실제 원가 계산이나 규제 판단 완료가 아니다.
- 서비스 방향: '사면 돈을 번다'가 아니라 비교할 가치가 있는 후보·차이가 나는 이유·확인된 근거·남은 확인사항을 제공한다. 구매 절감과 재판매 이익은 서로 다른 사용 목적이다. 현실 구매/판매/계약/결제·개인화 투자 추천·성과 보장으로 자동 확장하지 않는다.
- D372 후속 확정: 게임에서는 재미와 게임 정보에 집중하고, 관심이 생긴 사용자가 '현실 자료 살펴보기'를 선택했을 때 별도 참고 화면에서 현실 자료·조건·불확실성을 본다. 현실 자료 열람은 게임 진행의 필수 조건이 아니며 자동으로 현실 구매/계약에 연결하지 않는다.
- D373 후속 확정: 상품 상세 화면과 거래 결과 상세 화면에 '현실 자료 살펴보기' 진입 항목을 둔다. 게임 중 상시 팝업을 강제하는 방식이 아니라 궁금해진 사용자가 상세 화면에서 선택하는 방식이다. 이 위치 선택이 미확보 자료나 미확정 상품 대응을 실제 연결 완료로 만드는 것은 아니다.
- 미정: 패널/화면의 세부 형태·외부 링크 열기 방식·상품 범위·자료 접근/갱신·수익모델·연결 자료가 없을 때의 항목 상태. 선택형 열람과 상세 화면 진입 위치는 다시 미승인으로 돌리지 않는다. 광고·실구매와 게임 보상을 연계하는 기능은 승인하지 않았다.
- 기존 준비 조사: [Amazon 수출 준비](../../../AmazonExportReadiness.md)는 직접 SP-API 실행 전 준비 경계를 가진 문서이며 상품 데이터 수집/게임 통찰 구현 완료 증거가 아니다. 기존 가격 비교/품목 대응과 자료 조사 체계를 우선 검토한다.
- 공식 안내 확인(2026-08-30): [Alibaba MOQ 안내](https://seller.alibaba.com/businessblogs/px6g2lut-what-is-minimum-order-quantity-moq)는 최소 수량·샘플과 도매 가격 차이, [Amazon 판매 비용 안내](https://sell.amazon.com/pricing)는 판매 수수료와 선택적 물류 등 추가 비용의 근거다. 실제 상품 쌍·가격·수익성은 이번에 검증하지 않았다.
- 조사/개발 경계: 자료 조사 담당은 허용된 데이터 접근·보관/재노출 조건과 비교 식별자를 먼저 조사한다. 대량 크롤링·계정 연결·유료 API·구매·새 운영 기능은 별도 승인 없이 하지 않는다. 기획 방향만으로 E/Save/Scene/새 WI를 활성화하지 않으며 기존 게임 개발을 막지 않는다.

## Q-403 게임 상품 우선과 운영자 현실 자료 검토

- 식별: `Q-생존경제-D3-03 · 전체 Q-403`. 상태: `ConfirmedDirection`.
- 확정: 지금은 게임 상품을 먼저 만든다. Apify를 향후 Amazon·Alibaba 자료 수집 경로 후보로 인지하되 지금 호출하지 않는다. 나중에 보온병/병 등 유사 현실 상품 후보와 가격을 비교하고 운영자가 사용자에게 제공할 자료를 결정하는 운영 서버 골격을 마련한다.
- 실행 범위: [게임·현실 상품 자료 운영 기반](../../../게임현실상품자료운영기반.md)의 `ApprovedFoundationScope`는 기존 계약 재사용·비활성 초안/검토 상태·가상 Fixture 시험만 승인한다. 실제 수집·게시·push·게임 Save/UI 변경은 제외한다.
- 미정: 실제 수집 Actor/조건/예산, 검토 UI, 공개/통지 전달 방식과 갱신 주기. 현재 Apify 상품 연동이 검증됐거나 플랫폼 자료를 자유롭게 재배포할 수 있다는 뜻이 아니다. D372/D373의 선택형 열람은 유지한다.
