## 재질문하지 않는 결정

제때 수확하지 않으면 효율·수량 저하 또는 수확 불가가 생길 수 있다는 방향은 이미 확정됐다. 무기한 무손실 대기는 채택하지 않았다. 원문에는 작물별 지연 구간·손실량·수확 불가 시점이 미정으로 남아 있다. 이번은 손실 유무를 다시 묻지 않고 **수확 가능 직후 손실이 시작되기 전 여유를 둘지**만 묻는다.

## 지금·여기·나·너·이렇게

아래는 질문을 위한 가상 상황이며 실제 실행 화면이나 초기 세계 상태가 아니다.

| 관점 | 상황 |
| --- | --- |
| 지금 | 첫 작물이 막 수확 가능해졌다. |
| 여기 | 내 밭 근처이며 다른 일을 하러 잠시 자리를 비울 수 있다. |
| 나 | 수확할 수 있지만 지금 다른 일도 하고 싶다. |
| 너 | 수확 가능한 작물이다. 늦은 수확의 손실 방향은 기존 결정을 따른다. |
| 이렇게 | 지금 수확하거나 잠시 다른 일을 하고 돌아온다. |
| 결과 | 손실 시작 전 여유의 유무가 선택의 긴박함을 바꾼다. |
| 다음 선택 | 돌아와 수확하거나 이후 지연에 따른 손실을 감수한다. 자동 수확·자동 위임은 가정하지 않는다. |

## 질문 하나

첫 작물은 수확 가능해진 직후 바로 손실이 시작되지 않고, 잠시 다른 일을 하고 돌아올 수 있는 여유를 두는 게 좋을까?

- 추천: 첫 작물에는 손실 시작 전 여유를 둔다. 즉각 복귀 압박을 줄이되 무기한 무손실 대기로 만들지 않는다.
- 대가: 당장 수확할 긴박함은 낮아지며, 여유가 끝나는 때를 알아볼 수 있게 하는 표현은 후속 검토가 필요하다.
- 이번에 묻지 않는 것: 정확한 시간/게임 시간 환산, 감소 곡선·최종 손실, 난이도별 차이, 모든 작물에의 적용, 알림 형태. 다른 일을 끝낼 때까지 시간이 멈추거나 항상 안전하다는 뜻이 아니다.
- 구현 경계: 답변 전 코드·정책·Save·기존 FB01 승인 원문을 변경하지 않는다. 답변 이후에도 추가 승인과 기존 명세 결속을 거쳐 해당 범위만 인계한다. 기존 D396 E4 준비를 이 답변 대기로 막지 않는다.
