## 다음 처리

전체 답변을 확정했으므로 같은 선택을 다시 묻지 않는다. 개발이 기존 Farm 기획·공간 연구 r2를 보존한 추가 승인으로 이 판본/hash와 경관 작업 범위를 결속하고, 공간 담당이 보유 자산 확인·비교 후보 제작부터 진행한다. 구체 후보는 실제 크기·통행·수원 접근·시야 검증과 기획의 화면 검토를 거쳐 확정한다. 맵 논의로 애니메이션의 미확인 제작 방식 사용조건을 승인한 것으로 해석하지 않는다.

## 개발 인계 범위

- 공간 담당은 동일 지형·Barn·카메라·시간대를 기준으로 기존 후보와 LS-01 경관 후보를 비교할 수 있게 만든다. 우선 Q387~392의 기존 자산 배치/표면 표현을 조사·준비하고, Q393~395 가림·빛·날씨는 Renderer/재질·Sky 연결 담당과 경로 소유를 나눠 검증한다. Q396은 실제 상태 공급이 있는 범위부터 표현하며 누락 상태를 가상 재고/성과로 채우지 않는다.
- 새 공급사 자산·텍스처 구매/원본 수정, 강/부지/생산량 변경, 임의 자동 평탄화, 전체 Farm/Town/City 강제 동일화는 제외한다. 기존 native 크기·부지 확대·자유 이동·단일 주 하천 보존·핵심 통행은 유지한다.
- 수관 가림은 표현만 바꾸며 Collider·권위 시야/위험을 제거하지 않는다. 기존 재질에서 수관만 분리할 수 없으면 기술 공백과 대안을 반환한다. 조명은 실제 화재·전력·방호 능력을 만들지 않고, 비·안개는 Sky 상태를 읽되 자체 날씨 권위를 만들지 않는다.
- 실제 조립 전에 공간 Required 연구의 추가 기준선을 원본 r2와 구분해 작성/검토하고 명세에 결속한다. 해당 기준선이 승인되는 범위부터 후보/실제 Scene으로 진행하며 기존 dirty를 일괄 저장/폐기하지 않는다. 새 공식 Scene을 만들지 않는다.
- 완료 검증은 같은 후보에서 접근·뒤편 자유 통행·급수/작업 접근, 원근 시야, 가림 복원, 낮/밤/비 판독과 Console을 구분한다. 공간 담당이 Game View 비교 PNG를 남기고 개발이 실제 결과를 검토해 기획에 반환한다. 기준선 상태/미구현 조건은 이미지와 함께 표시한다.
- 이번 확정은 추가 경관 작업의 기획 승인이지 패턴 후보의 시각 승인·E5/E7 완료가 아니다. 기존 E와 전달 상한·저장 호환을 유지하며 공통 원장과 CURRENT_WORK 동기화는 개발 담당 소유다.
