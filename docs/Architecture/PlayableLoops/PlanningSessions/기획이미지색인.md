# PlayableLoop 기획 이미지 색인

- 현행 기획 계보: `PLAN-PRESENTATION-SYNTY-SURVEY-001`과 이미지가 연결된 개별 현행 기획
- 현행화 판정: `ReferenceOnly / PlanningConceptIndex`; 기획 이미지와 실제 Prefab·Scene·Game View 증거를 구분

이 문서는 문답에서 확정하거나 검토 중인 플레이 순간을 Synty 기능 자산으로 어떻게 조립할지 상상하기 위한 기획 이미지의 색인이다. 이미지는 `PlanningConceptOnly`이며 실제 Prefab, Scene 배치, Animation 호환, Play Mode 또는 Game View 증거가 아니다.

## 사용 원칙

- 이미지의 건물·소품·인물은 보유 Synty 팩의 기능군으로 표현 가능한 범위를 우선한다.
- 정확한 Prefab은 Presentation E4의 후보 조사와 fingerprint 동결을 거쳐 E5에서 실제 배치한다.
- 이미지 속 빛·경로·선택선·마법진·상태 막대는 표현 후보이며 Simulation 상태나 비용을 확정하지 않는다.
- 한 이미지가 H1~H3 관계를 설명해도 H 등록·조립 승격·Scene 저장을 증명하지 않는다.
- 생성 이미지가 실제 자산에 없는 전용 외형을 포함하면 해당 부분은 조합·대체 표현 또는 별도 자산 검토 대상으로 남긴다.

## 첫 묶음: Nature 생존·회복

### Q-025 수면 안전의 중첩 공간층

![오두막·불·울타리·마법진 수면 안전층](../../../../assets/planning/playable-loops/nature-shelter-sleep/q-025-nested-sleep-safety-layers-concept.png)

- 문답: 오두막 실내, 불의 열·야생동물 억제, 울타리의 물리 침입 지연, 마법진의 상위 위협 억제를 서로 다른 중첩 범위로 둔다.
- H 연결: 수면점·열원점·방어 경계 H1 → 거점 안전 H2 → Nature 생존 경관 H3.
- Synty 후보: Nature CampFire·Tree·Rock, Farm Bed·Fence, Town Fireplace·Light, Construction Tarp·Plank. 마법진은 프로젝트 고유 FX 후보이다.
- 알려진 차이: 이미지의 완전한 원형 울타리, 위협 개체와 보호 반경은 확정 배치·수치가 아니다.

### Q-051 폐야영지 처방 발견

![폐야영지 약초 처방 발견](../../../../assets/planning/playable-loops/herbal-recipe-crafting/q-051-abandoned-camp-recipe-discovery-concept.png)

- 문답: 안전 빈터 가까운 폐야영지에서 기록, 식은 화로, 솥과 주변 식생을 함께 발견한다.
- H 연결: 지식 발견점·조리점·채집 접근점 H1 → 기초 약초 회복 H2 → Nature 첫날 귀환 경관 H3.
- Synty 후보: Town BookOpen·Mug, Generic Paper, Construction Clipboard·Rubbish Papers, Nature CampFire·Plant·Flower.
- 알려진 차이: 책의 내용과 식물 효능은 Simulation의 Recipe·Effect가 소유하며 외형으로 추론하지 않는다.

## 첫 묶음: Farm 골격·농지·관수

### Q-078 Farm 승인 골격과 자유형 밭

![Farm 기본 골격과 자유형 밭 후보](../../../../assets/planning/playable-loops/building-spatial-placement/q-078-farm-authored-skeleton-concept.png)

- 문답: Farm은 승인된 건물·밭·작물 골격을 먼저 두고, 배치 엔진은 그 안에 변주와 생활감을 채운다. 밭은 사각 격자를 강제하지 않고 지형에 맞는 닫힌 경계와 실제 면적을 사용한다.
- H 연결: 농가·헛간·작업장·재배구획 H1 → 독립 생산 Farm H2 → Farm 생산 경관 H3.
- Synty 후보: Farm Farmhouse·Barn·Shelter·Greenhouse·Silo·WaterTower·Crop·Fence, Nature 지면·수계, Construction 공사 상태층.
- 알려진 차이: 이미지의 건물 수, 작물 종류, 수원 거리와 밭 면적은 공식 기준안이 아니다.

### Q-143~155 관수 H 조립과 경로 Preview

![수원에서 밭까지 관수 경로 Preview](../../../../assets/planning/playable-loops/building-spatial-placement/q-143-155-irrigation-route-preview-concept.png)

- 문답: 빗물 저장점·수동 급수점·짧은 급수구간으로 시작하고, 실제 설치 가능 경로의 길이·고저차·횡단 조건에 따라 Pump와 중간 저수조 후보를 보여 준다.
- H 연결: 수원·저장·급수구간 H1 → 초기 관수작업장 H2 → Farm 용수망 H3.
- Synty 후보: Farm WaterTower·WaterTank·Well·SprinklerHose, Town HoseReel, Construction Tank·Pipe·Gutter와 Pump 대체 조립.
- 알려진 차이: 반투명 경로와 시설 Ghost는 프로젝트 UI다. 색이나 선 길이만으로 재료·노동·운영 비용을 확정하지 않는다.

## 첫 묶음: Town 입고

### Q-151 상점 입고 작업장

![Town 트럭 도착과 입고 작업 구역](../../../../assets/planning/playable-loops/town-order-pickup/q-151-town-receiving-work-area-concept.png)

- 문답: 트럭 도착 뒤 인수 → 하차 → 검수 → 격리 또는 후방 적재 → 차량 귀환을 공간적으로 읽게 한다.
- H 연결: 차량정차점·하차점·검수점·격리점 H1 → 상점입고장 H2 → Town 상점공급구역 H3.
- Synty 후보: Town DeliveryTruck, Construction HandTrolley·Pallet·Crate, Town·Generic Shelf·Counter·Sign, 보유 작업자 Actor.
- 알려진 차이: 이미지의 숫자와 색 구획은 개념 표식이다. 상자 이동과 Animation은 재고 증가를 확정하지 않는다.

## 첫 묶음: 개인·공동체 내면 UI

### Q-196~198 공동체의 마음 패널

![개인과 공동체 회복·위협 비율 패널](../../../../assets/planning/playable-loops/player-mind-meditation/q-196-198-community-mind-panel-concept.png)

- 문답: 개인과 공동체의 회복·위협을 분리하되 각 관점에서는 두 비율의 합을 100%로 표시한다. 개인 광복기와 공동체 광복기는 서로 독립적으로 판정한다.
- UI 연결: 공동체 비율·상태·주요 원인을 먼저 보여 주고 선택한 개인의 비율과 기간 상태를 별도 영역에 표시한다.
- 자산 경계: 배경 Actor·건물은 Synty 표현 후보이고 카드 틀·막대·아이콘은 프로젝트 고유 UI다. 마음을 중앙 시설로 표현하지 않는다.
- 알려진 차이: 이미지의 정확한 문구·색·초상·배치는 최종 UI가 아니다. 색 이외의 패턴·아이콘·접근성 표현을 E4에서 함께 동결한다.
