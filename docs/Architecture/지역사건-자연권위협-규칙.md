# 업무 사건과 심리 영역 발전소 영향 규칙

> 구현 책임의 최신 분리는 [지역 사건·Nature 위협·지역 발전 모듈 경계](지역사건-Nature위협-지역발전모듈경계.md)를 따른다. 이 문서의 기존 저장·인과 규칙은 보존하되, 신규 발전 기회와 Farm 공간 프로젝트는 분리된 모듈에서 추가한다.

## 목적

Farm·Town·City/Hub에서 처리한 업무의 결과가 발생 영역에 직접 영향을 남기는 동시에, 플레이어의 심리 상태를 공간으로 표현한 영역에 어떻게 전이되는지 정의한다. Unity는 확정된 결과를 시설·환경·경고·조우로 표현할 뿐 업무 결과나 발전소 상태를 확정하지 않는다.

## 세계와 시설 용어

| 용어 | 정의 | 기존 기술 이름과의 관계 |
| --- | --- | --- |
| 심리 영역 | 업무 결과가 플레이어의 회복력과 위협 상태에 미친 심리적 영향을 명시적으로 공간화한 상시 체류 세계 | 현재 `NatureHome`과 Nature 팩 중심 경관을 재사용한다. Nature는 계속 표현 팩과 안정 식별자에 쓰인다. |
| 업무 영역 | 사건이 발생하고 Farm 생산, Town 생활·시장, City/Hub 물류 업무가 직접 처리되는 독립 AreaSet 묶음 | 현재 `ProfessionalWorld`인 Farm·Town·City/Hub를 가리키는 Simulation 문맥의 용어다. |
| 회복 발전소 | 좋은 업무 결과와 심리 영역의 회복 행동을 받아 회복력을 축적하고 업무 영역으로 긍정적 효과를 되돌려주는 시설 | 서버의 `RecoveryScore`와 원인 계보는 구현됐고 실제 Unity 시설·Scene 표현은 아직 없다. |
| 위협 발전소 | 잘못된 업무 결과와 기한 초과를 받아 위협을 축적하고 심리·업무 영역에 부정적 효과를 되돌려주는 시설 | 서버의 `ThreatScore`와 원인 계보는 구현됐고 실제 Unity 시설·Scene 표현은 아직 없다. |
| 업무 직접 영향 | 사건이 발생한 업무 영역의 재고·생산·생활·물류 상태에 남는 원인과 결과 | 심리 영역 행동으로 해결할 수 없으며 해당 업무 영역의 후속 WI로 처리한다. |
| 심리 영향 | 확정된 업무 결과가 두 발전소 상태에 만드는 동시 변화 | `simulation-save.v5`의 지역 인과 원장이 같은 결과 계보와 `WorldTick`으로 확정한다. |

심리 영역은 일체유심조처럼 업무와 외부 세계 전체가 마음에서 생겼다고 설명하는 형이상학적 세계가 아니다. 업무 영역의 원인과 직접 결과는 독립적으로 존재하고, 심리 영역은 그 결과가 플레이어에게 남긴 심리적 영향을 플레이 가능한 공간으로 보여준다.

## 목표 인과 규칙

업무 결과 하나는 미래의 Simulation 계약에서 다음 두 변화를 원자적으로 남긴다.

```text
업무 영역의 확정된 결과
├─ 발생 업무 영역: 업무 직접 영향
└─ 심리 영역: 회복 발전소와 위협 발전소의 동시 변화
```

- 좋은 결과는 회복 발전소를 강화하고 위협 발전소를 약화한다.
- 잘못된 결과와 기한 초과는 회복 발전소를 약화하고 위협 발전소를 강화한다.
- 미리보기에서 차단된 요청과 일반 작업 취소는 업무 결과가 아니므로 두 발전소를 바꾸지 않는다.
- 두 발전소는 서로 반대 방향으로 함께 변하지만 한 수치로 합치지 않는다. 각 상태와 원인 계보를 독립적으로 보존한다.
- 심리 영역의 관찰·후퇴·복원·회복·전투는 확산과 플레이어 피해를 완충할 수 있지만 업무 직접 영향을 해결하거나 업무 사건을 종료하지 않는다.
- 발전소 상태는 Farm·Town·City/Hub 여러 업무 영역에 다시 영향을 줄 수 있다. 효과 대상과 강도는 원인 경로와 업무 종류별로 정하며 모든 업무 영역에 같은 전역 수치를 일괄 적용하지 않는다.
- 현재 발전소 점수 범위는 각각 0~12이며 업무 영역별 세부 생산·재고 보정표와 실제 시설 표현은 후속 수직 조각에서 확정한다.

## 현재 구현된 위협·회복 흐름

현재 런타임은 확정 결과·Nature 행위·턴 카드가 원인 경로별 `Threat`·`Recovery` 원장을 바꾸고, 두 점수의 차이를 자연권 유효 압력에 반영한다. 업무 영역별 생산·재고 수치에 직접 되돌리는 세부 표는 아직 구현하지 않았다.

```text
업무 영역의 사건
→ 사람의 선택
→ 후속 WI 수행 또는 방치
→ 확정된 안전/불안전 결과
→ 경로별 Threat·Recovery 변화
→ 사건 압력 + Threat - Recovery
→ 경고 또는 자연권 조우
→ 원인 WI 해결 / 조우 승리
→ 압력 완화
```

## 첫 사건 묶음

| 출발 경관 | 사건 | 안전한 선택과 후속 WI | 안전하지 않은 선택 | 심각도 |
| --- | --- | --- | --- | ---: |
| Farm | 수확물 현장 노출 | 집하 `WI-FARM-05` + 포장 `WI-FARM-06` | 노출 상태로 방치 | 2 |
| Town | 시장 재고 오염 | 시장 검수 + 후방 적재 + 진열 보충 | 타운 외곽에 폐기 | 2 |
| City/Hub | 도착 화물 적체 | 입고 검수 `WI-001` + 창고 적재 `WI-002` | 야외 적치 | 3 |

안전한 선택을 했더라도 필요한 WI를 기한 안에 완료하지 못하면 `DeadlineMissed` 결과가 된다.

## 자연권 압력

경로는 `NatureToFarm`, `NatureToTown`, `NatureToCityHub` 세 개다. 사건별 `RemainingSeverity`만 압력에 참여한다.

```text
사건 압력
= 해당 경로 남은 심각도 × 2
 + floor(전체 경로 남은 심각도 / 3)

경로 유효 압력
= clamp(사건 압력 + 경로 Threat - 경로 Recovery, 0, 12)

최댓값 = 12
```

| 압력 | 상태 | 표현 |
| ---: | --- | --- |
| 0~1 | Stable | 안정 |
| 2~3 | Warning | 경고 |
| 4~7 | Threatened | 자연권 조우 |
| 8~12 | Infested | 강화된 자연권 조우 |

조우 적 수는 `ceil((압력 - 2) / 2)`이며 최대 5개다. 다른 경로의 사건 압력은 약한 전역 확산에만 참여한다. 해당 경로 사건이 없어도 경로 없는 전역 카드가 `Threat`를 남기면 조우가 생길 수 있고, 경로별 `Recovery`는 그 유효 압력을 상쇄한다.

## 회복 규칙

- 원인이 된 후속 WI를 모두 완료하면 해당 사건의 남은 심각도를 0으로 만든다.
- 현재 구현은 자연권 조우에서 승리하면 같은 경로의 가장 오래된 미해결 사건 심각도를 1 줄인다. 이는 심리 영역 행동은 업무 직접 영향을 해결하지 않는 새 목표 규칙과 맞지 않는 이행 대상이며, 후속 Simulation 수직 조각에서 업무 사건과 심리 완충 상태를 분리해야 한다.
- 같은 전투 결과의 재적용은 멱등하게 무시한다.
- 시간이 지났다는 이유만으로 압력이 자동 감소하지 않는다.
- 기존 농장의 계절 방어 위협은 별도 규칙이며 지역 사건 압력에 다시 입력하지 않는다.

## 카드·턴 마감 되먹임

- 역방향(`Reversed`) 카드는 절댓값 기준 최소 1만큼 `Threat`를 높인다.
- 정방향(`Upright`) 또는 양의 효과 카드는 같은 기준으로 `Recovery`를 높인다.
- 서버는 누적 점수에서 다음 날 결과를 `Normal / Opportunity / Threat / Recovery` 중 하나로 확정한다.
- Unity는 선택된 카드와 서버 결과를 표시할 뿐 점수·방향 효과·다음 날 결과를 다시 계산하지 않는다.

## 자연권 행위 계약

위협 상태를 실제 플레이어 행위로 다루기 위해 다음 네 WI를 독립 계약으로 둔다.
이들은 기존 지역 사건 압력 계산을 대체하지 않고, 그 상태를 관찰하고 대응하는
명시적 행위 계층이다.

| WI | 행위 | 공간 요구 | 완료가 의미하지 않는 것 |
| --- | --- | --- | --- |
| `WI-NATURE-01` | 자연권 위협 관찰 | 관찰·위협 감시 공간 | 압력 감소·사건 해결 |
| `WI-NATURE-02` | 자연권 긴급 후퇴 | 비상 접근·탈출 경로·안전 생활핵 | 전투 승리·사건 해결 |
| `WI-NATURE-03` | 자연권 복원 | 복원 작업공간·화물 접근 | 업무 사건 자체 해결·다른 경로 자동 회복 |
| `WI-NATURE-04` | 파티 회복 | 휴식 공간·안전 생활핵 | 업무 사건 자체 해결 |

흐름은 `관찰 → 후퇴 → 회복` 또는 `관찰 → 원인 해결 확인 → 복원 → 회복`으로
분기한다. 관찰·후퇴·회복은 지역 사건 원인의 심각도를 변경하지 않는다. 복원도
원인 해결 계보가 확인된 경로에만 적용한다. `WI-NATURE-01`은 Scenario 관찰 공간을
사용한 Preview·Confirm·공간 예약·Task·Effect·저장 재생과 HTTP 자동 시험까지 E3로
완결했다. `WI-NATURE-02`도 선행 관찰 또는 활성 조우를 검사하고 Scenario
후퇴 경로를 예약한 뒤 `PartyRetreatedToSafeCore` 효과와 예약 반환, 저장 재생·HTTP
시험을 닫아 E3다. `WI-NATURE-03`도 관찰 효과가 가리킨 원인 사건이 모두 해결되고
현재 경로에 남은 심각도가 없을 때만 Scenario 복원 공간·자재를 예약·소비하도록
E3를 닫았다. `WI-NATURE-04`는 후퇴 또는 복원 효과를 선행 조건으로 받고 Scenario
안전 회복 야영지의 파티 휴식 용량·회복 보급을 사용해 E3를 닫았다. 네 Nature WI
모두 행위 구현 E3이며 작성 Scenario의 실제 E5 공간에 직접 결속됐다. 공공데이터 E6와 사람 시각 승인은 별도 증거다.

## 서버 계약

기존 세계 사건 조회를 유지한다.

```text
GET /api/simulation/v1/sessions/{sessionStableId}/world-events
```

지역 사건은 전용 미리보기·확정 경로를 사용한다.

```text
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/{eventStableId}/response-previews
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/{eventStableId}/responses/confirm
```

자연권 위협 관찰은 다음 전용 경로를 사용한다.

```text
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/observation-previews
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/observations/confirm
```

긴급 후퇴는 다음 전용 경로를 사용한다.

```text
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/retreat-previews
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/retreats/confirm
```

자연권 복원은 다음 전용 경로를 사용한다.

```text
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/restoration-previews
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/restorations/confirm
```

파티 회복은 다음 전용 경로를 사용한다.

```text
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/party-recovery-previews
POST /api/simulation/v1/sessions/{sessionStableId}/world-events/nature-threat/party-recoveries/confirm
```

관찰 확정은 기존 범용 결정·작업·효과 원장을 사용한다. 완료 효과는 관찰 당시 압력과
원인 사건 계보를 기록하지만 압력 변화량은 0이며 사건 상태를 변경하지 않는다. 현재
관찰 공간의 근거 종류는 작성 `Scenario` E5이며 공공데이터 E6나 사람 시각 승인으로
해석하지 않는다.
후퇴 확정도 범용 결정·작업·효과 원장을 사용한다. 선행 `NatureThreatObserved`
효과 또는 같은 경로의 활성 조우가 없으면 차단하고, 후퇴 완료는 지역 사건·압력·조우를
해결하지 않는다. 현재 후퇴 경로도 `Scenario` 근거다.
복원은 관찰 효과의 원인 사건 계보와 현재 경로 심각도 0을 모두 요구한다.
복원 자재는 Scenario 공간의 소모성 용량으로 예약하고 완료 시 소비하며, 취소하면
반환한다. `NatureRouteRestored`는 사건 심각도를 바꾸지 않지만 해당 경로의
`Threat -1`, `Recovery +1`을 한 번 적용해 유효 압력을 완충한다.
파티 회복은 같은 경로의 `PartyRetreatedToSafeCore` 또는 `NatureRouteRestored`
효과를 요구한다. 휴식 용량은 완료 시 반환하고 회복 보급은 소비하며,
`PartyRecovered`는 다음 탐색을 열고 해당 경로의 `Threat -1`, `Recovery +1`을
한 번 적용하지만 업무 사건의 심각도 자체는 바꾸지 않는다.

클라이언트는 행위자, 선택 고유 식별자, 예상 개정과 확정 명령 고유 식별자만 보낸다. 심각도, 필요한 WI, 기한, 압력, 적 수와 카드 보정은 서버 규칙이 정한다. 선택 확정·자연권 전투 승리·지역 인과 원장은 `simulation-save.v5`에 포함되며 v1~v4 읽기·재생에는 새 인과 규칙을 적용하지 않는다.

## Unity 표현 경계

- 압력이 있으면 `POLYGON Apocalypse` 설치 여부와 무관하게 경고는 표시할 수 있다.
- 적 개체는 `POLYGON Apocalypse`가 설치·검토되고 `EncounterBand`와 지원 표현 키가 일치할 때만 표시한다.
- 팩이 없으면 `WaitingForApocalypseAssetPack`으로 남기고 다른 Synty 팩이나 절차 Primitive로 대체하지 않는다.
- Unity의 이동, Animator, NavMesh, 전투 연출 종료는 사건 해결 또는 압력 감소를 확정하지 않는다.

## 현재 증거 수준

지역 사건·경로별 압력·관찰·후퇴·복원·회복, `Threat`·`Recovery` 원장, 카드 되먹임과 v5 저장·재생은 서버 계약·도메인 규칙·집중 시험으로 확인했다. Unity에는 서버 상태 사본을 표시하는 HUD와 실제 E5 Network Root를 canonical Scene에 저장했지만, 두 발전소의 실제 Prefab·Apocalypse 조우 표현·Play Mode·Game View·실행 중 외부 서버 종단 검증은 수행하지 않았다.
