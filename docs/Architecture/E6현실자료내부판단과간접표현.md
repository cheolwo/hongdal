# E6 현실 자료 내부 판단과 간접 표현

## 목적

공공자료와 현실 공간자료는 게임 화면의 주인공이 아니다. 서버가 Farm·Nature의 현재 문맥을 판단할 때 사용하는 내부 근거이며, 플레이어에게는 그 결과인 젖은 작업 환경·찬 기운 주의·작물 상태 확인·시장 흐름 변화 같은 게임 현상으로 먼저 보인다. 출처와 기준 시각은 사용자가 정보 카드를 명시적으로 열었을 때만 보조 설명으로 제공한다.

## 권위 흐름

```text
수집된 원자료
  → 출처·기준 시각·단위·공간 정밀도·품질·이용 조건 검사
  → 승인 현실 자료 대장
  → 세션 시작 시 현실 자료 상태 사본 동결
  → 의미 신호 제안
  → 기존 Simulation 업무·사건 규칙
  → 사건·업무·Effect
  → Unity 게임 현상 표현
```

다음 불변식을 지킨다.

> 현실 문맥의 의미 신호는 사건이나 Effect가 아니다. 의미 신호만으로 생산량·수익·업무 성공·사건 발생·H5 상대 배치를 바꾸지 않는다.

공공자료 Provider는 Simulation Tick이나 Unity 조회 도중 호출하지 않는다. 수집과 정규화는 세션 밖에서 끝내고, 세션은 승인 대장의 상태 사본만 시작 시 한 번 동결한다. 같은 상태 사본과 규칙 판본은 같은 의미 신호와 저장·재생 hash를 만든다. 세션 도중 Provider 장애나 새 관측 도착은 이미 시작한 세션을 바꾸지 않는다.

## 상태 사본과 누락 처리

`SimulationRealityContextSnapshot`은 다음 계보를 보존한다.

- 프로필 고유 식별자·판본과 의미 신호 규칙 판본
- 대상 AreaSet과 동결 시각
- 출처별 관측·수집 시각, 공간 정밀도, 단위, 원자료 hash, 이용 조건과 한계
- `Available / PartiallyAvailable / Unavailable`
- `Current / Stale / Unknown`
- 파생된 의미 신호와 입력 hash

원자료 값 자체는 상태 사본 밖의 승인 대장에만 존재한다. 누락·낡음·품질 부족·미승인 이용 조건은 `Unavailable` 또는 `Stale`로 남기며 시나리오 값으로 대체하지 않는다. 현재 작성 Farm 프로필은 ASOS·KAMIS·기상청 단기예보 계약을 등록했지만 승인 관측·예보를 아직 적재하지 않았으므로 의도적으로 `Unavailable`이다.

## 세션과 저장·재생

클라이언트는 `RealityContextProfileStableId`만 보낸다. 실제 E5 세션 생성 서비스가 AreaSet 일치와 승인 대장을 확인하고 상태 사본을 만든다. 일반 세션 생성 경로에서 프로필만 제출하고 권위 상태 사본을 우회 주입할 수 없다.

현실 문맥이 있는 저장 자료는 `simulation-save.v8`을 사용한다. v8은 프로필, 동결 시각, 출처 계보, 의미 신호와 입력 hash를 재생 hash에 포함한다. v1~v7은 당시 정규형을 유지한다.

## Unity 간접 표현

Unity 기본 조회는 `includeSourceDetails=false`다. 응답에는 서버가 확정한 게임 현상과 권고 의미 코드만 있으며 관측 원수치, 원자료 hash, API key, 필지 식별자는 없다.

```text
기본 세계 화면
├─ 젖은 작업 환경
├─ 찬 기운 주의
├─ 작물 상태 확인
└─ 시장 흐름 변화

선택형 C 카드 서랍 > 정보·개념
├─ 출처 이름
├─ 기준 시각
├─ 공간 정밀도
├─ 이용·해석 한계
└─ 원문 Web 연결
```

정보 카드는 `Knowledge + ProjectionReadOnly`이며 업무 허용이나 카드 효과를 변경하지 않는다. Unity는 서버 의미 신호를 다시 계산하지 않고 현상·환경·NPC 권고를 표현한다.

## 증거 경계

계약·파일 대장·서버 API·저장·재생·Unity 투영 시험은 구현 증거다. 실제 공공자료 수집 성공, 실행 중 Provider 검증, 실제 Unity HTTP 왕복, Play Mode와 Game View는 각각 별도 증거이며 현재 구현 완료로 간주하지 않는다.
