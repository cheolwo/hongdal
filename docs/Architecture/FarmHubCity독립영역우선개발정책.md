# Farm·Hub·City 독립 영역 우선 개발 정책

## 1. 결정

Farm, Hub, City는 공급망의 연속 단계가 아니라 각각 독립적으로 개발하고 검증하는 업무 영역이다.

기본 개발 단위는 `Farm→Hub` 또는 `Farm→Hub→City` 경로가 아니다. 다음 세 영역 slice를 각각 먼저 닫는다.

- Farm 독립 slice: 재배, 수확, 집하, 포장과 영역 내부의 정상·위협·회복 흐름
- Hub 독립 slice: 반입 후보, 검사, 보관, 분류·출고 준비와 영역 내부의 정상·위협·회복 흐름
- City 독립 slice: 수요, 주문·거래 후보, 수령, 소비·피드백과 영역 내부의 정상·위협·회복 흐름

구현 순서는 완성도와 현재 목표에 따라 달라질 수 있지만 영역 간 종속 관계를 뜻하지 않는다.

## 2. 기본 선택 규칙

새 계획이나 다음 수직 slice를 정할 때는 다음 순서를 따른다.

1. 사용자가 특정 영역이나 연결 경로를 지정했는지 확인한다.
2. 지정이 없으면 Farm·Hub·City의 독립 준비 상태를 각각 비교한다.
3. 독립 폐루프나 증거가 가장 부족한 영역 하나를 선택한다.
4. 선택한 영역 안에서 가장 작은 결정론적 Fixture로 서버 계약부터 닫는다.
5. 다른 영역과의 화물·가격·사건 인계는 독립 완료 조건에서 제외한다.

Farm이 먼저 구현되어 있다는 이유만으로 Farm 출하, Farm→Hub 운송 또는 감자 여정을 다음 기본 작업으로 선택하지 않는다.

## 3. 독립 준비 조건

영역 하나가 독립 준비 상태가 되려면 최소한 다음을 가져야 한다.

- 다른 영역의 상태를 요구하지 않는 시작 Fixture
- 영역 내부에서 시작하고 결과를 확인한 뒤 다시 행동 가능한 플레이 폐루프
- 서버가 확정하는 Preview, 명시적 Confirm, Tick·결과 재조회 경계
- 고유 AreaSet 의도와 내부 LandscapeGraph 또는 미확정 상태를 사실대로 나타내는 공간 증거
- 영역 고유 상태의 저장·재생과 결정성 검증
- canonical `SimulationWorldShell`에서 다른 영역 모듈 없이도 선택·관찰 가능한 Unity 표현 경계

실제 Play Mode·Game View, E6 현실 자료, 운영 Provider 호출은 해당 작업이 요구할 때 별도 증거로 남긴다. 이들이 없다는 이유로 Scenario나 Unity 표현을 서버 사실로 승격하지 않는다.

## 4. 영역 간 연결

`Farm→Hub`, `Hub→City`, `Farm→City`는 영역 자체가 아니라 별도의 통합 slice다.

통합 slice는 다음 조건을 모두 만족할 때만 기본 후보가 된다.

- 출발 영역과 도착 영역이 각각 독립 준비 상태다.
- 양쪽 경계에 명시적인 `ExternalConnectorStub` 또는 동등한 계약이 있다.
- 운송·인계의 stable ID, expected revision, 멱등성, 저장·재생 경계가 정의되어 있다.
- 연결 실패나 미사용 시에도 두 영역의 내부 플레이가 계속 가능하다.
- 연결의 성공을 영역 자체의 완성 증거로 중복 계산하지 않는다.

과거의 감자 `Farm→Hub` Fixture와 회랑 자산은 호환·회귀 검증 자료로 보존한다. 다만 새 기능의 기본 출발점이나 전체 World의 필수 골격으로 간주하지 않는다.

## 5. Unity와 명명 경계

- 공식 Play Scene은 하나의 canonical `SimulationWorldShell`을 유지한다.
- Farm, Hub, City는 같은 Scene 안의 독립 모듈·Root·조회 대상으로 구성한다.
- 새 공식 Scene을 영역별로 만들지 않는다.
- 새 문서와 개발 판단에서는 Hub와 City를 `City/Hub`로 합치지 않는다.
- 기존 API route, JSON 필드, 공개 계약, 저장 값, stable ID의 `CityHub` 표기는 호환성 검토 없이 바꾸지 않는다.

## 6. 계획과 완료 보고

계획에는 영역별 상태와 연결 상태를 분리해서 적는다.

| 구분 | 보고 내용 |
| --- | --- |
| Farm | 내부 폐루프, Fixture, 저장·재생, 공간·Unity 증거 |
| Hub | 내부 폐루프, Fixture, 저장·재생, 공간·Unity 증거 |
| City | 내부 폐루프, Fixture, 저장·재생, 공간·Unity 증거 |
| 영역 간 연결 | 출발·도착 준비, 인계 계약, 경로, 통합 검증 |

`Farm→Hub`가 동작한다는 사실만으로 Hub가 독립 완성되었다고 보고하지 않는다. 마찬가지로 Farm 화물을 받는 City 화면만으로 City 독립 플레이를 완료했다고 보고하지 않는다.
