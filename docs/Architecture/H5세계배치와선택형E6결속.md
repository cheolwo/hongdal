# H5 세계 배치와 선택형 E6 현실 결속

## 목적

H1~H4의 재사용 공간 의미를 특정 게임 세계에 실제로 배치하면서도 현실 GIS 자료에 종속시키지 않는다. H5는 H4 AreaSet 인스턴스와 물리 회랑의 상대 위치를 권위 있게 정하고, E6는 세계 의도가 요구할 때 H5 전체를 현실 좌표계에 투영하는 별도 결속이다.

## 계층과 좌표

```text
H5 WorldLayout                         ScenarioLocalMeters
├─ H4 AreaSet 인스턴스                 ScenarioLocalMeters
│  └─ H3 LandscapeGraph 인스턴스       ParentLocalMeters
│     └─ H2 블록                       ParentLocalMeters
│        └─ H1 행동 공간               ParentLocalMeters
└─ H3 물리 회랑 인스턴스               ScenarioLocalMeters
```

`ScenarioLocalMeters`는 H5가 소유하는 루트 로컬 좌표계다. H5에 직접 배치되는 AreaSet과 회랑만 이 좌표계를 사용한다. 그 아래 공간은 바로 위 부모를 기준으로 `ParentLocalMeters`를 사용한다. 최종 좌표는 값을 단순히 더하지 않고 부모 위치와 회전을 차례대로 합성한다. 임의 Scale은 허용하지 않고 승인된 크기 변형과 반전 코드만 사용한다.

## 청사진, 인스턴스, 이동 관계

- H4 지역 청사진은 재사용 가능한 공간 의미 정의다.
- H4 AreaSet 인스턴스는 청사진을 특정 세계 문맥에 인스턴스화한 지역이다.
- H5는 AreaSet과 실제 물리 회랑의 배치를 소유한다.
- `AreaSetNetwork`는 이동·물류 가능성과 경로 선택을 소유한다.
- Network 관계가 있다고 해서 H5가 가짜 회랑을 자동 생성하지 않는다. 물리 회랑이 없는 관계는 `AbstractTravel`로 남긴다.

첫 세계 배치는 Nature–Farm, Farm–City/Hub, City/Hub–Town 세 관계만 물리 회랑으로 결속한다. 직접 Nature–City/Hub, Nature–Town과 역방향 관계는 Network 의미를 유지하되 물리 회랑을 꾸며내지 않는다.

## 선택형 E6

E6는 모든 H5 세계의 필수 후속 단계가 아니다.

| 정책 | 의미 |
| --- | --- |
| `NotRequired` | 현실 결속을 고려하지 않는 세계 |
| `Optional` | H5만으로 실행 가능하며 필요할 때 E6를 결속할 수 있는 세계 |
| `Required` | H5 실행은 가능하지만 최종 목표 완료에는 E6 근거가 필요한 세계 |

세계 배치 정의(`WorldLayoutDefinition`)와 현실 결속 적용 상태(`WorldGroundingBinding`)는 분리한다. DEM·도로 등이 일부 준비된 상태는 권위 적용 상태가 아니라 별도 준비도(`WorldGroundingReadiness`)다. 같은 H5에 E6를 붙이거나 교체해도 H5 배치 해시는 바뀌지 않는다.

E6는 H5 이하 상대 X/Z 구조를 변형할 수 없다. 현실 자료와 맞추기 위해 Farm이나 Hub를 따로 옮기거나 회랑을 변형해야 한다면 E6 갱신이 아니라 새로운 H5 배치 revision이다. E6는 실제 좌표 Anchor, CRS, 자료 계보, 높이와 정합 검증을 제공하고 H5 전체를 외부 좌표계에 투영한다.

## LH와 Unity 실행 경계

LH는 E6 유무가 아니라 유효한 H5 권위 세계의 존재를 기준으로 실제 세계 셀 내용 공급자를 사용한다. E6가 `NotApplied`인 `ScenarioRelative` 세계를 시험용 절차생성으로 후퇴시키지 않는다. 셀 내용은 H5 배치 고유 식별자·revision·hash와 현실 결속 상태를 입력으로 결정한다.

Unity 계층은 권위 좌표를 부모 Transform으로 합성한 뒤 Floating Origin 보정을 표현 좌표에만 적용한다. Floating Origin 이동은 H5/H4/H3/H2/H1 원본 좌표, 세계 배치 hash, 저장·재생 계보를 변경하지 않는다.

## 완료와 증거

현재 첫 세계는 `ScenarioRelative`, E6 정책 `Optional`, 적용 상태 `NotApplied`다. 이는 E6 없이도 완성된 H5 권위 세계다. 다만 코드·생성기·서버 API·Unity EditMode 시험은 실제 플레이 폐루프 E7, 사람 조작, Play Mode 또는 Game View 증거를 대신하지 않는다.
