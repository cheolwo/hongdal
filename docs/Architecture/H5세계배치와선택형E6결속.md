# H5 세계 배치와 E6 플레이 전 정제·선택형 GIS 결속

## 목적

H1~H4의 재사용 공간 의미를 특정 게임 세계에 실제로 배치하면서도 현실 GIS 자료에 종속시키지 않는다. H5는 H4 AreaSet 인스턴스와 물리 회랑의 상대 위치를 권위 있게 정한다. E6는 E5 AreaSet을 E7 실제 플레이에 올리기 전에 H3·H2·H1·WI·상태 변화와 현실 문맥을 정제하는 성숙도이며, GIS 투영은 그 안에서 독립적으로 선택하는 결속 축이다.

## 계층과 좌표

```text
H5 WorldLayout                         ScenarioLocalMeters
├─ H4 AreaSet 인스턴스                 ScenarioLocalMeters
│  └─ H3 LandscapeGraph 인스턴스       ParentLocalMeters
│     └─ H2 블록                       ParentLocalMeters
│        └─ H1 행동 공간               ParentLocalMeters
└─ H3 물리 회랑 인스턴스               ScenarioLocalMeters
```

`ScenarioLocalMeters`는 H5가 소유하는 루트 로컬 좌표계다. H5에 직접 배치되는 AreaSet과 회랑만 이 좌표계를 사용한다. 그 아래 공간은 바로 위 부모를 기준으로 `ParentLocalMeters`를 사용한다. 최종 좌표는 값을 단순히 더하지 않고 부모 위치와 회전을 차례대로 합성한다. 임의 Scale은 허용하지 않고 승인된 크기 변형과 반전 코드만 사용한다.

## 청사진, 인스턴스, 이동 관계

- H4 지역 청사진은 재사용 가능한 공간 의미 정의다.
- H4 AreaSet 인스턴스는 청사진을 특정 세계 문맥에 인스턴스화한 지역이다.
- H5는 AreaSet과 실제 물리 회랑의 배치를 소유한다.
- `AreaSetNetwork`는 이동·물류 가능성과 경로 선택을 소유한다.
- Network 관계가 있다고 해서 H5가 가짜 회랑을 자동 생성하지 않는다. 물리 회랑이 없는 관계는 `AbstractTravel`로 남긴다.

첫 세계 배치는 Nature–Farm, Farm–Hub, Hub–Town 세 관계만 물리 회랑으로 결속한다. 직접 Nature–Hub, Nature–Town과 역방향 관계는 Network 의미를 유지하되 물리 회랑을 꾸며내지 않는다. 과거 `CityHub` 역할 코드는 Hub의 읽기 호환 별칭이며 새 H5 판단에서는 Hub와 City를 합치지 않는다.

## 다섯 영역 고정 앵커

H5 revision 3부터 `WorldAreaAnchor`가 폐루프 개발 순서와 무관하게 다섯 영역의 기준 위치와 특징을 먼저 봉인한다.

| 영역 | ScenarioLocalMeters X/Z | 상태 | 특징 Profile |
| --- | ---: | --- | --- |
| Nature | `0 / 0` | `Composed` | 불규칙 숲·회복 생활핵·위협 외곽 |
| Farm | `634.910789 / -93.977416` | `Composed` | 십자 농로·네 밭·완만한 작업 지형·능선 건축 금지 |
| Hub | `395.256719 / -564.642079` | `Composed` | 평탄 포장·차량 회전·입고→검수→적치→출고 동선 |
| Town | `-384.825022 / -1929.888118` | `Composed` | 저층 시장·보행 생활권·소비 후 다음 욕구 귀환 |
| City | `-980.157889 / -2971.799236` | `Reserved` | 고밀도 서비스망·대형 시설·공공 공간 후보 |

City 위치는 기존 Hub→Town 방향을 Town 밖으로 1,200m 연장한 상대 위치다. `Reserved` 앵커는 메타데이터 선행 적재만 허용하며 Actual E5 Graph가 없으므로 통행·활성화·WI 실행을 허용하지 않는다. Town–City 관계도 `ReservedCorridor`로 노출해 다음 영역의 존재를 숨기지 않되 실제 회랑을 꾸며내지 않는다.

E6·DEM·도로·토지피복은 이 위치를 움직이지 않는다. 위치를 바꾸려면 E6 갱신이 아니라 새 WorldLayout revision과 구판 호환 규칙이 필요하다.

## E6 AreaSet 플레이 전 정제

E6는 E5 상태를 덮어쓰지 않는다. 한 AreaSet은 다음 축을 동시에 가진다.

| 축 | 값 |
| --- | --- |
| 공간 성숙도 | `E5Qualified` |
| 몰입 성숙도 | `NotInspected / StructureInspected / ContextEvidenceBound / ImmersionQualified` |
| 최신성 | `Current / Stale` |
| GIS 결속 | `NotApplied / Partial / Applied` |

E6 합격은 모든 H3의 필수 정제 질문이 통과하고 AreaSet 안의 H3 사이 인과·이동 폐루프가 닫혀야 한다. Graph·H 정의·WI·정제 질문표·근거 스냅샷·생성기 판본 중 하나가 바뀌면 기존 결과는 `ImmersionQualified + Stale`로 표현할 수 있으며 E7 시작 관문은 다시 닫힌다. 기존 상태 코드 `ImmersionQualified`는 저장·API 호환을 위해 유지한다.

`E6 정제 질문표`는 장소의 존재 이유, Actor와 물건의 이동, WI 시작·완료 상태, 반복 사용에 따른 공간 변화, 선행 H3 결과가 후속 H3 입력으로 이어지는지와 배치·통행·권위·최신성 결함이 남았는지를 묻는다. 공공자료는 이 답을 설명하는 근거이며 Simulation 규칙으로 자동 승격되지 않는다.

세션 실행에서 현실 자료를 내부 판단 근거로 사용할 때는 [E6 현실 자료 내부 판단과 간접 표현](E6현실자료내부판단과간접표현.md)의 승인 대장·세션 시작 동결·의미 신호·선택형 출처 상세 경계를 따른다.

Farm은 첫 `RequiredBeforeE7` AreaSet이다. 농가·생산·후처리, 고지대 농장, 계절 생산·출하, 사고 격리·회복 네 H3가 모두 합격하고 교차 H3 폐루프가 닫혀야 E7 실제 플레이 검증을 시작할 수 있다.

## 선택형 GIS 결속

GIS 결속은 모든 H5 세계 또는 모든 E6 질문의 필수 후속 단계가 아니다.

DEM·도로·건물·블록 경계도 공통 필수 자료가 아니다. 현실 결속 프로필이 `TerrainElevation`, `RoadNetwork` 같은 자료 목적을 명시적으로 선택했을 때만 그 프로필 안에서 요구하며, 자료가 없는 사실을 H 설계나 Scenario 실행의 결손으로 전파하지 않는다.

| 정책 | 의미 |
| --- | --- |
| `NotRequired` | 현실 결속을 고려하지 않는 세계 |
| `Optional` | H5만으로 실행 가능하며 필요할 때 E6를 결속할 수 있는 세계 |
| `Required` | H5 실행은 가능하지만 최종 목표 완료에는 E6 근거가 필요한 세계 |

`Required`를 선택한 뒤 자료가 없을 때는 그 현실 결속 목표를 `Missing`으로 유지한다. 비슷한 다른 자료나 Scenario 표현으로 묵시 대체하지 않지만, 이미 성립한 H5 상대 배치와 Simulation 규칙까지 무효화하지도 않는다.

세계 배치 정의(`WorldLayoutDefinition`)와 현실 결속 적용 상태(`WorldGroundingBinding`)는 분리한다. DEM·도로 등이 일부 준비된 상태는 권위 적용 상태가 아니라 별도 준비도(`WorldGroundingReadiness`)다. 같은 H5에 E6를 붙이거나 교체해도 H5 배치 해시는 바뀌지 않는다.

E6는 H5 이하 상대 X/Z 구조를 변형할 수 없다. 현실 자료와 맞추기 위해 Farm이나 Hub를 따로 옮기거나 회랑을 변형해야 한다면 E6 갱신이 아니라 새로운 H5 배치 revision이다. E6는 실제 좌표 Anchor, CRS, 자료 계보, 높이와 정합 검증을 제공하고 H5 전체를 외부 좌표계에 투영한다.

## LH와 Unity 실행 경계

LH는 E6 유무가 아니라 유효한 H5 권위 세계의 존재를 기준으로 실제 세계 셀 내용 공급자를 사용한다. E6가 `NotApplied`인 `ScenarioRelative` 세계를 시험용 절차생성으로 후퇴시키지 않는다. 셀 내용은 H5 배치 고유 식별자·revision·hash와 현실 결속 상태를 입력으로 결정한다.

Unity 계층은 권위 좌표를 부모 Transform으로 합성한 뒤 Floating Origin 보정을 표현 좌표에만 적용한다. Floating Origin 이동은 H5/H4/H3/H2/H1 원본 좌표, 세계 배치 hash, 저장·재생 계보를 변경하지 않는다.

## 완료와 증거

현재 첫 세계는 `ScenarioRelative`, GIS 정책 `Optional`, 적용 상태 `NotApplied`다. 조립된 AreaSet은 네 개지만 고정 앵커는 다섯 개이며 City 예약을 E5 구현으로 세지 않는다. Farm은 별도 E6 정제 질문과 교차 H3 폐루프를 통과해도 GIS 상태를 `NotApplied`로 유지할 수 있다. 코드·생성기·서버 API·Unity EditMode 시험과 E7 시작 관문 개방은 실제 플레이 폐루프 E7, 사람 조작, Play Mode 또는 Game View 증거를 대신하지 않는다.
