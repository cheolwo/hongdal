# Unity 경관 품질 Rendering Pipeline

## 목적

공간 데이터와 Synty 배치가 끝난 뒤 모든 영역이 같은 시각 품질 관문을 통과하게 한다. 개별 타일에 URP 수치를 복제하지 않고, 지역 역할·계절·시간대·날씨 의미를 `RenderingProfile`로 해석한다.

```text
공공 공간자료와 Simulation 규칙
→ 공간 Tile·Area·AreaSet
→ Synty 의미 배치 계획
→ VisualKey·구성 대장·Prefab
→ 경관 품질 RenderingProfile
→ 태양·환경광·그림자
→ 하늘·안개·대기 원근
→ URP 색보정·Bloom·Vignette
→ Overview·Region·Task·플레이어 1인칭·RTS 전술 카메라
→ Game View 검증
```

## 책임 분리

| 입력 또는 단계 | 책임 | 소유하지 않는 것 |
| --- | --- | --- |
| 공간 Pipeline | 위치, 경사, 수계, 배치 가능 영역 | 색보정, Bloom, 카메라 구도 |
| Simulation 규칙 | 시간대·날씨·업무 상태 의미 | URP 세부 수치, Material 경로 |
| Synty Pipeline | 의미 기반 VisualKey를 Prefab으로 해석 | 공간 사실, 업무 완료 |
| 경관 품질 Pipeline | 의미 코드를 조명·대기·후처리·카메라 Profile로 해석 | 서버 원장, WorldTick 변경 |
| URP | 실제 Renderer와 후처리 실행 | 업무 의미 결정 |

## Profile 계약

첫 구현의 `경관RenderingProfile`은 다음 값을 가진다.

- 고유 식별자와 규칙 개정
- 태양 세기·각도
- 그림자 거리
- 안개 시작·종료 거리
- 노출·대비·채도
- Bloom·Vignette 강도
- 1인칭 눈높이·시야각
- `PresentationOnly = true`

영역별 추천 Profile은 다음과 같이 확장한다.

| 영역 | 기본 미감 | 우선 조절 항목 |
| --- | --- | --- |
| Farm | 따뜻한 흙, 풍부한 초록, 긴 그림자 | 태양 색, 채도, 대기 원근 |
| Town | 크림·벽돌, 생활감 있는 중간 대비 | 환경광, 대비, 창가 강조 |
| Hub | 중성 콘크리트와 안전 주황 | 명료한 그림자, 낮은 채도, 작업등 |
| City | 청회색과 높은 형태 대비 | 노출, 반사, 야간 Emission |

## 카메라 모드

- `Overview`: 전체 관계와 대형 군집을 읽는다.
- `Region`: 건물·밭 블록과 지역 구조를 읽는다.
- `Task`: 작물·화물·생활 소품을 읽는다.
- `FirstPerson`: 사람 눈높이에서 실제 스케일과 가림, 전경·중경·배경 구성을 검수한다.
- `PlayerFirstPerson`: Synty 플레이어의 눈높이에서 WASD로 직접 걸으며 실제 스케일과 가림을 검수한다.
- `PlayerThirdPerson`: 높은 사선 RTS 전술 화면에서 영역·건물·Synty 플레이어를 함께 읽고, 유닛 선택·우클릭 이동과 카메라 탐색성을 검수한다. 농장 경영의 기본 시점이며 농지 다중 선택·영역 상태·작업 초안처럼 넓은 시야에 맞는 도구를 활성화한다.

첫 1인칭 구현은 대관령 Farm 1km 안에서 WASD 이동, Shift 빠른 이동, 오른쪽 마우스 시선을 지원한다. 이동 범위는 완결 영역 안으로 제한하고 서버 상태나 Simulation 개정을 변경하지 않는다.

플레이어 탐색은 별도 `플레이어경관Profile`을 사용한다. Profile은 보행·달리기 속도, 충돌체 크기, 1인칭 눈높이·시야각, RTS 전술 카메라의 방위각·경사각·최소/최대 거리·화면 이동/줌 속도, 클릭 이동 정지 거리, 시선 감도와 이동 경계를 가진다. PolygonFarm 농부 Prefab은 `VisualRoot`에만 연결하며 `CharacterController`는 의미 기반 플레이어 루트, 전술 카메라 초점은 영역의 표현 계층이 소유한다.

- 농장 진입 기본: RTS 전술 3인칭. 농장에서도 F2 또는 화면 버튼으로 1인칭을 선택할 수 있다.
- 탐험 진입 기본: 1인칭. 필요하면 F3으로 전술 3인칭을 선택할 수 있다.
- F2 1인칭: WASD·방향키 직접 이동, Shift 달리기, 클릭 후 마우스 시선
- F3 RTS 전술 3인칭: 캐릭터 좌클릭 선택·강조, 선택 뒤 지형 우클릭 목적지 이동. 농지에서는 Shift+좌클릭 다중 선택, 1~4 작업 종류, 우클릭 작업 초안을 사용한다.
- 1인칭↔3인칭 전환: 전환 전용 카메라가 현재 화면 위치에서 목표 카메라까지 짧은 이차 곡선을 따라 이동하고 회전·화각을 ease-in-out으로 보간한다. 전환 중 두 시점의 이동·선택·경영 입력을 모두 잠그고 완료 뒤 목표 시점 규칙만 활성화한다. 전환 도중 반대 시점을 다시 선택하면 현재 전환 위치를 새 시작점으로 사용한다.
- RTS 카메라: WASD·방향키 화면 이동, 휠 확대·축소, 휠 클릭 드래그 시선, F 선택 유닛 재집중
- F1 전략 화면: 기존 World 탐색 카메라 복원

RTS 전술 화면의 클릭 이동은 현재 `CharacterController` 기반 로컬 표현이다. 카메라 초점 이동과 줌도 화면 표현일 뿐 도로망·NavMesh·서버 배차를 확정하지 않으며 선택 원과 목적지 표식도 `PresentationOnly`다.

농장 경영 작업 초안도 같은 경계를 따른다. 초안은 선택 대상·작업 종류·세계 좌표를 묶지만 서버 Preview 결과, 비용, 소요 시간, 성공 가능성이나 Confirm 식별자를 만들지 않는다. 후속 연결은 초안을 기존 농장 작업 Preview 요청으로 명시적으로 변환하고, 사용자의 Confirm 뒤 canonical Session 상태를 다시 조회해야 한다.

## 검증

- Profile 교체가 공간·업무 상태·Synty 원본을 바꾸지 않는다.
- 같은 Profile과 Scene은 같은 조명·후처리 설정을 만든다.
- Volume 구성 요소는 자산 새로고침 뒤에도 하위 자산으로 보존된다.
- 원경 카메라가 안개로 과도하게 희어지지 않는다.
- 1인칭 카메라가 지면 아래나 배치 객체 내부에서 시작하지 않는다.
- 플레이어가 지형 `MeshCollider`를 따라 이동하고, RTS 전술 카메라는 플레이어와 독립된 초점을 완결 영역 안에서 이동한다.
- 1인칭 진입 시 캐릭터 Renderer가 카메라를 가리지 않고 3인칭 복귀 시 원래 표시 상태로 돌아온다.
- RTS 전술 3인칭에서는 캐릭터를 선택해야만 우클릭 목적지를 만들 수 있고 이동 완료 뒤 목적지 표식이 사라진다.
- 농장 경영 진입은 전술 3인칭이 기본이며 1인칭 수동 전환 뒤에도 같은 플레이어와 Session 상태가 유지된다.
- 1인칭과 전술 3인칭 사이에서 카메라 위치·회전·화각이 연속적으로 변하고 전환 도중 입력이 중복 적용되지 않는다.
- 전술 3인칭에서 농지 다중 선택과 작업 초안은 가능하지만 초안 생성만으로 `WorldTick`이나 농장 상태가 바뀌지 않는다.
- 플레이어 입력 전후에 `WorldTick`과 서버 상태 개정 번호가 유지된다.
- 실제 Play Mode Game View로 색, 그림자, 전경 가림과 사람 눈높이를 확인한다.
