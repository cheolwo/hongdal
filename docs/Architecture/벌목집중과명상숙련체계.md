# 벌목 집중과 명상 숙련 체계

## 목적

`WI-NATURE-06 벌목`의 기본 성공과 선택적 수행 품질을 분리한다. 나무를 정상적으로 베면 채집·자원 현장 숙련을 얻고, 작업 마지막 구간의 집중 판정에 성공하면 작은 명상 경험과 플레이어 개인 회복 기여를 얻는다. 집중 실패는 벌목 성공을 취소하지 않는다. 공통 파이프라인·적용 대상·저장 원칙은 [전 행위 몰입과 명상 숙련·행위 원장 통합 체계](전행위몰입과명상숙련행위원장통합체계.md)가 소유한다.

## 권위 흐름

1. 벌목 Confirm은 4초 작업과 `FocusTiming` Challenge를 시작한다. 이 시점에는 현장·명상 숙련을 지급하지 않는다.
2. Unity 또는 다른 신뢰 Adapter는 `ChallengeStableId`, 기대 세계 개정, 기대 Challenge 개정, `InputOffsetMillis`만 보낸다.
3. Simulation Core는 백만분율 정수 왕복 위치로 `Perfect`, `Good`, `Miss`를 판정한다. 입력하지 않으면 작업 완료 시 `NoInput`으로 판정한다.
4. 작업이 권위 완료될 때 통나무 결과, 완료 행위 기록, 채집·자원 현장 숙련, 명상 기여, NatureMind 회복을 공통 실행 파이프라인의 같은 완료 개정 계보에 남긴다.
5. 취소·차단·도구 해제·미완료 작업은 Challenge를 `Voided`로 끝내며 숙련·회복을 만들지 않는다.

## 판정 정책

| 모드 | 왕복 시간 | 정확 | 양호 | 자동 건너뛰기 |
| --- | ---: | ---: | ---: | --- |
| Standard | 2,000ms | 중심 ±60,000 | 중심 ±180,000 | 해당 없음 |
| Assisted | 3,000ms | 중심 ±90,000 | 중심 ±270,000 | 해당 없음 |
| NeutralSkip | 없음 | 없음 | 없음 | `AssistedNeutral`, 모든 증감 0 |

위치는 부동소수점 없이 다음 정수식으로 계산한다.

`phase = InputOffsetMillis × 1,000,000 ÷ DurationMillis`

`position = phase ≤ 500,000 ? phase × 2 : (1,000,000 - phase) × 2`

## 성장과 심리

- 벌목 완료: 채집·자원 / `logging` 현장 숙련 `+2`
- Perfect: 명상 경험 `+250 Milli`(`+0.25`), 개인 회복 `+250 Milli`(`+0.25`)
- Good: 명상 경험 `+100 Milli`(`+0.10`), 개인 회복 `+100 Milli`(`+0.10`)
- Miss·NoInput: 명상·회복 `0`; 집중 실패만으로 위협을 만들지 않음
- NeutralSkip: 명상·회복을 변경하지 않음

명상은 17번째 분야가 아니라 모든 분야를 가로지르는 수행 품질 성장축이다. 권위 원본은 `명상경험Milli`이고 단계 이름은 기존 `0/1/5/12`를 `0/1000/5000/12000 Milli`로 환산한다. 지역 전체 위협, 몬스터 생성량, 자원량, 운영 DB는 이 결과로 직접 변경하지 않는다.

## 저장과 표현 경계

명상 기여가 있는 저장은 `simulation-save.v29`로 봉인하고 v1~v28 읽기 호환을 유지한다. Challenge 입력도 Command Log에 포함한다. 완료된 Challenge는 활성 목록에 남기지 않고 행위 원장·명상 기여·NatureMind 효과로 보존한다.

현재 서버·LocalProcess 계약과 자동 시험은 Logic E5 근거다. Unity 게이지, Space 실제 입력, 결과 피드백, 상태창과 Game View는 아직 구현·검증하지 않았으므로 Presentation E1보다 높게 판정하지 않는다.
