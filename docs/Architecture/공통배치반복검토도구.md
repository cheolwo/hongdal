# 공통 배치 반복 검토 도구

## 이번 작업 범위

2026-08-30 사용자의 공간 배치·재판정 요청을 공통 Editor 도구로 구현한다. 기존 배치 엔진을 대체하거나 활성 Farm WI의 승인 상한을 올리지 않는다. LH가 준비한 지면과 실내·실외 배치 엔진이 만든 객체를 사람이 반복 검토하는 보조 도구이며 독립 PlayableLoop/E를 소유하지 않는다.

## 반복 절차

1. 기존 Scene의 프로젝트 배치 Wrapper와 지지 Collider를 명시적으로 선택한다.
2. 실제 활성 Renderer 외곽과 지지면의 3×3 표본을 측정한다. 여기의 3×3은 LH 스트리밍 창과 무관하다.
3. 지지면 누락, 경사·높이 편차, 하단 매몰·부유, 지정 주변 객체와의 간격, 지정 통행 보호 범위 침범을 판정한다. 플레이어 기준 높이 비율도 표시한다.
4. 검사는 Transform을 변경하지 않는다. 모든 지지 조건을 통과하고 허용 보정량 안일 때만 별도 버튼으로 높이를 보정한다. 기존 `배치객체표면정렬Utility`를 재사용하며 Undo를 지원한다.
5. 위치·회전·크기·지지면·주변 객체가 바뀌면 다시 검사한다. 보정 버튼도 실행 직전 현재 입력을 재검사한다.

## 안전 경계

- Scene 자동 열기·저장, 원본 Prefab 변경, x/z 이동·회전·크기 자동 조정, 서버 호출·WorldRevision 변경은 하지 않는다.
- Play Mode에서는 보정을 거부한다. 원본 자산·자기 자신에 속한 지지면·다른 Scene의 지지면도 거부한다.
- 큰 경사나 부분 지지는 높이만 올려 숨기지 않고 위치 재선택 대상으로 남긴다.
- 외곽 범위 검사는 보수적이다. 9개 표본 사이의 작은 돌출, 실제 메시 교차, 문 개폐, NavMesh, 카메라 가림을 증명하지 않는다. 지정하지 않은 주변 객체와 통행 보호 구역도 검사한 것으로 간주하지 않는다.
- 실제 Synty Prefab을 임시 시험 객체로 배치·재배치해 검사한다. 기존 Scene과 공급자 자산은 보존하며 이 시험을 공식 H 배치·WI 발현·E5/E7 완료로 기록하지 않는다.
