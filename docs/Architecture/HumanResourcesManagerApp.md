# HumanResourcesManagerApp

인력 관리자 앱은 현장 근무자와 HR 세부 역할을 관리하는 사람을 위한 클라이언트 앱이다.

## 현재 범위

- 앱 프로젝트: `HumanResourcesManagerApp`
- 홈 라우트: `/`
- 공통 홈 셸: `PlatformCommunityHome`
- 모드:
  - 커뮤니티 모드: 인력 운영 공지, 현장 요청, 개선 제안 공유
  - 업무 모드: 인력 관리 콘솔

## 업무 모드 첫 화면

- 활성 근무자 요약
- 역할 미확정 인원
- 근무 시간 외 요청
- 계약/급여 예정 항목
- 오늘 확인할 인력 업무
  - 창고 입고조 역할 확인
  - 포장 공정 신규 근무자 등록
  - 근로계약서 초안 확인
  - 급여 지급 예정 생성
- 교육/모임 참여 혜택 이관
  - 교육 과정 참여
  - 오프라인 모임 참석
  - 플랫폼 커뮤니티 이벤트 참여
  - 참여 사실과 혜택 부여 상태를 HR 사람 이력으로 기록

## 서버 API

- `GET /api/v1/admin/hr-participation-benefits`
  - `userId`, `sourceType`으로 HR 참여 혜택 기록 조회
- `POST /api/v1/admin/hr-participation-benefits/transfer`
  - 교육/모임/커뮤니티 이벤트 참여 사실을 HR 혜택 기록으로 이관

현재 저장소는 인메모리 골격이다. 운영 연결 시 기존 `살뜰_오프라인모임`, `살뜰_모임참석`, `살뜰_혜택자격`, `살뜰_혜택정책` 테이블과 매핑한다.

## 설계 의도

- HR 업무는 서버에 이미 있는 역할/근무 시간/IP 검증 흐름과 연결될 예정이다.
- 초기 앱은 실제 API 전체 연결보다 인력 관리자 전용 업무 콘솔과 커뮤니티 흐름을 먼저 잡는다.
- 이후 `HrRolesController`, `HrEmploymentContractsController` API를 순차 연결한다.
