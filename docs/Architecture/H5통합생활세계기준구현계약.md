# H5 통합 생활세계 기준 구현 계약

## 목적

농사·제조·물류·건설·군사·전투·복구를 별도 게임 모드로 만들지 않고, 하나의 Simulation Session에서 서로의 다음 행동 가능성을 바꾸는 생활세계로 연결한다.

```text
H5 정적 공간
  + Session 가변 시설·행위자·재고·편성
        ↓
Preview → Confirm → 예약 → Task → Effect
        ↓
시설·자원·공간·행위자 상태 변화
        ↓
다음 WI 가능성 변화
```

## 권위 경계

- H5·H1은 장소와 상대 배치를 제공한다.
- 시설은 H1을 점유하는 Session 가변 객체다. 병영·창고·제조소를 H1과 동일시하지 않는다.
- Simulation 서버가 시설·재고·작업·피해·수리·편성의 현재 상태를 확정한다.
- Unity와 Synty는 확정된 결과를 표현하며 작업 완료 권위를 갖지 않는다.
- E6 공공데이터 결속은 선택형 후속 단계이며 이 계약의 실행 선행 조건이 아니다.

## 기준 폐루프

1. Hub 제조소가 운송 상자와 시설 부품을 생산한다.
2. 일반 화물 물류가 이를 Farm으로 옮긴다. 운송 상자는 일반 화물 운송의 필수조건이 아니다.
3. 시설 부품으로 병영 건설 프로젝트를 시작한다. 확정 시 `Planned` 시설이 생기고 건설 중 `UnderConstruction`, 완료 시 `Operational`로 바뀐다.
4. 운송 상자는 감자 포장 WI에서 소비되고 포장 감자 Lot 계보를 만든다.
5. 실제 Farm Actor를 모집·훈련·편성하며 노동 가용성과 군사 가용성이 같은 점유 원장으로 판정된다.
6. Farm Gate 전투 문맥은 H5 정적 문맥과 해당 전투 범위의 가변 시설·편성을 결합해 계산한다.
7. 전투 피해는 불변 Effect와 적용 대기 항목을 만들고, 다음 안전한 WorldTick에 시설 제한과 적용 영수증을 원자적으로 남긴다.
8. 수리는 확정 시 고정한 제한만 해결한다. 수리 중 새 피해가 생기면 자동으로 함께 제거하지 않는다.
9. 창고 상차 능력이 복구되면 Farm 출하 Preview가 다시 가능해진다.

## 주요 불변조건

- `WorldRevision`은 Session 명령 동시성을 보호하고 전투 문맥 해시는 전투 의미를 보호한다.
- 전투 문맥 해시는 전투 범위별 파생값이며 `SourceWorldRevision`을 해시 재료로 사용하지 않는다.
- Effect는 수정·삭제하지 않는다. 적용 대기와 적용 영수증을 별도 원장으로 둔다.
- 시설 능력의 현재 상태는 정의와 활성 제한 중 가장 강한 값으로 계산한다.
- 같은 Actor는 활성 Formation Duty를 하나만 가지며 훈련·전투·일반 Task 충돌을 호환 규칙으로 판정한다.
- 제조법·청사진의 revision, hash, 계산된 입력·출력·기간은 Job·Project 생성 시 동결한다.
- 입력 Lot 소비, 출력 Lot 생성, 건설 자재 소비, 피해 적용은 멱등하며 재시도 때 중복되지 않는다.

## 증거 경계

이 계약의 기본 구현 목표는 E3 자동 시험이다. 위치 독립 H5 Scenario fixture와 Save/Replay가 통과해도 실제 E5 공간 결속, E6 현실 자료, Unity E7 Play Mode·Game View를 주장하지 않는다. 기계 대장은 `eng/world-seedbeds/h5-integrated-living-world.v1.json`이다.
