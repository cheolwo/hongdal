# 공동구매 체험 모드

## 목적

`공동구매 체험 모드`는 공동구매를 처음 접하는 사용자가 음식과 재료를 둘러본 뒤, 가상 이웃과 게임처럼 집단화 과정을 연습하는 `1.0` 경험이다. 로그인, 실제 참여자 모집, 주문과 결제 없이 목표 인원·수량이 채워지는 과정을 이해한 다음 사용자가 원할 때만 별도의 비구속 수요 화면으로 이동한다.

체험의 결과는 주문이나 수요 원장이 아니라 **저장되지 않는 학습용 진행 결과**다.

## 사용자 흐름

```text
음식·재료 탐색
  → 연습 재료와 희망 수량 선택
  → 명시적으로 표시된 가상 이웃 만나기
  → 보관·요리·수령 이야기를 고르며 3라운드 진행
  → 목표 인원·수량과 연습 예상 단가 확인
  → 체험 종료
  → 사용자가 선택한 경우에만 실제 비구속 수요를 별도 화면에서 다시 확인
```

연습 결과와 입력값은 실제 수요 화면으로 자동 제출하거나 복사하지 않는다. 실제 단계에서는 상품, 수량, 배송권과 비구속 동의를 다시 확인해야 한다.

## 체험과 실제 수요의 경계

| 구분 | 체험 모드 | 실제 비구속 수요 |
| --- | --- | --- |
| 참여자 | `연습 이웃 · ...`로 표시된 고정 가상 참여자 | 실제 사용자가 직접 남긴 수요 |
| 로그인 | 필요 없음 | 저장 전에 필요 |
| 서버 저장 | 없음 | 멱등 원장에 저장 |
| 진행 결과 | 학습용 계산 | 모집 원장의 실제 집계 |
| 가격 | 최대 15% 범위의 연습 예시 | 공급·가격 근거를 별도로 검토 |
| HS 코드 | 학습용 후보 | 성분·용도·가공 상태에 따라 별도 검토 |
| 다음 단계 | 링크만 제공 | 사람 확인을 거쳐 모집·인계 |
| 외부 효과 | 없음 | 명시적 후속 절차에서만 허용 |

## 안전 원칙

- 가상 참여자와 가상 대화는 모든 응답과 화면에서 명시적으로 표시한다.
- 실제 사용자처럼 보이는 이름, 프로필, 활동 수치나 실시간 참여 신호를 만들지 않는다.
- 체험 요청은 사용자 계정, 주소, 연락처와 결제 정보를 받지 않는다.
- 세션 ID는 같은 연습의 라운드를 이어 가기 위한 값일 뿐 서버나 원장에 저장하지 않는다.
- 주문, 결제, 계약, 수입 신고, 연락처 전달, 운송 의뢰와 자동 배차를 실행하지 않는다.
- 목표 달성과 연습 예상 단가는 구매 성립, 가격 보장이나 실제 견적을 뜻하지 않는다.
- 체험 완료는 실제 수요를 자동 생성하지 않으며 사용자의 별도 선택과 재확인을 요구한다.

## 서버 책임

`공동구매체험Service`는 고정 시나리오와 가상 이웃을 기존 `공동구매주문자집단화Engine`의 진행 계산에 넣는다. 이를 통해 연습과 실제 모집이 목표 인원·목표 수량을 같은 방식으로 설명하되, 체험 서비스에는 저장소나 외부 adapter를 주입하지 않는다.

지원 시나리오는 냉동 삼겹살, 간편식 소스와 가공육 세트다. 각 시나리오는 상품 stable key, 연습용 HS 코드 후보, 온도, 배송권, 목표 수량과 기준 단가를 제공한다.

| Method | Route | 역할 |
| --- | --- | --- |
| `GET` | `/api/v1/orderer/group-purchase-practice/scenarios` | 공개 연습 시나리오 조회 |
| `POST` | `/api/v1/orderer/group-purchase-practice/simulate` | 저장 없는 라운드별 집단화 계산 |

두 API는 익명 접근을 허용하지만 `GroupPurchasePracticeWorkflow` 기능 플래그를 요구한다.

## 기능 플래그

`GroupPurchasePracticeWorkflow`는 `CommunityTrustWorkflow`가 켜져 있을 때만 활성화된다. `GroupPurchaseDemandWorkflow` 또는 `CustomsAndTradeDataWorkflow`와 독립적이므로 실제 수요와 무역 기능을 닫은 배포에서도 체험만 제공할 수 있다.

기본 설정은 체험을 켜고 실제 비구속 수요를 닫는다.

```text
GroupPurchasePracticeWorkflow = true
GroupPurchaseDemandWorkflow = false
```
