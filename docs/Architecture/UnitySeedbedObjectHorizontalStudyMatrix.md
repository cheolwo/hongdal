# Unity 모판 배치 객체 수평 연구 대장

## 1. 목적

이 문서는 [배치 객체 심층 연구 우선순위](UnitySeedbedObjectDeepStudyPriority.md)의 감자 재배체 기준을 나머지 배치 객체에도 같은 높이로 적용한다. 객체마다 설명 형식이 달라지는 것을 막고, 같은 질문의 답을 위아래로 비교해 책임 중복과 누락을 찾는 것이 목적이다.

감자 재배체는 기준행이고, 그 이후 14개 객체는 비교행이다. 표의 내용은 구현 완료 사실이 아니라 심층 연구에서 확인할 **작업 가설**이다. 서버 계약, 저장 데이터, 기존 고유 식별자, O0~O6 단계는 이 문서만으로 변경하지 않는다.

읽는 방법은 두 가지다.

- 한 행을 왼쪽에서 오른쪽으로 읽어 한 배치 객체의 현실→업무→데이터→권위→Unity 표현→행동을 이해한다.
- 한 열을 위에서 아래로 읽어 여러 배치 객체가 같은 책임을 중복 소유하거나 서로 다른 규칙을 잘못 공유하는지 비교한다.

## 2. 공통 비교 축

| 축 | 포함하는 질문 | 판정 목적 |
| --- | --- | --- |
| 현실·업무 | 현실 존재 이유, 직전·직후 상태 | 장식이 아닌 업무상 자리 확인 |
| 데이터·권위 | 표현 데이터, 결정하면 안 되는 것 | 서버 사실과 Unity 표현 분리 |
| 인지·시각 | 멀리·가까이·선택 시 인지, 상태별 변화 | 데이터를 알아볼 수 있는 시각 변화로 변환 |
| 구성·연결 | 주변 객체, 관계 목적, 연결 지점 | 완성 Scene이 아닌 재사용 가능한 모듈 관계 정의 |
| 행동·필요성 | 허용 행동, 금지 행동, World 분류 | 실제 World에 독립 배치할 가치 판정 |

## 6. 열 방향으로 먼저 확인할 충돌

감자 재배체의 규모·생산 능력·품목 속성은 [별도 심층 연구](UnityPotatoPlantScaleYieldProductAttributeStudy.md)를 기준으로 한다. 수평 대장에서는 그 결론이 다른 객체의 책임을 침범하는지 비교한다.

### 6.1 생산 객체 사이

- 감자 재배체는 작물 상태, 감자 밭고랑은 토양 상태를 우선 표현한다. 생육 스트레스를 양쪽에 중복 표시할 때는 원인과 결과를 구분해야 한다.
- 스프링클러의 물 효과는 관수 실행의 표현이지 토양 수분의 최종 사실이 아니다.
- 온실은 환경의 경계이고 재배체는 그 안의 작물 상태다. 온실이 내부 작물 생육을 대신 표현하지 않는다.
- 수확 상자는 생산 Lot의 현장 취급 단위이고 출하 Pallet은 여러 상자를 묶는 출하 화물 단위다.

### 6.2 물류 객체 사이

- 농장 출하 Pallet과 공용 화물 Pallet은 외형이 비슷해도 전자는 생산→출하 경계, 후자는 시설 간 표준 취급 단위다.
- 차량의 도착과 Gate의 입고 승인은 같은 상태가 아니다.
- Pallet의 위치 이동, 차량의 이동 애니메이션, Gate 개방은 창고 인계 완료의 근거가 아니다.

### 6.3 수요·마트 객체 사이

- 주민 관점 Visual은 개인에게 허가된 관점, Cart Table은 개인정보가 제거된 집단 요약을 표현한다.
- 도심마트 Shop은 공개 상품만, 운영자 Shelf는 권한이 필요한 후방 재고와 진열 작업만 보여준다.
- 마트 운영자 Visual은 사람의 권한을 소유하지 않고, 서버가 허가한 운영자 관점을 표현한다.
- Cart Table의 집계 규모는 자동 가입, 주문 확정 또는 대표자 선정을 의미하지 않는다.

### 6.4 화물과 음식 인계 사이

- 공용 화물 Pallet은 시설 간 화물 취급, 음식 픽업 인계 상자는 음식점·기사·주문자 사이의 시간 민감한 인계를 표현한다.
- 음식 조리 완료, 기사 배정, 픽업, 전달, 주문자 수령은 각각 다른 서버 상태로 유지한다.
- 음식 상자의 위치 변화만으로 픽업이나 수령 완료를 판정하지 않는다.

## 7. 객체별 심층 연구를 시작할 때 남길 기록

수평 대장은 답을 확정하는 문서가 아니라 질문의 누락을 막는 출발점이다. 각 객체의 차례가 오면 별도 연구 기록에서 다음을 확정한다.

```text
배치 객체:
고유 식별자:
현재 단계:

이 배치 객체가 보여주는 것:
이 배치 객체가 결정하지 않는 것:

현실 존재 이유:
업무 직전 → 등장 → 직후:
멀리 → 가까이 → 선택 시 인지:
데이터 변화 → 시각 변화:
필수 주변과 관계 목적:
허용할 관찰·정보·시뮬레이션·실운영 행동:
실제 World 필요성 판정:
미확정 질문과 필요한 검증 근거:
```

## 8. 수평 연구 실행 순서

1. 감자 재배체의 실제 답을 확정해 기준행을 작업 가설에서 연구 결과로 바꾼다.
2. 감자 밭고랑·스프링클러·온실을 같은 열로 비교해 작물·토양·관수·시설 책임을 분리한다.
3. 수확 상자·농장 출하 Pallet·공용 화물 Pallet을 비교해 Lot·출하 화물·창고 취급 단위를 분리한다.
4. 차량·Hub 입고 Gate를 비교해 이동·도착·검수·입고·인계를 분리한다.
5. 주민·Cart Table·도심마트 Shop·운영자 Shelf·마트 운영자를 비교해 개인·집단·공개·운영자 권한 범위를 분리한다.
6. 마지막으로 음식 픽업 인계 상자를 공용 화물 Pallet과 비교해 음식배달 전용 시간·수령 규칙을 도출한다.
7. 각 묶음의 연구 결과가 나온 뒤에만 O6 실제 World 배치 검증 순서를 다시 정한다.
