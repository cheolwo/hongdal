# Platform Home Mode

클라이언트 앱의 첫 화면은 커뮤니티와 업무 진입을 분리해서 다룬다.

## 핵심 개념

- 커뮤니티 모드: 공지, 운영 공유, 사용자 게시글, 이미지/댓글/추천 흐름을 보여준다.
- 업무 모드: 앱별 핵심 업무 화면으로 바로 진입한다.
- 전환 장치: 하단 접이식 모드 바에서 커뮤니티 모드와 업무 모드를 전환한다.
- 시각 상태:
  - 커뮤니티 모드: 파란 계열의 부드러운 공유/소통 톤
  - 업무 모드: 청록/그린 계열의 선명한 작업 톤
  - 히어로, 업무 패널, 카드 테두리, 하단 모드 바가 같은 모드 색상으로 함께 바뀐다.

## 현재 구현

- 공통 컴포넌트: `Hongdal.Ui.Common/Areas/App/Components/Community/PlatformCommunityHome.razor`
- 모드 상태:
  - `isWorkMode = false`: 커뮤니티 모드
  - `isWorkMode = true`: 업무 모드
  - `isModeBarExpanded`: 하단 모드 바 접기/펼치기
- 업무 모드 콘텐츠:
  - 앱이 `WorkModeContent`를 넘기면 기존 대시보드를 업무 모드 본문으로 렌더링한다.
  - `WorkModeContent`가 없으면 `QuickActions` 기반 업무 바로가기를 렌더링한다.
- 업무에서 커뮤니티 글쓰기:
  - 업무 모드에서 `궁금한 점`, `처리한 일`, `개선 제안` 초안 버튼을 제공한다.
  - 버튼을 누르면 커뮤니티 모드로 전환하고 글쓰기 폼의 분류, 제목, 본문 템플릿을 자동 입력한다.
  - 사용자는 닉네임/비밀번호와 세부 내용을 보완해 등록한다.
- 적용 앱:
  - `HongdalAdmin`
  - `WarehouseManagerApp`
  - `OrdererApp`
  - `RestaurantDeskApp`: 기존 주문/운영 대시보드를 업무 모드에 배치
  - `ShipperApp`: 기존 화주 업무 대시보드와 로그인/요청/입고/재고 흐름을 업무 모드에 배치하고, 업무 모드 내부를 운송/창고/판매/통관 탭으로 구분
  - `HumanResourcesManagerApp`: 인력관리 콘솔을 업무 모드에 배치하고, 인력 운영 공유를 커뮤니티 모드로 제공

## 운영 의도

- 앱 첫 화면을 커뮤니티로만 고정하지 않는다.
- 사용자는 커뮤니티를 보다가 업무 모드로 전환해 바로 업무 화면으로 들어갈 수 있다.
- 업무 중에도 다시 커뮤니티 모드로 돌아와 공지나 플랫폼 공유 글을 확인할 수 있다.

## 다음 적용 대상

- `DriverApp`: 기존 지도 홈은 유지하고, 별도 홈 셸 또는 메뉴에서 커뮤니티/업무 모드를 제공한다.
- `ShipperApp`: 업무 모드 안에서 운송/창고/판매/통관 탭을 제공한다. 다음 단계는 각 탭의 요약 지표를 실제 서버 API 기준으로 더 세분화한다.
- `RestaurantDeskApp`: 주문 수신 대시보드는 업무 모드에 들어갔다. 다음 단계는 실제 주문 수신 API와 연결한다.
