# KAMIS·USDA AMS 핵심 분석과 데이터 이관 기준

## 목적

KAMIS 국내 조사 가격, USDA AMS 미국 시장 가격과 HS 수입 통계단가를 한 화면에서
참고할 수 있게 하되, 시장 단계·통화·포장·품종이 다른 값을 하나의 직접 비교가격으로
합치지 않는다. 원천 관측값은 수정하지 않고 보존하며, 조회와 커뮤니티 발행에는
별도 분석 투영을 사용한다.

이 문서의 수치는 2026-07-30 로컬 MySQL 원본을 직접 집계한 결과다. KAMIS는
2026-07-29, USDA AMS는 2026-07-28까지 수집되어 있다.

## 원본 현황과 품질 판정

| 원천 | 관측값 | 품목 범위 | 품질 판정 |
| --- | ---: | --- | --- |
| KAMIS | 35,191건 | 96개 품목코드, 6개 부류 | RecordKey 중복 0건, 빈 품목·단위 0건 |
| USDA AMS | 1,131,591건 | 322개 2026년 Catalog 상품, 3개 시장 단계 | RecordKey 중복 0건, 음수·가격범위 역전·날짜 역전 0건 |
| USDA AMS 공개 사업체 | Profile 27,888건, 취급품목 44,233건 | 공개 Directory 근거 | 가격 원장 및 거래·계약 권한과 분리 |

다음 행은 삭제하지 않고 원본에 유지하되 가격 분석 투영에서 제외한다.

- KAMIS `0원` 14건: 모두 동일 품목코드의 2026-07-16~2026-07-29 일별 관측이다.
- USDA AMS 가격 필드 전체 공란 12,697건: 산지 출하 3,127건, 도매 터미널 9,570건이다.
- USDA AMS `Commodity=N/A` 55건은 상품 Catalog와의 1개 불일치 원인이다.
- USDA AMS 소매 광고 42,652건은 `Package`와 `Origin`이 비어 있으나
  `OriginalUnit`에 `per lb`, `each` 같은 광고 단위를 보존한다. 원천 구조상 공란을
  임의 포장이나 원산지로 채우지 않는다.

## 시장 단계와 비교 가능성

| KAMIS 기준 | USDA AMS 후보 | 판정 | 사용 방법 |
| --- | --- | --- | --- |
| 소매 조사 `01` | 소매 광고 `AdvertisedRetail` | 참고 문맥만 가능 | 조사 소매가격과 주간 광고·프로모션 가격임을 각각 표시 |
| 중도매 조사 `02` | 도매 터미널 `TerminalWholesale` | 참고 문맥만 가능 | 도시 터미널·원산지·품종·등급·포장단위가 맞는 후보만 나란히 표시 |
| 직접 대응 없음 | 산지 출하 `ShippingPoint` | 직접 비교 불가 | 미국 산지·선적 단계의 별도 가격 근거로 표시 |

통화 환산이나 kg 환산만으로 직접 차액·절감률·순위를 만들지 않는다. 다음 차원을
모두 확인한 뒤에도 값은 `동일가격`이 아니라 `비교 후보`다.

1. 품목과 품종
2. 등급·크기·유기농 여부
3. 시장 단계
4. 국가·지역·원산지
5. 관측 주와 기준일
6. 통화와 환율 기준일
7. 원 포장단위와 검증된 순중량

## 단위와 포장 분석

KAMIS 저장 관측값 35,191건의 `Unit`은 모두 `1kg`이다. 현재 Archive는 KAMIS의
kg 환산 조회 결과이므로 국내 가격 비교에는 사용할 수 있지만, 원 상자·망·포대 크기나
FCL 적재량 근거로 사용하면 안 된다. 포장과 FCL은
`agri_packaging_fcl_analysis_snapshots`의 별도 근거를 사용한다.

USDA AMS는 원 포장·판매단위·크기를 합친 `OriginalUnit` 2,884종을 보존한다.

| 시장 단계 | 관측값 | 상품 | 원 단위 | 포장 표현 |
| --- | ---: | ---: | ---: | ---: |
| 소매 광고 | 42,652 | 91 | 81 | 원천상 별도 Package 없음 |
| 산지 출하 | 105,474 | 99 | 410 | 104 |
| 도매 터미널 | 983,465 | 293 | 2,757 | 562 |

`40 lb cartons`, `50 lb sacks`, `5 kg/11 lb cartons`처럼 질량이 명시된 표현만
검증된 중량 후보로 파싱할 수 있다. `bushel`, `cartons tray pack`, `each`,
개수 규격은 품목별 밀도·개수·순중량 근거 없이는 kg로 환산하지 않는다.

## KAMIS·AMS·HS 매핑 범위

현재 서버의 실제 Mapping Catalog를 2026년 AMS Catalog에 적용한 결과는 다음과 같다.

| 매핑 단계 | 결과 |
| --- | ---: |
| KAMIS 관측 품목 | 96 |
| AMS Catalog 상품 | 322 |
| AMS 후보가 있는 KAMIS 품목 | 50 |
| 동일 품목 후보 | 32 |
| 넓은 품목군 후보 | 18 |
| AMS 후보 없음 | 46 |
| KAMIS–AMS 후보 link | 146 |

HS 수입가격용 `FoodPriceCrosswalkCatalog`에는 47개 HS prefix와 35개 KAMIS
품목코드가 있다. 동일 품목 후보는 37개, 대표 품목 후보는 10개다. KAMIS–AMS와
HS 후보가 모두 있는 품목은 20개다.

`agri_hs_usda_commodity_mappings`의 24개 HS6 매핑은 모두 `NeedsReview`이며
USDA NASS 용도의 후보 원장이다. 이 중 AMS Catalog와 상품명이 정확히 겹치는 것은
10개 HS6, 7개 상품뿐이다. 이 원장을 검토 완료된 AMS–HS Crosswalk로 간주하지 않는다.

첫 이관 뒤 조회 우선순위는 다음과 같다.

1. KAMIS–AMS–HS가 모두 연결된 20개 품목
2. KAMIS–AMS만 연결된 30개 품목
3. KAMIS만 있는 46개 품목

후보가 없는 품목도 검색 결과에서 숨기지 않고 `AMS 후보 없음`, `HS 검토 필요`처럼
데이터 경계를 표시한다. HS4·HS6 후보는 실제 수입신고용 HSK10 확정값이 아니며
가공도·용도·품종에 대한 전문가 검토가 필요하다.

## 주간 분석 투영

원본 전체를 매 화면 요청마다 집계하지 않는다. 원본은 감사·재처리용 Archive로
유지하고 다음 두 수준의 주간 투영을 별도로 둔다.

### 품목·시장 단계 Coverage

`주차 + 원천 + 시장 단계 + 품목` 단위로 관측 건수, 유효가격 건수, 최신 기준일,
지역 수를 보관한다. 가격을 서로 다른 단위 사이에서 평균하지 않는다.

- KAMIS 주차·유통단계·품목 그룹: 3,500행
- USDA AMS 주차·시장단계·상품 그룹: 13,441행
- USDA AMS에 지역까지 포함한 Coverage: 58,552행

### 비교 가능한 Series

가격 수치는 원 거래단위를 유지한 다음 차원으로만 묶는다.

`주차 + 시장 단계 + 품목 + 지역 + 품종 + 등급 + 원 거래단위 + 유기농 + 원산지`

- KAMIS 비교 Series: 7,298행
- USDA AMS 비교 Series: 234,343행

USDA AMS 원본 1,131,591건을 약 23만 개 비교 Series로 줄일 수 있지만
원 거래단위를 제거해 더 작게 만들지는 않는다. 화면의 목록·Coverage 조회는 약
1.3만 행 수준 투영을, 근거 상세는 비교 Series와 원본을 순서대로 조회한다.

기존 `agri_weekly_country_product_comparison_*`는 KAMIS와 USDA NASS의 6개
대표 품목을 커뮤니티에 게시하는 Curated Snapshot이다. AMS 전체 검색 투영으로
책임을 확대하지 않는다.

## 이관 판정과 실행 Gate

핵심 원본은 이관 가능하다. 단, 다음 순서를 지킨다.

1. Azure 현재 DB와 볼륨을 백업한다.
2. 현재 서버 이미지와 AgriculturalFisheries migration을 먼저 배포한다.
3. KAMIS·AMS Archive와 수집 Run·Catalog를 원본 그대로 이관한다.
4. USDA AMS 공개 사업체, 포장 FCL Snapshot과 검토 상태를 유지한 HS 매핑을
   가격 원장과 구분해 이관한다.
5. 정확한 행 수, 최소·최대 기준일, RecordKey 중복, 가격 예외 수와 인덱스를
   로컬 기준값과 대조한다.
6. 주간 Coverage와 비교 Series는 원본 이관 검증 후 재생성한다.
7. 외부 수집 배치는 이관과 조회 검증이 끝날 때까지 비활성으로 유지한다.

현재 데이터는 약 2.9GB이며 gzip 압축 Dump는 약 221MB다. Azure에서는 Import,
인덱스와 임시 로그를 고려해 최소 6GB, 권장 10GB 이상의 여유 공간을 확보한다.

## 2026-07-30 Azure 이관 결과

원본 분석 뒤 Azure 상시 체험 서버에 스키마와 데이터를 순서대로 이관했다. 이관 전
DB Dump와 직전 서버 이미지 rollback tag를 보존했으며, 수집 배치를 실행하지 않고
로컬 원본과 Azure 행 수를 직접 대조했다.

| 원장 | Azure 행 수 |
| --- | ---: |
| KAMIS 수집 Run / 관측 | 35 / 35,191 |
| USDA AMS 수집 Run / 관측 / 2026 Catalog | 4 / 1,131,591 / 322 |
| USDA AMS 공개 사업체 수집 Run / Profile / 취급품목 | 1 / 27,888 / 44,233 |
| 포장·FCL Snapshot / HS–USDA 검토 매핑 | 96 / 24 |

KAMIS 기준일은 `2025-07-31~2026-07-29`, AMS 기준일은
`2026-01-02~2026-07-28`로 로컬과 일치한다. RecordKey 중복, 가격·날짜 역전,
시장 단계와 통화 예외도 로컬 집계와 동일하다.

113만 건 AMS 원본의 최신일 조회에는
`ReportBeginDate + Commodity + MarketLocationName` 인덱스를 추가했다.
품목은 기존 `Apple → Apples` 사용성을 유지하는 접두 검색으로 제한하고
`MarketStageCode`를 명시적 필터로 받는다. Azure 공개 URL에서 확인한 결과는
다음과 같다.

- 연도별 AMS 최신 1건: 약 18.6초에서 0.36초
- `Apples + TerminalWholesale` 5건: 0.07초
- KAMIS 중심 비교 20품목: 0.73초

실행계획은 전체 스캔과 filesort에서 날짜 범위와 역방향 인덱스 스캔으로 바뀌었다.
일반 API의 30초 명령 제한은 유지하고, 대용량 인덱스 생성이 필요한 일회성 DB
초기화 동안에만 농수산물 migration 제한을 15분으로 확장한다. 배포 중간 이미지는
정리한 뒤 30GB 디스크에서 6.2GB 여유 공간과 앱 `healthy` 상태를 확인했다.

## 공개·업무 경계

- 가격은 정보 근거이며 견적·판매가·계약가가 아니다.
- USDA AMS 공개 사업체 정보는 공개 Directory 근거이며 업체 인증, 공급 가능성,
  재고, 계약 권한을 의미하지 않는다.
- 수입 통계단가는 신고 수입금액과 순중량의 기간 가중평균 CIF 참고값이며 관세,
  검역, 통관, 보험, 국내 운송, 보관과 판매마진을 포함하지 않는다.
- 분석 결과는 발주·계약·수입 실행을 자동 생성하지 않는다.
