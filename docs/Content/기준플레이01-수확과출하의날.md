# 기준 플레이 01 — 수확과 출하의 날

## 오늘의 약속

> 대관령에서 하루를 시작해 농장을 둘러보고, 오늘의 수확을 계획하고,
> 직접 또는 농장 일꾼에게 맡겨 감자 300kg를 수확·집하·포장한 뒤
> 저녁 결과를 보고 하루를 마감한다.

이 문서의 기준은 시스템 수가 아니라 플레이어가 한 번의 하루를 이해하고
끝낼 수 있는가이다. 목표 플레이 시간은 20~40분이며, 첫 결정적 시험 자료는
100m² 재배 구역과 3kg/m² 생산 규칙으로 300kg를 만든다. 이 수치는 게임용
Fixture이며 실제 생산량이나 운영 자료가 아니다.

## 플레이 흐름

| 장면 | 플레이어가 하는 일 | 느껴야 하는 변화 |
| --- | --- | --- |
| 아침 | 오늘 목표와 농장 상태를 확인한다 | “오늘 무엇을 할까?” |
| 걷기 | 1인칭으로 농가에서 밭까지 이동한다 | “여기가 내 농장이구나.” |
| 발견 | 밭, 작업마당, 출하 준비 지점을 확인한다 | “농장 안의 일이 연결되어 있네.” |
| 계획 | 전술 3인칭에서 수확 밭과 직접/NPC 작업을 고른다 | “부족한 하루를 어디에 쓸까?” |
| 수확 | 서버 미리보기와 오늘 작업 확정 뒤 현장에서 작업한다 | “내 결정 때문에 밭이 변했다.” |
| 집하 | 현장 감자 Lot 300kg를 작업마당으로 옮긴다 | “수확물이 실제 물건이 되었다.” |
| 포장 | 집하된 Lot을 출하 준비 포장 Lot으로 바꾼다 | “농장 밖으로 보낼 준비가 됐다.” |
| 저녁 | 결과와 카드를 확인하고 턴 마감을 확정한다 | “오늘의 선택이 내일을 만든다.” |

## 현재 조작 기준

- `F2`: 1인칭, `F3`: 농장 경영 전술 화면
- 전술 화면에서 `4`: 수확, 좌클릭: 밭 선택, 우클릭: 작업 초안
- `N`: 직접 작업과 NPC 위임 전환
- `P`: 현재 단계의 서버 미리보기
- `Enter`: 미리 본 작업 계획 확정
- 1인칭에서 `E`: 확정된 작업을 한 Tick 진행

수확이 끝나면 같은 흐름이 집하와 포장으로 이어진다. 각 단계는 서버가 현재
Lot 상태를 다시 준 뒤에만 다음 단계로 넘어간다. 포장 Lot이
`PreparedForShipment`가 되면 저녁 결과와 별도 턴 마감 화면으로 인계한다.

## Confirm 원칙

밭·담당자·우선순위는 하나의 ‘오늘 작업 계획’으로 편집하고 마지막에 한 번
확정한다. 서버는 모든 항목을 먼저 검증하며 한 항목이라도 막히면 자원 예약,
작업 생성, 개정을 전혀 바꾸지 않는다. 턴 마감, 계절 방어, 비축 소모처럼
되돌리기 어려운 결정은 기존 개별 Confirm을 유지한다.

## 기준작 완료 조건

- 직접 작업과 NPC 위임 중 하나를 선택할 수 있다.
- Preview가 300kg, 비용, 소요 Tick, 차단 이유를 서버 기준으로 보여준다.
- Confirm 한 번이 계획 전체를 한 개정으로 확정하며 Save/Replay된다.
- 직접 수확은 선택한 밭 가까이에서만 진행된다.
- 수확 뒤 밭 색과 감자 Lot 표현이 서버 상태에 따라 바뀐다.
- 수확 → 집하 → 포장을 거쳐 300kg 포장 Lot이 출하 준비 상태가 된다.
- 턴 마감은 진행 중 작업이 없는 서버 상태에서 별도로 Preview/Confirm한다.

Farm→Hub 실제 운송은 이 기준작의 다음 장면이며 이 문서의 완료 범위에 넣지
않는다.
