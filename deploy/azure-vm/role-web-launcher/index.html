SSALDDEL · ROLE WEBAPPS 01—05

커뮤니티, 주문자, 화주, 기사, 창고 화면을 독립된 WebApp으로 나눴습니다. 다른 역할의 화면과 코드는 앱을 전환할 때 내려받습니다.

01 커뮤니티

지역 이야기와 공공정보에서 공동행동을 시작합니다.

커뮤니티 열기 → 02 주문자

가격을 비교하고 같이 주문·수입할 의향을 검토합니다.

주문자 열기 → 03 화주

운송 의뢰와 입고·수입 물류 준비를 관리합니다.

화주 열기 → 04 기사

추천 운송과 현재 운송, 증빙·정산을 관리합니다.

기사 열기 → 05 창고

입고·재고·피킹·포장·출고 인계를 관리합니다.

창고 열기 →
공통 원장은 그대로 연결됩니다.
