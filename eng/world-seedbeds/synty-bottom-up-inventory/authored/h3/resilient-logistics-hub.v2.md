## 존재 이유

입출고 외에 격리·장기·저온·반품 흐름을 독립적으로 운영할 수 있는 Hub 청사진이다.

## 설계 상태

- 재고 상태: `IdeaInventory`
- 공간 계층: `H3`
- 실제 지역 권위: 없음

## 미해결

- 실제 AreaSet과 공공데이터 근거를 적용하기 전까지 조립 후보로 유지한다.

이 문서는 상향식 공간 설계 지식이며 실제 좌표·AreaSet·LandscapeGraph·Unity 자산 권위를 만들지 않는다.
